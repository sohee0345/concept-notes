# Optimizer

## 1. 개념

옵티마이저는 역전파로 계산한 기울기를 이용해 손실이 작아지는 방향으로 가중치와 편향을 갱신하는 알고리즘이다. 학습률은 한 번의 갱신에서 이동하는 크기를 조절한다.

> **핵심:** 역전파가 기울기를 구하면 옵티마이저가 그 기울기를 파라미터 갱신 규칙에 적용한다.

---

## 2. 주요 알고리즘

| 알고리즘 | 핵심 아이디어 |
| --- | --- |
| SGD | 현재 미니배치의 기울기를 따라 이동 |
| Momentum | 이전 이동 방향을 누적해 진동을 줄임 |
| Adagrad | 파라미터별 누적 기울기로 학습률 조절 |
| RMSprop | 최근 제곱 기울기를 더 크게 반영 |
| Adam | Momentum과 RMSprop 계열 아이디어 결합 |

---

## 3. PyTorch 사용 방법

```python
import torch

optimizer = torch.optim.Adam(
    model.parameters(),
    lr=1e-3,
)

optimizer.zero_grad()
loss.backward()
optimizer.step()
```

- `model.parameters()` → 갱신할 모델 파라미터
- `lr` → 학습률
- `zero_grad()` → 누적 기울기 초기화
- `step()` → 설정한 규칙으로 파라미터 갱신

---

## 4. 주의할 점

- 학습률이 너무 크면 최솟값 주변을 지나치거나 발산할 수 있다.
- 학습률이 너무 작으면 수렴이 매우 느리거나 좋지 않은 지점에 머물 수 있다.
- Adam이 널리 쓰이지만 항상 가장 좋은 일반화 성능을 보장하지는 않는다.
- 옵티마이저를 비교할 때 학습률과 스케줄러 조건도 함께 맞춘다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `학습률` | 한 번의 파라미터 갱신 크기 |
| `Momentum` | 이전 이동 방향을 누적하는 방법 |
| `Adam` | 1차·2차 모멘트를 함께 사용하는 적응적 방법 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `torch.optim.SGD()` | SGD 옵티마이저 생성 |
| `torch.optim.Adam()` | Adam 옵티마이저 생성 |
| `optimizer.step()` | 파라미터 갱신 |
