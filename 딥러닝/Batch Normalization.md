# Batch Normalization

## 1. 개념

Batch Normalization은 미니배치의 평균과 분산으로 층의 활성값을 정규화한 뒤 학습 가능한 스케일과 이동 파라미터를 적용하는 방법이다. 학습을 안정시키고 더 큰 학습률을 사용할 수 있게 도우며 기울기 소실을 완화하는 데도 도움을 줄 수 있다.

> **핵심:** 학습과 추론에서 사용하는 통계가 다르므로 모델 모드를 올바르게 전환해야 한다.

---

## 2. 쉽게 이해하기

각 층으로 들어오는 값의 범위가 학습 중 크게 흔들리지 않도록 정돈한 뒤, 모델이 필요한 크기와 위치를 다시 학습하게 하는 과정이다.

```text
활성값 → 미니배치 통계로 정규화 → 스케일·이동 → 다음 층
```

---

## 3. 사용 방법

```python
model = nn.Sequential(
    nn.Linear(784, 128),
    nn.BatchNorm1d(128),
    nn.ReLU(),
)
```

- 학습 모드 → 현재 미니배치의 평균과 분산을 사용하고 이동 통계를 갱신한다.
- 평가 모드 → 학습 중 누적한 이동 평균과 분산을 사용한다.
- `model.train()`·`model.eval()` → 학습과 평가 모드를 전환한다.

---

## 4. 예제

```python
model.train()
for x, y in train_loader:
    prediction = model(x)

model.eval()
with torch.no_grad():
    prediction = model(test_x)
```

평가 시 `model.eval()`을 호출해야 Batch Normalization이 새 배치의 통계가 아니라 학습 중 누적한 통계를 사용한다.

---

## 5. 헷갈리는 개념 비교

|구분|학습 모드|평가 모드|
|---|---|---|
|사용 통계|현재 미니배치 통계|학습 중 누적한 통계|
|통계 갱신|수행|수행하지 않음|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|미니배치 통계|현재 배치의 평균과 분산|
|이동 통계|추론에 사용할 누적 평균과 분산|
|학습 가능 파라미터|정규화 후 크기와 위치를 조절하는 값|

### 💻 주요 코드

|코드|의미|
|---|---|
|`nn.BatchNorm1d(128)`|128개 특성 정규화|
|`model.train()`|학습 모드 설정|
|`model.eval()`|평가 모드 설정|

### ⭐ 한 줄 정리

> **Batch Normalization은 활성값을 안정시키며 학습과 추론에서 서로 다른 통계를 사용한다.**
