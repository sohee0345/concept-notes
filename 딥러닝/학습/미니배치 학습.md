# 미니배치 학습

## 1. 개념

미니배치 학습은 전체 학습 데이터를 작은 샘플 묶음으로 나누고 각 묶음마다 순전파, 역전파, 파라미터 갱신을 수행하는 방식이다. 배치는 한 번에 처리하는 샘플 묶음, Iteration은 한 번의 갱신, Epoch는 전체 학습 데이터를 한 번 사용한 주기이다.

> **핵심:** 한 Epoch의 Iteration 수는 전체 샘플 수를 배치 크기로 나눈 값을 올림하여 구한다.

---

## 2. 쉽게 이해하기

책 전체를 한꺼번에 공부하지 않고 여러 묶음으로 나누어 공부와 피드백을 반복한 뒤, 책을 끝까지 보면 1 Epoch가 끝난 것과 같다.

```text
전체 데이터 → 여러 미니배치 → 배치마다 1회 갱신 → 모두 처리하면 1 Epoch
```

---

## 3. 사용 방법

$$\text{Iterations per Epoch}=\left\lceil\frac{\text{Number of Samples}}{\text{Batch Size}}\right\rceil$$

- Batch Gradient Descent → 전체 학습 데이터로 한 번 갱신한다.
- Stochastic Gradient Descent → 샘플 하나마다 갱신한다.
- Mini-Batch Gradient Descent → 일부 샘플 묶음마다 갱신한다.

---

## 4. 예제

```python
train_loader = DataLoader(
    train_dataset,
    batch_size=100,
    shuffle=True,
)
```

샘플 60,000개를 배치 크기 100으로 학습하면 한 Epoch에 600 Iteration이 필요하다. 마지막 배치가 배치 크기보다 작을 수 있으므로 나누어떨어지지 않을 때는 올림한다.

---

## 5. 헷갈리는 개념 비교

|구분|Batch|Iteration|Epoch|
|---|---|---|---|
|의미|한 번에 처리하는 샘플 묶음|배치 1개를 처리한 갱신 단계|전체 데이터를 한 번 사용한 주기|
