# 전이학습과 미세조정

## 1. 개념

전이학습(transfer learning)은 큰 데이터셋으로 미리 학습된 모델의 표현을 새로운 문제에 활용하는 방법이다. 미세조정(fine-tuning)은 사전학습된 가중치에서 시작해 일부 또는 전체 층을 새 데이터로 추가 학습하는 전이학습 방식이다.

> **핵심:** 전이학습은 사전학습 지식을 옮기는 전체 과정이고, 미세조정은 사전학습된 층의 가중치도 새 문제에 맞게 업데이트하는 방법이다.

---

## 2. 쉽게 이해하기

처음부터 모든 내용을 배우는 대신 이미 익힌 기초 지식을 새 과목에 활용하는 것과 비슷하다. 새 데이터가 적고 기존 문제와 비슷하면 배운 특징은 그대로 두고 새 정답 체계만 익힐 수 있다. 데이터가 충분하거나 두 문제가 다르면 기존 지식도 조금씩 조정한다.

```text
사전학습 모델
  ↓ 특징 추출부 동결
새 분류층만 학습

사전학습 모델
  ↓ 일부 또는 전체 층의 동결 해제
새 데이터로 미세조정
```

---

## 3. 사용 방법

```python
from torch import nn
from torchvision.models import resnet18, ResNet18_Weights

weights = ResNet18_Weights.DEFAULT
model = resnet18(weights=weights)

for param in model.parameters():
    param.requires_grad = False

model.fc = nn.Linear(model.fc.in_features, 3)
```

- `weights=ResNet18_Weights.DEFAULT` → 사전학습 가중치를 불러온다.
- `requires_grad=False` → 해당 파라미터의 기울기 계산과 업데이트를 막는다.
- `model.fc = ...` → 새 문제의 클래스 수에 맞는 학습 가능한 분류층으로 교체한다.

미세조정이 필요하면 학습할 층의 `requires_grad`를 다시 `True`로 설정하고, 보통 새 분류층보다 작은 학습률을 사용해 기존 표현이 급격히 변하지 않도록 한다.

---

## 4. 예제

```python
import torch
from torch import nn
from torchvision.models import resnet18, ResNet18_Weights

model = resnet18(weights=ResNet18_Weights.DEFAULT)

for param in model.parameters():
    param.requires_grad = False

model.fc = nn.Linear(model.fc.in_features, 3)

images = torch.randn(2, 3, 224, 224)
logits = model(images)
print(logits.shape)
```

출력 형태:

```text
torch.Size([2, 3])
```

사전학습된 특징 추출부는 동결되고 새 `fc`만 학습 대상이 된다. 실습에서 같은 구조의 ResNet18이 세 클래스 logits를 출력하는 것을 확인했으며, 위 코드에서는 두 장의 이미지마다 세 클래스 값이 만들어진다.

## 5. 헷갈리는 개념 비교

| 구분 | 특징 추출 방식 | 미세조정 |
| --- | --- | --- |
| 사전학습 층 | 동결 | 일부 또는 전체를 학습 |
| 주 학습 대상 | 새 분류층 | 새 분류층과 동결을 푼 층 |
| 장점 | 빠르고 적은 데이터에 유리 | 새 문제에 더 세밀하게 적응 가능 |
| 주의점 | 두 문제가 다르면 표현이 부족할 수 있음 | 데이터가 적으면 과적합하거나 기존 표현이 훼손될 수 있음 |

두 방식은 완전히 분리된 절차가 아니다. 새 분류층만 먼저 학습한 뒤 뒤쪽 층부터 동결을 풀어 미세조정하는 식으로 단계적으로 사용할 수 있다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 사전학습 | 큰 데이터셋으로 가중치를 미리 학습하는 과정 |
| 전이학습 | 사전학습된 표현을 새로운 문제에 활용하는 방법 |
| 특징 추출 | 사전학습 층을 동결하고 새 분류층만 학습하는 방식 |
| 미세조정 | 사전학습 층의 일부 또는 전체를 추가 학습하는 방식 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `weights=...DEFAULT` | 기본 사전학습 가중치 사용 |
| `param.requires_grad = False` | 파라미터 동결 |
| `nn.Linear(..., num_classes)` | 새 클래스 수에 맞는 분류층 생성 |

### ⭐ 한 줄 정리

> **전이학습은 사전학습 모델의 지식을 새 문제에 재사용하고, 미세조정은 그 가중치까지 새 데이터에 맞게 다시 학습한다.**
