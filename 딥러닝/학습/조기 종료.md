# 조기 종료

## 1. 개념

조기 종료(Early Stopping)는 검증 손실이 일정 횟수 동안 개선되지 않으면 학습을 중단하는 방법이다. 학습 시간이 불필요하게 길어지는 것을 막고, 훈련 데이터에 지나치게 맞춰지기 전에 성능이 가장 좋았던 모델을 보존한다.

> **핵심:** 검증 손실의 최저점을 추적하고 그 시점의 모델을 최종 모델로 사용한다.

---

## 2. 쉽게 이해하기

연습을 계속하더라도 모의시험 점수가 더 좋아지지 않는다면, 가장 높은 점수를 받았던 시점의 답안 상태를 보관하고 연습을 멈추는 것과 같다.

```text
검증 손실 개선 → 최적 모델 저장·대기 횟수 초기화
검증 손실 미개선 → 대기 횟수 증가
대기 횟수 도달 → 학습 종료
```

---

## 3. 사용 방법

```python
best_loss = float("inf")
counter = 0
patience = 5

if validation_loss < best_loss:
    best_loss = validation_loss
    counter = 0
    torch.save(model.state_dict(), "best_model.pt")
else:
    counter += 1
```

- `best_loss` → 지금까지 가장 낮은 검증 손실이다.
- `patience` → 개선 없이 기다릴 최대 횟수다.
- `counter` → 연속으로 개선되지 않은 횟수다.

---

## 4. 예제

```python
import torch

class EarlyStopper:
    def __init__(self, patience=5, save_path="best_model.pt"):
        self.best_loss = float("inf")
        self.patience = max(1, patience)
        self.counter = 0
        self.save_path = save_path

    def should_stop(self, model, validation_loss):
        if validation_loss < self.best_loss:
            self.best_loss = validation_loss
            self.counter = 0
            torch.save(model.state_dict(), self.save_path)
            return False

        self.counter += 1
        return self.counter >= self.patience

early_stopper = EarlyStopper(patience=5)
```

매 에포크의 검증이 끝난 뒤 `should_stop(model, validation_loss)`를 호출한다. 학습이 끝나면 마지막 모델이 아니라 `best_model.pt`에 저장된 최저 검증 손실 시점의 파라미터를 불러와 평가한다.

---

## 5. 헷갈리는 개념 비교

| 구분 | 검증 세트 | 테스트 세트 |
| --- | --- | --- |
| 용도 | 조기 종료와 모델 선택 | 최종 일반화 성능 평가 |
| 학습 중 확인 | 가능 | 사용하지 않음 |
| 반복 사용 영향 | 모델 선택에 반영됨 | 반복 사용하면 평가 편향 발생 |

조기 종료에 테스트 손실을 사용하면 테스트 데이터가 모델 선택에 관여하므로 최종 평가의 독립성이 사라진다.

## 🟦 핵심 정리

### 💡 주요 개념

조기 종료는 검증 성능을 감시해 과도한 학습을 줄이고 가장 좋은 시점의 모델을 선택한다.

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `best_loss = float("inf")` | 최초 최저 손실 초기화 |
| `counter += 1` | 미개선 횟수 증가 |
| `counter >= patience` | 학습 중단 조건 |
| `torch.save(model.state_dict(), path)` | 최적 파라미터 저장 |

### ⭐ 한 줄 정리

> **조기 종료는 검증 손실이 개선되지 않는 상태를 감지해 학습을 멈추고 최적 시점의 모델을 보존한다.**
