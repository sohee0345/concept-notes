# 자동미분과 계산 그래프

## 1. 개념

PyTorch의 자동미분(Autograd)은 텐서 연산을 계산 그래프로 기록하고, 손실에서 시작해 연쇄법칙으로 각 파라미터의 기울기를 자동 계산하는 기능이다. 계산된 기울기는 `requires_grad=True`인 리프 텐서의 `.grad`에 저장된다.

> **핵심:** 자동미분은 기울기를 계산하고, 옵티마이저는 계산된 기울기로 파라미터를 갱신한다.

---

## 2. 쉽게 이해하기

순전파에서 결과가 만들어진 경로를 기록해 두었다가, 손실이 계산되면 그 경로를 거꾸로 따라가며 각 값이 손실에 얼마나 영향을 주었는지 구한다.

```text
x, w, b → z = xw + b → loss
                         ↓ backward
x, w, b ← 각 기울기 계산
```

---

## 3. 사용 방법

```python
w = torch.randn(5, 3, requires_grad=True)
b = torch.randn(3, requires_grad=True)

z = torch.matmul(x, w) + b
loss = loss_fn(z, y)
loss.backward()
```

- `requires_grad=True` → 해당 텐서와 관련된 연산을 기울기 계산 대상으로 추적한다.
- `grad_fn` → 결과 텐서를 만든 연산 정보를 가리킨다.
- `loss.backward()` → 계산 그래프를 역방향으로 따라가며 기울기를 계산한다.

---

## 4. 예제

```python
import torch

x = torch.ones(5)
y = torch.zeros(3)
w = torch.randn(5, 3, requires_grad=True)
b = torch.randn(3, requires_grad=True)

z = torch.matmul(x, w) + b
loss = torch.nn.functional.binary_cross_entropy_with_logits(z, y)
loss.backward()

print(w.grad.shape)
print(b.grad.shape)
```

각 파라미터의 기울기는 해당 파라미터와 같은 shape을 가진다. 반복 학습에서는 기울기가 기본적으로 누적되므로 다음 역전파 전에 `optimizer.zero_grad()`로 초기화한다.

---

## 5. 헷갈리는 개념 비교

| 구분 | `torch.no_grad()` | `detach()` |
| --- | --- | --- |
| 대상 | 블록 안의 모든 연산 | 특정 텐서 |
| 효과 | 새 계산 그래프를 기록하지 않음 | 기존 그래프에서 분리된 텐서 반환 |
| 주요 사용 | 검증·추론 | 로깅·후속 비미분 연산 |

`loss.backward()`는 기울기를 계산하지만 파라미터를 변경하지 않는다. 실제 갱신은 `optimizer.step()`이 수행한다.

## 🟦 핵심 정리

### 💡 주요 개념

계산 그래프는 순전파 연산의 연결 관계를 기록하며, 자동미분은 이 그래프를 역방향으로 따라가 기울기를 계산한다.

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `requires_grad=True` | 기울기 추적 활성화 |
| `loss.backward()` | 역전파로 기울기 계산 |
| `tensor.grad` | 계산된 기울기 확인 |
| `torch.no_grad()` | 연산 구간의 추적 중단 |
| `tensor.detach()` | 특정 텐서를 계산 그래프에서 분리 |

### ⭐ 한 줄 정리

> **자동미분은 순전파에서 만든 계산 그래프를 이용해 손실에 대한 각 파라미터의 기울기를 자동으로 구한다.**
