# 인공신경망과 퍼셉트론

## 1. 개념

인공 뉴런은 여러 입력의 가중합에 편향을 더하고 활성화 함수를 적용해 하나의 출력을 만든다. 이런 뉴런을 층으로 연결한 모델이 인공신경망이며, 여러 은닉층을 사용하는 신경망을 딥러닝 모델이라고 한다.

$$z=b+\sum_i w_i x_i,\qquad y=h(z)$$

> **핵심:** 가중치와 편향은 학습되는 값이고 활성화 함수는 신경망이 비선형 관계를 표현하게 한다.

---

## 2. 구조

```text
입력층
  → 은닉층: 가중합 + 활성화 함수
  → 은닉층: 더 높은 수준의 표현 학습
  → 출력층: 문제에 맞는 예측 생성
```

피드포워드 신경망에서는 정보가 입력에서 출력 방향으로 흐르며 순환 연결이 없다.

---

## 3. 문제별 출력층

| 문제 | 출력 활성화 | 대표 손실함수 |
| --- | --- | --- |
| 회귀 | 선형 출력 | MSE, MAE |
| 이진분류 | Sigmoid | Binary Cross Entropy |
| 다중분류 | Softmax | Cross Entropy |
| 다중 레이블 분류 | 클래스별 Sigmoid | Binary Cross Entropy |

---

## 4. 주의할 점

- 층과 뉴런 수가 늘면 표현력과 함께 과적합 위험도 커진다.
- 딥러닝도 과적합될 수 있으므로 검증 데이터, 규제와 데이터 양을 함께 관리한다.
- 출력 활성화 함수와 손실함수는 문제 유형에 맞게 조합한다.
- 깊은 모델이 항상 얕은 모델보다 좋은 것은 아니다.
