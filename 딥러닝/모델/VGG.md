# VGG

## 1. 개념

VGG는 작은 `3×3` 합성곱을 여러 번 반복해 이미지 특징을 추출하고, 각 블록 끝에서 최대 풀링으로 공간 크기를 줄이는 CNN 구조다. 깊어질수록 채널 수를 늘려 단순한 선과 모서리부터 복잡한 형태까지 단계적으로 표현한다.

> **핵심:** VGG는 크기가 작은 합성곱을 일정한 규칙으로 반복하여 깊은 특징 추출기를 구성한다.

---

## 2. 쉽게 이해하기

VGG의 한 블록은 이미지를 여러 번 자세히 살펴본 뒤 크기를 절반으로 줄이는 과정으로 이해할 수 있다. 공간 크기가 줄어드는 대신 특징 맵 수가 늘어나므로, 위치 정보는 압축하면서 더 다양한 특징을 저장한다.

```text
(3, 224, 224)
  ↓ 합성곱 블록 1 + 풀링
(64, 112, 112)
  ↓ 합성곱 블록 2 + 풀링
(128, 56, 56)
  ↓ 합성곱 블록 3~5 + 풀링
(512, 7, 7)
  ↓ Flatten + 완전연결층
클래스별 logits
```

---

## 3. 사용 방법

```python
from torch import nn

block = nn.Sequential(
    nn.Conv2d(3, 64, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.Conv2d(64, 64, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2, stride=2),
)
```

- `kernel_size=3, padding=1` → 합성곱 전후의 높이와 너비를 유지한다.
- `MaxPool2d(2)` → 높이와 너비를 절반으로 줄인다.
- `out_channels` → 블록이 깊어질수록 늘려 더 다양한 특징을 표현한다.

---

## 4. 예제

```python
import torch
from torch import nn

block = nn.Sequential(
    nn.Conv2d(3, 64, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.Conv2d(64, 64, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2, stride=2),
)

images = torch.randn(8, 3, 224, 224)
features = block(images)
print(features.shape)
```

실행 결과:

```text
torch.Size([8, 64, 112, 112])
```

합성곱은 공간 크기를 유지하고 최대 풀링이 `224×224`를 `112×112`로 줄인다. 출력 채널은 첫 블록의 설정에 따라 64가 된다.

---

## 5. 헷갈리는 개념 비교

| 구분 | 합성곱층 | 풀링층 |
| --- | --- | --- |
| 역할 | 학습 가능한 커널로 특징 추출 | 특징 맵의 공간 크기 축소 |
| VGG 설정 | 주로 `3×3`, padding 1 | 주로 `2×2`, stride 2 |
| 크기 변화 | 높이·너비 유지 | 높이·너비 절반 |

VGG16의 16은 가중치를 학습하는 합성곱층과 완전연결층의 수를 나타낸다. ReLU와 풀링층은 이 수에 포함하지 않는다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| VGG 블록 | 여러 `3×3` 합성곱과 하나의 최대 풀링을 묶은 구조 |
| 채널 증가 | 깊은 층에서 더 다양한 특징을 표현하기 위한 구성 |
| 공간 축소 | 풀링으로 높이와 너비를 단계적으로 줄이는 과정 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `nn.Conv2d(..., 3, padding=1)` | 공간 크기를 유지하는 합성곱 |
| `nn.MaxPool2d(2, 2)` | 높이와 너비를 절반으로 축소 |
| `nn.Flatten()` | 마지막 특징 맵을 분류용 벡터로 변환 |
