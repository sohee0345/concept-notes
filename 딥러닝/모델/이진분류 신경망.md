# 이진분류 신경망

## 1. 개념

이진분류 신경망은 두 클래스 중 하나를 예측하는 모델이다. 마지막 계층은 샘플마다 logit 하나를 출력하고, Sigmoid로 이를 클래스 1일 확률로 바꾼 뒤 임계값을 적용해 최종 클래스를 결정한다.

> **핵심:** 학습에는 원시 logit을 사용하고, 예측 클래스를 구할 때만 Sigmoid와 임계값을 적용한다.

---

## 2. 쉽게 이해하기

모델은 먼저 어느 한쪽을 얼마나 강하게 지지하는지 제한 없는 점수로 표현한다. 그 점수를 0과 1 사이의 확률로 바꾸고 기준선을 넘었는지 확인한다.

```text
logit → Sigmoid → 클래스 1의 확률 → 0.5와 비교 → 0 또는 1
```

---

## 3. 사용 방법

```python
loss_fn = nn.BCEWithLogitsLoss()

logits = model(features).squeeze(dim=1)
loss = loss_fn(logits, targets)

probabilities = torch.sigmoid(logits)
predictions = (probabilities >= 0.5).float()
```

- `BCEWithLogitsLoss` → Sigmoid와 이진 교차 엔트로피를 결합한 손실 함수다.
- `torch.sigmoid()` → logit을 0과 1 사이의 확률로 바꾼다.
- `squeeze(dim=1)` → `(batch, 1)` 출력을 `(batch,)` target 형태에 맞춘다.

---

## 4. 예제

```python
class BinaryClassifier(nn.Module):
    def __init__(self):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Linear(2, 30),
            nn.ReLU(),
            nn.Linear(30, 60),
            nn.ReLU(),
            nn.Linear(60, 1),
        )

    def forward(self, features):
        return self.layers(features)
```

원형처럼 비선형적인 분포에서는 선형 계층 사이에 ReLU를 넣어야 곡선 형태의 결정 경계를 학습할 수 있다. 마지막 계층에는 Sigmoid를 넣지 않고 logits를 그대로 반환한다.

---

## 5. 헷갈리는 개념 비교

| 구분 | logit | 확률 | 예측 클래스 |
| --- | --- | --- | --- |
| 범위 | 제한 없음 | 0~1 | 0 또는 1 |
| 변환 | 모델의 원시 출력 | `sigmoid(logit)` | 확률과 임계값 비교 |
| 학습 사용 | `BCEWithLogitsLoss`에 입력 | 직접 넣지 않음 | 정확도 계산에 사용 |

선형 계층만 연속해서 쌓으면 전체 모델은 여전히 선형 변환이다. 계층 수보다 활성화 함수의 유무가 비선형 결정 경계를 표현하는 데 중요하다.

---

## 🟦 핵심 정리

### 💡 주요 개념

이진분류에서는 출력 형태, target 형태, 손실 함수가 서로 맞아야 하며 비선형 데이터에는 활성화 함수가 필요하다.

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `nn.Linear(..., 1)` | 샘플마다 logit 하나 출력 |
| `nn.BCEWithLogitsLoss()` | 이진분류 손실 계산 |
| `torch.sigmoid(logits)` | logit을 확률로 변환 |
| `squeeze(dim=1)` | 출력의 마지막 1차원 제거 |

### ⭐ 한 줄 정리

> **이진분류 신경망은 logit을 학습에 사용하고 Sigmoid와 임계값으로 최종 클래스를 결정한다.**
