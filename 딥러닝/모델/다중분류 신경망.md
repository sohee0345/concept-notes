# 다중분류 신경망

## 1. 개념

다중분류 신경망은 서로 배타적인 여러 클래스 중 하나를 예측하는 모델이다. 마지막 계층은 클래스마다 하나의 logit을 출력하고, 가장 큰 logit의 인덱스를 최종 클래스로 선택한다.

> **핵심:** 출력 계층의 크기는 클래스 수와 같고, 학습에는 원시 logits를 `CrossEntropyLoss`에 전달한다.

---

## 2. 쉽게 이해하기

모델이 각 클래스에 점수를 하나씩 부여한 뒤 가장 높은 점수를 받은 클래스를 답으로 고르는 과정이다.

```text
클래스별 logits
  ↓ Softmax가 필요하면 확률로 변환
클래스별 확률
  ↓ argmax
최종 예측 클래스
```

---

## 3. 사용 방법

```python
loss_fn = nn.CrossEntropyLoss()

logits = model(features)       # (batch, class_count)
loss = loss_fn(logits, targets)  # targets: (batch,)

predictions = torch.argmax(logits, dim=1)
```

- `logits` → Softmax 적용 전 클래스별 원시 점수다.
- `targets` → 각 샘플의 정수 클래스 인덱스다.
- `argmax(dim=1)` → 샘플별 가장 큰 클래스 점수의 위치를 반환한다.

---

## 4. 예제

```python
from torch import nn

class FashionClassifier(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()
        self.layers = nn.Sequential(
            nn.Linear(28 * 28, 512),
            nn.ReLU(),
            nn.Linear(512, 1024),
            nn.ReLU(),
            nn.Linear(1024, 512),
            nn.ReLU(),
            nn.Linear(512, 10),
        )

    def forward(self, features):
        return self.layers(self.flatten(features))
```

FashionMNIST는 클래스가 10개이므로 마지막 선형 계층이 logit 10개를 출력한다. `CrossEntropyLoss`를 사용할 때 출력층에 Softmax를 추가하지 않는다.

---

## 5. 헷갈리는 개념 비교

| 구분 | 이진분류 | 다중분류 |
| --- | --- | --- |
| 출력 크기 | 보통 1 | 클래스 수 |
| 손실 함수 | `BCEWithLogitsLoss` | `CrossEntropyLoss` |
| 확률 변환 | Sigmoid | Softmax |
| 클래스 결정 | 임계값과 비교 | `argmax(dim=1)` |

다중분류에서 최종 클래스만 필요하면 Softmax를 생략하고 logits에 직접 `argmax`를 적용할 수 있다. Softmax는 값의 크기 순서를 바꾸지 않기 때문이다.

## 🟦 핵심 정리

### 💡 주요 개념

다중분류에서는 모델 출력의 클래스 축과 target의 정수 클래스 인덱스가 올바르게 대응해야 한다.

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `nn.Linear(hidden, class_count)` | 클래스 수만큼 logits 출력 |
| `nn.CrossEntropyLoss()` | 다중분류 손실 함수 |
| `torch.softmax(logits, dim=1)` | logits를 클래스 확률로 변환 |
| `torch.argmax(logits, dim=1)` | 예측 클래스 선택 |

### ⭐ 한 줄 정리

> **다중분류 신경망은 클래스별 logits를 출력하고 CrossEntropyLoss로 학습한 뒤 argmax로 예측 클래스를 선택한다.**
