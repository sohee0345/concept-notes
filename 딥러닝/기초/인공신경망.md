# 인공신경망

## 1. 개념

인공신경망은 입력에 가중치를 곱하고 편향을 더한 뒤 활성화 함수를 적용하는 인공 뉴런을 층으로 연결한 모델이다. 입력층, 하나 이상의 은닉층, 출력층으로 구성되며 데이터가 입력에서 출력 방향으로 흐르는 구조를 피드포워드 신경망이라고 한다.

> **핵심:** 여러 층의 가중치와 활성화 함수가 입력을 단계적으로 변환하여 복잡한 관계를 학습한다.

---

## 2. 쉽게 이해하기

각 뉴런은 여러 신호의 중요도를 다르게 반영해 하나의 결과를 만들고, 다음 층은 앞 층의 결과를 다시 조합한다.

```text
입력층 → 은닉층 → 은닉층 → 출력층
```

---

## 3. 사용 방법

$$z=b+\sum_{i=1}^{m}w_i x_i, \qquad y=h(z)$$

- $x_i$ → 입력 특성이다.
- $w_i$ → 각 입력의 영향력을 나타내는 가중치이다.
- $b$ → 출력 기준을 이동시키는 편향이다.
- $h$ → 비선형성을 추가하는 활성화 함수이다.

출력층과 손실함수는 문제에 맞게 선택한다. 회귀는 선형 출력, 이진분류는 Sigmoid, 상호 배타적 다중분류는 Softmax를 주로 사용한다.

---

## 4. 예제

```python
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(784, 128),
    nn.ReLU(),
    nn.Linear(128, 10),
)
```

28×28 이미지를 784개 값으로 펼쳐 은닉층에서 128개 표현으로 변환한 뒤 10개 클래스의 점수를 출력한다.

---

## 5. 헷갈리는 개념 비교

|구분|가중치|편향|활성화 함수|
|---|---|---|---|
|역할|입력별 영향 조절|출력 기준 이동|비선형 변환 추가|
|학습 여부|학습함|학습함|보통 함수 자체는 고정|
