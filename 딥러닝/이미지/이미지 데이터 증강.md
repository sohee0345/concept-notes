# 이미지 데이터 증강

## 1. 개념

이미지 데이터 증강은 원본 이미지를 무작위로 자르거나 회전하고 색상과 크기를 바꾸어 새로운 학습 샘플처럼 사용하는 방법이다. 모델이 특정 위치나 방향을 외우지 않고 객체의 공통 특징을 학습하도록 돕는다.

> **핵심:** 학습 데이터의 의미는 유지하면서 실제로 발생할 수 있는 변화를 다양하게 보여 준다.

---

## 2. 쉽게 이해하기

같은 사물을 여러 각도와 크기, 위치에서 촬영한 사진을 함께 보여 주면 모델은 배경이나 위치보다 사물 자체의 특징에 집중할 수 있다.

```text
원본 이미지
  ↓ 무작위 크롭·회전·색상 변화
서로 다른 학습 이미지
  ↓
위치와 방향 변화에 덜 민감한 모델
```

---

## 3. 사용 방법

```python
import torchvision.transforms as T

train_transform = T.Compose([
    T.RandAugment(),
    T.RandomCrop((200, 200)),
    T.ToTensor(),
])
```

- `RandAugment()` → 여러 증강 연산을 자동으로 조합한다.
- `RandomCrop()` → 무작위 위치의 영역을 자른다.
- `RandomRotation()` → 범위 안에서 무작위 각도로 회전한다.
- `ColorJitter()` → 밝기, 대비와 색상을 변화시킨다.

---

## 4. 예제

```python
from torchvision import datasets
import torchvision.transforms as T

train_data = datasets.ImageFolder(
    root=train_path,
    transform=T.Compose([
        T.RandAugment(),
        T.RandomCrop((200, 200)),
        T.ToTensor(),
    ]),
)

test_data = datasets.ImageFolder(
    root=test_path,
    transform=T.Compose([
        T.Resize((200, 200)),
        T.ToTensor(),
    ]),
)
```

학습 데이터에는 무작위 증강을 적용하고 테스트 데이터에는 크기만 일정하게 맞추는 고정 변환을 적용한다. 두 transform의 최종 출력 형태는 모두 `(3, 200, 200)`이어야 한다.

---

## 5. 헷갈리는 개념 비교

| 구분 | 학습 데이터 변환 | 검증·테스트 데이터 변환 |
| --- | --- | --- |
| 목적 | 다양한 변형 학습 | 일정한 조건에서 평가 |
| 무작위 변환 | 사용 가능 | 사용하지 않음 |
| 최종 크기·채널 | 모델 입력과 일치 | 학습 데이터와 일치 |

변환이 클래스의 의미를 바꾸거나 실제 환경에서 생기지 않는 모습을 만들면 오히려 학습을 방해할 수 있다.

## 🟦 핵심 정리

### 💡 주요 개념

데이터 증강은 원본 수를 직접 늘리지 않고도 이미지를 읽을 때마다 다양한 변형을 만들어 일반화에 도움을 준다.

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `T.Compose([...])` | 변환을 순서대로 결합 |
| `T.RandAugment()` | 자동 증강 조합 적용 |
| `T.RandomCrop(...)` | 무작위 영역 자르기 |
| `T.RandomRotation(...)` | 무작위 회전 |

### ⭐ 한 줄 정리

> **이미지 데이터 증강은 의미를 유지하는 무작위 변형으로 학습 이미지의 다양성을 높인다.**
