# 이미지 정규화

## 1. 개념

이미지 정규화는 각 색상 채널에서 평균을 빼고 표준편차로 나누어 픽셀값 분포를 조정하는 전처리다. 채널마다 밝기와 변화 폭이 다를 수 있으므로 RGB 통계를 각각 계산한다.

> **핵심:** 정규화 통계는 학습 데이터에서만 구하고 모든 데이터 분할에 동일하게 적용한다.

---

## 2. 쉽게 이해하기

R, G, B 채널이 서로 다른 기준과 범위의 값을 가지고 있다면, 각 채널의 중심을 0 부근으로 옮기고 변화 폭을 비슷하게 맞추는 과정이다.

```text
학습 이미지 모음
  ↓ 채널별 평균·표준편차 계산
R 평균·표준편차 / G 평균·표준편차 / B 평균·표준편차
  ↓
훈련·검증·테스트에 같은 Normalize 적용
```

---

## 3. 사용 방법

$$x'_c=\frac{x_c-\mu_c}{\sigma_c}$$

```python
normalize = T.Normalize(
    mean=channel_mean.tolist(),
    std=channel_std.tolist(),
)
```

- $x_c$ → 특정 채널의 픽셀값이다.
- $\mu_c$ → 학습 데이터에서 구한 해당 채널 평균이다.
- $\sigma_c$ → 학습 데이터에서 구한 해당 채널 표준편차다.

## 4. 예제

```python
import torch
from PIL import Image
import torchvision.transforms as T

to_tensor = T.Compose([
    T.Resize((200, 200)),
    T.ToTensor(),
])
images = torch.stack([
    to_tensor(Image.open(path).convert("RGB"))
    for path in train_path.glob("*/*.jpg")
])

channel_mean = images.mean(dim=(0, 2, 3))
channel_std = images.std(dim=(0, 2, 3))

transform = T.Compose([
    T.Resize((200, 200)),
    T.ToTensor(),
    T.Normalize(
        mean=channel_mean.tolist(),
        std=channel_std.tolist(),
    ),
])
```

결합된 텐서가 `(N, C, H, W)`일 때 이미지 수, 높이와 너비 축인 `(0, 2, 3)`을 집계하면 채널별 값 $C$개가 남는다.

## 5. 헷갈리는 개념 비교

| 구분 | 통계 계산 | 정규화 적용 |
| --- | --- | --- |
| 학습 데이터 | 사용 | 사용 |
| 검증·테스트 데이터 | 사용하지 않음 | 학습 통계로 적용 |
| 픽셀 스케일 | `ToTensor`와 동일해야 함 | 평균·표준편차와 동일한 스케일 |

검증·테스트 통계를 계산에 포함하면 데이터 누수가 생긴다. 또한 `0~255`에서 구한 통계를 `0~1` 텐서에 그대로 적용하면 스케일이 맞지 않는다.

## 🟦 핵심 정리

### 💡 주요 개념

이미지 정규화는 학습 이미지의 채널별 분포를 기준으로 모든 데이터의 픽셀 스케일을 일관되게 조정한다.

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `torch.stack(images)` | 이미지를 `(N, C, H, W)`로 결합 |
| `mean(dim=(0, 2, 3))` | 채널별 평균 계산 |
| `std(dim=(0, 2, 3))` | 채널별 표준편차 계산 |
| `T.Normalize(mean, std)` | 채널별 정규화 적용 |
