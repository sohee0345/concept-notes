# 리스트 · 튜플 · 딕셔너리 · 집합

## 1. 개념
여러 개의 데이터를 저장할 때 목적에 따라 리스트, 튜플, 딕셔너리, 집합을 사용한다.

> **핵심:** 순서·수정 가능 여부·key/value 사용 여부·중복 허용 여부에 따라 자료구조를 선택한다.

---

## 2. 쉽게 이해하기
```text
여러 값 저장
 ├─ list  : 순서 O / 수정 O
 ├─ tuple : 순서 O / 수정 X
 ├─ dict  : key:value
 └─ set   : 중복 X
```

---

## 3. 사용 방법
```python
numbers = [1, 2, 3]
numbers.append(4)

point = (10, 20)

person = {"name": "홍길동", "age": 20}

unique = {1, 1, 2, 3}
```

- `append()` → 값을 하나의 원소로 추가
- `extend()` → 여러 값을 각각 추가
- `dict[key]` → key에 해당하는 value 조회
- `dict.items()` → key와 value를 함께 조회
- `set` → 중복값 제거에 활용 가능

---

## 4. 예제
```python
numbers = [1, 2]
numbers.append([3, 4])
print(numbers)
```

실행 결과:
```text
[1, 2, [3, 4]]
```

---

## 5. 헷갈리는 개념 비교
|구분|`append()`|`extend()`|
|---|---|---|
|추가 방식|값을 통째로 1개 추가|여러 값을 각각 추가|
|예시|`[1,2,[3,4]]`|`[1,2,3,4]`|
