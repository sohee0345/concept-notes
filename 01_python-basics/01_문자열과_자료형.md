# 문자열과 자료형

## 1. 개념
파이썬의 값은 각각 자료형을 가지며, 문자열(`str`)은 문자 데이터를 저장하고 다루는 자료형이다.

> **핵심:** `type()`으로 자료형을 확인하고, 문자열은 인덱싱·슬라이싱·문자열 메소드로 원하는 부분을 다룬다.

---

## 2. 쉽게 이해하기
```text
"Hello World"
  ↓
문자열(str)
  ↓
인덱싱 / 슬라이싱 / 메소드로 가공
```

문자열은 글자들이 순서대로 들어있는 데이터라서 위치 번호를 이용해 특정 글자를 꺼낼 수 있다.

---

## 3. 사용 방법
```python
text = "Hello World"

type(text)
text[0]
text[0:5]
text.split(" ")
text.replace("World", "Python")
```

- `type()` → 자료형 확인
- `len()` → 데이터 길이 확인
- `[시작:끝:간격]` → 문자열 슬라이싱
- `split()` → 문자열 나누기
- `strip()` → 양쪽 공백 제거
- `replace()` → 문자열 치환
- `f"{변수}"` → 문자열 안에 값 삽입

---

## 4. 예제
```python
name = "홍길동"
age = 20

print(f"{name}님의 나이는 {age}살입니다.")
```

실행 결과:
```text
홍길동님의 나이는 20살입니다.
```

---

## 5. 헷갈리는 개념 비교
|구분|인덱싱|슬라이싱|
|---|---|---|
|의미|한 위치의 값 조회|범위의 값 조회|
|예시|`text[0]`|`text[0:5]`|
