# enum

## 1. 개념
`enum`은 서로 관련된 상수 값에 이름을 붙여 관리하는 기능이다.

> **핵심:** 숫자나 문자열을 그대로 쓰는 대신 의미 있는 이름으로 값의 종류를 제한하고 관리할 수 있다.

---

## 2. 쉽게 이해하기
```text
0, 1, 2
  ↓
가위, 바위, 보
  ↓
의미가 분명한 값으로 관리
```

---

## 3. 사용 방법
```python
import enum

class RSP(enum.Enum):
    가위 = 0
    바위 = 1
    보 = 2
```

- `enum.Enum` → 열거형 클래스의 부모
- `RSP.가위` → enum 멤버
- `RSP.가위.name` → 멤버 이름
- `RSP.가위.value` → 멤버 값
- `RSP.__members__` → 정의된 멤버 확인

---

## 4. 예제
```python
assert "가위" in RSP.__members__, "잘못 입력했습니다."
print(RSP["가위"].value)
```

실행 결과:
```text
0
```

---

## 5. 헷갈리는 개념 비교
|구분|일반 값|enum|
|---|---|---|
|표현|`0`, `1`, `2`|`RSP.가위`, `RSP.바위`, `RSP.보`|
|장점|간단함|의미가 명확하고 값 관리가 쉬움|

## 🟦 핵심 정리

### 💡 주요 개념
enum, member, name, value, `__members__`

### 💻 주요 코드
|코드|의미|
|---|---|
|`class X(enum.Enum)`|enum 정의|
|`X.멤버.value`|값 조회|
|`X.__members__`|멤버 목록 확인|

### ⭐ 한 줄 정리
> **enum은 정해진 선택지를 이름이 있는 상수로 관리할 때 유용하다.**
