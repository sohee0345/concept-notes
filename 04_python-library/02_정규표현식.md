# 정규표현식 (Regex)

## 1. 개념
정규표현식은 문자열에서 특정한 규칙을 가진 패턴을 찾거나 바꾸는 방법이다.

> **핵심:** 반복되는 문자열 규칙을 패턴으로 표현해 검색·검사·치환할 수 있다.

---

## 2. 쉽게 이해하기
```text
문자열
  ↓
패턴 지정
  ↓
찾기 / 검사 / 바꾸기
```

---

## 3. 사용 방법
```python
import re

re.findall(r"\d+", "010-1234-5678")
re.match(r"hello", "hello world")
re.sub(r"\s+", " ", "hello   world")
```

- `re.findall()` → 패턴에 맞는 값 모두 찾기
- `re.match()` → 문자열 시작 부분이 패턴과 맞는지 확인
- `re.sub()` → 패턴에 맞는 문자열 치환
- `\d` → 숫자
- `+` → 앞 패턴이 1번 이상 반복
- `\s` → 공백 문자

---

## 4. 예제
```python
import re

phone = "010-1234-5678"
print(re.findall(r"\d+", phone))
```

실행 결과:
```text
['010', '1234', '5678']
```

---

## 5. 헷갈리는 개념 비교
|구분|`findall()`|`match()`|
|---|---|---|
|역할|모든 일치값 찾기|문자열 시작 부분 검사|
|결과|리스트|match 객체 또는 None|
