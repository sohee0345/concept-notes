# 벡터 관계 · 코사인 유사도 · Norm

## 1. 개념

벡터는 직교, 1차 독립, 1차 종속 등의 관계를 가질 수 있다.

코사인 유사도는 두 벡터의 **길이가 아니라 방향의 유사성**을 측정하고, Norm은 벡터의 크기 또는 길이를 측정한다.

> **핵심:** 코사인 유사도는 방향의 유사성을, Norm은 벡터의 크기를 나타낸다.

---

## 2. 쉽게 이해하기

```text
코사인 유사도
1  → 같은 방향
0  → 직교
-1 → 반대 방향
```

1차 종속은 한 벡터가 다른 벡터의 배수인 경우다.

```text
A = [1, 2]
B = [2, 4]  → B = 2A
```

---

## 3. 사용 방법

L1 Norm:

```text
[1, 2, 3]
→ |1| + |2| + |3|
→ 6
```

L2 Norm:

```text
[3, 4]
→ √(3² + 4²)
→ 5
```

---

## 4. 예제

| 구분 | L1 | L2 |
|---|---|---|
| 계산 | 절댓값 → 합 | 제곱 → 합 → 제곱근 |
| 거리 | Manhattan | Euclidean |

독립변수끼리 너무 강하게 비슷한 정보를 가지면 다중공선성 문제가 생길 수 있다.

---

## 5. 헷갈리는 개념 비교

| 구분 | 의미 |
|---|---|
| 직교 | 두 벡터가 90° |
| 1차 독립 | 서로의 배수로 표현 불가 |
| 1차 종속 | 한 벡터가 다른 벡터의 배수 |
| Norm | 벡터 자체의 크기 |
| Distance | 두 벡터 사이 거리 |
