# Git 초기 설정과 Clone

## 1. 개념

Git을 설치한 뒤 사용자 이름과 이메일을 등록하고, GitHub의 원격 저장소를 로컬 컴퓨터로 복제하는 기본 준비 과정이다.

> **핵심:** 사용자 정보를 설정한 뒤 `Clone`을 실행하면 원격 저장소의 자료를 로컬에서 사용할 수 있다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

Git 사용자 정보는 변경 이력을 남길 때 사용할 이름표이고, Clone은 GitHub에 있는 저장소를 내 컴퓨터로 가져오는 작업이다.

``` text
Git 설치와 버전 확인
  ↓
사용자 이름·이메일 등록
  ↓
설정 목록 검증
  ↓
GitHub 저장소 Clone
```

> **쉽게 말하면:** Git에 내 이름표를 등록한 뒤 온라인 저장소의 작업 사본을 컴퓨터에 만드는 과정이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` powershell
git --version
git config --global user.name "GitHub 아이디"
git config --global user.email "GitHub 이메일"
git config --list
```

- `--global` → 모든 로컬 Git 저장소에 공통으로 적용할 설정
- `user.name` → Git 기록에 사용할 사용자 이름
- `user.email` → Git 기록에 사용할 이메일
- `git config --list` → 현재 등록된 설정 목록 확인

> **핵심:** 설정 명령을 실행한 뒤 `git config --list`로 값이 제대로 등록되었는지 확인한다.

------------------------------------------------------------------------

## 4. 예제

``` powershell
git config --global user.name "my-id"
git config --global user.email "me@example.com"
git config --list
```

VSCode에서 원격 저장소를 Clone하는 순서는 다음과 같다.

``` text
GitHub → Code → 저장소 링크 복사
  ↓
VSCode → Ctrl+Shift+P → Git: Clone
  ↓
링크 붙여넣기 → 저장할 폴더 선택 → Enter
```

### 코드 해석

- `git config --global user.name` → 전역 사용자 이름을 등록한다.
- `git config --global user.email` → 전역 사용자 이메일을 등록한다.
- `Git: Clone` → 선택한 GitHub 저장소를 로컬 폴더에 복제한다.

> **결과 해석:** 설정 목록에서 이름과 이메일을 확인할 수 있고, 선택한 로컬 폴더에는 원격 저장소의 자료가 생성된다.

## 5. 헷갈리는 개념 비교

| 구분 | 설치 | 설정 | Clone |
| --- | --- | --- | --- |
| 의미 | Git 프로그램을 컴퓨터에 추가 | 사용자 이름과 이메일을 등록 | 원격 저장소를 로컬로 복제 |
| 확인 방법 | `git --version` | `git config --list` | 선택한 폴더의 저장소 확인 |
| 실행 시점 | 가장 먼저 | 설치 후 | 저장소 링크를 확보한 뒤 |

------------------------------------------------------------------------

## 6. 주의할 점

- 사용자 이름과 이메일을 감싸는 따옴표는 명령에서 사용할 수 있는 일반 큰따옴표(`"`)로 입력한다.
- Clone할 때 저장 위치를 확인해 강의 자료가 의도한 `course` 폴더에 들어가도록 한다.
