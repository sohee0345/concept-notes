# Git 설정과 Clone

## 1. 개념

Git을 설치한 뒤에는 커밋 작성자를 구분할 사용자 이름과 이메일을 등록한다. GitHub 저장소를 내 컴퓨터로 가져올 때는 저장소 복제(`clone`)를 사용한다.

> **핵심:** 사용자 정보는 커밋에 기록되며, 저장소 복제는 원격 저장소의 파일과 Git 이력을 로컬로 가져온다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
Git 설치
  ↓ 사용자 이름·이메일 등록
커밋 작성자 설정
  ↓ GitHub 저장소 주소로 clone
로컬 Git 저장소 생성
```

> **쉽게 말하면:** Git에 작성자 이름표를 붙인 뒤 GitHub의 작업 공간을 내 컴퓨터로 가져오는 과정이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` powershell
git --version
git config --global user.name "GitHub 아이디"
git config --global user.email "이메일"
git config --list
```

- `git --version` → 설치된 Git의 버전을 확인한다.
- `--global` → 현재 사용자 계정 전체에 설정을 적용한다.
- `user.name`과 `user.email` → 커밋에 남길 작성자 정보를 등록한다.
- `git config --list` → 저장된 설정을 확인한다.

GitHub 저장소의 `Code`에서 주소를 복사한 뒤 VSCode 명령 팔레트에서 `Git: Clone`을 실행하고 저장 위치를 선택한다.

> **핵심:** 설정과 복제를 마친 뒤에는 조회 명령과 생성된 폴더를 확인하여 결과를 검증한다.

------------------------------------------------------------------------

## 4. 예제

``` powershell
git config --global user.name "student"
git config --global user.email "student@example.com"
git config --list
```

### 코드 해석

- 첫 번째와 두 번째 명령은 Git 작성자 정보를 등록한다.
- 마지막 명령은 저장된 설정을 목록으로 보여 준다.

> **결과 해석:** 목록에서 입력한 이름과 이메일이 보이면 초기 설정이 적용된 것이다.

------------------------------------------------------------------------

## 6. 주의할 점

- 사용자 이름과 이메일은 커밋 작성자를 구분하는 정보이므로 정확하게 입력한다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `user.name` | 커밋 작성자 이름 |
| `user.email` | 커밋 작성자 이메일 |
| `clone` | 원격 Git 저장소를 로컬로 복제하는 작업 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `git --version` | Git 버전 확인 |
| `git config --global` | 현재 사용자 전체에 Git 설정 저장 |
| `git config --list` | 저장된 Git 설정 확인 |

### ⭐ 한 줄 정리

> **Git 설치 후 작성자 정보를 등록하고, `clone`으로 GitHub 저장소를 로컬에 가져온다.**
