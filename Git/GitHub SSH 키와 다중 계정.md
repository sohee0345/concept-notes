# GitHub SSH 키와 다중 계정

## 1. 개념

GitHub에 SSH 공개키를 등록하면 로컬 컴퓨터가 계정의 저장소에 접근할 수 있음을 인증할 수 있다. 여러 계정은 계정별 SSH Host Alias로 구분한다.

> **핵심:** 계정마다 키와 Alias를 연결하면 Clone할 때 사용할 GitHub 계정을 구분할 수 있다.

------------------------------------------------------------------------

## 2. SSH 키 등록

```text
Settings → SSH and GPG keys → New SSH key
```

공개키와 알아보기 쉬운 Title을 입력하고 등록한다.

------------------------------------------------------------------------

## 3. Alias를 적용한 Clone 주소

```text
git@github.com:owner/repository.git
git@github.com-account:owner/repository.git
```

콜론 앞의 호스트를 SSH 설정의 Alias로 바꾸면 해당 Alias에 연결된 계정과 키를 사용한다.

------------------------------------------------------------------------

## 4. 주의할 점

- 여러 계정을 사용하면 Windows 자격 증명 관리자에 남은 인증 정보도 확인한다.
- Clone 주소의 소유자와 저장소 이름은 그대로 두고 호스트 부분만 Alias로 바꾼다.
- 적용할 VS Code SSH Profile과 대상 저장소 계정이 일치하는지 확인한다.
