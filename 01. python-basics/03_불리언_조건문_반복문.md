# 불리언 · 조건문 · 반복문

## 1. 개념
불리언은 `True`와 `False`를 표현하고, 조건문과 반복문은 프로그램의 실행 흐름을 제어한다.

> **핵심:** 조건에 따라 실행을 나누고, 반복할 작업은 `for` 또는 `while`로 처리한다.

---

## 2. 쉽게 이해하기
```text
조건 확인
  ↓
참/거짓 판단
  ↓
if로 분기
  ↓
for/while로 반복
```

---

## 3. 사용 방법
```python
score = 70

if score >= 60:
    print("합격")
else:
    print("불합격")

for number in [1, 2, 3]:
    print(number)
```

- `if / elif / else` → 조건별 실행
- `and` → 모두 참일 때 참
- `or` → 하나 이상 참이면 참
- `not` → 결과 반전
- `for` → 순서가 있는 데이터를 하나씩 반복
- `while` → 조건이 참인 동안 반복
- `break` → 반복 종료
- `pass` → 아무 동작 없이 넘어가기

---

## 4. 예제
```python
for number in range(1, 6):
    if number == 3:
        break
    print(number)
```

실행 결과:
```text
1
2
```

---

## 5. 헷갈리는 개념 비교
|구분|`for`|`while`|
|---|---|---|
|기준|데이터를 순회|조건이 참인 동안 반복|
|사용|반복 횟수/대상이 비교적 명확|종료 조건 중심|

## 🟦 핵심 정리

### 💡 주요 개념
boolean, 조건식, if, for, while

### 💻 주요 코드
|코드|의미|
|---|---|
|`if 조건:`|조건 분기|
|`for x in data:`|데이터 반복|
|`break`|반복 즉시 종료|
