# 스칼라 · 벡터 · 행렬 · Shape

## 1. 개념

NumPy 배열은 차원에 따라 스칼라(0차원), 벡터(1차원), 행렬(2차원), 고차원 배열로 구분할 수 있다.

배열의 차원은 `ndim`, 각 차원의 크기는 `shape`으로 확인한다.

> **핵심:** NumPy 배열의 구조는 ndim으로 차원을, shape으로 각 차원의 크기를 확인한다.

---

## 2. 쉽게 이해하기

```text
3                → Scalar → 0차원
[1, 2, 3]        → Vector → 1차원
[[1, 2], [3, 4]] → Matrix → 2차원
```

Shape의 숫자 개수는 차원의 개수와 같다.

---

## 3. 사용 방법

```python
import numpy as np

a = np.array([1, 2, 3])

a.ndim
a.shape
```

```text
(3,)      → 1차원, 데이터 3개
(2, 3)    → 2행 3열
(2, 2, 3) → 3차원
```

---

## 4. 예제

```python
np.array(3).shape
# ()

np.array([1, 2, 3]).shape
# (3,)
```

`(3,)`은 원소 하나짜리 튜플 표기처럼 끝에 쉼표가 붙는다.

---

## 5. 헷갈리는 개념 비교

| 개념 | 차원 |
|---|---:|
| Scalar | 0 |
| Vector | 1 |
| Matrix | 2 |
| 고차원 배열 | 3 이상 |

## 🟦 핵심 정리

### 💡 주요 개념

- `ndim` → 차원 수
- `shape` → 각 축의 크기
- row → 행
- column → 열

### 💻 주요 코드

| 코드 | 의미 |
|---|---|
| `np.array()` | NumPy 배열 생성 |
| `a.ndim` | 차원 확인 |
| `a.shape` | Shape 확인 |

### ⭐ 한 줄 정리

> **NumPy 배열의 구조는 ndim으로 차원을, shape으로 각 차원의 크기를 확인한다.**
