# NumPy 배열 연산과 axis

## 1. 개념

NumPy 배열끼리 기본 산술연산을 하면 같은 위치의 원소끼리 계산한다.

2차원 이상 배열에서 합계나 평균을 구할 때는 `axis`를 이용해 어느 축을 없애면서 계산할지 지정할 수 있다.

> **핵심:** axis는 계산 방향을 외우기보다 어떤 축을 없애는지로 이해하면 쉽다.

---

## 2. 쉽게 이해하기

```python
a = [[1, 2, 3],
     [4, 5, 6]]
```

`axis=0`은 0번째 축을 없애면서 계산하고, `axis=1`은 1번째 축을 없애면서 계산한다.

---

## 3. 사용 방법

```python
a.sum()
# 21

a.sum(axis=0)
# [5, 7, 9]

a.sum(axis=1)
# [6, 15]
```

```python
np.eye(3)
```

→ 3×3 단위행렬 생성

---

## 4. 예제

```text
axis=0
1 2 3
↓ ↓ ↓
4 5 6
= [5, 7, 9]

axis=1
1 2 3 → 6
4 5 6 → 15
```

---

## 5. 헷갈리는 개념 비교

| 구분 | 결과 |
|---|---|
| `sum()` | 전체 합 → 스칼라 |
| `sum(axis=0)` | 0번째 축 제거 |
| `sum(axis=1)` | 1번째 축 제거 |

---

## 🟦 핵심 정리

### 💡 주요 개념

- 원소별 연산 → 같은 위치끼리 계산
- `axis` → 연산하면서 없앨 축
- `np.eye()` → 단위행렬 생성

### 💻 주요 코드

| 코드 | 의미 |
|---|---|
| `a.sum()` | 전체 합계 |
| `a.sum(axis=0)` | 0축 기준 합계 |
| `a.sum(axis=1)` | 1축 기준 합계 |
| `np.eye(n)` | n×n 단위행렬 |

### ⭐ 한 줄 정리

> **axis는 계산 방향을 외우기보다 어떤 축을 없애는지로 이해하면 쉽다.**
