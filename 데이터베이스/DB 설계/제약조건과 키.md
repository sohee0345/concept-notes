# 제약조건과 키

## 1. 개념

제약조건은 테이블에 잘못된 데이터가 저장되지 않도록 적용하는 규칙이다. 기본키는 각 행을 고유하게 식별하고 외래키는 다른 테이블의 행을 참조한다.

> **핵심:** 제약조건과 키로 값의 필수 여부·중복·범위·테이블 간 참조를 데이터베이스가 검사하게 한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
NOT NULL → 비워 둘 수 없음
UNIQUE → 같은 값 반복 금지
CHECK → 정한 조건만 허용
PRIMARY KEY → 행의 고유 번호
FOREIGN KEY → 다른 표의 행을 가리키는 번호
```

> **쉽게 말하면:** 데이터가 지켜야 할 입력 규칙과 테이블을 연결하는 식별표를 만드는 것이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` sql
CREATE TABLE students (
    student_id INT AUTO_INCREMENT,
    name VARCHAR(50) NOT NULL,
    email VARCHAR(120) NOT NULL UNIQUE,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (student_id)
);
```

- `NOT NULL` → 값 필수
- `UNIQUE` → 중복 값 금지
- `DEFAULT` → 생략 시 기본값 사용
- `AUTO_INCREMENT` → 숫자 자동 증가
- `PRIMARY KEY` → 행을 고유하게 식별

> **핵심:** 컬럼의 목적에 따라 데이터 타입과 제약조건을 함께 결정한다.

------------------------------------------------------------------------

## 4. 예제

``` sql
CREATE TABLE courses (
    course_id INT AUTO_INCREMENT,
    title VARCHAR(100) NOT NULL,
    price DECIMAL(10, 2) NOT NULL DEFAULT 0 CHECK (price >= 0),
    level ENUM('beginner', 'intermediate', 'advanced') NOT NULL,
    PRIMARY KEY (course_id)
);
```

다음 데이터는 가격이 음수이므로 `CHECK` 조건을 위반한다.

``` sql
INSERT INTO courses (title, price, level)
VALUES ('잘못된 강의', -1000, 'beginner');
```

### 코드 해석

- `CHECK (price >= 0)` → 0 이상의 가격만 허용한다.
- `ENUM(...)` → 지정된 문자열 중 하나만 저장한다.
- `PRIMARY KEY` → 각 강의를 ID로 구분한다.

> **결과 해석:** 제약조건을 만족하지 않는 행은 저장되지 않는다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 기본키 | 외래키 |
| --- | --- | --- |
| 역할 | 현재 테이블의 행 식별 | 다른 테이블의 행 참조 |
| 값 | 고유하며 NULL 불가 | 참조 대상 키와 연결 |
| 예시 | `students.student_id` | `enrollments.student_id` |

------------------------------------------------------------------------

## 6. 주의할 점

- 외래키가 참조할 부모 데이터가 먼저 존재해야 한다.
- 외래키가 있는 테이블을 삭제할 때는 참조하는 자식 테이블부터 삭제한다.
- 복합 `UNIQUE KEY`는 여러 컬럼의 값 조합이 중복되지 않도록 한다.

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `제약조건` | 저장할 데이터가 지켜야 하는 규칙 |

| `외래키` | 다른 테이블의 키를 참조하는 키 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `NOT NULL` | 값 필수 |
| `UNIQUE` | 중복 금지 |
| `CHECK` | 조건 검사 |
| `DEFAULT` | 기본값 지정 |
| `PRIMARY KEY` | 기본키 지정 |
| `FOREIGN KEY ... REFERENCES` | 외래키와 참조 대상 지정 |
