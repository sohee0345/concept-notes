# 서브쿼리

## 1. 개념

서브쿼리는 다른 SQL문 안에 포함되어 중간 결과를 만드는 SQL문이다. 복잡한 조회를 작은 단계로 나누고 그 결과를 바깥 쿼리에서 사용할 수 있다.

> **핵심:** 안쪽 쿼리의 결과를 먼저 만든 뒤 바깥 쿼리에서 필터링하거나 JOIN한다.

---

## 2. 쉽게 이해하기

큰 문제를 한 번에 풀지 않고 먼저 상위 고객 목록을 만든 다음 고객 정보와 연결하는 방식이다.

```text
안쪽 쿼리 실행
  ↓ 중간 결과
별칭 지정
  ↓
바깥 쿼리에서 사용
```

---

## 3. 사용 방법

```sql
SELECT c.customerName, ranked.order_count
FROM customers AS c
JOIN (
    SELECT customerNumber, COUNT(*) AS order_count
    FROM orders
    GROUP BY customerNumber
    LIMIT 3
) AS ranked ON c.customerNumber = ranked.customerNumber;
```

- 괄호 안의 SELECT가 중간 결과를 만든다.
- 서브쿼리 결과에는 `AS ranked`처럼 별칭을 붙인다.
- 바깥 쿼리는 별칭을 테이블처럼 사용한다.

---

## 4. 예제

복잡한 조회는 안쪽 쿼리만 먼저 실행해 결과를 확인한 다음 바깥 쿼리와 연결한다. 이렇게 하면 계산 단계와 JOIN 조건의 오류를 찾기 쉽다.

---

## 5. 헷갈리는 개념 비교

|구분|일반 테이블|서브쿼리 결과|
|---|---|---|
|존재|데이터베이스에 저장|쿼리 실행 중 생성|
|사용|테이블 이름 사용|별칭으로 참조|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|서브쿼리|다른 SQL문 안의 SQL문|
|중간 결과|바깥 쿼리에서 사용할 임시 조회 결과|
|별칭|서브쿼리 결과를 참조할 이름|

### 💻 주요 코드

|코드|의미|
|---|---|
|`JOIN (SELECT ...) AS name`|서브쿼리 결과와 JOIN|
|`name.column`|서브쿼리 결과 컬럼 참조|

### ⭐ 한 줄 정리
