# 서브쿼리

## 1. 개념

서브쿼리는 SQL 문 안에 포함된 다른 SQL 문이다. 내부 쿼리로 먼저 중간 결과를 만든 뒤 그 결과를 테이블처럼 조회하거나 JOIN할 수 있다.

> **핵심:** 복잡한 질문을 작은 조회로 나누고 검증한 결과를 바깥 쿼리에서 연결한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
내부 SELECT로 중간 결과 계산
  ↓ 별칭 부여
임시 테이블처럼 사용
  ↓ JOIN
바깥 SELECT에서 최종 정보 조회
```

> **쉽게 말하면:** 어려운 계산을 먼저 작은 표로 만든 다음 원래 표와 합쳐 최종 답을 구한다.

------------------------------------------------------------------------

## 3. 사용 방법

``` sql
SELECT ...
FROM table1 t1
JOIN (
    SELECT ...
    FROM table2
) t2 ON t1.key = t2.key;
```

- 괄호 안 `SELECT` → 서브쿼리
- `t2` → 서브쿼리 결과의 별칭
- 바깥 쿼리 → 서브쿼리 결과의 컬럼 사용
- `ON` → 양쪽 결과를 연결할 조건

> **핵심:** 바깥 쿼리에서는 서브쿼리가 실제로 반환한 컬럼만 `t2.컬럼`으로 사용할 수 있다.

------------------------------------------------------------------------

## 4. 예제

``` sql
SELECT
    c.customerName,
    top_orders.cnt
FROM customers c
JOIN (
    SELECT
        customerNumber,
        COUNT(orderNumber) AS cnt
    FROM orders
    GROUP BY customerNumber
    ORDER BY cnt DESC
    LIMIT 3
) top_orders
    ON c.customerNumber = top_orders.customerNumber;
```

### 코드 해석

- 내부 쿼리 → 주문 횟수 상위 3명의 고객 번호와 횟수 계산
- `top_orders` → 중간 결과에 붙인 별칭
- 바깥 쿼리 → 고객 번호가 같은 고객 정보 연결

> **결과 해석:** 집계 결과의 고객 번호를 이용해 고객 이름과 주문 횟수를 함께 조회한다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 일반 JOIN | 서브쿼리 JOIN |
| --- | --- | --- |
| 연결 대상 | 실제 테이블 | SELECT로 만든 중간 결과 |
| 사용 목적 | 저장된 행 연결 | 계산·집계 결과 연결 |
| 별칭 | 테이블 별칭 | 서브쿼리 결과 별칭 필수 |

------------------------------------------------------------------------

## 6. 주의할 점

- 서브쿼리를 먼저 따로 실행해 컬럼과 결과를 확인한다.
- 서브쿼리 결과에 없는 컬럼을 바깥 쿼리에서 참조하면 오류가 발생한다.
- 같은 `t1`, `t2`를 여러 단계에서 반복하면 혼동하기 쉬우므로 역할이 드러나는 별칭을 사용할 수 있다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `서브쿼리` | SQL 안에 포함된 다른 SQL |
| `중간 결과` | 내부 쿼리가 반환하는 임시 조회 결과 |
| `Alias` | 테이블이나 서브쿼리 결과에 붙이는 별칭 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `JOIN (SELECT ...) alias` | 서브쿼리 결과 연결 |
| `alias.column` | 별칭으로 컬럼 참조 |
| `ON left.key = right.key` | 연결 조건 지정 |

### ⭐ 한 줄 정리

> **서브쿼리는 작은 조회 결과를 중간 테이블처럼 만들어 바깥 쿼리에서 다시 연결하게 한다.**
