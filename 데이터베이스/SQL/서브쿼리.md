# 서브쿼리

## 1. 개념

서브쿼리는 다른 SQL문 안에 포함된 SQL문이다. 먼저 필터링하거나 집계한 중간 결과를 만들고, 바깥 쿼리에서 그 결과를 다시 조회하거나 다른 테이블과 연결할 수 있다.

> **핵심:** 서브쿼리는 복잡한 문제를 중간 결과와 최종 결과의 단계로 나누는 방법이다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

먼저 주문이 많은 고객 번호 3개를 구한 뒤, 그 고객 번호를 고객 테이블과 연결해 이름과 전화번호를 찾는다.

```text
안쪽 쿼리: 상위 고객 번호 계산
  ↓
중간 결과에 별칭 부여
  ↓
바깥 쿼리: 고객 상세 정보와 JOIN
```

------------------------------------------------------------------------

## 3. 사용 방법

```sql
SELECT
    c.customerName,
    ranked.order_count
FROM customers AS c
JOIN (
    SELECT
        customerNumber,
        COUNT(*) AS order_count
    FROM orders
    GROUP BY customerNumber
    ORDER BY order_count DESC
    LIMIT 3
) AS ranked
    ON c.customerNumber = ranked.customerNumber;
```

- 괄호 안의 `SELECT` → 먼저 상위 고객 번호와 주문 횟수를 계산한다.
- `AS ranked` → FROM 절에서 사용한 서브쿼리 결과에 붙인 별칭이다.
- 바깥 `JOIN` → 중간 결과를 고객 테이블과 연결한다.

------------------------------------------------------------------------

## 4. 작성 순서

- 가장 안쪽 쿼리를 독립적으로 실행해 결과 컬럼과 행을 확인한다.
- 중간 결과에 의미가 드러나는 컬럼 별칭과 테이블 별칭을 붙인다.
- 바깥 쿼리의 JOIN 조건에 필요한 키가 중간 결과에 포함되었는지 확인한다.
- 최종 쿼리를 실행해 중복 행과 정렬 순서를 검사한다.

------------------------------------------------------------------------

## 5. 주의할 점

- FROM 절의 서브쿼리에는 MySQL에서 별칭이 필요하다.
- 너무 깊게 중첩하면 읽기 어려워지므로 단계별 실행으로 검증한다.
