# 테이블 정의와 변경

## 1. 개념

DDL은 데이터베이스와 테이블의 구조를 정의하는 SQL이다. `CREATE`로 만들고 `ALTER`로 구조를 바꾸며 `DROP`으로 삭제한다.

> **핵심:** 테이블 생성문은 저장 공간뿐 아니라 컬럼 타입과 허용 규칙까지 정의한다.

---

## 2. 쉽게 이해하기

테이블을 건물에 비유하면 CREATE는 설계와 건축, ALTER는 구조 변경, DROP은 건물 전체 철거이다.

```text
CREATE → 구조 생성
ALTER → 구조 변경
DROP → 구조와 데이터 삭제
```

---

## 3. 사용 방법

```sql
CREATE TABLE usertb (
    id INT AUTO_INCREMENT,
    name VARCHAR(10) DEFAULT '없음',
    PRIMARY KEY (id)
);

DESCRIBE usertb;
```

- `CREATE TABLE` → 테이블과 컬럼을 정의한다.
- `DESCRIBE` → 컬럼, 타입, 키, 기본값을 확인한다.
- `ALTER TABLE` → 기존 구조를 변경한다.
- `DROP TABLE` → 구조와 데이터를 함께 삭제한다.

---

## 4. 예제

```sql
ALTER TABLE usertb ADD COLUMN email VARCHAR(120);
ALTER TABLE usertb MODIFY COLUMN name VARCHAR(50);
ALTER TABLE usertb DROP COLUMN email;
```

컬럼을 추가하고 기존 컬럼의 길이를 변경한 뒤 불필요한 컬럼을 삭제한다.

---

## 5. 헷갈리는 개념 비교

|구분|CREATE|ALTER|DROP|
|---|---|---|---|
|역할|구조 생성|기존 구조 변경|구조와 데이터 삭제|
