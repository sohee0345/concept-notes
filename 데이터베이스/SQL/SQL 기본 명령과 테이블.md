# SQL 기본 명령과 테이블

## 1. 개념

SQL은 데이터베이스의 구조를 만들고 데이터를 추가·조회하는 언어이다. 테이블은 행과 열로 데이터를 저장하며 각 컬럼에는 데이터 타입을 지정한다.

> **핵심:** 데이터베이스를 선택하고 테이블 구조를 만든 뒤 데이터를 추가하고 조회하는 흐름을 익힌다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
데이터베이스 선택
  ↓
테이블 생성
  ↓
행 추가
  ↓
데이터 조회
```

> **쉽게 말하면:** 데이터를 담을 표의 구조를 먼저 만들고 그 안에 값을 저장해 꺼내 보는 과정이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` sql
USE examplesdb;
DROP TABLE IF EXISTS userdb;

CREATE TABLE userdb (
    id INT AUTO_INCREMENT,
    name VARCHAR(20) DEFAULT '없음',
    addr VARCHAR(500) NOT NULL,
    PRIMARY KEY (id)
);
```

- `USE` → 사용할 데이터베이스 선택
- `DROP TABLE IF EXISTS` → 테이블이 존재할 때만 삭제
- `CREATE TABLE` → 테이블과 컬럼 정의
- `VARCHAR(n)` → 최대 `n`문자의 가변 길이 문자열

> **핵심:** SQL 문장은 세미콜론으로 끝내고 컬럼마다 저장할 값에 맞는 타입을 지정한다.

------------------------------------------------------------------------

## 4. 예제

``` sql
INSERT INTO userdb (name, addr)
VALUES
    ('홍길동', '서울 강남'),
    ('신사임당', '부산 해운대');

SELECT id, name, addr
FROM userdb;
```

실행 결과:

``` text
id | name     | addr
1  | 홍길동    | 서울 강남
2  | 신사임당  | 부산 해운대
```

### 코드 해석

- `INSERT INTO` → 지정한 컬럼에 새 행을 추가한다.
- `VALUES` → 추가할 값을 컬럼 순서에 맞게 작성한다.
- `SELECT ... FROM` → 지정한 테이블의 컬럼을 조회한다.
- `id` 생략 → `AUTO_INCREMENT`가 값을 자동 생성한다.

> **결과 해석:** 두 행이 추가되고 자동 증가한 ID와 함께 조회된다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 구조 명령 | 데이터 명령 |
| --- | --- | --- |
| 목적 | 데이터베이스·테이블 구조 관리 | 테이블의 행 관리·조회 |
| 예시 | `CREATE`, `DROP`, `ALTER` | `INSERT`, `SELECT` |
| 대상 | 스키마 구조 | 저장된 데이터 |

------------------------------------------------------------------------

## 6. 주의할 점

- `DROP TABLE`은 테이블을 삭제하므로 대상 이름을 확인한다.
- 여러 행을 추가할 때 각 값의 순서가 지정한 컬럼 순서와 일치해야 한다.
- SQL 문장은 `;` 단위로 구분한다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `테이블` | 행과 열로 데이터를 저장하는 구조 |
| `컬럼` | 저장할 데이터의 이름과 타입을 정의 |
| `행` | 한 건의 데이터 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `CREATE TABLE` | 테이블 생성 |
| `ALTER TABLE` | 테이블 구조 변경 |
| `DROP TABLE` | 테이블 삭제 |
| `INSERT INTO` | 행 추가 |
| `SELECT` | 데이터 조회 |

### ⭐ 한 줄 정리

> **SQL로 테이블 구조를 정의하고 행을 추가한 뒤 필요한 컬럼을 조회한다.**
