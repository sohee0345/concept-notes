# SELECT와 그룹 집계

## 1. 개념

`SELECT`는 테이블에서 데이터를 조회하는 명령이다. `WHERE`, `ORDER BY`, `LIMIT`으로 결과를 제한하고 `GROUP BY`와 집계 함수로 기준별 개수와 합계를 계산할 수 있다.

> **핵심:** 조회할 행을 고르고 그룹화한 뒤 집계·정렬·개수 제한을 적용한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
테이블 선택
  ↓ 조건에 맞는 행 선택
  ↓ 같은 기준으로 그룹화
  ↓ 개수·합계 계산
  ↓ 정렬하고 상위 N개 선택
```

> **쉽게 말하면:** 표에서 필요한 행만 골라 같은 종류끼리 묶고 요약값을 계산하는 과정이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` sql
SELECT
    customerNumber,
    COUNT(orderNumber) AS order_count
FROM orders
GROUP BY customerNumber
ORDER BY order_count DESC
LIMIT 3;
```

- `WHERE` → 집계 전에 필요한 행 선택
- `GROUP BY` → 같은 값끼리 그룹화
- `COUNT()` → 그룹별 개수
- `SUM()` → 그룹별 합계
- `ORDER BY` → 결과 정렬
- `LIMIT` → 반환할 행 수 제한

> **핵심:** 집계하지 않은 컬럼을 함께 조회할 때는 어떤 기준으로 그룹화하는지 확인한다.

------------------------------------------------------------------------

## 4. 예제

``` sql
SELECT
    o.customerNumber,
    SUM(od.quantityOrdered * od.priceEach) AS total_price
FROM orders o
JOIN orderdetails od
    ON o.orderNumber = od.orderNumber
GROUP BY o.customerNumber
ORDER BY total_price DESC
LIMIT 3;
```

### 코드 해석

- `quantityOrdered * priceEach` → 주문 상품 금액 계산
- `SUM(...)` → 고객별 상품 금액 합계
- `GROUP BY customerNumber` → 고객별로 행을 묶음
- `ORDER BY ... DESC` → 총액이 큰 순서로 정렬

> **결과 해석:** 주문 상세를 고객별로 묶어 총 구매액 상위 3명의 고객 번호를 얻는다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `WHERE` | `GROUP BY` | `ORDER BY` | `LIMIT` |
| --- | --- | --- | --- | --- |
| 역할 | 행 필터링 | 행 그룹화 | 결과 정렬 | 행 수 제한 |
| 예시 | USA 고객 | 고객 번호별 | 총액 내림차순 | 상위 3개 |

------------------------------------------------------------------------

## 6. 주의할 점

- `ASC`는 오름차순이며 생략할 수 있고 `DESC`는 내림차순이다.
- 계산 결과에 별칭을 붙이면 `ORDER BY`에서 읽기 쉽게 사용할 수 있다.
- 집계가 맞는지 작은 결과부터 확인한 뒤 복잡한 JOIN으로 확장한다.
