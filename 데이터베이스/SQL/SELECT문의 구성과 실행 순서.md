# SELECT문의 구성과 실행 순서

## 1. 개념

`SELECT` 조회문은 테이블에서 필요한 행과 컬럼을 골라 정렬하거나 개수를 제한해 결과를 만든다. 각 절의 역할뿐 아니라 논리적으로 처리되는 순서를 알면 복잡한 조회문을 이해하기 쉽다.

> **핵심:** SQL은 작성된 위쪽부터 단순 실행되는 것이 아니라 데이터를 가져오고 거른 뒤 결과를 선택하고 정렬한다.

------------------------------------------------------------------------

## 2. 주요 절

| 절 | 역할 |
| --- | --- |
| `SELECT` | 출력할 컬럼과 계산식을 정한다. |
| `FROM` | 조회할 테이블을 정한다. |
| `WHERE` | 조건에 맞는 행만 남긴다. |
| `ORDER BY` | 결과를 정렬한다. |
| `LIMIT` | 반환할 행 수를 제한한다. |

기본 조회문의 논리적 처리 흐름은 다음과 같다.

```text
FROM → WHERE → SELECT → ORDER BY → LIMIT
```

------------------------------------------------------------------------

## 3. 예제

```sql
SELECT
    customerName,
    country,
    creditLimit
FROM customers
WHERE country = 'USA'
ORDER BY creditLimit DESC
LIMIT 10;
```

### 코드 해석

- `FROM customers` → 고객 테이블을 조회 대상으로 정한다.
- `WHERE country = 'USA'` → 미국 고객만 남긴다.
- `SELECT` → 이름, 국가, 신용한도를 결과 컬럼으로 선택한다.
- `ORDER BY ... DESC` → 신용한도가 큰 순서로 정렬한다.
- `LIMIT 10` → 정렬된 결과 중 앞의 10행만 반환한다.

------------------------------------------------------------------------

## 4. 주의할 점

- `ASC`는 오름차순이며 생략했을 때의 기본 정렬 방향이다.
- `LIMIT`으로 상위 데이터를 고를 때는 원하는 기준의 `ORDER BY`를 먼저 지정해야 한다.
- 같은 값의 행 순서까지 고정하려면 추가 정렬 기준을 지정한다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 행 필터링 | `WHERE`로 조건에 맞는 행만 남긴다. |
| 정렬 | `ORDER BY`로 결과 순서를 정한다. |
| 결과 제한 | `LIMIT`으로 반환할 행 수를 정한다. |

### ⭐ 한 줄 정리

> **조회 대상을 정하고 행을 거른 뒤 출력 컬럼을 만들고 정렬과 개수 제한을 적용한다.**
