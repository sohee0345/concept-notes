# DDL과 DML

## 1. 개념

SQL 명령은 수행하는 역할에 따라 여러 범주로 나눌 수 있다. DDL(Data Definition Language)은 데이터베이스 객체의 구조를 정의하고, DML(Data Manipulation Language)은 테이블에 저장된 데이터를 조회하거나 변경한다.

> **핵심:** DDL은 데이터가 들어갈 구조를 다루고, DML은 그 구조 안의 데이터를 다룬다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

테이블을 서류 양식에 비유하면 DDL은 칸의 이름과 형식을 만드는 작업이고, DML은 완성된 양식에 내용을 쓰거나 찾아보는 작업이다.

```text
DDL로 테이블 구조 정의
  ↓
DML로 행 추가·조회·변경·삭제
```

------------------------------------------------------------------------

## 3. 주요 명령

| 분류 | 명령 | 역할 |
| --- | --- | --- |
| DDL | `CREATE` | 데이터베이스나 테이블을 생성한다. |
| DDL | `ALTER` | 기존 테이블의 구조를 변경한다. |
| DDL | `DROP` | 데이터베이스 객체를 삭제한다. |
| DML | `SELECT` | 데이터를 조회한다. |
| DML | `INSERT` | 새 행을 추가한다. |
| DML | `UPDATE` | 기존 행의 값을 변경한다. |
| DML | `DELETE` | 행을 삭제한다. |

------------------------------------------------------------------------

## 4. 예제

```sql
CREATE TABLE users (
    user_id INT PRIMARY KEY,
    name VARCHAR(50) NOT NULL
);

INSERT INTO users (user_id, name)
VALUES (1, '홍길동');

SELECT user_id, name
FROM users;
```

### 코드 해석

- `CREATE TABLE` → 저장 구조를 만드는 DDL이다.
- `INSERT` → 테이블에 행을 추가하는 DML이다.
- `SELECT` → 저장된 행을 조회하는 DML이다.

------------------------------------------------------------------------

## 5. 주의할 점

- `DROP TABLE`은 테이블의 구조와 데이터를 함께 삭제하므로 대상을 반드시 확인한다.
- `DELETE`는 행을 지우지만 테이블 구조는 남긴다는 점에서 `DROP`과 다르다.
- SQL 분류는 문맥이나 데이터베이스 제품에 따라 더 세분되기도 하지만, 구조와 데이터의 구분이 기본이다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `DDL` | 데이터베이스 객체의 구조를 정의한다. |
| `DML` | 테이블에 저장된 데이터를 조회하거나 변경한다. |
| 데이터베이스 객체 | 테이블처럼 데이터베이스 안에서 생성하고 관리하는 대상이다. |

### ⭐ 한 줄 정리

> **DDL은 구조를 만들고 바꾸며, DML은 그 구조에 저장된 데이터를 다룬다.**
