# 데이터 타입과 제약조건

## 1. 개념

데이터 타입은 컬럼에 저장할 값의 종류를 정하고 제약조건은 어떤 값까지 허용할지 정한다. 올바른 설계는 잘못된 데이터 저장을 데이터베이스 단계에서 막는다.

> **핵심:** 타입은 값의 형태를, 제약조건은 값의 허용 규칙을 결정한다.

---

## 2. 쉽게 이해하기

데이터 타입이 상자에 담을 물건의 종류라면 제약조건은 비어 있어도 되는지, 중복되어도 되는지 정하는 규칙이다.

```text
컬럼 정의
  ↓ 데이터 타입 선택
값의 형태 결정
  ↓ 제약조건 추가
허용 규칙 결정
```

---

## 3. 사용 방법

- `INT`, `DECIMAL` → 정수와 정확한 소수 저장
- `VARCHAR`, `TEXT` → 문자열 저장
- `DATE`, `DATETIME` → 날짜와 시간 저장
- `ENUM`, `JSON` → 제한된 문자열과 구조화된 값 저장
- `NOT NULL`, `UNIQUE`, `DEFAULT`, `CHECK` → 값의 허용 규칙 지정

---

## 4. 예제

```sql
CREATE TABLE students (
    student_id INT AUTO_INCREMENT,
    name VARCHAR(50) NOT NULL,
    email VARCHAR(120) NOT NULL UNIQUE,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (student_id)
);
```

식별자는 자동 증가하고 이름과 이메일은 필수이며 이메일 중복은 허용하지 않는다.

---

## 5. 헷갈리는 개념 비교

|구분|데이터 타입|제약조건|
|---|---|---|
|결정|저장할 값의 형태|허용할 값의 규칙|
|예시|`INT`, `VARCHAR`|`NOT NULL`, `UNIQUE`|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|데이터 타입|컬럼에 저장할 값의 종류|
|제약조건|저장 가능한 값의 규칙|
|`AUTO_INCREMENT`|새 행의 정수 값을 자동 증가|

### 💻 주요 코드

|코드|의미|
|---|---|
|`NOT NULL`|NULL 금지|
|`UNIQUE`|중복 금지|
|`DEFAULT`|생략 시 기본값 사용|
|`PRIMARY KEY`|행의 고유 식별자 지정|
