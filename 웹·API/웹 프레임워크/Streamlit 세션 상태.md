# Streamlit 세션 상태

## 1. 개념

`st.session_state`는 Streamlit 앱이 다시 실행되어도 같은 사용자 세션에서 유지해야 하는 값을 저장하는 공간이다. 대화 이력처럼 이전 상호작용을 기억해야 하는 데이터에 사용한다.

> **핵심:** 재실행 때 사라지면 안 되는 데이터는 일반 변수가 아니라 session_state에 저장한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
사용자 입력
  ↓ 앱 재실행
일반 변수 다시 생성
session_state 값은 유지
```

> **쉽게 말하면:** Streamlit 코드가 처음부터 다시 실행되어도 남아 있는 사용자별 보관함이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
if "history" not in st.session_state:
    st.session_state.history = []

st.session_state.history.append({
    "role": "user",
    "msg": "안녕하세요"
})
```

- 키 확인 → 최초 실행인지 판단한다.
- 초기화 → 처음에만 빈 값을 만든다.
- 추가 → 새 상호작용을 기존 상태에 이어 붙인다.

> **핵심:** 조건 없이 초기화하면 재실행 때마다 기존 데이터가 사라진다.

------------------------------------------------------------------------

## 4. 예제

``` python
if "messages" not in st.session_state:
    st.session_state.messages = []

for message in st.session_state.messages:
    with st.chat_message(message["role"]):
        st.markdown(message["content"])
```

### 코드 해석

- 최초 실행에서만 메시지 리스트를 만든다.
- 재실행 때 저장된 메시지를 순서대로 다시 출력한다.

> **결과 해석:** 입력으로 앱이 다시 실행되어도 이전 대화가 화면에 복원된다.

------------------------------------------------------------------------

## 6. 주의할 점

- 기존 이력을 복원하면서 같은 데이터를 다시 저장하면 메시지가 중복된다.
- 초기화·복원·새 데이터 추가의 단계를 구분한다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 세션 상태 | 재실행 사이에 유지되는 데이터 |
| 초기화 | 키가 없을 때 최초 값 생성 |
| 복원 | 저장된 상태를 화면에 다시 표시 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `if "key" not in st.session_state` | 최초 초기화 조건 |
| `st.session_state.key = []` | 상태 저장 |
| `st.session_state.key.append(...)` | 새 데이터 추가 |

### ⭐ 한 줄 정리

> **Streamlit 세션 상태는 앱 재실행 사이에 유지해야 하는 사용자 데이터를 저장한다.**
