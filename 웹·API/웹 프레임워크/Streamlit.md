# Streamlit

## 1. 개념

Streamlit은 Python 코드로 텍스트, 데이터, 입력 위젯을 갖춘 웹 애플리케이션을 만드는 외부 라이브러리이다.

> **핵심:** 화면 요소를 Python 함수로 선언하여 웹 앱을 구성한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
Python 코드
  ↓ Streamlit 함수 실행
웹 화면의 제목·표·버튼·입력 폼
```

> **쉽게 말하면:** HTML을 직접 작성하지 않고 Python 함수로 웹 화면을 쌓아 가는 도구이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
import streamlit as st

st.title("제목")
name = st.text_input("이름을 입력하세요.")

if st.button("인사"):
    st.write(f"안녕하세요, {name}님!")
```

- `st.title()` → 제목 출력
- `st.text_input()` → 문자열 입력
- `st.button()` → 버튼 생성
- `st.write()` → 값 출력
- `st.dataframe()` → DataFrame 표시

> **핵심:** 위젯의 반환값을 변수에 저장하고 조건문과 연결해 상호작용을 만든다.

------------------------------------------------------------------------

## 4. 예제

``` python
with st.form(key="my_form"):
    name = st.text_input("이름을 입력하세요.")
    submitted = st.form_submit_button("Submit")

if submitted:
    st.write(f"Hello, {name}!")
```

### 코드 해석

- `st.form()` → 여러 입력을 묶는다.
- `form_submit_button()` → 입력값을 처리할 제출 시점을 만든다.

> **결과 해석:** 사용자가 Submit을 눌렀을 때 모아 둔 입력을 한 번에 처리한다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 일반 위젯 | Form 내부 위젯 |
| --- | --- | --- |
| 처리 시점 | 값 변경 시 앱이 다시 실행될 수 있음 | Submit할 때 모아 처리 |
| 용도 | 즉시 상호작용 | 여러 입력 일괄 제출 |

------------------------------------------------------------------------

## 6. 주의할 점

- Streamlit은 표준 라이브러리가 아니므로 별도 설치가 필요하다.
- DataFrame 열 표시 방식은 `column_config`로 설정할 수 있다.

### 💡 주요 개념
