# Streamlit 채팅 UI

## 1. 개념

Streamlit 채팅 UI는 `st.chat_input()`으로 사용자 메시지를 받고 `st.chat_message()`로 사용자와 챗봇의 메시지를 역할별로 표시한다.

> **핵심:** 입력, 응답 생성, 저장, 출력의 순서를 연결해 대화형 화면을 만든다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
chat_input으로 입력
  ↓
답변 생성
  ↓
chat_message로 사용자·챗봇 메시지 출력
```

> **쉽게 말하면:** 채팅 입력창에서 받은 문장을 답변 함수에 보내고 두 역할의 말풍선으로 보여 주는 것이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
user_input = st.chat_input("메시지를 입력하세요")

if user_input:
    with st.chat_message("user"):
        st.markdown(user_input)
```

- `st.chat_input()` → 채팅 입력 위젯 생성
- `st.chat_message("user")` → 사용자 메시지 영역 생성
- `st.chat_message("assistant")` → 챗봇 메시지 영역 생성

> **핵심:** chat_input의 반환값이 있을 때만 새 메시지를 처리한다.

------------------------------------------------------------------------

## 4. 예제

``` python
user_input = st.chat_input("메시지를 입력하세요")

if user_input:
    answer = get_response(user_input)

    with st.chat_message("user"):
        st.markdown(user_input)

    with st.chat_message("assistant"):
        st.markdown(answer)
```

### 코드 해석

- 사용자 입력을 응답 함수에 전달한다.
- 사용자와 챗봇의 내용을 서로 다른 역할로 출력한다.

> **결과 해석:** 하나의 입력을 받아 답변을 생성하고 두 개의 채팅 메시지로 화면에 표시한다.

------------------------------------------------------------------------

## 6. 주의할 점

- 대화 기록을 유지하려면 메시지를 session_state에 저장해야 한다.
- 같은 사용자 입력을 AI 요청이나 이력에 두 번 추가하지 않는다.
