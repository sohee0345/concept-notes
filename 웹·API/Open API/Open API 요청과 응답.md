# Open API 요청과 응답

## 1. 개념

Open API는 외부 프로그램이 정해진 주소와 형식으로 요청하면 서비스의 데이터나 기능을 사용할 수 있도록 공개한 인터페이스이다. 공공데이터 API는 활용 신청과 인증키 발급이 필요한 경우가 많다.

> **핵심:** API 문서에 맞는 요청을 보내고 상태 코드와 응답 구조를 확인해야 데이터를 사용할 수 있다.

------------------------------------------------------------------------

## 2. 사용 흐름

```text
API 검색과 활용 신청
  ↓
인증키 발급 및 환경 변수 저장
  ↓
요청 URL 구성
  ↓
GET 요청
  ↓
상태 코드와 JSON 응답 확인
```

------------------------------------------------------------------------

## 3. 예제

```python
import os
import requests
from dotenv import load_dotenv

load_dotenv()
api_key = os.getenv("FOOD_SAFETY_API_KEY")

url = f"http://openapi.foodsafetykorea.go.kr/api/{api_key}/I2570/json/1/5"
response = requests.get(url)

print(response.status_code)
data = response.json()
```

- `requests.get()` → HTTP GET 요청을 보낸다.
- `status_code` → 요청 처리 결과를 숫자로 나타낸다.
- `response.json()` → JSON 본문을 Python 자료구조로 변환한다.

------------------------------------------------------------------------

## 4. 인증키 관리

```dotenv
FOOD_SAFETY_API_KEY="발급받은인증키"
```

인증키는 코드에 직접 작성하지 않고 `.env`에 분리하며, `.env`는 `.gitignore`에 등록한다.
