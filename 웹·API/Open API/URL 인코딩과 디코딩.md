# URL 인코딩과 디코딩

## 1. 개념

URL 인코딩은 한글, 공백, 특수문자 등을 URL로 전송할 수 있는 형태로 변환하는 과정이다. 디코딩은 인코딩된 문자열을 원래 문자로 되돌린다.

> **핵심:** URL에 직접 넣기 어려운 문자는 인코딩하고 읽거나 사용할 때 디코딩한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
안녕하세요
  ↓ 인코딩
%EC%95%88...
  ↓ 디코딩
안녕하세요
```

> **쉽게 말하면:** 문자를 URL이 전달할 수 있는 표기로 포장했다가 다시 원래 모습으로 푸는 것이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
from urllib.parse import quote, unquote

encoded = quote("안녕하세요")
decoded = unquote(encoded)
```

- `quote()` → 문자열을 URL 인코딩
- `unquote()` → 인코딩된 문자열을 디코딩

> **핵심:** 인코딩과 디코딩은 서로 반대 방향의 변환이다.

------------------------------------------------------------------------

## 4. 예제

``` python
encoded = quote("인공지능")
print(encoded)
print(unquote(encoded))
```

실행 결과:

``` text
%EC%9D%B8%EA%B3%B5%EC%A7%80%EB%8A%A5
인공지능
```

### 코드 해석

- `quote()`는 한글을 `%`가 포함된 전송 형태로 바꾼다.
- `unquote()`는 그 값을 원래 한글로 복원한다.

> **결과 해석:** 같은 문자열이 URL용 표현과 사람이 읽는 표현 사이에서 변환된다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| URL 인코딩 | 문자를 URL 전송 형태로 변환 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `quote(text)` | URL 인코딩 |
| `unquote(text)` | URL 디코딩 |

### ⭐ 한 줄 정리

> **quote는 문자를 URL 형식으로 인코딩하고 unquote는 원래 문자로 디코딩한다.**
