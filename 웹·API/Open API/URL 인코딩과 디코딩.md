# URL 인코딩과 디코딩

## 1. 개념

URL 인코딩은 한글, 공백, 특수문자 등을 URL로 전송할 수 있는 형태로 바꾸는 과정이다. 디코딩은 인코딩된 값을 다시 원래 문자로 되돌린다.

> **핵심:** URL에 직접 넣기 어려운 문자는 인코딩하여 전송하고 사용할 때 디코딩한다.

---

## 2. 쉽게 이해하기

전송하기 어려운 문자를 URL이 이해할 수 있는 약속된 표현으로 포장하고, 받은 뒤 다시 원래 문자로 푸는 과정이다.

```text
원래 문자열
  ↓ 인코딩
URL 전송 형식
  ↓ 디코딩
원래 문자열
```

---

## 3. 사용 방법

```python
from urllib.parse import quote, unquote

encoded = quote("안녕하세요")
decoded = unquote(encoded)
```

- `quote()` → 문자열을 URL 전송 형식으로 인코딩한다.
- `unquote()` → 인코딩된 문자열을 원래 문자로 디코딩한다.

---

## 4. 예제

```python
from urllib.parse import quote, unquote

encoded = quote("안녕하세요")
print(encoded)
print(unquote(encoded))
```

실행 결과:

```text
%EC%95%88%EB%85%95%ED%95%98%EC%84%B8%EC%9A%94
안녕하세요
```

한글이 URL 전송 형식으로 바뀌었다가 원래 문자열로 복원된다.

---

## 5. 헷갈리는 개념 비교

|구분|인코딩|디코딩|
|---|---|---|
|방향|원래 문자 → URL 형식|URL 형식 → 원래 문자|
|함수|`quote()`|`unquote()`|
