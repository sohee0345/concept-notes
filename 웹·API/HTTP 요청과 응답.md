# HTTP 요청과 응답

## 1. 개념

HTTP 요청과 응답은 클라이언트가 웹 서버에 필요한 작업이나 데이터를 요청하고 서버가 처리 결과를 돌려주는 과정이다. Python에서는 `requests`로 URL, 파라미터, 헤더를 전달할 수 있다.

> **핵심:** 요청을 구성해 서버에 보내고 상태 코드와 응답 형식에 따라 결과를 처리한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
Python 클라이언트
  ↓ URL + params + headers
웹 서버
  ↓ status code + body
response 객체
```

> **쉽게 말하면:** 서버에 주소와 추가 조건을 보내고 성공 여부와 데이터를 답으로 받는 과정이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
import requests

response = requests.get(
    url="https://jsonplaceholder.typicode.com/posts",
    params={"userId": "1"},
    headers={"User-Agent": "Mozilla/5.0 ..."},
)
```

- `url` → 요청할 주소
- `params` → URL 쿼리 파라미터
- `headers` → 요청에 포함할 추가 정보
- `response` → 서버 응답 객체

> **핵심:** URL의 `?` 뒤 조건은 `params`로 분리해 전달할 수 있다.

------------------------------------------------------------------------

## 4. 예제

``` python
if response.status_code < 400:
    titles = [
        item["title"]
        for item in response.json()
    ]
```

### 코드 해석

- `status_code` → HTTP 응답 상태 확인
- `response.json()` → JSON 응답을 Python 자료형으로 변환
- 리스트 컴프리헨션 → 각 JSON 항목의 `title` 추출

> **결과 해석:** 요청이 성공하거나 리다이렉션 범위이면 응답 데이터를 변환해 제목 목록을 만든다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `params` | `headers` |
| --- | --- | --- |
| 역할 | 요청할 데이터 조건 | 요청 환경과 추가 정보 |
| 전달 위치 | URL의 쿼리 문자열 | HTTP 요청 헤더 |
| 예시 | `userId=1` | `User-Agent`, `Referer` |

------------------------------------------------------------------------

## 6. 주의할 점

- 1xx는 정보 응답, 2xx는 성공, 3xx는 리다이렉션, 4xx는 클라이언트 오류, 5xx는 서버 오류이다.
- JSON 응답은 `response.json()`, HTML 등의 문자열은 `response.text`로 다룬다.
- `Referer`는 현재 요청 직전의 URL 정보를 나타낸다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `HTTP 요청` | 클라이언트가 서버에 보내는 작업·데이터 요청 |
| `HTTP 응답` | 서버가 반환하는 상태와 데이터 |
| `상태 코드` | 요청 처리 결과를 나타내는 숫자 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `requests.get()` | GET 요청 전송 |
| `params={...}` | 쿼리 파라미터 전달 |
| `headers={...}` | 요청 헤더 전달 |
| `response.status_code` | 상태 코드 확인 |
| `response.json()` | JSON 응답 변환 |
| `response.text` | 문자열 응답 조회 |

### ⭐ 한 줄 정리

> **HTTP 요청은 URL·파라미터·헤더를 서버에 전달하고 응답은 상태 코드와 본문을 반환한다.**
