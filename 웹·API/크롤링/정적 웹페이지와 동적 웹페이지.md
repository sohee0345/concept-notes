# 정적 웹페이지와 동적 웹페이지

## 1. 개념

정적 웹페이지는 서버에 저장된 문서를 요청에 따라 전달하고, 동적 웹페이지는 입력·클릭·로그인이나 추가 통신의 결과에 따라 내용이 생성되거나 변경된다.

> **핵심:** 페이지 내용이 언제 만들어지는지에 따라 적합한 수집 도구가 달라진다.

------------------------------------------------------------------------

## 2. 동작 방식

```text
정적 페이지: URL 요청 → 저장된 HTML 응답 → 구조 분석

동적 페이지: 브라우저 실행 → 입력·클릭·추가 통신 → 화면 내용 생성
```

------------------------------------------------------------------------

## 3. 개념 비교

| 구분 | 정적 웹페이지 | 동적 웹페이지 |
| --- | --- | --- |
| 내용 | 저장된 문서를 전달 | 사용자 동작과 통신에 따라 변경 |
| 기본 도구 | requests, BeautifulSoup | Playwright, Selenium |
| 처리 | 응답 HTML을 바로 분석 | 브라우저 실행과 요소 대기가 필요할 수 있음 |

------------------------------------------------------------------------

## 4. 동기와 비동기

동기 방식은 요청의 응답을 받은 뒤 다음 동작을 실행한다. 비동기 방식은 기다리는 시간을 효율적으로 다룰 수 있도록 실행 흐름을 구성하며, Playwright의 비동기 API에서는 `async`와 `await`를 사용한다.
