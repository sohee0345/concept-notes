# 정적 페이지 수집

## 1. 개념

정적 페이지는 URL 요청의 응답에 필요한 HTML이 포함된 페이지이다. `requests`로 HTML을 받고 BeautifulSoup으로 구조를 분석해 정보를 찾는다.

> **핵심:** 정적 HTML 수집은 요청, 응답 본문 확인, 마크업 분석 순서로 진행한다.

---

## 2. 쉽게 이해하기

서버에서 완성된 문서를 내려받은 뒤 문서의 태그 구조를 검색 가능한 형태로 바꾸는 과정이다.

```text
requests 요청 → HTML 문자열 → BeautifulSoup 분석 → 태그·텍스트 탐색
```

---

## 3. 사용 방법

```python
response = requests.get("https://example.com")
soup = BeautifulSoup(response.text, "html.parser")
```

- `response.text` → 응답 본문을 문자열로 읽는다.
- `BeautifulSoup()` → HTML 문자열을 탐색 가능한 구조로 분석한다.
- JSON 응답은 BeautifulSoup 대신 `response.json()`을 사용한다.

---

## 4. 예제

```python
import requests
from bs4 import BeautifulSoup

response = requests.get("https://example.com")
soup = BeautifulSoup(response.text, "html.parser")
print(soup)
```

HTML 응답이 분석되어 태그와 텍스트를 찾을 수 있는 BeautifulSoup 객체가 된다.

---

## 5. 헷갈리는 개념 비교

|구분|HTML 응답|JSON 응답|
|---|---|---|
|처리|BeautifulSoup|`response.json()`|
|형태|마크업 문서|딕셔너리·리스트 구조|
