# 웹 크롤링과 스크래핑

## 1. 개념

웹 크롤링은 정해진 규칙에 따라 여러 웹페이지를 탐색하는 활동이고, 웹 스크래핑은 페이지에서 원하는 정보를 추출하는 활동이다. 실제 데이터 수집에서는 두 과정이 함께 사용되어 크롤링이 넓은 의미로 쓰이기도 한다.

> **핵심:** 크롤링은 페이지 탐색에, 스크래핑은 정보 추출에 초점이 있다.

------------------------------------------------------------------------

## 2. 수집 흐름

```text
대상 페이지 탐색
  ↓
HTML 또는 화면 내용 가져오기
  ↓
구조 분석
  ↓
필요한 데이터 추출
  ↓
저장과 분석
```

------------------------------------------------------------------------

## 3. 활용 예

- 온라인 상품 가격 변화 수집
- 시장 조사와 경쟁사 분석
- 소셜 미디어의 주제별 반응과 동향 수집

수집한 데이터는 목적에 맞게 분석하여 의사결정에 활용할 수 있다.

------------------------------------------------------------------------

## 4. 주의할 점

- 사이트의 이용약관과 `robots.txt`를 확인한다.
- 서버에 부담을 주지 않도록 요청 사이에 간격을 둔다.
- 개인정보와 민감한 정보를 수집하지 않는다.
- 저작권과 상업적 이용 가능 범위를 확인한다.
