# 웹 크롤링과 스크래핑

## 1. 개념

웹 크롤링은 규칙에 따라 여러 웹페이지를 탐색하는 활동이고 웹 스크래핑은 특정 페이지에서 원하는 정보를 추출하는 활동이다.

> **핵심:** 수집 전에 Open API 제공 여부와 사이트 규칙을 확인하고 서버에 부담을 주지 않도록 요청 간격을 둔다.

---

## 2. 쉽게 이해하기

크롤링이 여러 책장을 돌아다니는 과정이라면 스크래핑은 책에서 필요한 문장을 뽑아 기록하는 과정이다.

```text
페이지 탐색 → 내용 가져오기 → 구조 분석 → 정보 추출·저장
```

---

## 3. 사용 방법

- 이용약관과 `robots.txt`를 확인한다.
- 개인정보와 민감 정보를 수집하지 않는다.
- 저작권과 상업적 이용 범위를 확인한다.
- 반복 요청 사이에 `time.sleep()`으로 간격을 둔다.

---

## 4. 예제

```python
import time

for page in range(1, 6):
    # 페이지 요청과 정보 추출
    time.sleep(1)
```

각 요청 사이에 1초를 기다려 짧은 시간에 많은 요청을 보내지 않는다.

---

## 5. 헷갈리는 개념 비교

|구분|정적 페이지|동적 페이지|
|---|---|---|
|내용|요청 응답에 HTML 포함|JavaScript·입력·클릭 후 변경|
|도구|requests, BeautifulSoup|Playwright, Selenium|
