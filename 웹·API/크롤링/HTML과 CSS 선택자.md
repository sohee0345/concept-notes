# HTML과 CSS 선택자

## 1. 개념

HTML은 태그의 계층 구조로 웹페이지 내용을 표현하고, CSS 선택자는 태그·id·class·부모 자식 관계를 기준으로 원하는 요소를 찾는 규칙이다.

> **핵심:** 크롤링할 데이터가 들어 있는 태그의 구조와 id·class를 확인해 선택자를 작성한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
body
  └─ div.item-price
      ├─ div.o-price
      │   └─ span: 27,000원
      └─ div.s-price
          └─ span: 12,900원
```

> **쉽게 말하면:** HTML이 폴더 구조라면 선택자는 원하는 파일까지 찾아가는 경로와 같다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
price_areas = soup.select("body > div")
news_sections = soup.select("#newsct")
```

- `tag` → 해당 이름의 태그
- `#id` → 지정한 id의 요소
- `.class` → 지정한 class의 요소
- `parent > child` → 부모의 바로 아래 자식 요소

> **핵심:** `select()`는 선택자와 일치하는 모든 요소를 리스트로 반환한다.

------------------------------------------------------------------------

## 4. 예제

``` html
<div class="item-price">
    <div class="o-price">
        <span>27,000원</span>
    </div>
</div>
```

``` python
areas = soup.select("body > div")
prices = areas[0].find_all("div", class_="o-price")
text = prices[0].get_text().strip()
print(text)
```

실행 결과:

``` text
27,000원
```

### 코드 해석

- `select()` → CSS 선택자로 영역 검색
- `find_all()` → 태그와 class에 맞는 모든 요소 검색
- `class_` → Python 키워드와 구분한 class 검색 인자
- `get_text()` → 태그를 제외한 텍스트 추출

> **결과 해석:** 가격 영역 안의 원래 가격 요소를 찾아 텍스트만 가져온다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `select()` | `find()` | `find_all()` |
| --- | --- | --- | --- |
| 검색 방식 | CSS 선택자 | 태그·속성 조건 | 태그·속성 조건 |
| 반환 | 일치 요소 리스트 | 첫 요소 또는 없음 | 일치 요소 리스트 |
| 텍스트 추출 | 요소 선택 후 `get_text()` | 바로 `get_text()` 가능 | 각 요소를 순회 |

------------------------------------------------------------------------

## 6. 주의할 점

- `class`는 Python 키워드이므로 BeautifulSoup 인자에는 `class_`를 사용한다.
- `select()`와 `find_all()`은 리스트를 반환하므로 요소 하나를 선택하거나 순회한 뒤 `get_text()`를 호출한다.
- 웹페이지의 HTML 구조나 class 이름이 바뀌면 선택자도 수정해야 한다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `HTML 태그` | 웹페이지의 구조와 내용을 표현 |
| `id` | 요소를 구분하는 식별 속성 |
| `class` | 여러 요소에 사용할 수 있는 분류 속성 |
| `CSS 선택자` | HTML 요소를 찾는 규칙 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `soup.select("#id")` | id로 요소 검색 |
| `soup.select("parent > child")` | 직접 자식 요소 검색 |
| `find_all("div", class_="name")` | class가 일치하는 div 검색 |
| `get_text().strip()` | 텍스트 추출 후 양 끝 공백 제거 |
