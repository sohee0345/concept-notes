# HTTP 요청과 응답

## 1. 개념

HTTP 통신에서는 클라이언트가 서버에 요청을 보내고 서버가 처리 결과를 응답한다. Python의 `requests`를 사용하면 URL, 쿼리 파라미터와 헤더를 구성해 GET 요청을 보내고 Response 객체로 결과를 받을 수 있다.

> **핵심:** 요청에는 대상과 조건·부가 정보를 담고, 응답에서는 상태 코드와 본문을 확인한다.

------------------------------------------------------------------------

## 2. 요청 구성

```python
import requests

response = requests.get(
    url="https://jsonplaceholder.typicode.com/posts",
    params={"userId": "1"},
    headers={"User-Agent": "Mozilla/5.0 ..."},
)
```

- `url` → 요청할 자원의 주소이다.
- `params` → URL의 `?` 뒤에 전달할 조회 조건이다.
- `headers` → 클라이언트 환경 같은 부가 정보이다.

------------------------------------------------------------------------

## 3. 응답 확인

| 상태 코드 범위 | 의미 |
| --- | --- |
| `1xx` | 처리 중임을 알리는 정보 응답 |
| `2xx` | 요청 성공 |
| `3xx` | 리다이렉션 |
| `4xx` | 클라이언트 요청 오류 |
| `5xx` | 서버 처리 오류 |

```python
print(response.status_code)
data = response.json()
```

JSON 응답은 `json()`으로 딕셔너리나 리스트 형태로 변환하고, HTML 같은 문자열 응답은 `response.text`로 읽는다.

------------------------------------------------------------------------

## 4. User-Agent와 Referer

- `User-Agent` → 요청을 보내는 브라우저나 실행 환경 정보이다.
- `Referer` → 현재 자원을 요청하기 전에 방문한 페이지의 URL 정보이다.

두 값은 HTTP 요청 헤더로 전달된다.
