# URL 인코딩과 디코딩

## 1. 개념

URL 인코딩은 한글, 공백, 특수문자 등을 URL로 전송할 수 있는 `%XX` 형태로 바꾸는 과정이다. 디코딩은 인코딩된 문자열을 원래 문자로 복원한다.

> **핵심:** `quote()`로 URL에 사용할 문자열을 인코딩하고 `unquote()`로 원래 문자열을 복원한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
인공지능
  ↓ 인코딩
%EC%9D%B8%EA%B3%B5%EC%A7%80%EB%8A%A5
  ↓ 디코딩
인공지능
```

> **쉽게 말하면:** URL로 보내기 어려운 문자를 전송용 표기로 바꾸었다가 다시 읽을 수 있는 문자로 되돌리는 과정이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
from urllib.parse import quote, unquote

quote("안녕하세요")
unquote("%EC%95%88%EB%85%95")
```

- `quote()` → 원래 문자열을 URL 인코딩
- `unquote()` → 인코딩 문자열을 디코딩
- `%XX` → URL에 표현된 인코딩 단위

> **핵심:** 변환 방향을 구분해 인코딩에는 `quote`, 디코딩에는 `unquote`를 사용한다.

------------------------------------------------------------------------

## 4. 예제

``` python
from urllib import parse

url = (
    "https://search.naver.com/search.naver"
    "?query=%EC%9D%B8%EA%B3%B5%EC%A7%80%EB%8A%A5"
)

print(parse.unquote(url))
```

실행 결과:

``` text
https://search.naver.com/search.naver?query=인공지능
```

### 코드 해석

- `parse.unquote(url)` → URL 전체에서 인코딩된 부분을 원래 문자로 복원한다.
- `%EC...` → 인코딩된 `인공지능` 문자열이다.

> **결과 해석:** 검색어 부분이 읽을 수 있는 한글 문자열로 복원된다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 인코딩 | 디코딩 |
| --- | --- | --- |
| 방향 | 원래 문자 → 전송용 문자열 | 전송용 문자열 → 원래 문자 |
| 함수 | `quote()` | `unquote()` |
| 예시 | `안녕` → `%EC...` | `%EC...` → `안녕` |

------------------------------------------------------------------------

## 6. 주의할 점

- 인코딩과 디코딩의 변환 방향을 반대로 사용하지 않는다.
- URL 전체를 디코딩하면 쿼리 문자열의 인코딩된 값도 함께 복원된다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `URL 인코딩` | 문자를 URL 전송용 형태로 변환 |
| `URL 디코딩` | 인코딩된 값을 원래 문자로 복원 |
| `%XX` | URL의 인코딩된 문자 표기 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `quote(text)` | 문자열 URL 인코딩 |
| `unquote(text)` | URL 인코딩 문자열 복원 |

### ⭐ 한 줄 정리

> **URL 인코딩은 문자를 전송 가능한 표기로 바꾸고 디코딩은 이를 원래 문자로 복원한다.**
