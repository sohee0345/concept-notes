# 상관관계와 데이터 시각화 해석

## 1. 개념

상관관계는 두 변수가 서로 어떤 관계를 가지는지 나타낸다.

기본적으로 두 변수 모두 수치형일 때 관계를 확인하며, 상관관계가 있다고 해서 반드시 원인과 결과 관계라는 뜻은 아니다.

> **핵심:** 상관관계는 두 변수의 관계를 보여주지만 인과관계를 의미하지는 않는다.

---

## 2. 쉽게 이해하기

예:

```text
키 ↔ 몸무게
나이 ↔ 요금
```

처럼 두 숫자형 변수의 관계를 볼 수 있다.

하지만

```text
상관관계 있음
≠
A가 B의 원인
```

이다.

---

## 3. 사용 방법

두 수치형 변수의 관계는 Scatter Plot 등으로 확인할 수 있다.

```python
sns.scatterplot(
    data=df,
    x="x값",
    y="y값"
)
```

통계값만 보지 말고 실제 그래프 모양도 확인해야 한다.

---

## 4. 예제

Anscombe's Quartet은 평균, 분산, 상관계수, 회귀 결과가 비슷해도 실제 그래프 모양은 전혀 다를 수 있음을 보여준다.

```text
통계값 비슷함
       ↓
그래프 확인
       ↓
실제 데이터 모양은 다를 수 있음
```

---

## 5. 헷갈리는 개념 비교

| 구분 | 상관관계 | 인과관계 |
|---|---|---|
| 의미 | 두 변수가 함께 변하는 관계 | 한 변수가 다른 변수에 영향을 줌 |
| 확인 | 통계·그래프 | 추가적인 분석 필요 |
| 주의 | 원인이라고 단정하면 안 됨 | 원인·결과 관계 |

- Anscombe's Quartet → 통계값만 보면 안 되는 대표 예시
