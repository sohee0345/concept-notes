# Sweetviz 데이터 탐색

## 1. 개념

Sweetviz는 데이터셋을 자동으로 분석해 탐색 보고서를 만드는 도구이다. 분석할 컬럼을 선택하고 특정 컬럼을 제외하거나 범주형으로 강제 지정할 수 있다.

> **핵심:** 자동 보고서를 만들기 전에 분석할 컬럼과 각 컬럼의 의미를 올바르게 지정한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
DataFrame 준비
  ↓
필요한 컬럼 선택
  ↓
FeatureConfig 설정
  ↓
sv.analyze()로 보고서 생성
  ↓
Notebook에 보고서 표시
```

> **쉽게 말하면:** Sweetviz는 데이터 표를 넣으면 여러 특징을 자동으로 살펴볼 수 있는 탐색 보고서를 만들어준다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
import sweetviz as sv
import seaborn as sns

df = sns.load_dataset("titanic")

feature_config = sv.FeatureConfig(
    skip="fare",
    force_cat=["survived"],
)

report = sv.analyze(source=df, feat_cfg=feature_config)
report.show_notebook(scale=0.9)
```

- `skip` → 분석에서 제외할 컬럼
- `force_cat` → 범주형으로 처리할 컬럼
- `sv.analyze()` → 분석 보고서 생성
- `show_notebook()` → Notebook 안에 보고서 표시

> **핵심:** 저장된 dtype뿐 아니라 값의 의미를 보고 범주형 처리 여부를 정한다.

------------------------------------------------------------------------

## 4. 예제

Titanic 데이터에서 필요한 컬럼만 고른다.

``` python
df = df[[
    "survived",
    "pclass",
    "sex",
    "age",
    "sibsp",
    "parch",
    "fare",
    "embarked",
]]
```

`survived`는 숫자 `0`, `1`로 저장되지만 각각 사망과 생존이라는 범주를 의미한다.

``` text
0 → 사망
1 → 생존
```

### 코드 해석

- `skip="fare"` → 요금 컬럼을 보고서 분석에서 제외
- `force_cat=["survived"]` → 생존 여부를 수치가 아닌 범주로 처리

> **결과 해석:** Sweetviz는 지정한 설정에 따라 선택한 DataFrame의 자동 탐색 보고서를 생성한다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 저장 자료형 | 데이터의 의미 |
| --- | --- | --- |
| `survived` 예시 | 숫자 `0`, `1` | 사망·생존 범주 |
| 판단 기준 | 파일에 저장된 형식 | 분석에서 값이 나타내는 역할 |
| Sweetviz 설정 | 자동 추론 가능 | 필요하면 `force_cat`으로 지정 |

------------------------------------------------------------------------

## 6. 주의할 점

- 숫자로 저장된 컬럼도 의미에 따라 범주형일 수 있다.
- 보고서 생성 전에 분석에 필요한 컬럼만 선택할 수 있다.
- 실습에서는 보고서 생성 중 글꼴을 찾지 못했다는 경고가 반복되었으므로 보고서 표시 상태를 확인한다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `Sweetviz` | 데이터셋 자동 탐색 보고서 도구 |
| `FeatureConfig` | 컬럼 분석 방식을 설정하는 객체 |
| `skip` | 분석에서 제외할 컬럼 지정 |
| `force_cat` | 범주형으로 처리할 컬럼 지정 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `sv.FeatureConfig(...)` | 컬럼 처리 방식 설정 |
| `sv.analyze(source=df, feat_cfg=...)` | 분석 보고서 생성 |
| `report.show_notebook(scale=0.9)` | Notebook에 보고서 표시 |

### ⭐ 한 줄 정리

> **Sweetviz는 선택한 DataFrame을 자동 탐색하며 FeatureConfig로 제외·범주형 컬럼을 지정할 수 있다.**
