# 왜도와 첨도

## 1. 개념

왜도는 분포의 비대칭 방향과 정도를 나타내고 첨도는 꼬리와 극단값의 성향을 포함한 분포 형태를 나타낸다.

> **핵심:** 왜도의 부호는 긴 꼬리 방향을 나타내며 Pandas의 kurt는 정규분포가 0인 초과첨도이다.

------------------------------------------------------------------------

## 2. 왜도

| 값 | 해석 |
| ---: | --- |
| 0 근처 | 비교적 대칭 |
| 양수 | 오른쪽 꼬리가 김 |
| 음수 | 왼쪽 꼬리가 김 |

```python
df["age"].skew()
```

------------------------------------------------------------------------

## 3. 첨도

```python
df["fare"].kurt()
```

Pandas는 정규분포의 첨도 3에서 3을 뺀 초과첨도를 반환하므로 정규분포 기준은 0이다. 양수가 크면 정규분포보다 두꺼운 꼬리와 극단값 성향을 나타낸다.

------------------------------------------------------------------------

## 4. 주의할 점

- 첨도를 꼭대기의 뾰족함만으로 해석하지 않는다.
- 통계값만 보지 않고 히스토그램과 Box Plot을 함께 확인한다.

------------------------------------------------------------------------

## 🟦 핵심 정리


### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 왜도 | 분포의 비대칭을 나타낸다. |
| 첨도 | 꼬리와 극단값 성향을 나타낸다. |
| 초과첨도 | 정규분포를 0으로 맞춘 첨도이다. |

### ⭐ 한 줄 정리

> **왜도는 긴 꼬리 방향을, 초과첨도는 정규분포 대비 꼬리와 극단값 성향을 보여 준다.**
