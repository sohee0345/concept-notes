# 왜도·첨도와 로그 변환

## 1. 개념

왜도는 분포의 비대칭 방향과 정도를, 첨도는 꼬리와 극단값 발생 성향을 나타낸다. 오른쪽 꼬리가 긴 0 이상의 데이터는 로그 변환으로 큰 값의 차이를 압축할 수 있다.

> **핵심:** 통계량만 보지 말고 변환 전후의 히스토그램과 Box Plot을 함께 비교한다.

---

## 2. 쉽게 이해하기

왜도는 분포가 어느 쪽으로 늘어졌는지, 첨도는 극단값이 나타날 꼬리 성향을 보여 준다. 로그 변환은 큰 값을 상대적으로 더 많이 압축한다.

```text
원본 분포 확인 → 왜도·첨도 계산 → log1p 변환 → 분포 다시 비교
```

---

## 3. 사용 방법

```python
df["age"].skew()
df["fare"].kurt()
df["fare_log"] = np.log1p(df["fare"])
```

- 양의 왜도 → 오른쪽 꼬리가 길다.
- 음의 왜도 → 왼쪽 꼬리가 길다.
- Pandas `kurt()` → 정규분포를 0으로 둔 초과첨도이다.
- `log1p(x)` → $\log(1+x)$를 계산한다.

---

## 4. 예제

```python
print(df["fare"].skew())
print(df["fare_log"].skew())
sns.displot(df, x="fare_log")
sns.boxplot(data=df, y="fare_log")
```

변환 전후의 왜도와 그래프를 비교해 극단값 영향이 줄었는지 확인한다.

---

## 5. 헷갈리는 개념 비교

|구분|왜도|초과첨도|
|---|---|---|
|의미|비대칭 방향과 정도|꼬리와 극단값 성향|
|기준 0|대칭에 가까움|정규분포와 비슷함|
