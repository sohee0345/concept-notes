# Sweetviz

## 1. 개념

Sweetviz는 DataFrame의 컬럼별 분포와 관계를 자동으로 분석해 탐색 보고서를 만드는 라이브러리이다.

> **핵심:** 분석할 컬럼과 자료형 해석을 지정한 뒤 자동 탐색 보고서를 생성한다.

------------------------------------------------------------------------

## 2. 사용 방법

```python
import sweetviz as sv

feature_config = sv.FeatureConfig(
    skip="fare",
    force_cat=["survived"],
)

report = sv.analyze(source=df, feat_cfg=feature_config)
report.show_notebook(scale=0.9)
```

- `skip` → 분석에서 제외할 컬럼을 정한다.
- `force_cat` → 숫자로 저장된 값을 범주형으로 처리한다.
- `analyze()` → DataFrame 분석 보고서를 만든다.
- `show_notebook()` → 보고서를 노트북에 표시한다.

------------------------------------------------------------------------

## 3. 숫자 코드 해석

`survived`의 0과 1은 연속적인 크기가 아니라 사망과 생존이라는 범주를 구분한다. `force_cat`으로 의미에 맞는 자료형 해석을 지정할 수 있다.
