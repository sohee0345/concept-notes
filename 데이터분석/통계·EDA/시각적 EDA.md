# 시각적 EDA

## 1. 개념

시각적 EDA는 요약 통계량과 그래프를 함께 확인하여 데이터의 관계, 분포, 이상치와 구조를 탐색하는 과정이다.

> **핵심:** 비슷한 통계량을 가진 데이터도 모양이 다를 수 있으므로 실제 그래프를 함께 확인한다.

---

## 2. 쉽게 이해하기

숫자 요약은 데이터의 짧은 설명이고 그래프는 실제 생김새이다. 둘을 함께 봐야 숨은 패턴을 찾을 수 있다.

```text
자료형·결측 확인 → 요약 통계 → 그래프 → 관계·이상치 해석
```

---

## 3. 사용 방법

- 상관관계는 두 변수 관계의 방향과 정도를 나타내지만 인과관계를 뜻하지 않는다.
- 앤스콤 4분할은 통계량이 비슷해도 그래프 모양이 다를 수 있음을 보여 준다.
- Sweetviz는 컬럼별 분포와 관계를 자동 분석해 보고서를 만든다.

---

## 4. 예제

```python
feature_config = sv.FeatureConfig(skip="fare", force_cat=["survived"])
report = sv.analyze(source=df, feat_cfg=feature_config)
report.show_notebook(scale=0.9)
```

`survived`처럼 숫자로 저장된 범주를 범주형으로 강제하고 분석에서 제외할 컬럼을 지정한다.

---

## 5. 헷갈리는 개념 비교

|구분|상관관계|인과관계|
|---|---|---|
|의미|함께 변하는 방향과 정도|한 변수가 다른 변수의 원인이 되는 관계|
|해석|원인을 보장하지 않음|추가 근거가 필요함|
