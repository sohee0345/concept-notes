# 왜도와 첨도와 로그 변환

## 1. 개념

왜도는 분포의 비대칭 정도, 첨도는 꼬리 두께와 극단값 발생 정도를 나타낸다. 오른쪽 꼬리가 긴 양수 데이터에는 로그 변환을 적용해 큰 값의 영향과 치우침을 줄일 수 있다.

> **핵심:** 왜도는 꼬리 방향으로 부호를 정하고 Pandas `kurt()`는 초과첨도를 반환한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
오른쪽 꼬리가 김 → 양의 왜도
왼쪽 꼬리가 김   → 음의 왜도

큰 양수 값의 차이가 큼
  ↓ log1p()
값의 차이와 치우침 완화
```

> **쉽게 말하면:** 왜도는 어느 쪽으로 꼬리가 늘어졌는지, 첨도는 극단값이 얼마나 나타나기 쉬운지를 살핀다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
df["age"].skew()
df["fare"].kurt()

df["fare_log"] = np.log1p(df["fare"])
df["fare_log"].skew()
df["fare_log"].kurt()
```

- `skew()` → 왜도 계산
- `kurt()` → Pandas 초과첨도 계산
- `np.log1p(x)` → $\log(1+x)$ 변환

> **핵심:** 변환 전후의 분포·왜도·첨도를 비교해 효과를 확인한다.

------------------------------------------------------------------------

## 4. 예제

``` text
fare_log 왜도: 0.3949280095189306
fare 첨도: 33.39814088089868
fare_log 첨도: 0.976142106683104
```

### 코드 해석

- 원래 `fare` → 매우 큰 양의 초과첨도
- `log1p` 변환 후 → 큰 값의 차이가 줄고 초과첨도가 낮아짐

> **결과 해석:** Titanic 요금 데이터에서는 로그 변환 후 분포의 극단적인 특성이 완화되었다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 왜도 | 첨도 |
| --- | --- | --- |
| 확인 내용 | 좌우 비대칭 | 꼬리 두께와 극단값 정도 |
| Pandas 코드 | `skew()` | `kurt()` |
| 정규분포 기준 | `0` | 초과첨도 `0` |

------------------------------------------------------------------------

## 6. 주의할 점

- 실습 주석과 달리 양의 왜도는 오른쪽 꼬리, 음의 왜도는 왼쪽 꼬리가 길다.
- Pearson 첨도의 정규분포 기준은 3이지만 Pandas `kurt()`는 3을 뺀 초과첨도를 반환하므로 기준이 0이다.
- 로그 변환이 제곱근 변환보다 항상 좋은 것은 아니다.
- 정규분포가 모든 모델에 반드시 필요한 것은 아니므로 결과를 확인해 변환 여부를 정한다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `왜도` | 분포의 비대칭 정도 |
| `양의 왜도` | 오른쪽 꼬리가 긴 분포 |
| `음의 왜도` | 왼쪽 꼬리가 긴 분포 |
| `초과첨도` | Pearson 첨도에서 3을 뺀 값 |
| `로그 변환` | 큰 양수 값의 차이와 치우침을 줄이는 변환 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `series.skew()` | 왜도 계산 |
| `series.kurt()` | 초과첨도 계산 |
| `np.log1p(series)` | 0을 포함할 수 있는 로그 변환 |
