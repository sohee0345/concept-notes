# 결측치 확인과 처리

## 1. 개념

결측치는 값이 없거나 관측되지 않은 상태이다. 결측치 처리에서는 개수·비율·발생 원인을 먼저 확인한 뒤 삭제하거나 적절한 값으로 대체한다.

> **핵심:** 결측치를 무조건 지우거나 채우지 말고 원인과 분포 변화를 함께 확인한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
결측치 발견
  ↓
개수·비율·발생 패턴 확인
  ↓
삭제 또는 대체 방법 선택
  ↓
결측치와 분포 다시 확인
```

> **쉽게 말하면:** 빈칸이 왜 생겼는지 살핀 뒤 자료를 버릴지 알맞은 값으로 채울지 결정한다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
df.isnull().sum()

missing_ratio = (
    df.isnull().sum() / df.shape[0]
).sort_values(ascending=False)
```

- `isnull()` → 결측치 여부를 True·False로 반환
- `sum()` → True를 1로 계산해 결측치 개수 확인
- 행 개수로 나누기 → 결측치 비율 계산
- `sort_values(ascending=False)` → 많은 항목부터 확인

> **핵심:** 개수와 비율을 함께 보고 중요한 항목이 위에 오도록 정렬한다.

------------------------------------------------------------------------

## 4. 예제

``` python
df["age_mean"] = df["age"].fillna(df["age"].mean())
df["age_median"] = df["age"].fillna(df["age"].median())

embarked_mode = df["embarked"].mode().values[0]
df["embarked"] = df["embarked"].fillna(embarked_mode)
```

### 코드 해석

- `mean()` → 평균으로 수치형 결측치 대체
- `median()` → 중앙값으로 수치형 결측치 대체
- `mode().values[0]` → 첫 번째 최빈값 선택
- `fillna()` → 선택한 값으로 결측치 채우기

> **결과 해석:** 처리 후 `isnull().sum()`으로 결측치가 남았는지 다시 확인해야 한다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 방법 | 특징 | 주의점 |
| --- | --- | --- |
| 평균 대체 | 계산이 간단함 | 이상치 영향, 평균 주변 집중 |
| 중앙값 대체 | 이상치에 비교적 안정적 | 중앙값 주변 집중 |
| 최빈값 대체 | 범주형에 사용 가능 | 특정 범주 비율 증가 |
| 무작위 표본 대체 | 원래 분포를 덜 왜곡할 수 있음 | 다른 변수와의 관계는 보존하지 못할 수 있음 |
| 삭제 | 결측값을 제거 | 데이터 손실 가능 |

------------------------------------------------------------------------

## 6. 주의할 점

- 숫자 `0`은 실제 값이며 결측치가 아니다.
- 결측 비율만으로 고정된 삭제·대체 규칙을 적용하지 않는다.
- 결측치가 있는 숫자 컬럼은 일반 `int`로 바로 변환할 때 오류가 날 수 있다.
- Series를 조건 위치에 대입하면 인덱스를 맞추므로 의도와 다르게 결측치가 남을 수 있다.

무작위 표본의 값만 순서대로 대입하려면 다음처럼 인덱스를 제거한다.

``` python
random_sampling = df["age"].dropna().sample(
    n=df["age"].isnull().sum(),
    random_state=42,
)

df["age_random"] = df["age"].copy()
df.loc[df["age_random"].isnull(), "age_random"] = (
    random_sampling.to_numpy()
)
```

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `결측치` | 값이 없거나 관측되지 않은 상태 |
| `MCAR` | 완전히 우연히 발생한 결측 |
| `MAR` | 관측된 다른 Feature와 관련된 결측 |
| `MNAR` | 결측값 자체나 관측되지 않은 요인과 관련된 결측 |
| `대체` | 결측치를 평균·중앙값·최빈값 등으로 채우는 처리 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `df.isnull().sum()` | 컬럼별 결측치 개수 |
| `df.fillna(value)` | 결측치 대체 |
| `df.dropna()` | 결측치 제거 |
| `series.sample()` | 무작위 표본 추출 |
| `series.to_numpy()` | 인덱스를 제외한 값 사용 |
