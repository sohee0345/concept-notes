# 데이터 유형과 EDA

## 1. 개념

데이터는 저장 구조에 따라 정형·반정형·비정형으로, 값의 의미에 따라 수치형·범주형으로 나눌 수 있다. EDA는 분석 전에 데이터의 구조와 특징을 탐색하는 과정이다.

> **핵심:** 저장된 dtype만 보지 말고 데이터의 실제 의미까지 확인한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
데이터 확보
  ↓
구조와 자료형 확인
  ↓
분포·결측치·이상치·관계 탐색
  ↓
분석과 전처리 방향 결정
```

> **쉽게 말하면:** EDA는 데이터를 본격적으로 사용하기 전에 어떤 모습이고 어떤 문제가 있는지 살펴보는 건강검진이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
df.shape
df.columns
df.info()
df.head()
df.tail()

df.select_dtypes(include=np.number)
df.select_dtypes(exclude=np.number)
df.describe()
```

- `shape` → 행과 열 개수
- `info()` → non-null 개수와 dtype
- `select_dtypes()` → dtype 기준 컬럼 선택
- `describe()` → 기술통계 확인

> **핵심:** 자동으로 선택한 자료형이 데이터의 의미와 맞는지 다시 검토한다.

------------------------------------------------------------------------

## 4. 예제

| 분류 | 종류 | 예시 |
| --- | --- | --- |
| 저장 구조 | 정형 | Excel, 관계형 데이터베이스 |
| 저장 구조 | 반정형 | XML, JSON |
| 저장 구조 | 비정형 | 텍스트, 이미지 |
| 수치형 | 연속형 | 키, 몸무게, 요금 |
| 수치형 | 이산형 | 승객 수, 형제 수 |
| 범주형 | 순서형 | 객실 등급 |
| 범주형 | 명목형 | 성별, 혈액형 |

`survived`는 정수 `0`, `1`로 저장되지만 사망과 생존을 구분하므로 의미상 범주형이다.

> **결과 해석:** 저장 dtype과 분석에서 사용하는 데이터 유형은 항상 같지 않다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 수치형 | 범주형 |
| --- | --- | --- |
| 역할 | 크기나 양을 측정 | 종류나 그룹을 구분 |
| 세부 유형 | 연속형, 이산형 | 순서형, 명목형 |
| 판단 기준 | 숫자 계산의 의미 | 값이 나타내는 종류의 의미 |

------------------------------------------------------------------------

## 6. 주의할 점

- 숫자로 저장된 값도 코드나 등급을 뜻하면 범주형일 수 있다.
- `exclude=np.number`에는 문자열뿐 아니라 `category`, `bool`도 포함될 수 있다.
- `describe()` 결과는 수치형과 범주형에서 서로 다르다.
