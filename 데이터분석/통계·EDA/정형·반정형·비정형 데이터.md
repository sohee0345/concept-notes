# 정형·반정형·비정형 데이터

## 1. 개념

데이터는 구조가 얼마나 명확하게 정해져 있는지에 따라 정형, 반정형, 비정형으로 구분할 수 있다.

> **핵심:** 고정된 표 구조의 유무와 구조 정보를 표현하는 방식이 구분 기준이다.

------------------------------------------------------------------------

## 2. 비교

| 구분 | 특징 | 예시 |
| --- | --- | --- |
| 정형 | 행과 열의 고정된 스키마 | RDB 테이블, Excel 표 |
| 반정형 | 키·태그로 구조를 표현 | JSON, XML |
| 비정형 | 고정된 표 구조가 없음 | 텍스트, 이미지 |

------------------------------------------------------------------------

## 🟦 핵심 정리


### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 정형 데이터 | 고정된 행·열 구조를 가진다. |
| 반정형 데이터 | 키나 태그에 구조 정보가 들어 있다. |
| 비정형 데이터 | 일정한 스키마가 없는 데이터이다. |

### ⭐ 한 줄 정리

> **데이터의 고정 구조와 구조 표현 방식에 따라 정형·반정형·비정형으로 구분한다.**
