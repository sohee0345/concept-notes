# 데이터 유형과 기술통계

## 1. 개념

EDA에서는 데이터 구조와 변수의 실제 의미를 확인한 뒤 기술통계로 분포를 요약한다. 저장 자료형이 같아도 분석 목적에 따라 수치형·범주형 해석이 달라질 수 있다.

> **핵심:** 저장 dtype만 보지 말고 변수의 의미와 측정 방식을 기준으로 유형을 판단한다.

---

## 2. 쉽게 이해하기

숫자로 저장됐더라도 생존 여부처럼 종류를 나타내면 범주형이고, 승객 수처럼 개수를 나타내면 이산형이다.

```text
구조 확인 → 변수 의미 확인 → 유형 분류 → 기술통계 확인
```

---

## 3. 사용 방법

- 정형·반정형·비정형 → 고정된 표 구조의 정도로 구분한다.
- 연속형·이산형 → 측정값과 개수형 수치로 구분한다.
- 명목형·순서형 → 순서가 없는 범주와 순서가 있는 범주이다.
- `select_dtypes()` → 저장 자료형 기준으로 컬럼을 선택한다.
- `describe()` → 자료형에 맞는 기술통계를 보여 준다.

---

## 4. 예제

```python
numeric = df.select_dtypes(include=np.number)
non_numeric = df.select_dtypes(exclude=np.number)
numeric.describe()
pd.crosstab(df["pclass"], df["survived"])
```

교차표는 두 범주형 변수 조합의 빈도를 보여 준다.

---

## 5. 헷갈리는 개념 비교

|구분|수치형|범주형|
|---|---|---|
|하위 유형|연속형·이산형|명목형·순서형|
|판단|크기와 연산의 의미|종류와 순서의 의미|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|기술통계|데이터 분포를 요약하는 통계|
|수치형|크기와 계산에 의미가 있는 변수|
|범주형|종류나 등급을 구분하는 변수|

### 💻 주요 코드

|코드|의미|
|---|---|
|`df.select_dtypes()`|저장 자료형별 컬럼 선택|
|`df.describe()`|기술통계 확인|
|`pd.crosstab()`|범주형 변수 교차표 생성|
|`astype()`|자료형 변경|
