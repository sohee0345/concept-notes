# 기술통계와 EDA

## 1. 개념

EDA는 모델링 전에 데이터의 구조, 분포, 결측치, 이상치와 변수 관계를 탐색하는 과정이다. 기술통계는 데이터를 개수·평균·표준편차·사분위수 등으로 요약한다.

> **핵심:** 요약 통계와 시각화를 함께 사용해 데이터의 실제 모습을 확인한다.

------------------------------------------------------------------------

## 2. 기본 확인

```python
df.shape
df.head()
df.tail()
df.info()
df.describe()
```

수치형 `describe()`와 범주형 `describe()`가 제공하는 통계는 다르다.

------------------------------------------------------------------------

## 3. 자료형별 선택

```python
numeric = df.select_dtypes(include=np.number)
non_numeric = df.select_dtypes(exclude=np.number)
```

저장 자료형 기준 선택 후 변수의 실제 의미를 다시 확인한다.
