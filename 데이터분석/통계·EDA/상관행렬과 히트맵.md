# 상관행렬과 히트맵

## 1. 개념

상관행렬은 여러 수치형 변수 쌍의 상관계수를 표로 정리한 것이고 히트맵은 값의 크기를 색으로 표현한다.

> **핵심:** 상관행렬로 선형 관계를 요약하고 히트맵으로 전체 패턴을 빠르게 확인한다.

------------------------------------------------------------------------

## 2. 사용 방법

```python
corr = df.select_dtypes(include=np.number).corr()

sns.heatmap(
    corr,
    vmin=-1,
    vmax=1,
    annot=True,
    cmap="coolwarm",
)
```

- `annot=True` → 각 칸에 상관계수를 표시한다.
- `vmin`, `vmax` → 색상 범위를 -1부터 1로 고정한다.

------------------------------------------------------------------------

## 3. 해석

| 값 | 의미 |
| ---: | --- |
| 1 근처 | 강한 양의 선형 관계 |
| -1 근처 | 강한 음의 선형 관계 |
| 0 근처 | 선형 관계가 약함 |

------------------------------------------------------------------------

## 4. 주의할 점

- 0이라고 모든 관계가 없는 것은 아니다.
- 상관관계는 인과관계를 뜻하지 않는다.
- 숫자 코드로 저장된 범주형 컬럼의 의미를 확인한다.
