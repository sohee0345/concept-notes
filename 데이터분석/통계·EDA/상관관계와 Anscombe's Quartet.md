# 상관관계와 Anscombe's Quartet

## 1. 개념

상관관계는 두 변수가 서로 어떤 관계를 가지는지 나타낸다. Anscombe's Quartet은 요약 통계량이 비슷한 데이터도 그래프로 보면 전혀 다른 형태일 수 있음을 보여준다.

> **핵심:** 상관계수와 같은 통계량만 보지 말고 실제 데이터의 그래프도 확인한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
여러 데이터 그룹
  ↓
평균·분산·상관계수·회귀 결과는 비슷함
  ↓
그래프로 시각화
  ↓
분포와 패턴은 서로 다름
```

> **쉽게 말하면:** 성적표의 평균이 같아도 학생별 점수 모양은 다를 수 있으므로 숫자 요약과 실제 모양을 함께 봐야 한다.

------------------------------------------------------------------------

## 3. 사용 방법

- 관계를 확인할 두 수치형 변수를 정한다.
- Scatter Plot으로 실제 점의 분포를 확인한다.
- 상관관계와 그래프에서 보이는 패턴을 함께 해석한다.
- 이상치나 특이한 곡선 형태가 있는지 살핀다.

> **핵심:** 상관관계가 비슷하더라도 점들이 놓인 모양은 다를 수 있다.

------------------------------------------------------------------------

## 4. 예제

``` text
키 ↔ 몸무게 → 두 수치형 변수의 관계
나이 ↔ 요금 → 두 수치형 변수의 관계
```

Anscombe's Quartet의 여러 그룹은 다음 통계량이 비슷할 수 있다.

- 평균
- 분산
- 상관계수
- 회귀 결과

하지만 그래프로 그리면 선형 패턴, 곡선 패턴, 이상치의 영향 등 서로 다른 모습이 나타날 수 있다.

> **결과 해석:** 하나의 통계량만으로 데이터 구조를 모두 설명할 수 없다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 상관관계 | 인과관계 |
| --- | --- | --- |
| 의미 | 두 변수가 함께 변하는 관계 | 한 변수가 다른 변수의 원인이 되는 관계 |
| 해석 | 관련성이 있음을 나타냄 | 원인과 결과를 설명함 |
| 주의 | 원인을 증명하지 않음 | 별도의 근거가 필요함 |

------------------------------------------------------------------------

## 6. 주의할 점

- 상관관계가 있다고 반드시 원인과 결과 관계인 것은 아니다.
- 요약 통계량만으로 이상치나 비선형 패턴을 확인하기 어렵다.
- 수업에서는 기본적으로 수치형 변수끼리의 상관관계를 다뤘다.
