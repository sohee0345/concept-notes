# 이상치와 Box Plot

## 1. 개념

이상치는 다른 관측값과 크게 떨어져 있는 잠재적인 특이값이다. Box Plot은 사분위수와 IQR을 이용해 데이터의 중심, 퍼짐, 잠재적 이상치를 한눈에 보여준다.

> **핵심:** Box Plot 밖의 점은 확인이 필요한 후보이지 자동으로 삭제해야 하는 오류가 아니다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
Q1 ├────[ 가운데 50% │ 중앙값 ]────┤ Q3
            박스 = Q1~Q3

수염 밖의 점 → 잠재적 이상치
```

> **쉽게 말하면:** 데이터 대부분이 모인 가운데 범위와 멀리 떨어진 값을 함께 보여주는 그래프이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
sns.boxplot(data=df, y="fare")
sns.boxplot(data=df, y="fare_log")
```

- 박스 아래 → `Q1`, 25% 지점
- 박스 안의 선 → 중앙값 `Q2`, 50% 지점
- 박스 위 → `Q3`, 75% 지점
- 박스 → `Q1~Q3`, 가운데 50% 범위
- 수염 밖의 점 → 잠재적 이상치

> **핵심:** 원본 값과 변환한 값을 같은 종류의 그래프로 비교할 수 있다.

------------------------------------------------------------------------

## 4. 예제

``` python
sns.boxplot(data=df, y="fare")
sns.boxplot(data=df, y="fare_log")
```

### 코드 해석

- 첫 그래프 → 원래 요금의 분포와 잠재적 이상치 확인
- 두 번째 그래프 → 로그 변환 후 요금 분포 확인

> **결과 해석:** 로그 변환 전후의 Box Plot을 비교하면 큰 값의 영향이 어떻게 달라졌는지 볼 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | Histogram | Box Plot |
| --- | --- | --- |
| 주요 목적 | 구간별 빈도와 분포 모양 | 사분위수와 잠재적 이상치 확인 |
| 중심 정보 | 막대의 빈도 | 중앙값 |
| 이상치 확인 | 직접 판단하기 어려움 | 수염 밖의 점으로 후보 표시 |

------------------------------------------------------------------------

## 6. 주의할 점

- 수염 밖의 점이 반드시 잘못된 데이터라는 뜻은 아니다.
- 박스 아래·위 경계는 정상 데이터의 하위·상위 25%가 아니라 각각 Q1과 Q3이다.
- 이상치 처리 여부는 데이터의 의미를 확인한 뒤 결정한다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `Q1` | 제1사분위수, 25% 지점 |
| `Q2` | 중앙값, 50% 지점 |
| `Q3` | 제3사분위수, 75% 지점 |
| `IQR` | Q3와 Q1 사이의 범위 |
| `이상치 후보` | 일반적으로 수염 밖에 표시되는 점 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `sns.boxplot(data=df, y="col")` | 컬럼의 Box Plot 생성 |

### ⭐ 한 줄 정리

> **Box Plot은 사분위수와 IQR로 분포를 요약하고 멀리 떨어진 값을 잠재적 이상치로 표시한다.**
