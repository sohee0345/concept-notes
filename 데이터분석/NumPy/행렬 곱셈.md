# 행렬 곱셈

## 1. 개념

행렬 곱셈은 앞 행렬의 행과 뒤 행렬의 열을 대응시켜 계산하는 연산이다. 앞 행렬의 열 개수와 뒤 행렬의 행 개수가 같아야 한다.

> **핵심:** `(a, b) × (b, c)`만 계산할 수 있으며 결과 Shape은 `(a, c)`이다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
(2, 4) × (4, 8)
     ↑     ↑
     4  =  4  → 계산 가능

바깥 차원만 남음 → (2, 8)
```

> **쉽게 말하면:** 가운데 숫자가 같아야 연결할 수 있고, 연결하고 나면 양 끝 숫자가 결과에 남는다.

------------------------------------------------------------------------

## 3. 사용 방법

- 앞 행렬의 열 개수와 뒤 행렬의 행 개수가 같은지 확인한다.
- 앞 행렬의 각 행과 뒤 행렬의 각 열을 대응시켜 곱한 뒤 더한다.
- 결과 Shape에는 앞 행렬의 행 개수와 뒤 행렬의 열 개수가 남는다.

> **핵심:** 같은 위치끼리 계산하는 원소별 곱셈과 앞 행·뒤 열을 이용하는 행렬 곱셈을 구분한다.

------------------------------------------------------------------------

## 4. 예제

``` text
A = [[1, 2],
     [3, 4]]

B = [[5, 6],
     [7, 8]]

AB = [[1×5 + 2×7, 1×6 + 2×8],
      [3×5 + 4×7, 3×6 + 4×8]]
   = [[19, 22],
      [43, 50]]
```

실행 결과:

``` text
[[19 22]
 [43 50]]
```

### 코드 해석

- 첫 번째 결과 원소 → `A`의 첫 행과 `B`의 첫 열을 곱해 더함
- 결과 Shape → `(2, 2) × (2, 2) → (2, 2)`

> **결과 해석:** 행렬 곱셈의 각 결과 원소는 앞 행렬의 한 행과 뒤 행렬의 한 열의 내적이다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 원소별 곱셈 | 행렬 곱셈 |
| --- | --- | --- |
| 계산 기준 | 같은 위치 | 앞 행과 뒤 열 |
| 계산 | 같은 위치의 원소끼리 곱함 | 앞 행과 뒤 열을 곱해 더함 |
| Shape 조건 | 같은 Shape 등 브로드캐스팅 가능 조건 | 앞 열 개수와 뒤 행 개수가 같아야 함 |

------------------------------------------------------------------------

## 6. 주의할 점

- 행렬 곱셈은 일반적으로 `AB ≠ BA`이므로 순서가 중요하다.
- 순서를 바꾸면 결과가 달라지거나 Shape이 맞지 않아 계산할 수 없을 수 있다.
- 여러 행렬은 앞에서부터 차례로 중간 결과 Shape을 확인한다.
