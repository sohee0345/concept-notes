# 불리언 인덱싱

## 1. 개념

불리언 인덱싱은 배열 비교로 만든 True·False 배열을 인덱스로 사용하여 조건을 만족하는 원소만 선택하는 방법이다.

> **핵심:** NumPy의 여러 조건은 `&`, `|`로 결합하고 각 비교식을 괄호로 묶는다.

---

## 2. 쉽게 이해하기

각 원소에 조건 검사를 붙여 통과한 위치만 골라내는 필터와 같다.

```text
배열 비교 → 불리언 배열 → True 위치의 원소 선택
```

---

## 3. 사용 방법

```python
arr[(arr >= 10) & (arr < 15)]
arr[(arr < 5) | (arr > 15)]
np.where(arr > 5, 1, 0)
```

- `&` → 두 조건을 모두 만족한다.
- `|` → 두 조건 중 하나 이상을 만족한다.
- `np.where()` → 조건에 따라 위치별 값을 선택한다.

---

## 4. 예제

```python
arr = np.arange(20)
print(arr[(arr >= 10) & (arr < 15)])
```

실행 결과:

```text
[10 11 12 13 14]
```

두 조건이 모두 True인 위치의 값만 반환한다.

---

## 5. 헷갈리는 개념 비교

|구분|Python 논리 연산|NumPy 원소별 논리 연산|
|---|---|---|
|AND|`and`|`&`|
|OR|`or`|`|`|

|---|---|
|불리언 배열|각 원소의 조건 결과를 담은 배열|

|코드|의미|
