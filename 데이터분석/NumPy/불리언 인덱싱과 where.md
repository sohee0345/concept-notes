# 불리언 인덱싱과 where

## 1. 개념

불리언 인덱싱은 배열의 각 원소에 조건을 적용하고 결과가 `True`인 위치의 원소만 선택하는 방법이다. `np.where()`는 같은 조건에 따라 각 위치에 반환할 값을 정한다.

> **핵심:** 불리언 인덱싱은 조건에 맞는 원소를 추출하고 where는 조건에 따라 값을 선택한다.

------------------------------------------------------------------------

## 2. 조건으로 원소 선택

```python
arr = np.arange(20)

selected = arr[(arr >= 10) & (arr < 15)]
```

실행 결과:

```text
[10, 11, 12, 13, 14]
```

NumPy 배열 조건은 `&`와 `|`로 결합하고 각 비교식을 괄호로 묶는다.

------------------------------------------------------------------------

## 3. np.where()

```python
result = np.where(arr > 5, 1, 0)
```

조건이 참인 위치에는 1, 거짓인 위치에는 0이 들어간 새 배열을 반환한다.

------------------------------------------------------------------------

## 4. 주의할 점

- 배열 전체 조건에는 Python의 `and`, `or` 대신 `&`, `|`를 사용한다.
- 연산 순서를 분명히 하기 위해 각 비교식을 괄호로 묶는다.
- 조건식의 결과 shape은 비교 대상 배열과 같다.

------------------------------------------------------------------------
