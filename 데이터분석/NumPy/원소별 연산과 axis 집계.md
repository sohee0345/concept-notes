# 원소별 연산과 axis 집계

## 1. 개념

NumPy의 기본 산술 연산은 대응하는 위치의 원소끼리 계산한다. 합계·최댓값 같은 집계 연산은 `axis`를 지정해 특정 축을 따라 계산할 수 있다.

> **핵심:** 기본 산술 연산은 원소별로 수행되고 axis 집계는 지정한 축을 결과에서 없앤다.

------------------------------------------------------------------------

## 2. 원소별 연산

```python
arr = np.array([1, 2])

arr * arr  # [1, 4]
arr * 2    # [2, 4]
```

배열끼리 `*`를 사용하면 같은 위치의 원소를 곱한다. 이는 행렬 곱셈과 다른 연산이다.

------------------------------------------------------------------------

## 3. axis 집계

```python
matrix = np.array([[1, 2, 3], [4, 5, 6]])

matrix.sum()        # 21
matrix.sum(axis=0)  # [5, 7, 9]
matrix.sum(axis=1)  # [6, 15]
```

```text
shape (2, 3)
  ├─ axis=0 집계 → shape (3,)
  └─ axis=1 집계 → shape (2,)
```

------------------------------------------------------------------------

## 4. 주의할 점

- 세로·가로 방향만 외우기보다 어느 축이 사라지는지 확인한다.
- 축을 지정하지 않은 집계는 배열 전체를 하나의 값으로 줄인다.
- 연산 전에 배열의 shape을 확인한다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 원소별 연산 | 같은 위치의 원소끼리 계산한다. |
| 집계 | 여러 원소를 합계나 최댓값으로 줄인다. |
| `axis` | 집계하며 제거할 축을 지정한다. |

### ⭐ 한 줄 정리

> **NumPy 산술은 대응 원소끼리 계산하고 axis를 지정한 집계는 해당 축을 따라 값을 줄인다.**
