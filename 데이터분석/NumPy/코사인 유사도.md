# 코사인 유사도

## 1. 개념

코사인 유사도는 두 벡터 사이 각도의 코사인 값으로 방향이 얼마나 비슷한지 측정한다.

> **핵심:** 벡터의 절대적인 길이보다 방향의 유사성을 비교한다.

------------------------------------------------------------------------

## 2. 계산식

$$
\operatorname{cos\_sim}(\mathbf{a},\mathbf{b})
=\frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|_2\|\mathbf{b}\|_2}
$$

| 값 | 의미 |
| ---: | --- |
| `1` | 같은 방향 |
| `0` | 직교 |
| `-1` | 반대 방향 |

------------------------------------------------------------------------

## 3. 주의할 점

- 각도가 커지면 코사인 값이 작아지는 것이며 벡터 길이가 줄어드는 것은 아니다.
- 영벡터는 크기가 0이어서 식의 분모가 0이 되므로 코사인 유사도를 계산할 수 없다.

------------------------------------------------------------------------
