# Norm과 거리

## 1. 개념

Norm은 벡터 자체의 크기 또는 길이를 측정하는 방법이다. 두 벡터의 차이에 Norm을 적용하면 두 벡터 사이의 거리를 구할 수 있다.

> **핵심:** Norm은 벡터 하나의 크기이고 Distance는 두 벡터 사이의 차이에 대한 크기이다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
벡터 A
  ↓ Norm
A 자체의 크기

벡터 A - 벡터 B
  ↓ Norm
A와 B 사이의 거리
```

> **쉽게 말하면:** 한 위치가 원점에서 얼마나 떨어졌는지는 Norm이고, 두 위치가 서로 얼마나 떨어졌는지는 Distance이다.

------------------------------------------------------------------------

## 3. 사용 방법

- L1 Norm → 각 원소에 절댓값을 취한 뒤 모두 더한다.
- L2 Norm → 각 원소를 제곱해 더한 뒤 제곱근을 구한다.
- 두 벡터 사이의 거리 → 두 벡터를 먼저 뺀 뒤 차이 벡터의 Norm을 구한다.

> **핵심:** 거리를 구할 때는 두 벡터의 차이를 먼저 구한 뒤 Norm을 계산한다.

------------------------------------------------------------------------

## 4. 예제

``` text
A = [1, 2]
B = [4, 6]
A - B = [-3, -4]

L1 거리 = |-3| + |-4| = 7
L2 거리 = √((-3)² + (-4)²) = 5
```

### 코드 해석

- `a - b` → `[-3, -4]`
- L1 → `|-3| + |-4| = 7`
- L2 → $\sqrt{(-3)^2 + (-4)^2} = 5$

> **결과 해석:** 같은 두 벡터도 어떤 Norm을 사용하느냐에 따라 거리가 다르게 계산된다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | L1 Norm | L2 Norm |
| --- | --- | --- |
| 계산 | 절댓값 → 합 | 제곱 → 합 → 제곱근 |
| 두 벡터 사이 거리 | Manhattan Distance | Euclidean Distance |
| 예시 `[-3, -4]` | `7` | `5` |

------------------------------------------------------------------------

## 6. 주의할 점

- Norm과 Distance를 같은 말로 사용하지 않는다. Distance는 두 벡터의 차이에 Norm을 적용한 값이다.
- L1과 L2는 계산 방식이 다르므로 같은 벡터에도 다른 값을 낼 수 있다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `Norm` | 벡터 자체의 크기 또는 길이 |
| `L1 Norm` | 원소 절댓값의 합 |
| `L2 Norm` | 원소 제곱합의 제곱근 |
| `Distance` | 두 벡터 차이에 Norm을 적용한 값 |

### ⭐ 한 줄 정리

> **L1은 절댓값의 합, L2는 제곱합의 제곱근이며 두 벡터의 차이에 적용하면 거리가 된다.**
