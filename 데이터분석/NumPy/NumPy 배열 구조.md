# NumPy 배열 구조

## 1. 개념

NumPy 배열은 축의 개수에 따라 스칼라, 벡터, 행렬, 고차원 배열로 구분된다. 배열 구조는 `ndim`, `shape`, `size`, `dtype`으로 정확하게 확인한다.

> **핵심:** 배열을 이해할 때는 차원 수, 각 축의 크기, 전체 원소 수, 원소 자료형을 함께 확인한다.

---

## 2. 쉽게 이해하기

축은 배열에서 위치를 지정하는 방향이다. 숫자 하나는 0차원, 한 줄은 1차원, 행과 열이 있는 표는 2차원이다.

```text
스칼라 0차원 → 벡터 1차원 → 행렬 2차원 → 고차원 배열
```

---

## 3. 사용 방법

```python
scalar = np.array(3)
vector = np.array([1, 2, 3])
matrix = np.array([[1, 2, 3], [4, 5, 6]])

print(matrix.ndim, matrix.shape, matrix.size, matrix.dtype)
```

- `ndim` → 축의 개수이다.
- `shape` → 각 축의 크기를 나타내는 튜플이다.
- `size` → 전체 원소 수이다.
- `dtype` → 원소의 자료형이다.

---

## 4. 예제

```python
matrix = np.array([[1, 2], [3, 4], [5, 6]])
print(matrix.shape)
print(matrix.ndim)
print(matrix.size)
```

실행 결과:

```text
(3, 2)
2
6
```

3행 2열의 2차원 배열이며 전체 원소는 6개이다.

---

## 5. 헷갈리는 개념 비교

|구분|`(3)`|`(3,)`|
|---|---|---|
|자료형|정수|원소 하나인 튜플|
|의미|숫자 3|길이 3인 1차원 shape 표현|

### 💡 주요 개념
