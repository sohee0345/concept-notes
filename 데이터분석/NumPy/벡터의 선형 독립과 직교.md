# 벡터의 선형 독립과 직교

## 1. 개념

벡터의 관계는 내적과 선형 결합으로 설명할 수 있다. 직교는 내적이 0인 관계이고, 선형 독립은 어느 벡터도 나머지 벡터의 선형 결합으로 표현되지 않는 관계이다.

> **핵심:** 직교는 각도와 내적의 관계이고 선형 독립은 정보의 중복 여부와 관련된 선형 결합의 관계이다.

------------------------------------------------------------------------

## 2. 관계 비교

| 관계 | 판단 기준 |
| --- | --- |
| 직교 | 두 벡터의 내적이 0 |
| 선형 독립 | 0이 아닌 계수로 만든 선형 결합이 영벡터가 될 수 없음 |
| 선형 종속 | 어느 벡터가 나머지 벡터의 선형 결합으로 표현됨 |

두 벡터에서 한쪽이 다른 쪽의 배수이면 선형 종속이다.

```text
[2, 4] = 2 × [1, 2]
[-1, -2] = -1 × [1, 2]
```

------------------------------------------------------------------------

## 3. 주의할 점

- 반대 방향도 음수 배수이므로 선형 종속이다.
- 두 영벡터가 아닌 직교 벡터는 선형 독립이다.
- 선형 독립은 두 벡터만이 아니라 여러 벡터의 선형 결합으로 판단한다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 직교 | 내적이 0인 관계이다. |
| 선형 독립 | 벡터가 서로 선형 결합으로 중복되지 않는다. |
| 선형 종속 | 한 벡터가 다른 벡터들의 선형 결합으로 표현된다. |

### ⭐ 한 줄 정리

> **내적이 0이면 직교하고 벡터 사이에 선형 결합 중복이 없으면 선형 독립이다.**
