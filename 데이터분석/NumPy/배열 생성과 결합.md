# 배열 생성과 결합

## 1. 개념

NumPy는 정해진 값이나 범위로 배열을 만드는 함수와 여러 배열을 세로 또는 가로로 결합하는 함수를 제공한다.

> **핵심:** 원하는 shape과 초기값에 맞는 생성 함수를 선택하고 결합 방향에 따라 vstack과 hstack을 구분한다.

---

## 2. 쉽게 이해하기

빈 표의 크기와 채울 값을 먼저 정하거나, 같은 크기의 표를 아래 또는 옆에 이어 붙이는 과정이다.

```text
shape·초기값 지정 → 배열 생성 → 방향 선택 → 배열 결합
```

---

## 3. 사용 방법

- `np.zeros(shape)` → 0으로 채운 배열을 만든다.
- `np.ones(shape)` → 1로 채운 배열을 만든다.
- `np.full(shape, value)` → 지정한 값으로 채운다.
- `np.eye(n)` → 단위행렬을 만든다.
- `np.arange(n)` → 0부터 n 직전까지의 배열을 만든다.
- `vstack()`, `hstack()` → 세로와 가로로 결합한다.

---

## 4. 예제

```python
arr1 = np.array([[1, 1], [2, 2]])
arr2 = np.array([[3, 3], [4, 4]])

print(np.vstack((arr1, arr2)))
print(np.hstack((arr1, arr2)))
```

`vstack()`은 행 방향으로 아래에 쌓고 `hstack()`은 열 방향으로 옆에 붙인다.

---

## 5. 헷갈리는 개념 비교

|구분|`vstack()`|`hstack()`|
|---|---|---|
|방향|세로로 쌓음|가로로 붙임|
|늘어나는 축|행|열|
