# 배열 생성과 결합

## 1. 개념

NumPy는 Python 데이터로 배열을 만들거나 일정한 값과 범위로 배열을 생성하는 함수를 제공한다. 여러 배열은 행 또는 열 방향으로 이어 붙일 수 있다.

> **핵심:** 필요한 shape과 값의 규칙에 맞는 생성 함수를 선택하고 결합 방향을 확인한다.

------------------------------------------------------------------------

## 2. 배열 생성 함수

```python
import numpy as np

np.array([1, 2, 3])
np.zeros((2, 3))
np.ones((2, 3))
np.full((2, 3), 5)
np.eye(3)
np.arange(5)
```

| 함수 | 결과 |
| --- | --- |
| `array()` | 전달한 데이터로 배열 생성 |
| `zeros()` | 0으로 채운 배열 생성 |
| `ones()` | 1로 채운 배열 생성 |
| `full()` | 지정한 값으로 채운 배열 생성 |
| `eye()` | 단위행렬 생성 |
| `arange()` | 일정 범위의 연속된 값 생성 |

------------------------------------------------------------------------

## 3. 배열 결합

```python
arr1 = np.array([[1, 1], [2, 2]])
arr2 = np.array([[3, 3], [4, 4]])

np.vstack((arr1, arr2))
np.hstack((arr1, arr2))
```

- `vstack()` → 배열을 위아래로 쌓는다.
- `hstack()` → 배열을 좌우로 붙인다.

------------------------------------------------------------------------

## 4. 주의할 점

- 결합하지 않는 방향의 크기가 서로 맞아야 한다.
- `zeros()`와 `ones()`는 기본적으로 실수형 배열을 만든다.
- `np.eye(n)`은 대각선이 1이고 나머지가 0인 정사각행렬을 만든다.
