# 배열 생성과 reshape

## 1. 개념

NumPy는 일정한 값이나 연속된 값으로 배열을 만들고, `reshape()`로 전체 원소 수를 유지하면서 배열의 shape를 바꿀 수 있다.

> **핵심:** 배열 생성 함수로 초기값을 만들고 reshape 전후의 전체 원소 수가 같은지 확인한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
원소 20개인 1차원 배열
  ↓ reshape(4, 5)
같은 원소 20개인 4×5 배열
```

> **쉽게 말하면:** 같은 개수의 블록을 버리지 않고 행과 열의 배치만 다시 정리하는 것이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
np.zeros((3, 5))
np.ones((5, 3))
np.full((2, 3), 5)
np.eye(3)
np.arange(20)
```

- `zeros()` → 0으로 채운 배열
- `ones()` → 1로 채운 배열
- `full()` → 지정한 값으로 채운 배열
- `eye()` → 단위행렬
- `arange()` → 범위의 연속된 값 배열

> **핵심:** shape는 튜플로 전달하고 함수별 초기값의 차이를 구분한다.

------------------------------------------------------------------------

## 4. 예제

``` python
arr = np.arange(20)

matrix = arr.reshape(4, 5)
auto = arr.reshape(4, -1)
column = arr[:, np.newaxis]
float_arr = arr.reshape(2, -1, 2).astype(np.float32)
```

실행 결과의 shape:

``` text
matrix.shape    → (4, 5)
auto.shape      → (4, 5)
column.shape    → (20, 1)
float_arr.shape → (2, 5, 2)
```

### 코드 해석

- `-1` → 남은 축 크기 자동 계산
- `np.newaxis` → 크기 1인 축 추가
- `astype(np.float32)` → dtype을 float32로 변환

> **결과 해석:** 원소 개수는 유지하면서 차원을 늘리거나 축별 크기를 변경할 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `reshape()` | `np.newaxis` | `astype()` |
| --- | --- | --- | --- |
| 변경 대상 | 전체 shape | 크기 1인 새 축 | dtype |
| 원소 수 | 유지 | 유지 | 유지 |
| 예시 | `(20,) → (4,5)` | `(20,) → (20,1)` | `int → float32` |

------------------------------------------------------------------------

## 6. 주의할 점

- 원소 20개를 `(5, 5)`로 바꾸면 필요한 원소가 25개이므로 `ValueError`가 발생한다.
- `reshape()`에서 자동 계산할 축은 `-1`로 표시한다.
- shape와 dtype은 서로 다른 정보이다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `배열 생성` | shape와 초기값을 지정해 배열 만들기 |
| `reshape` | 원소 수를 유지하며 shape 변경 |
| `newaxis` | 크기 1인 축 추가 |
| `astype` | dtype 변환 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `np.arange(n)` | 0부터 n-1까지 배열 생성 |
| `np.eye(n)` | n×n 단위행렬 생성 |
| `arr.reshape(...)` | shape 변경 |
| `arr[:, np.newaxis]` | 축 추가 |
| `arr.astype(dtype)` | dtype 변환 |
