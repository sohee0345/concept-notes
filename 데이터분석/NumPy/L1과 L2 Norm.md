# L1과 L2 Norm

## 1. 개념

Norm은 벡터의 크기를 수치로 측정한다. L1 Norm은 절댓값의 합이고 L2 Norm은 제곱합의 제곱근이다.

> **핵심:** Norm은 벡터 하나의 크기를, 차이 벡터의 Norm은 두 벡터 사이의 거리를 나타낸다.

------------------------------------------------------------------------

## 2. 계산식

$$
\|\mathbf{x}\|_1=\sum_i |x_i|
$$

$$
\|\mathbf{x}\|_2=\sqrt{\sum_i x_i^2}
$$

| 구분 | 계산 | 관련 거리 |
| --- | --- | --- |
| L1 | 절댓값을 더함 | Manhattan Distance |
| L2 | 제곱을 더하고 제곱근 | Euclidean Distance |

------------------------------------------------------------------------

## 3. 거리 예제

```text
A = [1, 2], B = [4, 6]
A - B = [-3, -4]

L1 거리 = 3 + 4 = 7
L2 거리 = √(3² + 4²) = 5
```
