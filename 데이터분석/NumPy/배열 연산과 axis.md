# 배열 연산과 axis

## 1. 개념

NumPy 배열의 기본 산술연산은 같은 위치의 원소끼리 계산한다. 집계 함수에서 `axis`를 지정하면 해당 축을 따라 계산하고 그 축을 결과에서 제거한다.

> **핵심:** 연산 전 배열 shape를 확인하고 축별 집계 후 결과 shape를 예측한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
shape (2, 3)

axis=0 집계 → 0번째 축 제거 → shape (3,)
axis=1 집계 → 1번째 축 제거 → shape (2,)
```

> **쉽게 말하면:** axis는 어느 방향의 값들을 묶어 계산하고 그 방향을 없앨지 정한다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
a = np.array([[1, 2, 3], [4, 5, 6]])

a.sum()
a.sum(axis=0)
a.sum(axis=1)
a.max(axis=1)
```

- 축 생략 → 전체 원소 집계
- `axis=0` → 0번째 축을 따라 집계
- `axis=1` → 1번째 축을 따라 집계

> **핵심:** “가로·세로”만 외우기보다 제거되는 축과 결과 shape를 확인한다.

------------------------------------------------------------------------

## 4. 예제

``` python
a = np.array([
    [1, 2, 3],
    [4, 5, 6],
])

print(a.sum())
print(a.sum(axis=0))
print(a.sum(axis=1))
```

실행 결과:

``` text
21
[5, 7, 9]
[6, 15]
```

### 코드 해석

- `a.sum()` → 모든 원소를 합쳐 스칼라 반환
- `axis=0` → 두 행 사이의 같은 열 위치를 합산
- `axis=1` → 각 행 안의 열 값을 합산

> **결과 해석:** 같은 2차원 배열도 axis에 따라 결과의 값과 shape가 달라진다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `a * b` | 축별 집계 |
| --- | --- | --- |
| 동작 | 같은 위치 원소끼리 연산 | 한 축의 여러 값을 하나로 집계 |
| 차원 | 일반적으로 유지 | 지정한 축 제거 |
| 예시 | 원소별 곱셈 | `sum(axis=0)` |

------------------------------------------------------------------------

## 6. 주의할 점

- 배열의 `*`는 원소별 곱셈이며 행렬 곱셈과 다르다.
- 2차원에서만 방향을 외우면 고차원 배열에서 혼동하기 쉬우므로 축 번호를 기준으로 이해한다.
- 전체 집계는 여러 차원을 모두 없애 스칼라가 될 수 있다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `원소별 연산` | 같은 위치의 원소끼리 계산 |
| `집계 함수` | 합계·최댓값 등 여러 값을 요약 |
| `axis` | 집계하면서 제거할 축 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `a + b` | 원소별 덧셈 |
| `a * b` | 원소별 곱셈 |
| `a.sum()` | 전체 합계 |
| `a.sum(axis=0)` | 0번째 축 합계 |
| `a.max(axis=1)` | 1번째 축을 따라 최댓값 계산 |

### ⭐ 한 줄 정리

> **NumPy는 원소별로 배열을 연산하며 axis를 지정한 집계는 해당 축을 제거한 결과를 만든다.**
