# 벡터 관계와 코사인 유사도

## 1. 개념

두 벡터는 방향과 배수 관계에 따라 직교, 1차 독립, 1차 종속으로 구분할 수 있다. 코사인 유사도는 두 벡터의 길이가 아니라 방향이 얼마나 비슷한지를 나타낸다.

> **핵심:** 배수 관계로 1차 독립·종속을 판단하고, 코사인 값으로 방향의 유사성을 해석한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
같은 직선 위의 방향 → 한 벡터가 다른 벡터의 배수 → 1차 종속
배수로 표현 불가    → 서로 다른 정보                → 1차 독립
90°로 만남          → 내적과 코사인 유사도가 0      → 직교
```

> **쉽게 말하면:** 두 화살표가 같은 줄 위에 있으면 종속이고, 직각이면 직교이며, 그 밖에 배수로 만들 수 없으면 독립이다.

------------------------------------------------------------------------

## 3. 사용 방법

- 한 벡터가 다른 벡터의 배수인지 확인해 1차 독립·종속을 판단한다.
- 두 벡터가 90°를 이루고 내적이 `0`이면 직교이다.
- 코사인 유사도는 `1`, `0`, `-1`을 기준으로 같은 방향·직교·반대 방향을 해석한다.

> **핵심:** 코사인 유사도는 내적을 두 벡터 길이의 곱으로 나누어 방향만 비교한다.

------------------------------------------------------------------------

## 4. 예제

``` text
A = [1, 2]
B = [2, 4]   → B = 2A  → 1차 종속, 같은 방향
C = [-1, -2] → C = -A  → 1차 종속, 반대 방향
```

| 코사인 유사도 | 의미 |
| ---: | --- |
| `1` | 같은 방향 |
| `0` | 직교, 90° |
| `-1` | 완전히 반대 방향 |

> **결과 해석:** 양의 배수와 음의 배수는 모두 1차 종속이지만 코사인 유사도의 부호로 방향을 구분할 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 직교 | 1차 독립 | 1차 종속 |
| --- | --- | --- | --- |
| 기준 | 두 벡터가 90° | 배수로 표현할 수 없음 | 한 벡터가 다른 벡터의 배수 |
| 내적 | `0` | 반드시 `0`인 것은 아님 | 방향에 따라 양수 또는 음수 가능 |
| 정보 관계 | 방향적 관련성이 없음 | 서로 다른 정보 | 정보가 중복됨 |

------------------------------------------------------------------------

## 6. 주의할 점

- 벡터 사이의 각도가 커진다고 벡터 자체의 길이가 짧아지는 것은 아니다. 각도가 커질수록 코사인 값이 작아진다.
- 음의 배수도 1차 종속이다.
- 직교하는 두 영이 아닌 벡터는 1차 독립이지만, 모든 1차 독립 벡터가 직교하는 것은 아니다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `직교` | 두 벡터가 90°를 이루는 관계 |
| `1차 독립` | 한 벡터를 다른 벡터의 배수로 표현할 수 없는 관계 |
| `1차 종속` | 한 벡터가 다른 벡터의 배수인 관계 |
| `코사인 유사도` | 벡터 방향의 유사성을 나타내는 값 |
