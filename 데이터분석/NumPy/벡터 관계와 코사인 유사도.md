# 벡터 관계와 코사인 유사도

## 1. 개념

벡터는 내적과 선형 결합을 통해 직교·선형 독립·선형 종속 관계를 판단할 수 있다. 코사인 유사도는 두 벡터 사이 각도의 코사인 값으로 방향의 유사성을 측정한다.

> **핵심:** 직교는 내적, 독립성은 선형 결합, 방향 유사성은 코사인 유사도로 판단한다.

---

## 2. 쉽게 이해하기

벡터가 어느 방향을 가리키는지, 한 벡터를 다른 벡터들로 만들 수 있는지를 확인하는 방법이다.

```text
내적 0 → 직교
한 벡터가 다른 벡터의 배수 → 선형 종속
방향 비교 → 코사인 유사도
```

---

## 3. 사용 방법

$$
\mathrm{cos\_sim}(\mathbf{a},\mathbf{b})
=\frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|_2\|\mathbf{b}\|_2}
$$

- 코사인 값 `1` → 같은 방향
- 코사인 값 `0` → 직교
- 코사인 값 `-1` → 반대 방향

---

## 4. 예제

`A=[1,2]`, `B=[2,4]`이면 `B=2A`이므로 두 벡터는 선형 종속이다. 배수가 음수여도 종속 여부는 바뀌지 않는다.

---

## 5. 헷갈리는 개념 비교

|구분|직교|선형 독립|선형 종속|
|---|---|---|---|
|판단|내적이 0|서로의 선형 결합으로 표현 불가|0이 아닌 계수의 결합이 영벡터|
