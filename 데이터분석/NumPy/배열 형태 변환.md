# 배열 형태 변환

## 1. 개념

`reshape()`는 원소 순서를 유지하면서 배열의 shape을 바꾼다. 변환 전후의 전체 원소 수는 같아야 하며 새 축과 자료형도 별도로 변경할 수 있다.

> **핵심:** 배열 형태를 바꿀 때는 전체 원소 수를 유지하고 결과 shape을 확인한다.

---

## 2. 쉽게 이해하기

같은 개수의 블록을 버리지 않고 행과 열 배치만 다시 정리하는 과정이다.

```text
원소 수 확인 → 새 shape 지정 → 결과 shape 검증
```

---

## 3. 사용 방법

```python
arr = np.arange(20)
matrix = arr.reshape(4, 5)
tensor = arr.reshape(2, -1, 2)
column = arr[:, np.newaxis]
floats = tensor.astype(np.float32)
```

- `-1` → 나머지 축과 원소 수로 크기를 자동 계산한다.
- `np.newaxis` → 크기 1인 새 축을 추가한다.
- `astype()` → 원소 자료형을 변환한다.

---

## 4. 예제

```python
arr = np.arange(20)
print(arr.reshape(4, 5).shape)
print(arr.reshape(2, -1, 2).shape)
```

실행 결과:

```text
(4, 5)
(2, 5, 2)
```

두 변환 모두 전체 원소 수 20을 유지한다.

---

## 5. 헷갈리는 개념 비교

|구분|`reshape()`|`astype()`|
|---|---|---|
|변경|배열 모양|원소 자료형|
|유지|전체 원소 수|배열 shape|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|reshape|원소 수를 유지한 shape 변경|
|새 축|크기 1인 차원 추가|
|형 변환|원소 dtype 변경|

### 💻 주요 코드

|코드|의미|
|---|---|
|`arr.reshape(4, -1)`|한 축을 자동 계산해 변환|
|`arr[:, np.newaxis]`|새 축 추가|
|`arr.astype(np.float32)`|자료형 변환|

### ⭐ 한 줄 정리

> **배열 형태 변환은 원소 수를 유지하며 reshape, newaxis, astype을 목적에 맞게 사용한다.**
