# reshape와 차원 변환

## 1. 개념

`reshape()`는 배열의 원소 순서를 유지하면서 shape을 바꾼다. 차원 변환 전후의 전체 원소 수는 반드시 같아야 한다.

> **핵심:** reshape은 데이터를 추가하거나 삭제하지 않고 배열의 모양만 바꾼다.

------------------------------------------------------------------------

## 2. 사용 방법

```python
arr = np.arange(20)

arr.reshape(4, 5)
arr.reshape(2, -1, 2)
```

`-1`은 전체 원소 수와 다른 축의 크기를 바탕으로 한 축의 크기를 자동 계산한다.

------------------------------------------------------------------------

## 3. 새 축과 자료형

```python
column = arr[:, np.newaxis]
floats = arr.reshape(2, -1, 2).astype(np.float32)
```

- `np.newaxis` → 길이가 1인 새 축을 추가한다.
- `astype()` → 배열 원소의 자료형을 변환한다.

------------------------------------------------------------------------

## 4. 주의할 점

20개 원소를 가진 배열을 `(5, 5)`로 바꾸려면 25개 원소가 필요하므로 오류가 발생한다. 목표 shape의 크기를 모두 곱해 기존 `size`와 같은지 확인한다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `reshape` | 전체 원소 수를 유지하며 shape을 바꾼다. |
| `-1` | 한 축의 크기를 자동 계산한다. |
| `np.newaxis` | 길이가 1인 축을 추가한다. |

### ⭐ 한 줄 정리

> **reshape의 목표 shape은 기존 배열과 전체 원소 수가 같아야 한다.**
