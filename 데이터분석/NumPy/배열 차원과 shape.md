# 배열 차원과 shape

## 1. 개념

NumPy 배열은 축의 개수인 차원과 각 축의 크기인 shape를 가진다. 전체 원소 수는 `size`, 원소 자료형은 `dtype`으로 확인한다.

> **핵심:** 배열 구조는 `ndim`, `shape`, `size`, `dtype`을 함께 확인해 이해한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
스칼라  shape ()        ndim 0
벡터    shape (3,)      ndim 1
행렬    shape (2, 3)    ndim 2
3차원   shape (2, 2, 3) ndim 3
```

> **쉽게 말하면:** ndim은 방향이 몇 개인지, shape는 각 방향으로 데이터가 몇 개씩 있는지를 나타낸다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
import numpy as np

arr = np.array([
    [1, 2, 3],
    [4, 5, 6],
])

arr.ndim   # 2
arr.shape  # (2, 3)
arr.size   # 6
arr.dtype
```

- `ndim` → 축의 개수
- `shape` → 축별 크기 튜플
- `size` → 전체 원소 개수
- `dtype` → 원소 자료형

> **핵심:** shape의 숫자 개수는 ndim과 같고 shape의 숫자를 모두 곱하면 size가 된다.

------------------------------------------------------------------------

## 4. 예제

``` python
scalar = np.array(3)
vector = np.array([1, 2, 3])
matrix = np.array([[1, 2, 3], [4, 5, 6]])

print(scalar.shape, scalar.ndim)
print(vector.shape, vector.ndim)
print(matrix.shape, matrix.ndim)
```

실행 결과:

``` text
() 0
(3,) 1
(2, 3) 2
```

### 코드 해석

- `()` → 축이 없는 0차원 배열
- `(3,)` → 크기 3인 축 하나
- `(2, 3)` → 행 방향 크기 2, 열 방향 크기 3

> **결과 해석:** 같은 `np.array()`로 만들어도 입력 구조에 따라 차원과 shape가 달라진다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `(3)` | `(3,)` |
| --- | --- | --- |
| Python 타입 | `int` | `tuple` |
| 의미 | 정수 3 | 원소 하나인 튜플 |
| shape 표기 | 사용하지 않음 | 1차원 배열의 shape 형태 |

------------------------------------------------------------------------

## 6. 주의할 점

- 대괄호 개수만 추측하지 말고 `ndim`과 `shape`을 확인한다.
- `(2, 2, 3)`의 size는 $2 \times 2 \times 3 = 12$이다.
- shape는 튜플이므로 1차원도 `(3,)`처럼 쉼표가 표시된다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `ndim` | 배열의 차원 수 |
| `shape` | 각 축의 크기 |
| `size` | 전체 원소 개수 |
| `dtype` | 원소 자료형 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `np.array(data)` | 배열 생성 |
| `arr.ndim` | 차원 확인 |
| `arr.shape` | shape 확인 |
| `arr.size` | 원소 수 확인 |
| `arr.dtype` | 자료형 확인 |

### ⭐ 한 줄 정리

> **NumPy 배열은 ndim으로 차원 수를, shape로 축별 크기를, size로 전체 원소 수를 확인한다.**
