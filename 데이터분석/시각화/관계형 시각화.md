# 관계형 시각화

## 1. 개념

관계형 시각화는 두 수치형 변수의 관계나 순서에 따른 변화를 표현한다. 산점도는 관측값의 관계를, 선 그래프는 추세를 보여 준다.

> **핵심:** 산점도와 선 그래프에 색상·모양·크기·패싯을 추가해 여러 정보를 함께 비교할 수 있다.

---

## 2. 쉽게 이해하기

산점도는 점의 퍼짐으로 관계를 보고 선 그래프는 점을 순서대로 이어 변화 흐름을 본다.

```text
수치 관계 → scatter
순서·시간 변화 → line
범주 분리 → hue·style·row·col
```

---

## 3. 사용 방법

```python
sns.relplot(data=tips, x="total_bill", y="tip", kind="scatter", hue="smoker", style="time")
sns.relplot(data=fmri, x="timepoint", y="signal", kind="line", row="event", col="region")
```

- `hue` → 색상으로 범주를 구분한다.
- `style` → 점 모양으로 범주를 구분한다.
- `size` → 점 크기로 수치 정보를 표현한다.
- `row`, `col` → 범주별 패널을 만든다.

---

## 4. 예제

```python
num = 50
x = np.random.randn(num)
y = np.random.randn(num)
area = (30 * np.random.rand(num)) ** 2
colors = np.random.rand(num)

plt.scatter(x, y, s=area, c=colors, alpha=0.5, cmap="coolwarm")
plt.colorbar()
plt.show()
```

Matplotlib의 `scatter()`에서는 `s`, `c`, `alpha`, `cmap`으로 크기·색상·투명도·색상표를 지정하고 `colorbar()`로 색상 값을 읽는다.
