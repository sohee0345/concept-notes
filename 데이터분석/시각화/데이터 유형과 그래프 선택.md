# 데이터 유형과 그래프 선택

## 1. 개념

좋은 그래프는 변수의 자료형과 확인하려는 질문에 맞아야 한다. 먼저 수치형과 범주형을 구분하고 관계, 추세, 분포, 그룹 비교 중 목적을 정한다.

> **핵심:** 그래프 함수보다 먼저 데이터 유형과 분석 질문을 결정한다.

------------------------------------------------------------------------

## 2. 선택 기준

| 질문 | 그래프 |
| --- | --- |
| 두 수치의 관계는? | 산점도 |
| 시간에 따른 변화는? | 선 그래프 |
| 수치가 어떻게 분포하는가? | 히스토그램·KDE |
| 그룹별 중앙값·분포·이상치는? | 상자 그림 |
| 범주별 수치를 비교하면? | 막대그래프 |

------------------------------------------------------------------------

## 3. 숫자로 저장된 범주

`survived`의 0과 1처럼 숫자는 크기 계산보다 상태를 구분하는 코드일 수 있다. 저장 자료형만 보지 말고 값의 의미를 확인한다.
