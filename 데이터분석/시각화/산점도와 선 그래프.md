# 산점도와 선 그래프

## 1. 개념

산점도는 두 수치형 변수의 관계를 점으로 나타내고, 선 그래프는 순서나 시간에 따른 값의 변화와 추세를 나타낸다.

> **핵심:** 산점도는 변수 간 관계, 선 그래프는 순서에 따른 변화를 확인한다.

------------------------------------------------------------------------

## 2. Seaborn 예제

```python
sns.relplot(
    data=tips,
    x="total_bill",
    y="tip",
    kind="scatter",
    hue="smoker",
    style="time",
)

sns.relplot(
    data=fmri,
    x="timepoint",
    y="signal",
    kind="line",
    row="event",
    col="region",
)
```

- `hue`, `style` → 범주별 색과 모양을 구분한다.
- `size` → 수치에 따라 점 크기를 바꾼다.
- `row`, `col` → 범주별로 그래프 패널을 나눈다.
