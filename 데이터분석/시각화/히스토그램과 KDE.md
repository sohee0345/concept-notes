# 히스토그램과 KDE

## 1. 개념

히스토그램은 수치 범위를 구간으로 나누어 빈도를 막대로 표시하고, KDE는 값이 모인 정도를 부드러운 밀도 곡선이나 등고선으로 표현한다.

> **핵심:** 두 그래프 모두 수치 분포를 보여 주지만 표현 방식이 다르다.

------------------------------------------------------------------------

## 2. 사용 방법

```python
sns.displot(
    data=penguins,
    x="flipper_length_mm",
    hue="species",
    multiple="dodge",
)

sns.displot(
    data=penguins,
    x="bill_length_mm",
    y="bill_depth_mm",
    kind="kde",
    cbar=True,
)
```

- `hue` → 그룹별 분포를 색으로 나눈다.
- `col` → 그룹별 그래프를 별도 패널에 배치한다.
- `cbar` → 2차원 KDE의 밀도 수준을 색상 막대로 표시한다.

------------------------------------------------------------------------

## 3. 히스토그램과 막대그래프

히스토그램의 막대는 연속된 수치 구간의 빈도를 나타내고, 막대그래프는 서로 구분되는 범주별 수치를 비교한다.

------------------------------------------------------------------------

## 🟦 핵심 정리


### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 히스토그램 | 구간별 데이터 빈도를 나타낸다. |
| KDE | 부드러운 형태로 데이터 밀도를 나타낸다. |
| Color Bar | 색상과 밀도 수준의 대응 관계를 보여 준다. |

### ⭐ 한 줄 정리

> **히스토그램은 구간별 빈도를, KDE는 부드럽게 추정한 밀도 분포를 보여 준다.**
