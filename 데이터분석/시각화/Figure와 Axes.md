# Figure와 Axes

## 1. 개념

Matplotlib에서 Figure는 그래프를 담는 전체 도화지이고, Axes는 실제 데이터가 그려지는 개별 좌표 영역이다.

> **핵심:** 하나의 Figure 안에 하나 이상의 Axes를 배치할 수 있다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
Figure = 전체 도화지
  ├─ Axes 1 = 첫 번째 그래프 영역
  ├─ Axes 2 = 두 번째 그래프 영역
  └─ Axes 3 = 세 번째 그래프 영역
```

> **쉽게 말하면:** Figure는 종이 한 장이고 Axes는 그 종이 위에 나눈 각각의 그래프 칸이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
import matplotlib.pyplot as plt

plt.figure()
plt.axes()
plt.show()
```

- `plt.figure()` → Figure 생성
- `plt.axes()` → Axes 생성
- `plt.show()` → 완성된 그래프 출력

여러 Axes가 필요하면 `subplots()`를 사용한다.

``` python
fig, ax = plt.subplots(2, 2, figsize=(15, 5))
```

> **핵심:** `subplots(2, 2)`는 2행 × 2열의 Axes 4개를 만든다.

------------------------------------------------------------------------

## 4. 예제

``` python
fig, ax = plt.subplots(2, 2, figsize=(15, 5))
fig.suptitle("도화지 제목")

ax[0, 0].plot(np.arange(5))
ax[0, 1].plot(np.arange(2, 7))
ax[0, 1].set_title("그래프 제목")

plt.show()
```

실행 결과:

``` text
Figure 한 개 안에 2행 × 2열의 Axes 4개 생성
```

### 코드 해석

- `fig.suptitle()` → Figure 전체 제목 설정
- `ax[0, 0]` → 첫 번째 행, 첫 번째 열의 Axes
- `ax[0, 1].set_title()` → 첫 번째 행, 두 번째 열의 제목 설정

> **결과 해석:** `ax[row, col]`로 원하는 그래프 영역을 선택해 각각 다른 그래프를 그릴 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | Figure | Axes |
| --- | --- | --- |
| 의미 | 전체 도화지 | 개별 그래프 좌표 영역 |
| 제목 | `fig.suptitle()` | `ax.set_title()` |
| 개수 | 전체 출력의 바깥 틀 | Figure 안에 여러 개 배치 가능 |

------------------------------------------------------------------------

## 6. 주의할 점

- `figsize=(가로, 세로)` 순서로 크기를 지정한다.
- `ax[row, col]`의 행과 열 위치를 바꾸지 않도록 주의한다.
- 한 Axes에서 `plot()`을 여러 번 호출하면 여러 선이 같은 좌표 영역에 표시된다.

------------------------------------------------------------------------

### 💡 주요 개념

| --- | --- |
| `Figure` | 그래프를 담는 전체 도화지 |
| `Axes` | 실제 그래프가 그려지는 좌표 영역 |
| `subplots()` | Figure와 여러 Axes를 함께 생성 |

| 코드 | 의미 |
| --- | --- |

| `fig.suptitle()` | 전체 제목 설정 |
| `ax[row, col].set_title()` | 개별 제목 설정 |
