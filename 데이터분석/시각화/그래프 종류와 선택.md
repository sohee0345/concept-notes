# 그래프 종류와 선택

## 1. 개념

그래프는 데이터의 종류와 확인하려는 목적에 따라 선택한다. 관계, 추세, 분포, 그룹별 비교 중 무엇이 궁금한지 먼저 정해야 한다.

> **핵심:** 데이터가 수치형인지 범주형인지 확인하고 질문에 맞는 그래프를 고른다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
두 숫자의 관계      → Scatter Plot
시간에 따른 변화    → Line Plot
숫자 하나의 분포    → Histogram / KDE
그룹별 분포와 이상치 → Box Plot
범주별 수치 비교    → Bar Plot
```

> **쉽게 말하면:** 그래프를 먼저 고르는 것이 아니라 데이터에 묻고 싶은 질문을 먼저 정한다.

------------------------------------------------------------------------

## 3. 사용 방법

| 궁금한 내용 | 그래프 | 주요 데이터 |
| --- | --- | --- |
| 두 변수의 관계 | Scatter Plot | 수치형 + 수치형 |
| 변화와 추세 | Line Plot | 시간 기준 + 수치형 |
| 수치 분포 | Histogram, KDE | 수치형 |
| 분포·중앙값·이상치 비교 | Box Plot | 범주형 + 수치형 |
| 범주별 값 비교 | Bar Plot | 범주형 + 수치형 |

``` text
x축 → 비교하거나 나누는 기준
y축 → 궁금한 값
```

> **핵심:** 요일별 팁처럼 기준은 x축에, 확인하려는 수치 값은 y축에 둔다.

------------------------------------------------------------------------

## 4. 예제

``` python
sns.relplot(data=tips, x="total_bill", y="tip", kind="scatter")
sns.relplot(data=fmri, x="timepoint", y="signal", kind="line")
sns.displot(data=penguins, x="flipper_length_mm")
sns.catplot(data=tips, x="day", y="tip", kind="box")
```

### 코드 해석

- `scatter` → 총 결제 금액과 팁의 관계 확인
- `line` → 시간 지점에 따른 신호 변화 확인
- `displot` → 날개 길이의 분포 확인
- `box` → 요일별 팁의 분포 비교

> **결과 해석:** 같은 데이터도 무엇을 비교하는지에 따라 알맞은 그래프가 달라진다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | Histogram | Bar Plot |
| --- | --- | --- |
| 데이터 | 연속된 수치형 값 | 범주형 기준과 수치 값 |
| 목적 | 수치 구간별 빈도와 분포 | 범주별 값 비교 |
| 예시 | 연령 분포 | 지역별 등록대수 |

------------------------------------------------------------------------

## 6. 주의할 점

- 숫자로 저장됐다는 이유만으로 반드시 수치형인 것은 아니다. `0`, `1`이 종류를 구분하면 범주형일 수 있다.
- Histogram의 수치 구간과 Bar Plot의 범주를 같은 것으로 혼동하지 않는다.
- 그래프를 그리기 전에 `info()` 등으로 컬럼의 자료형과 결측치를 확인한다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `수치형` | 숫자로 측정하거나 계산하는 데이터 |
| `범주형` | 종류나 그룹을 구분하는 데이터 |
| `분포` | 값들이 퍼져 있는 형태 |
| `추세` | 시간이나 순서에 따른 변화 방향 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `sns.relplot(..., kind="scatter")` | 산점도 |
| `sns.relplot(..., kind="line")` | 선 그래프 |
| `sns.displot(...)` | 분포 그래프 |
| `sns.displot(..., kind="kde")` | 밀도 분포 그래프 |
| `sns.catplot(..., kind="box")` | Box Plot |
| `plt.bar()` | Bar Plot |

### ⭐ 한 줄 정리
