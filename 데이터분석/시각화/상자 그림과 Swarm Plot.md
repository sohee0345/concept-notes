# 상자 그림과 Swarm Plot

## 1. 개념

상자 그림(Box Plot)은 범주별 수치 데이터의 중앙값, 사분위 범위, 퍼짐과 이상치를 요약한다. Swarm Plot은 각 관측값을 겹치지 않도록 점으로 펼쳐 실제 데이터 분포를 보여 준다.

> **핵심:** Box Plot은 분포를 요약하고 Swarm Plot은 개별 관측값을 보여 준다.

------------------------------------------------------------------------

## 2. 사용 방법

```python
tips = sns.load_dataset("tips")

sns.catplot(
    data=tips,
    x="day",
    y="tip",
    kind="box",
)

sns.catplot(
    data=tips,
    x="day",
    y="tip",
    kind="swarm",
    hue="sex",
)
```

- `x="day"` → 비교할 범주를 x축에 둔다.
- `y="tip"` → 분포를 확인할 수치 값을 y축에 둔다.
- `hue="sex"` → 점의 색으로 추가 범주를 구분한다.

------------------------------------------------------------------------

## 3. 개념 비교

| 구분 | Box Plot | Swarm Plot |
| --- | --- | --- |
| 표현 | 분포의 요약 통계 | 개별 관측값 |
| 확인 | 중앙값·퍼짐·이상치 | 점의 밀집과 실제 값 |
| 주의 | 개별 값은 직접 보이지 않음 | 점이 많으면 배치 경고가 발생할 수 있음 |

------------------------------------------------------------------------

## 🟦 핵심 정리


### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| Box Plot | 범주별 수치 분포를 요약한다. |
| Swarm Plot | 범주별 개별 관측값을 점으로 표현한다. |
| `hue` | 색상으로 추가 범주를 구분한다. |

### ⭐ 한 줄 정리

> **범주별 요약 분포는 Box Plot, 실제 관측값의 퍼짐은 Swarm Plot으로 확인한다.**
