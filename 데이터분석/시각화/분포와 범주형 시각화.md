# 분포와 범주형 시각화

## 1. 개념

분포 그래프는 수치 값이 어느 범위에 얼마나 모였는지 보여 주고 범주형 그래프는 그룹별 수치의 차이와 퍼짐을 비교한다.

> **핵심:** 히스토그램과 KDE는 분포를, Swarm Plot과 Box Plot은 범주별 관측값과 요약 분포를 보여 준다.

---

## 2. 쉽게 이해하기

히스토그램은 구간별 개수를 세고 KDE는 부드러운 밀도 곡선을 만든다. Swarm은 개별 점을, Box Plot은 중앙값과 사분위를 요약한다.

```text
분포 → Histogram·KDE
범주별 개별값 → Swarm
범주별 요약 → Box Plot
```

---

## 3. 사용 방법

```python
sns.displot(data=penguins, x="flipper_length_mm", hue="species")
sns.displot(data=penguins, x="bill_length_mm", y="bill_depth_mm", kind="kde", cbar=True)
sns.catplot(data=tips, x="day", y="tip", kind="box")
```

- `multiple="dodge"` → 범주별 막대를 나란히 배치한다.
- `cbar=True` → 밀도 수준의 색상 막대를 표시한다.
- `kind="swarm"` → 관측값을 겹치지 않게 점으로 표현한다.

---

## 4. 예제

```python
sns.boxplot(data=df, y="fare")
plt.show()
```

운임의 Box Plot을 그리면 중앙값, 사분위 범위, 퍼짐과 이상치를 한눈에 확인할 수 있다.

---

## 5. 헷갈리는 개념 비교

|구분|Swarm Plot|Box Plot|
|---|---|---|
|표현|개별 관측값|요약 통계와 이상치|
|장점|실제 분포 확인|그룹 비교가 간결함|
