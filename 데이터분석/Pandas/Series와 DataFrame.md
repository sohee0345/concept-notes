# Series와 DataFrame

## 1. 개념

Series는 인덱스와 값을 가진 Pandas의 1차원 데이터 구조이고, DataFrame은 행과 열로 이루어진 2차원 데이터 구조이다.

> **핵심:** Series는 한 컬럼, DataFrame은 여러 컬럼을 표 형태로 다룬다.

------------------------------------------------------------------------

## 2. 생성 방법

```python
import pandas as pd

series = pd.Series({"a": 1, "b": 2, "c": 3})

df = pd.DataFrame({
    "one": [1, 2, 3],
    "two": [4, 5, 6],
})
```

------------------------------------------------------------------------

## 3. 구조 확인

```python
df.shape
df.index
df.columns
df.info()
```

- `shape` → 행과 컬럼 개수이다.
- `index` → 행을 구분하는 레이블이다.
- `columns` → 컬럼 이름이다.
- `info()` → 컬럼별 결측이 아닌 값과 자료형 등을 요약한다.

벡터와 행렬에 비유할 수 있지만 Series와 DataFrame에는 레이블이 있고 DataFrame은 컬럼마다 서로 다른 자료형을 가질 수 있다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| Series | 인덱스를 가진 1차원 데이터이다. |
| DataFrame | 행과 열로 구성된 2차원 데이터이다. |
| Index | 행이나 컬럼의 레이블을 관리한다. |

### ⭐ 한 줄 정리

> **Pandas는 Series와 DataFrame으로 레이블이 있는 1차원·2차원 데이터를 다룬다.**
