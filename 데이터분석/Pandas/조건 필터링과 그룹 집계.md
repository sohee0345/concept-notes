# 조건 필터링과 그룹 집계

## 1. 개념

조건 필터링은 불리언 조건으로 원하는 행만 선택하는 기능이고, 그룹 집계는 같은 범주의 행을 묶은 뒤 평균·최댓값·개수 등으로 요약하는 기능이다.

> **핵심:** 조건으로 필요한 행을 고르고 `groupby()`와 집계 함수로 범주별 특징을 요약한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
전체 DataFrame
  ↓ 조건 필터링
필요한 행만 선택
  ↓ groupby()
범주별로 묶기
  ↓ mean()·min()·agg()
그룹별 요약 결과
```

> **쉽게 말하면:** 필터링은 표에서 필요한 행만 거르는 일이고 그룹 집계는 같은 종류끼리 모아 통계를 내는 일이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
cond = (
    iris["sepal_width"].isin([3.5, 3.2])
) & (
    iris["species"] == "setosa"
)

filtered = iris[cond]

iris.groupby("species")["sepal_length"].agg(["mean", "max"])
```

- `isin([...])` → 여러 후보 값 중 하나인지 확인
- `&` / `|` / `~` → AND / OR / NOT
- `groupby(key)` → 같은 key 값을 가진 행끼리 묶음
- `agg([...])` → 여러 집계 함수를 한 번에 적용

> **핵심:** 여러 조건을 결합할 때는 각 비교식을 괄호로 감싼다.

------------------------------------------------------------------------

## 4. 예제

``` python
cond = iris["species"] == "setosa"
print(iris[cond]["sepal_length"].mean())

print(
    iris.groupby("species")["sepal_length"]
        .agg(["mean", "max"])
)
```

실행 결과:

``` text
5.006

             mean  max
species
setosa      5.006  5.8
versicolor  5.936  7.0
virginica   6.588  7.9
```

### 코드 해석

- 첫 계산 → setosa 행만 선택한 뒤 꽃받침 길이 평균 계산
- 두 번째 계산 → 품종별로 묶어 꽃받침 길이의 평균과 최댓값 계산

> **결과 해석:** 직접 조건을 반복하지 않고 `groupby()`를 사용하면 모든 품종의 결과를 한 번에 비교할 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 조건 필터링 | 그룹 집계 |
| --- | --- | --- |
| 목적 | 조건에 맞는 행 선택 | 범주별 통계 계산 |
| 결과 | 원래 컬럼을 가진 행들의 일부 | 그룹별 요약값 |
| 대표 코드 | `df[cond]` | `df.groupby(key).agg(...)` |

------------------------------------------------------------------------

## 6. 주의할 점

- `df[cond]`는 조회이지만 `df[cond] = value`는 실제 데이터를 변경하는 대입이다.
- `&`, `|`로 조건을 연결할 때 각 비교식을 괄호로 감싼다.
- `~cond`는 조건을 만족하지 않는 행을 선택한다.
- `groupby()` 뒤 어떤 컬럼에 어떤 집계 함수를 적용할지 확인한다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `불리언 조건` | 각 행의 선택 여부를 나타내는 True·False 값 |
| `조건 필터링` | 조건이 True인 행 선택 |
| `groupby()` | 같은 범주의 행을 그룹으로 묶음 |
| `집계` | 그룹의 평균·합계·최댓값 등을 계산 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `df[df["col"].isin(values)]` | 후보 값 중 하나인 행 선택 |
| `df[cond]` | 조건을 만족하는 행 선택 |
| `df[~cond]` | 조건을 만족하지 않는 행 선택 |
| `df.groupby(key)[col].mean()` | 그룹별 평균 |
| `df.groupby(key)[col].agg([...])` | 그룹별 여러 통계 계산 |

### ⭐ 한 줄 정리

> **불리언 조건으로 행을 선택하고 groupby와 집계 함수로 범주별 특징을 요약한다.**
