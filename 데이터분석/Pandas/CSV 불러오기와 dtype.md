# CSV 불러오기와 dtype

## 1. 개념

CSV 파일을 Pandas로 읽으면 행과 열로 구성된 DataFrame이 된다. 분석하기 전에는 행 개수와 각 컬럼의 `dtype`을 확인해 데이터가 의도한 형태로 들어왔는지 점검해야 한다.

> **핵심:** CSV를 읽은 직후 데이터의 크기와 자료형을 확인해야 이후 계산과 비교의 오류를 줄일 수 있다.

------------------------------------------------------------------------

## 2. 구조 확인

```python
import pandas as pd

df = pd.read_csv("data.csv", encoding="utf-8")
df.info()
```

`df.info()`는 행의 범위, 컬럼 이름, 결측이 아닌 값의 개수와 `dtype`을 요약한다.

```text
RangeIndex: 100 entries, 0 to 99
```

이는 0부터 99까지 총 100개의 행이 있다는 뜻이다.

------------------------------------------------------------------------

## 3. dtype 지정

```python
df = pd.read_csv(
    "data.csv",
    dtype={"지역코드": "string"},
)
```

지역 코드 `01`은 계산할 숫자가 아니라 지역을 구분하는 값이다. 문자열로 지정하면 앞의 0을 유지할 수 있다. 연도·분기 표기나 상품 코드도 계산 대상인지 식별값인지에 따라 자료형을 선택한다.

------------------------------------------------------------------------

## 4. 주의할 점

- 파일의 문자 인코딩과 `encoding` 값이 다르면 읽기 오류나 글자 깨짐이 생길 수 있다.
- 숫자처럼 보인다는 이유만으로 모든 컬럼을 숫자형으로 읽지 않는다.
- 원본의 예상 행 수와 `RangeIndex`를 비교해 누락 여부를 점검한다.

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| DataFrame | 행과 열로 구성된 2차원 데이터 구조이다. |
| `RangeIndex` | 기본 행 인덱스의 범위를 나타낸다. |
| `dtype` | 컬럼 값의 자료형이다. |
