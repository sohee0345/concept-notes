# CSV 불러오기와 dtype

## 1. 개념

Pandas의 `read_csv()`는 CSV 파일을 행과 열로 구성된 DataFrame으로 불러온다. `dtype`으로 특정 컬럼의 자료형을 지정하고 `info()`로 행 개수와 컬럼별 자료형을 확인한다.

> **핵심:** CSV를 읽은 뒤 데이터 개수와 자료형이 실제 의미에 맞는지 반드시 검증한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
CSV 파일
  ↓ pd.read_csv()
DataFrame
  ↓ df.info()
행 개수와 컬럼 dtype 확인
```

> **쉽게 말하면:** 파일을 표로 읽은 뒤 빠진 행은 없는지, 숫자와 문자열이 올바르게 구분됐는지 확인하는 과정이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
import pandas as pd

df = pd.read_csv(
    "data.csv",
    encoding="utf-8",
    dtype={"시점": "object"},
)

df.info()
```

- `encoding="utf-8"` → 파일 문자 인코딩 지정
- `dtype={...}` → 컬럼별 자료형 지정
- `object` → 수업에서 문자열로 처리하기 위해 사용한 dtype
- `df.info()` → 행 범위, 컬럼, 결측이 아닌 값 수, dtype 등 확인

> **핵심:** 숫자로 보여도 계산 대상이 아니라 코드나 이름이면 문자열 자료형으로 읽을 수 있다.

------------------------------------------------------------------------

## 4. 예제

지역 코드가 `01`, `02`, `03`이라면 정수로 읽을 때 앞의 0이 사라질 수 있으므로 문자열로 지정한다.

``` python
df = pd.read_csv(
    "data.csv",
    encoding="utf-8",
    dtype={"지역코드": "object"},
)

df.info()
```

실행 결과 예시:

``` text
RangeIndex: N entries
지역코드 ... object
```

### 코드 해석

- `지역코드` → 계산값이 아니라 지역을 구분하는 식별값
- `object` → 코드값을 문자열 형태로 보존
- `N entries` → 불러온 행 개수 확인

> **결과 해석:** 지역 코드를 문자열로 유지하고 CSV의 데이터 개수가 예상과 맞는지 확인할 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 계산값 | 코드값 |
| --- | --- | --- |
| 의미 | 수학 계산에 사용 | 대상을 구분하는 식별자 |
| 예시 | 인구수, 금액 | 지역 코드, 연도·분기 표기 |
| dtype | 수치 자료형 | 문자열로 지정 가능 |

------------------------------------------------------------------------

## 6. 주의할 점

- `RangeIndex`는 행 개수 자체가 아니라 DataFrame 행에 사용하는 범위형 인덱스이다.
- `df.info()`의 `N entries`에서 실제로 불러온 행 개수를 확인한다.
- 숫자 모양만 보고 자료형을 결정하지 말고 데이터의 의미를 확인한다.
