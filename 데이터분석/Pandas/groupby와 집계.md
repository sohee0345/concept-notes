# groupby와 집계

## 1. 개념

`groupby()`는 같은 값을 가진 행을 그룹으로 묶고 그룹마다 평균, 최솟값, 최댓값 같은 통계를 계산한다.

> **핵심:** 그룹 기준, 계산할 컬럼, 집계 함수를 순서대로 정한다.

------------------------------------------------------------------------

## 2. 사용 방법

```python
iris.groupby("species")["sepal_length"].agg(["mean", "max"])
```

```text
species로 그룹화
  ↓
sepal_length 선택
  ↓
평균과 최댓값 계산
```

------------------------------------------------------------------------

## 3. 여러 컬럼 집계

```python
iris.groupby("species")[[
    "sepal_length",
    "sepal_width",
]].min()
```

각 품종 그룹에서 두 컬럼의 최솟값을 계산한다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 그룹화 | 같은 기준값의 행을 묶는다. |
| 집계 | 그룹을 하나 이상의 통계값으로 요약한다. |
| `agg` | 여러 집계 함수를 함께 적용한다. |

### ⭐ 한 줄 정리

> **groupby로 같은 범주의 행을 묶고 선택한 컬럼에 집계 함수를 적용한다.**
