# 조건 필터링과 iloc

## 1. 개념

Pandas에서는 불리언 조건으로 원하는 행을 필터링하고 `iloc`으로 정수 위치에 따라 행과 열을 선택할 수 있다.

> **핵심:** 조건 필터링은 값의 조건으로, iloc은 정수 위치로 데이터를 선택한다.

------------------------------------------------------------------------

## 2. 조건 필터링

```python
cond = (
    iris["sepal_width"].isin([3.5, 3.2])
) & (
    iris["species"] == "setosa"
)

iris[cond]
iris[~cond]
```

- `isin()` → 후보 값 중 하나인지 검사한다.
- `&` → 두 조건을 모두 만족한다.
- `~` → 조건의 참과 거짓을 뒤집는다.

------------------------------------------------------------------------

## 3. iloc과 컬럼 선택

```python
iris.iloc[1:4, 1:3]
iris[["sepal_length", "sepal_width"]]
```

`iloc`은 정수 위치를 사용하고 여러 컬럼 이름은 리스트로 전달한다.

------------------------------------------------------------------------

## 4. 주의할 점

- 여러 조건은 각각 괄호로 묶는다.
- `iris[cond] = value`는 조회가 아니라 실제 값 변경이다.
- Pandas Index는 단순 행 번호가 아니라 행을 구분하는 레이블이다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 불리언 필터링 | 참인 행만 선택한다. |
| `isin` | 여러 후보 값과의 일치를 검사한다. |
| `iloc` | 정수 위치로 행과 열을 선택한다. |

### ⭐ 한 줄 정리

> **값 조건에는 불리언 필터를, 행·열의 정수 위치에는 iloc을 사용한다.**
