# map과 apply

## 1. 개념

`map()`과 `apply()`는 데이터에 함수를 적용해 값을 변환하거나 새 값을 계산할 때 사용한다. `map()`은 주로 Series의 각 값에 적용하고, `DataFrame.apply()`는 행 또는 열 단위 처리에 사용한다.

> **핵심:** 값 하나씩 변환할 때는 `map()`, 행·열을 하나의 단위로 처리할 때는 `apply()`를 우선 생각한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
Series의 값 하나씩
  ↓ map()
각 값을 새 값으로 변환

DataFrame의 행 또는 열
  ↓ apply()
여러 컬럼을 함께 사용해 계산
```

> **쉽게 말하면:** `map()`은 한 칸씩 바꾸고 `apply()`는 한 행이나 한 열을 묶어서 처리한다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
df["sex"].map({"male": 0, "female": 1})

def family_cnt(row):
    return row["sibsp"] + row["parch"]

df["family_cnt"] = df.apply(family_cnt, axis=1)
```

- `Series.map(함수 또는 딕셔너리)` → 각 값을 변환
- `DataFrame.apply(함수, axis=1)` → 각 행에 함수 적용
- `DataFrame.apply(함수, axis=0)` → 각 열에 함수 적용

> **핵심:** 여러 컬럼 값을 함께 계산하는 행 단위 함수에는 `axis=1`을 사용한다.

------------------------------------------------------------------------

## 4. 예제

``` python
df["age_group"] = df["age"].map(lambda x: (x // 10) * 10)

df = df[(df["age"] >= 10) & (df["age"] < 40)]
df.groupby("age_group")["survived"].mean()
```

실행 결과:

``` text
age_group
10.0    0.401961
20.0    0.350000
30.0    0.437126
```

### 코드 해석

- `map(lambda ...)` → 나이를 10대·20대·30대 단위 값으로 변환
- 조건식 → 10세 이상 40세 미만만 선택
- `groupby()` → 연령대별 생존율 계산

> **결과 해석:** `map()`으로 분석에 필요한 새 범주를 만든 뒤 그룹별 통계를 계산할 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `Series.map()` | `DataFrame.apply()` |
| --- | --- | --- |
| 처리 단위 | Series의 각 값 | DataFrame의 각 행 또는 열 |
| 입력 예시 | 성별 문자열 하나 | 한 승객의 여러 컬럼 |
| 사용 예시 | 성별을 0·1로 변환 | 가족 수 계산 |

------------------------------------------------------------------------

## 6. 주의할 점

- `apply()`도 Series에 사용할 수 있으므로 “Series에는 무조건 map만 사용한다”는 절대적인 규칙은 아니다.
- `DataFrame.apply()`에서 `axis=1`은 행 단위, `axis=0`은 열 단위이다.
- `map()`에 딕셔너리를 전달할 때 대응하는 키가 없으면 결과가 결측값이 될 수 있다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `map()` | Series의 각 값을 함수나 대응표로 변환 |
| `apply()` | DataFrame의 행 또는 열에 함수 적용 |
| `axis=1` | 각 행을 함수에 전달 |
| `axis=0` | 각 열을 함수에 전달 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `series.map(dict)` | 딕셔너리 기준으로 값 변환 |
| `series.map(lambda x: ...)` | 각 값에 익명 함수 적용 |
| `df.apply(func, axis=1)` | 각 행에 함수 적용 |

### ⭐ 한 줄 정리

> **map은 Series의 각 값을, DataFrame.apply는 행 또는 열을 단위로 함수를 적용한다.**
