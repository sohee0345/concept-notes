# map과 apply

## 1. 개념

`Series.map()`은 Series의 각 값을 다른 값으로 변환하고, `DataFrame.apply()`는 지정한 축의 각 행이나 컬럼에 함수를 적용한다.

> **핵심:** 값 하나씩 바꿀 때는 Series.map, 여러 컬럼을 함께 계산할 때는 DataFrame.apply를 사용할 수 있다.

------------------------------------------------------------------------

## 2. map()

```python
sex_code = {"male": 0, "female": 1}
df["sex_code"] = df["sex"].map(sex_code)
```

딕셔너리나 함수를 Series의 각 값에 적용한다.

------------------------------------------------------------------------

## 3. apply()

```python
def family_count(row: pd.Series) -> int:
    return row["sibsp"] + row["parch"]

df["family_cnt"] = df.apply(family_count, axis=1)
```

`axis=1`은 각 행을 함수에 전달한다. 이 예제에서는 한 행의 두 컬럼을 더해 가족 수 컬럼을 만든다.

------------------------------------------------------------------------

## 4. 주의할 점

- `Series.apply()`도 존재하므로 한 컬럼과 여러 컬럼이라는 구분은 절대적이지 않다.
- `DataFrame.apply(axis=1)`에서 함수가 받는 한 행은 Series이다.
- 새 컬럼 이름과 변환 결과의 의미가 일치하도록 작성한다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `map` | Series의 각 값을 변환한다. |
| `apply` | 행이나 컬럼 단위로 함수를 적용한다. |
| `axis=1` | DataFrame의 각 행을 처리한다. |

### ⭐ 한 줄 정리

> **Series의 값 변환에는 map을, 행의 여러 컬럼 계산에는 apply(axis=1)를 활용한다.**
