# DataFrame 선택과 필터링

## 1. 개념

DataFrame은 컬럼 이름, 정수 위치, 불리언 조건으로 필요한 행과 열을 선택할 수 있다. 조회 결과를 변수에 저장하는 것과 원본에 대입하는 것은 구분해야 한다.

> **핵심:** 불리언 조건은 행을 필터링하고 iloc은 정수 위치로 행과 열을 선택한다.

---

## 2. 쉽게 이해하기

표에서 조건에 맞는 행만 거르거나 행·열 번호로 필요한 사각형 범위를 잘라내는 방식이다.

```text
조건 생성 → df[조건] → 행 필터링
행·열 위치 → iloc → 범위 선택
```

---

## 3. 사용 방법

```python
cond = iris["sepal_width"].isin([3.5, 3.2]) & (iris["species"] == "setosa")
selected = iris[cond]
excluded = iris[~cond]
iris.iloc[1:4, 1:3]
iris[["sepal_length", "sepal_width"]]
```

- `isin()` → 여러 후보 중 하나와 일치하는지 검사한다.
- `~` → 불리언 조건을 반대로 바꾼다.
- `iloc` → 정수 위치로 행과 열을 선택한다.

---

## 4. 예제

```python
iris["species"].unique()
iris["species"].nunique()
iris["species"].value_counts()
iris["species"].mode()[0]
```

범주형 컬럼의 고유값, 고유값 개수, 값별 빈도, 최빈값을 확인한다.

---

## 5. 헷갈리는 개념 비교

|구분|`df[cond]`|`df[cond] = value`|
|---|---|---|
|역할|조건 행 조회|선택 위치의 실제 값 변경|

---

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|불리언 필터링|True인 행 선택|
|`iloc`|정수 위치 기반 선택|
|범주형 탐색|고유값과 빈도 확인|

### 💻 주요 코드

|코드|의미|
|---|---|
|`df[cond]`|조건 행 선택|
|`df[~cond]`|조건을 만족하지 않는 행 선택|
|`df.iloc[rows, cols]`|행·열 위치 선택|
|`value_counts()`|값별 행 개수 계산|
