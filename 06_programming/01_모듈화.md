# 모듈화

## 1. 개념
모듈화는 하나의 큰 프로그램을 역할별 파일이나 기능 단위로 나누는 방법이다.

> **핵심:** UI, 로직, 설정 등을 분리하면 코드가 읽기 쉽고 수정·재사용하기 편해진다.

---

## 2. 쉽게 이해하기
```text
하나의 큰 파일
  ↓ 역할별 분리
app.py        → 화면
chat_logic.py → 기능
config.py     → 설정
```

---

## 3. 사용 방법
```python
# chat_logic.py
def get_response(text):
    return f"{text}에 대한 답변"
```

```python
# app.py
from chat_logic import get_response
```

- module → 파이썬 코드가 들어있는 파일
- `import` → 다른 모듈 가져오기
- UI와 로직 분리 → 화면 코드와 기능 코드를 따로 관리
- 설정 분리 → API key, 상수 등 설정값을 별도 파일에서 관리

---

## 4. 예제
```text
project/
├─ app.py
├─ chat_logic.py
└─ config.py
```

실행 흐름:
```text
app.py
  ↓ 함수 호출
chat_logic.py
  ↓ 설정 사용
config.py
```

---

## 5. 헷갈리는 개념 비교
|구분|한 파일에 작성|모듈화|
|---|---|---|
|관리|파일이 커질수록 복잡|역할별로 분리되어 관리 쉬움|
|재사용|어려움|함수/모듈 재사용 쉬움|

## 🟦 핵심 정리

### 💡 주요 개념
module, import, 역할 분리, UI/로직 분리

### 💻 주요 코드
|코드|의미|
|---|---|
|`import module`|모듈 전체 가져오기|
|`from module import func`|특정 기능 가져오기|
