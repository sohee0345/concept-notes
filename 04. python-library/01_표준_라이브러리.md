# 표준 라이브러리

## 1. 개념
표준 라이브러리는 파이썬 설치 시 함께 제공되는 미리 만들어진 기능 모음이다.

> **핵심:** 자주 필요한 기능을 직접 구현하지 않고 필요한 모듈을 `import`해서 사용한다.

---

## 2. 쉽게 이해하기
```text
필요한 기능
  ↓
이미 만들어진 라이브러리 찾기
  ↓
import
  ↓
사용
```

---

## 3. 사용 방법
```python
from collections import Counter
from datetime import datetime
import math

Counter(["a", "a", "b"])
datetime.now()
math.sqrt(16)
```

- `collections.Counter` → 값의 개수 세기
- `collections.defaultdict` → 없는 key에 기본값 생성
- `math` → 수학 계산 기능
- `datetime` → 날짜와 시간 처리

---

## 4. 예제
```python
from collections import Counter

result = Counter(["a", "a", "a", "b", "c"])
print(result)
```

실행 결과:
```text
Counter({'a': 3, 'b': 1, 'c': 1})
```
