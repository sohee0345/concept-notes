# 문자열 인덱싱과 포맷팅

## 1. 개념

문자열은 순서가 있는 문자들의 모음이다. 인덱싱으로 문자 하나를 조회하고 슬라이싱으로 일정 범위를 가져올 수 있으며, 포맷팅을 사용하면 문자열 안에 값을 넣을 수 있다.

> **핵심:** 문자열의 위치는 `0`부터 시작하고 슬라이싱의 끝 인덱스는 결과에 포함되지 않는다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
Hello World
012345678910  ← 인덱스
```

`a[0]`은 첫 문자를, `a[0:3]`은 인덱스 `0`부터 `2`까지의 문자를 가져온다.

> **쉽게 말하면:** 인덱싱은 한 칸을 고르고, 슬라이싱은 시작과 끝을 정해 여러 칸을 잘라내는 것이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
a = "Hello World"

a[0]
a[0:3]
a[-9:-11:-1]
```

- `a[인덱스]` → 해당 위치의 문자 하나를 조회한다.
- `a[시작:끝:간격]` → 시작부터 끝 직전까지 간격에 맞춰 가져온다.
- 음수 인덱스 → 문자열의 뒤에서부터 위치를 센다.
- 음수 간격 → 뒤쪽 방향으로 이동한다.

줄바꿈은 `\n`, 탭은 `\t`, 역슬래시 문자는 `\\`로 표현한다.

> **핵심:** 시작·끝·간격은 생략할 수 있으며 기본 간격은 `1`이다.

------------------------------------------------------------------------

## 4. 예제

``` python
a = "Hello World"
who = "I"
number = 5

print(a[0:3])
print(f"{who} eat {number} apples.")
```

실행 결과:

``` text
Hel
I eat 5 apples.
```

### 코드 해석

- `a[0:3]` → 인덱스 `0`, `1`, `2`의 문자를 가져온다.
- f-string의 `{who}`와 `{number}` → 변수의 값을 문자열에 넣는다.

> **결과 해석:** 슬라이싱은 문자열 일부를 만들고 f-string은 변수 값을 포함한 문자열을 만든다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 인덱싱 | 슬라이싱 |
| --- | --- | --- |
| 결과 | 문자 하나 | 문자열 일부 |
| 형태 | `a[0]` | `a[0:3]` |
| 끝 위치 | 해당 없음 | 포함하지 않음 |

------------------------------------------------------------------------

## 6. 주의할 점

- `len()`은 공백도 문자 하나로 계산한다.
- 간격이 음수이면 시작 위치에서 더 작은 인덱스 방향으로 이동해야 한다.
- 문자열 메서드인 `count()`, `split()`, `strip()`, `replace()`는 각각 개수 확인, 분리, 양 끝 공백 제거, 치환에 사용한다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `인덱싱` | 위치로 문자 하나 조회 |
| `슬라이싱` | 시작·끝·간격으로 범위 조회 |
| `f-string` | 중괄호 안의 값을 문자열에 삽입 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `a[0]` | 첫 문자 조회 |
| `a[0:3]` | 인덱스 0부터 2까지 조회 |
| `f"{value}"` | 값을 문자열에 삽입 |

### ⭐ 한 줄 정리

> **문자열은 인덱싱과 슬라이싱으로 조회하고 f-string으로 값을 읽기 쉽게 조합한다.**
