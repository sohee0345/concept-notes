# 조건문과 반복문

## 1. 개념

조건문은 조건의 참·거짓에 따라 실행할 코드를 선택하고, 반복문은 데이터나 조건에 따라 같은 코드를 여러 번 실행한다.

> **핵심:** `if`는 분기, `for`는 데이터 순회, `while`은 조건이 참인 동안 반복할 때 사용한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
조건 확인 → 실행 경로 선택 → if
여러 값을 차례로 처리 → for
조건이 참인 동안 계속 실행 → while
```

> **쉽게 말하면:** 조건문은 길을 고르고, 반복문은 같은 일을 정해진 규칙에 따라 되풀이한다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
if 조건:
    실행할_코드
else:
    다른_코드

for item in 데이터:
    반복할_코드

while 조건:
    반복할_코드
```

- `break` → 반복문 즉시 종료
- `continue` → 현재 회차의 나머지를 건너뛰고 다음 반복
- `pass` → 아무 동작 없이 다음 코드로 진행
- `for ... else` → `break` 없이 반복이 끝나면 `else` 실행

> **핵심:** `continue` 아래 코드는 실행되지 않지만 `pass` 아래 코드는 계속 실행된다.

------------------------------------------------------------------------

## 4. 예제

``` python
x = 3
for i in [1, 2, 3, 4, 5]:
    if i % 2 == 0:
        print(f"{x} * {i} = {x * i}")
        break
```

실행 결과:

``` text
3 * 2 = 6
```

``` python
total = 0
index = 0
while index < 10:
    index += 1
    total += index
print(total)
```

실행 결과:

``` text
55
```

### 코드 해석

- `i % 2 == 0` → `i`가 짝수인지 검사한다.
- `print()` 뒤의 `break` → 한 줄을 출력한 다음 반복을 종료한다.
- `while index < 10` → 인덱스가 10보다 작은 동안 누적한다.

> **결과 해석:** 코드의 위아래 순서에 따라 `print()`가 먼저 실행되고 `break`가 그다음 실행된다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `break` | `continue` | `pass` |
| --- | --- | --- | --- |
| 동작 | 반복 전체 종료 | 현재 회차만 건너뜀 | 아무 동작 없음 |
| 아래 코드 | 반복문 밖으로 이동 | 다음 반복으로 이동 | 그대로 실행 |
| `for ... else` | `else` 실행 안 됨 | 반복 완료 시 실행 | 반복 완료 시 실행 |

------------------------------------------------------------------------

## 6. 주의할 점

- `while` 조건이 계속 참이면 반복이 끝나지 않으므로 조건을 바꾸는 코드가 필요하다.
- `break`, `continue`, `print()`의 배치 순서에 따라 출력 결과가 달라진다.
- `continue` 다음에 같은 블록으로 작성한 코드는 실행되지 않는다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `if` | 조건에 따른 분기 |
| `for` | 데이터 순회 반복 |
| `while` | 조건 기반 반복 |
| 흐름 제어 | 반복의 종료·건너뛰기·통과를 조절 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `if / elif / else` | 조건별 실행 경로 선택 |
| `for item in data` | 데이터를 차례로 순회 |
| `while condition` | 조건이 참인 동안 반복 |
| `break / continue / pass` | 종료 / 건너뛰기 / 아무 동작 없음 |
