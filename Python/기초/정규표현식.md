# 정규표현식

## 1. 개념

정규표현식은 문자열의 규칙을 패턴으로 표현하여 원하는 내용을 찾거나 검사하고 치환하는 방법이다. Python에서는 `re` 모듈을 사용한다.

> **핵심:** 정규표현식은 개별 문자가 아니라 문자열의 형태를 기준으로 처리한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
전화번호 문자열
  ↓ 숫자 패턴 적용
숫자 묶음만 추출
```

> **쉽게 말하면:** 찾고 싶은 문자열의 모양을 규칙으로 만들어 한꺼번에 검색하는 방법이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
import re

re.findall(r"\d+", "010-1234-5678")
re.sub(r"\s+", " ", "hello    world")
```

- `findall()` → 일치하는 모든 문자열 반환
- `match()` → 문자열 시작 부분의 일치 확인
- `sub()` → 일치하는 부분 치환
- `compile()` → 패턴을 미리 만들어 재사용

> **핵심:** 역슬래시가 있는 패턴은 `r"..."` 형태의 raw string으로 작성할 수 있다.

------------------------------------------------------------------------

## 4. 예제

``` python
text = "a1b2c3"
letters = re.findall(r"[a-zA-Z]", text)
numbers = re.findall(r"[0-9]", text)

print(letters)
print(numbers)
```

실행 결과:

``` text
['a', 'b', 'c']
['1', '2', '3']
```

### 코드 해석

- `[a-zA-Z]` → 영문자 한 글자와 일치한다.
- `[0-9]` → 숫자 한 글자와 일치한다.

> **결과 해석:** 하나의 문자열에서 문자와 숫자를 서로 다른 패턴으로 추출했다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `findall()` | `match()` | `sub()` |
| --- | --- | --- | --- |
| 목적 | 모두 찾기 | 시작 부분 검사 | 치환 |
| 결과 | 일치 목록 | 일치 객체 또는 없음 | 바뀐 문자열 |

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 패턴 | 문자열의 규칙 표현 |
| `\d` | 숫자 패턴 |
| `\s` | 공백 문자 패턴 |
| `+` | 앞 패턴이 한 번 이상 반복 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `re.findall(pattern, text)` | 모든 일치 항목 찾기 |
| `re.match(pattern, text)` | 시작 부분 일치 확인 |
| `re.sub(pattern, value, text)` | 일치 부분 치환 |

### ⭐ 한 줄 정리

> **정규표현식은 문자열 패턴을 정의해 검색·검사·치환한다.**
