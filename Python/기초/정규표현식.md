# 정규표현식

## 1. 개념

정규표현식은 문자열의 일정한 패턴을 표현하는 규칙이다. Python의 `re` 모듈로 패턴에 맞는 내용을 찾고, 형식을 검사하고, 문자열을 치환한다.

> **핵심:** 반복되는 문자열 규칙을 하나의 패턴으로 표현해 검색·검사·치환에 재사용한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
문자열 + 패턴
  ↓
찾기 / 형식 검사 / 바꾸기
```

> **쉽게 말하면:** 문자열에서 원하는 모양만 골라내는 검색 규칙이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
import re

pattern = re.compile(r"[0-9]")
pattern.findall("a1b2c3")
```

- `[a-zA-Z]` → 영문자 한 글자
- `[0-9]`, `\d` → 숫자 한 글자
- `\s` → 공백 문자
- `+` → 앞 패턴이 한 번 이상 반복
- `^`, `$` → 문자열 시작과 끝

> **핵심:** 패턴 앞에 `r`을 붙인 raw string을 사용하면 역슬래시가 포함된 정규식을 읽기 쉽게 작성할 수 있다.

------------------------------------------------------------------------

## 4. 예제

``` python
import re

text = "a1b2c3d4"
print(re.findall(r"[a-zA-Z]", text))
print(re.findall(r"\d+", "010-1234-5678"))
print(re.sub(r"\s+", " ", "hello    world"))
```

실행 결과:

``` text
['a', 'b', 'c', 'd']
['010', '1234', '5678']
hello world
```

### 코드 해석

- `findall()` → 패턴에 맞는 모든 부분을 리스트로 반환한다.
- `\d+` → 연속된 숫자 묶음을 찾는다.
- `sub()` → 연속 공백을 공백 하나로 바꾼다.

> **결과 해석:** 같은 문자열에서도 패턴에 따라 문자, 숫자 묶음, 치환 대상만 골라 처리할 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 함수 | 역할 | 결과 |
| --- | --- | --- |
| `findall()` | 패턴과 일치하는 모든 부분 찾기 | 리스트 |
| `match()` | 시작 부분의 패턴 일치 검사 | 매치 객체 또는 일치 없음 |
| `sub()` | 일치하는 부분 치환 | 변경된 문자열 |

------------------------------------------------------------------------

## 6. 주의할 점

- `match()`는 문자열의 시작 부분을 기준으로 검사한다.
- `+`의 적용 대상은 바로 앞의 패턴이다.
- 정규식의 역슬래시와 Python 문자열의 역슬래시가 겹칠 수 있으므로 raw string을 사용한다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `패턴` | 찾거나 검사할 문자열 규칙 |
| `문자 클래스` | 허용할 문자 범위 표현 |
| `raw string` | 역슬래시를 그대로 다루기 위한 문자열 표기 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `re.compile(pattern)` | 패턴 객체 생성 |
| `re.findall(pattern, text)` | 모든 일치 부분 찾기 |
| `re.match(pattern, text)` | 시작 부분 일치 검사 |
| `re.sub(pattern, value, text)` | 일치 부분 치환 |

### ⭐ 한 줄 정리

> **정규표현식은 문자열 패턴을 정의해 원하는 내용을 찾고 검사하고 치환한다.**
