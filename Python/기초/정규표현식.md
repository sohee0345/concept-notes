# 정규표현식

## 1. 개념

정규표현식은 문자열의 형태를 패턴으로 표현하여 원하는 내용을 검색·검사·치환하는 방법이다. Python에서는 표준 라이브러리 `re`를 사용한다.

> **핵심:** 정규표현식은 문자열을 하나씩 비교하는 대신 규칙을 만들어 처리한다.

---

## 2. 쉽게 이해하기

찾으려는 문자열 자체가 아니라 숫자, 공백, 영문자처럼 문자열의 모양을 설명하는 검색 규칙이다.

```text
문자열과 패턴 준비
  ↓
검색·검사·치환
  ↓
일치 결과 또는 변경된 문자열
```

---

## 3. 사용 방법

- `re.findall()` → 일치하는 모든 문자열을 리스트로 반환한다.
- `re.match()` → 문자열 시작 부분이 패턴과 일치하는지 확인한다.
- `re.sub()` → 일치하는 부분을 다른 문자열로 바꾼다.
- `re.compile()` → 패턴을 미리 만들어 반복 사용한다.
- `\d`, `\s`, `+` → 숫자, 공백 문자, 한 번 이상 반복을 표현한다.

---

## 4. 예제

```python
import re

text = "a1b2c3d4"
print(re.findall(r"[a-zA-Z]", text))
print(re.findall(r"[0-9]", text))
print(re.sub(r"\s+", " ", "hello    world"))
```

실행 결과:

```text
['a', 'b', 'c', 'd']
['1', '2', '3', '4']
hello world
```

패턴에 맞는 문자들을 찾고 연속된 공백을 하나로 치환한다.

---

## 5. 헷갈리는 개념 비교

|구분|`findall()`|`match()`|`sub()`|
|---|---|---|---|
|역할|모든 일치 검색|시작 부분 일치 검사|일치 부분 치환|
