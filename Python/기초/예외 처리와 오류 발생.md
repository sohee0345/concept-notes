# 예외 처리와 오류 발생

## 1. 개념

예외 처리는 실행 중 발생한 오류에 대응하는 방법이다. `try/except`로 오류를 처리하고, `assert`와 `raise`로 조건에 따라 오류를 발생시킬 수 있다.

> **핵심:** 예상 가능한 오류는 처리하고, 문제가 있는 조건은 명확한 예외로 알린다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
try에서 코드 실행
  ├─ 오류 발생 → except
  └─ 오류 없음 → else
마지막에는 finally 실행
```

> **쉽게 말하면:** 문제가 생겼을 때 실행할 대안을 준비하고, 필요하면 직접 문제 상황을 알리는 구조이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
try:
    실행할_코드
except ValueError as e:
    오류_처리
else:
    정상_실행_후_처리
finally:
    항상_실행할_코드
```

- `try` → 오류 가능성이 있는 코드
- `except` → 지정한 오류 발생 시 실행
- `else` → 오류가 없을 때 실행
- `finally` → 오류 여부와 관계없이 실행

> **핵심:** `else`와 `finally`의 실행 조건을 구분한다.

------------------------------------------------------------------------

## 4. 예제

``` python
x = "홍길동"
try:
    print(f"{int(x)}는 숫자입니다.")
except ValueError as e:
    print("오류에요")
```

실행 결과:

``` text
오류에요
```

``` python
x = 4
assert x % 3 == 0, "오류입니다."
```

실행 결과:

``` text
AssertionError: 오류입니다.
```

### 코드 해석

- `int("홍길동")` → 정수 변환에 실패하여 `ValueError`가 발생한다.
- `except ValueError` → 해당 오류를 처리한다.
- `assert` → 조건이 거짓이면 `AssertionError`를 발생시킨다.
- `raise Exception(...)` → 직접 예외를 발생시킨다.

> **결과 해석:** 변환 오류는 프로그램이 즉시 멈추는 대신 `except` 블록에서 처리되며, 잘못된 조건은 `assert`나 `raise`로 알릴 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `except` | `assert` | `raise` |
| --- | --- | --- | --- |
| 역할 | 발생한 예외 처리 | 조건 검사 | 직접 예외 발생 |
| 실행 조건 | 지정한 예외 발생 | 조건이 `False` | 작성한 코드가 실행될 때 |
| 예시 | `except ValueError` | `assert x > 0` | `raise Exception()` |

------------------------------------------------------------------------

## 6. 주의할 점

- 처리하려는 오류 종류에 맞는 `except`를 작성한다.
- `else`는 예외가 없을 때만 실행되고 `finally`는 예외 여부와 관계없이 실행된다.
- 코드가 위에서 아래로 실행되므로 오류가 발생한 이후의 같은 실행 흐름은 진행되지 않는다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `예외 처리` | 실행 중 오류에 대응하는 구조 |
| `AssertionError` | `assert` 조건이 거짓일 때 발생하는 오류 |
| `raise` | 원하는 위치에서 예외를 직접 발생시키는 문장 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `try / except` | 오류 발생 가능 코드와 처리 코드 구성 |
| `else / finally` | 정상 실행 후 처리 / 항상 실행 |
| `assert 조건, 메시지` | 조건이 거짓이면 오류 발생 |
| `raise Exception(메시지)` | 직접 예외 발생 |

### ⭐ 한 줄 정리

> **`try/except`는 발생한 오류를 처리하고, `assert`와 `raise`는 문제 조건에서 오류를 발생시킨다.**
