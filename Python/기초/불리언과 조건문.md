# 불리언과 조건문

## 1. 개념

불리언은 참과 거짓을 나타내는 자료형이며 `True`와 `False` 두 값을 가진다. 조건문은 불리언 결과에 따라 서로 다른 코드를 실행한다.

> **핵심:** 조건식의 결과가 참인지 거짓인지에 따라 프로그램의 실행 경로가 달라진다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
조건 확인
  ├─ True  → if 블록 실행
  └─ False → else 블록 실행
```

> **쉽게 말하면:** 조건문은 질문의 답이 참인지 거짓인지에 따라 갈림길을 선택한다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
if 조건:
    print("조건이 참")
elif 다른_조건:
    print("다른 조건이 참")
else:
    print("모든 조건이 거짓")
```

- `or` → 둘 중 하나 이상이 참이면 참
- `and` → 둘 다 참이어야 참
- `not` → 참과 거짓을 반대로 바꿈

> **핵심:** 분기할 경우가 여러 개라면 `elif`를 사용해 조건을 차례로 검사한다.

------------------------------------------------------------------------

## 4. 예제

``` python
value = []

if value:
    print("값이 있습니다.")
else:
    print("값이 비어 있습니다.")
```

실행 결과:

``` text
값이 비어 있습니다.
```

### 코드 해석

- 빈 리스트는 `bool()`로 변환하면 `False`이다.
- 조건이 거짓이므로 `else` 블록이 실행된다.

> **결과 해석:** 숫자 `0`과 빈 문자열·빈 리스트는 조건식에서 거짓으로 판단된다.

------------------------------------------------------------------------

## 6. 주의할 점

- `if`와 `else`에 속한 코드는 같은 깊이로 들여써야 한다.
- `not`은 조건의 결과를 반대로 바꾼다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `bool` | 참과 거짓을 표현하는 자료형 |
| `if` | 조건이 참일 때 실행 |
| `elif` | 앞 조건이 거짓일 때 다른 조건 검사 |
| `else` | 모든 앞 조건이 거짓일 때 실행 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `bool(value)` | 값을 불리언으로 변환 |
| `and` / `or` / `not` | 논리 조건 결합 또는 반전 |

### ⭐ 한 줄 정리

> **불리언은 참과 거짓을 나타내며 조건문은 그 결과에 따라 실행할 코드를 선택한다.**
