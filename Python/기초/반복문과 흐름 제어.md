# 반복문과 흐름 제어

## 1. 개념

반복문은 같은 코드 블록을 여러 번 실행한다. `for`문은 여러 데이터를 순서대로 순회하고, `while`문은 조건이 참인 동안 반복한다. `break`, `continue`, `pass`로 반복 중의 흐름을 조절할 수 있다.

> **핵심:** 반복 기준에 따라 `for`와 `while`을 선택하고 흐름 제어문의 동작을 구분해야 한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
for      → 준비된 값을 하나씩 사용
while    → 조건이 참인 동안 계속 실행
break    → 반복 종료
continue → 다음 회차로 이동
pass     → 아무 동작 없이 계속 진행
```

> **쉽게 말하면:** 반복문은 일을 되풀이하고, 흐름 제어문은 멈추거나 건너뛸 시점을 정한다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
for value in [1, 2, 3]:
    print(value)

while 조건:
    반복할_코드
```

- `for` → 컬렉션의 값을 차례로 변수에 대입하며 반복한다.
- `while` → 조건이 `True`인 동안 반복한다.
- `for ~ else` → `break` 없이 반복이 끝났을 때 `else`를 실행한다.

> **핵심:** `while`문에서는 반복 중 조건이 언젠가 거짓이 되도록 관련 값을 변경해야 한다.

------------------------------------------------------------------------

## 4. 예제

``` python
x = 3

for i in [1, 2, 3, 4, 5]:
    if i % 2 == 0:
        print(f"{x} * {i} = {x * i}")
        break
```

실행 결과:

``` text
3 * 2 = 6
```

### 코드 해석

- `i`가 `2`일 때 조건이 참이 된다.
- 출력문이 먼저 실행되고 `break`가 반복문을 종료한다.

> **결과 해석:** `break`보다 앞에 있는 코드는 실행되며 이후 반복만 중단된다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `break` | `continue` | `pass` |
| --- | --- | --- | --- |
| 동작 | 반복문 종료 | 현재 회차 중단 | 아무 동작 없음 |
| 다음 회차 | 실행하지 않음 | 실행함 | 정상 흐름에 따라 실행 |
| 아래 코드 | 실행하지 않음 | 현재 회차에서 실행하지 않음 | 실행함 |

------------------------------------------------------------------------

## 6. 주의할 점

- `continue` 아래의 같은 블록에 있는 코드는 해당 회차에서 실행되지 않는다.
- `pass`는 반복을 건너뛰는 명령이 아니다.
- `for ~ else`의 `else`는 `break`가 실행되면 실행되지 않는다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `for` | 데이터를 순서대로 순회 |
| `while` | 조건이 참인 동안 반복 |
| `break` | 반복 즉시 종료 |
| `continue` | 현재 회차만 건너뜀 |
| `pass` | 아무 동작도 하지 않음 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `for x in values` | 값을 하나씩 꺼내 반복 |
| `while 조건` | 조건을 검사하며 반복 |
| `for ~ else` | break 없이 종료되면 else 실행 |
