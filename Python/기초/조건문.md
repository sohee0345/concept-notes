# 조건문

## 1. 개념

조건문은 조건의 참과 거짓에 따라 실행할 코드를 나누는 흐름 제어 문법이다. 불리언은 `True`와 `False` 두 값을 가지며 `if`, `elif`, `else`로 여러 경우를 구분한다.

> **핵심:** 조건문은 불리언으로 평가된 조건에 따라 실행할 코드 블록을 선택한다.

---

## 2. 쉽게 이해하기

조건문은 갈림길과 같다. 첫 조건이 참이면 해당 길로 가고, 거짓이면 다음 조건이나 마지막 `else`로 이동한다.

```text
if 조건
  ├─ True → if 블록
  └─ False → elif 조건
                 ├─ True → elif 블록
                 └─ False → else 블록
```

---

## 3. 사용 방법

```python
if 조건:
    print("조건이 참")
elif 다른_조건:
    print("다른 조건이 참")
else:
    print("모든 조건이 거짓")
```

- `if` → 첫 조건이 참일 때 실행한다.
- `elif` → 앞 조건이 거짓일 때 추가 조건을 검사한다.
- `else` → 앞의 모든 조건이 거짓일 때 실행한다.
- `and`, `or`, `not` → 조건을 연결하거나 참과 거짓을 반대로 바꾼다.

---

## 4. 예제

```python
x = 4

if x % 3 == 0:
    print("3의 배수")
elif x % 2 == 0:
    print("2의 배수")
else:
    print("해당 없음")
```

실행 결과:

```text
2의 배수
```

조건을 위에서부터 검사하고 처음으로 참이 된 분기의 코드가 실행된다.

---

## 5. 헷갈리는 개념 비교

|구분|`and`|`or`|`not`|
|---|---|---|---|
|의미|모든 조건이 참|하나 이상이 참|참과 거짓 반전|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|`불리언`|참과 거짓을 나타내는 값|
|`if`|첫 조건을 검사하는 분기|
|`elif`|추가 조건을 검사하는 분기|
|`else`|앞 조건이 모두 거짓일 때 실행하는 분기|

### 💻 주요 코드

|코드|의미|
|---|---|
|`bool(값)`|값을 불리언으로 변환|
|`x and y`|두 조건이 모두 참인지 검사|
|`x or y`|하나 이상이 참인지 검사|
|`not x`|참과 거짓 반전|
