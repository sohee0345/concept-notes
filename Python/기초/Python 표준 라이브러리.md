# Python 표준 라이브러리

## 1. 개념

Python 표준 라이브러리는 Python 설치 시 기본으로 제공되어 별도 패키지 설치 없이 `import`할 수 있는 기능 모음이다. 수업에서는 `collections`, `math`, `datetime`을 사용했다.

> **핵심:** 자주 필요한 자료 처리, 수학 계산, 날짜·시간 기능을 기본 모듈에서 가져와 사용할 수 있다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
collections → 자료 개수와 기본값 처리
math → 수학 함수와 상수
datetime → 날짜와 시간 처리
```

> **쉽게 말하면:** Python을 설치하면 함께 제공되는 기본 도구 상자이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
from collections import Counter, defaultdict
import math
from datetime import datetime, timedelta
```

- `Counter` → 값별 개수 계산
- `defaultdict` → 없는 키에 기본값 생성
- `math` → 제곱근, 로그, 올림·내림 등 계산
- `datetime` → 날짜와 시간 표현 및 변환
- `timedelta` → 날짜와 시간의 차이 표현

> **핵심:** 모듈 전체가 필요하면 `import`, 특정 이름만 필요하면 `from ... import ...`을 사용한다.

------------------------------------------------------------------------

## 4. 예제

``` python
from collections import Counter
from datetime import datetime, timedelta
import math

print(Counter(["a", "b", "a"]))
print(math.sqrt(100))

now = datetime.now()
print(now.strftime("%Y-%m-%d"))
print(now + timedelta(days=7))
```

실행 결과 예시:

``` text
Counter({'a': 2, 'b': 1})
10.0
현재 날짜 형식의 문자열
현재보다 7일 뒤의 날짜와 시간
```

### 코드 해석

- `Counter(...)` → 같은 값의 등장 횟수를 센다.
- `math.sqrt(100)` → 100의 제곱근을 구한다.
- `strftime()` → 날짜·시간 객체를 문자열로 바꾼다.
- `timedelta(days=7)` → 7일이라는 시간 차이를 만든다.

> **결과 해석:** 서로 다른 표준 모듈의 기능을 하나의 프로그램에서 함께 사용할 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `strftime()` | `strptime()` |
| --- | --- | --- |
| 변환 방향 | 날짜·시간 → 문자열 | 문자열 → 날짜·시간 |
| 결과 | `str` | `datetime` |
| 형식 지정 | `%Y-%m-%d` 등 | 입력 문자열과 같은 형식 필요 |

------------------------------------------------------------------------

## 6. 주의할 점

- 표준 라이브러리는 별도 설치가 필요 없지만 사용 전 `import`는 필요하다.
- `weekday()`는 월요일이 `0`, 일요일이 `6`이다.
- `strptime()`의 형식 문자열은 입력 문자열 구조와 일치해야 한다.
