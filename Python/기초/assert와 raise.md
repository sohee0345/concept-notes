# assert와 raise

## 1. 개념

`assert`와 `raise`는 코드에서 예외를 발생시키는 방법이다. `assert`는 조건이 참인지 검사하고, `raise`는 원하는 상황에서 직접 예외를 발생시킨다.

> **핵심:** 조건 검사는 `assert`, 명시적인 예외 발생은 `raise`로 구분한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
assert → 조건이 맞는지 검사 → False이면 AssertionError
raise  → 지정한 시점에 직접 예외 발생
```

> **쉽게 말하면:** assert는 조건을 통과하는지 검사하는 문이고, raise는 코드가 직접 오류 신호를 보내는 명령이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
assert 조건, "오류 메시지"

if 잘못된_조건:
    raise Exception("오류 메시지")
```

- `assert` → 조건이 `False`이면 `AssertionError`를 발생시킨다.
- `raise` → 지정한 예외와 메시지를 직접 발생시킨다.

> **핵심:** 두 문법 모두 실행 흐름을 중단시킬 수 있으므로 어떤 조건에서 예외가 생기는지 명확히 작성한다.

------------------------------------------------------------------------

## 4. 예제

``` python
x = 4
assert x % 3 == 0, "오류입니다."
```

실행 결과:

``` text
AssertionError: 오류입니다.
```

``` python
x = 4
if x % 3 != 0:
    raise Exception("오류입니다.")
```

실행 결과:

``` text
Exception: 오류입니다.
```

### 코드 해석

- 첫 코드는 `4`가 `3`으로 나누어떨어지는지 검사한다.
- 두 번째 코드는 나누어떨어지지 않을 때 직접 예외를 발생시킨다.

> **결과 해석:** 같은 조건 문제를 검사해도 발생 방식과 예외 종류가 다르다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `assert` | `raise` |
| --- | --- | --- |
| 목적 | 조건 검사 | 직접 예외 발생 |
| 발생 조건 | 조건이 `False` | 코드가 `raise`에 도달 |
| 예외 | `AssertionError` | 지정한 예외 |

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `assert` | 조건이 거짓이면 검증 실패 예외 발생 |
| `raise` | 원하는 시점에 직접 예외 발생 |
| `AssertionError` | assert 조건이 거짓일 때 발생하는 예외 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `assert 조건, 메시지` | 조건 검사 |
| `raise Exception(메시지)` | 직접 예외 발생 |

### ⭐ 한 줄 정리

> **assert는 조건을 검사하고 raise는 원하는 상황에서 직접 예외를 발생시킨다.**
