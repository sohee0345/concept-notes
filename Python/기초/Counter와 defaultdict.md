# Counter와 defaultdict

## 1. 개념

`Counter`는 값별 등장 횟수를 계산하고, `defaultdict`는 존재하지 않는 키에 접근할 때 기본값을 자동으로 만드는 `collections`의 자료형이다.

> **핵심:** Counter는 빈도를 세고 defaultdict는 없는 키의 초기값 처리를 단순하게 만든다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
Counter     → 같은 값이 몇 개인지 집계
defaultdict → 처음 보는 키에 기본값 준비
```

> **쉽게 말하면:** 하나는 자동 개표기이고 다른 하나는 새 항목의 시작값을 자동으로 채우는 딕셔너리이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
from collections import Counter, defaultdict

counter = Counter(["a", "b", "a"])
counts = defaultdict(int)
counts["x"] += 1
```

- `Counter(values)` → 값별 개수를 저장한다.
- `defaultdict(int)` → 없는 키의 기본값으로 `0`을 만든다.
- `elements()` → 개수만큼 반복된 원소를 돌려준다.

> **핵심:** defaultdict에 기본값을 만드는 함수를 전달한다.

------------------------------------------------------------------------

## 4. 예제

``` python
counter = Counter(["aa", "bb", "aa", "tt"])
print(counter)
print(list(counter.elements()))
```

실행 결과:

``` text
Counter({'aa': 2, 'bb': 1, 'tt': 1})
['aa', 'aa', 'bb', 'tt']
```

### 코드 해석

- Counter는 각 문자열의 등장 횟수를 저장한다.
- `elements()`는 저장된 횟수만큼 원소를 반복한다.

> **결과 해석:** 빈도 정보와 원래 원소의 반복 형태를 모두 확인할 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `Counter` | `defaultdict` |
| --- | --- | --- |
| 목적 | 빈도 계산 | 없는 키의 기본값 생성 |
| 대표 입력 | 여러 값 | 기본값 생성 함수 |
