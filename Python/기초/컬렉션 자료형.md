# 컬렉션 자료형

## 1. 개념

컬렉션은 여러 데이터를 하나로 묶어 관리하는 자료형이다. 리스트, 튜플, 딕셔너리, 집합은 저장 방식과 조회·수정 방법이 서로 다르므로 목적에 맞게 선택해야 한다.

> **핵심:** 순서, 수정 가능 여부, 접근 방식, 중복 허용 여부를 기준으로 컬렉션을 구분한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
순서대로 저장하고 수정       → 리스트
순서대로 저장하되 수정 금지  → 튜플
이름표와 값을 함께 저장      → 딕셔너리
중복 없이 값 저장            → 집합
```

> **쉽게 말하면:** 같은 여러 값이라도 어떻게 찾고 바꿀 것인지에 따라 알맞은 그릇이 달라진다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
numbers = [1, 2, 3]
point = (10, 20)
person = {"name": "홍길동", "age": 20}
unique = {1, 1, 2, 3}
```

- 리스트와 튜플 → 정수 인덱스로 조회한다.
- 딕셔너리 → 키로 값을 조회한다.
- 집합 → 중복된 값을 하나만 남긴다.

> **핵심:** 데이터 자체만 순서대로 관리하면 리스트나 튜플을, 데이터의 의미를 나타내는 이름표가 필요하면 딕셔너리를 사용한다.

------------------------------------------------------------------------

## 4. 예제

``` python
a = [1, 2]
a.append([3, 4])
print(a)

b = [1, 2]
b.extend([3, 4])
print(b)

print({1, 1, 1, 1})
```

실행 결과:

``` text
[1, 2, [3, 4]]
[1, 2, 3, 4]
{1}
```

### 코드 해석

- `append()` → 리스트 `[3, 4]`를 하나의 원소로 추가한다.
- `extend()` → `[3, 4]`의 원소를 각각 추가한다.
- 집합 → 중복된 `1`을 하나만 보관한다.

> **결과 해석:** 추가 방식과 중복 처리 방식에 따라 컬렉션의 결과 구조가 달라진다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 리스트 | 튜플 | 딕셔너리 | 집합 |
| --- | --- | --- | --- | --- |
| 형태 | `[1, 2]` | `(1, 2)` | `{"a": 1}` | `{1, 2}` |
| 인덱싱 | 가능 | 가능 | 불가능 | 불가능 |
| 수정 | 가능 | 불가능 | 가능 | 가능 |
| 중복 | 허용 | 허용 | 키는 중복 불가 | 불허 |
| 접근 | 인덱스 | 인덱스 | 키 | 값 자체 |

------------------------------------------------------------------------

## 6. 주의할 점

- 튜플의 원소는 바꿀 수 없지만 튜플이 저장된 변수 전체에는 새 값을 대입할 수 있다.
- 리스트와 튜플처럼 서로 다른 자료형끼리는 `+`로 연결할 수 없다.
- `len()`은 리스트 안의 각 값의 길이가 아니라 리스트의 원소 개수를 센다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `list` | 순서가 있고 수정 가능한 컬렉션 |
| `tuple` | 순서가 있고 수정 불가능한 컬렉션 |
| `dict` | 키와 값의 쌍으로 구성된 컬렉션 |
| `set` | 중복을 허용하지 않는 컬렉션 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `append()` | 값을 하나의 원소로 추가 |
| `extend()` | 여러 원소를 풀어서 추가 |
| `dic.items()` | 딕셔너리의 키와 값 조회 |
