# 컬렉션 자료형

## 1. 개념

컬렉션 자료형은 여러 데이터를 한곳에 저장한다. Python의 대표적인 컬렉션에는 리스트, 튜플, 딕셔너리, 집합이 있으며 수정 여부와 접근 방법, 중복 허용 여부가 다르다.

> **핵심:** 데이터의 순서, 수정 가능성, 이름표 필요 여부, 중복 허용 여부에 맞춰 자료형을 선택한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
순서대로 저장하고 수정 → 리스트
순서대로 저장하고 원소 고정 → 튜플
키로 의미를 붙여 저장 → 딕셔너리
중복 없이 저장 → 집합
```

> **쉽게 말하면:** 여러 값을 어떤 방식으로 보관하고 찾을지에 따라 그릇을 선택하는 것이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
lst = [1, 2, 3]
tup = (1, 2, 3)
dic = {"one": 1, "two": 2}
numbers = {1, 1, 2}
```

- 리스트·튜플 → 인덱스로 조회
- 딕셔너리 → 키로 조회
- 집합 → 중복을 제거해 값 자체를 저장

> **핵심:** 리스트와 딕셔너리는 수정 가능하고, 튜플의 원소는 수정할 수 없다.

------------------------------------------------------------------------

## 4. 예제

``` python
lst = [1, 2]
lst.append([3, 4])
print(lst)

lst = [1, 2]
lst.extend([3, 4])
print(lst)

dic = {"one": 1, "two": 2}
for k, v in dic.items():
    print(k, v)
```

실행 결과:

``` text
[1, 2, [3, 4]]
[1, 2, 3, 4]
one 1
two 2
```

### 코드 해석

- `append()` → 전달한 리스트 전체를 원소 하나로 추가한다.
- `extend()` → 전달한 리스트의 원소를 각각 추가한다.
- `items()` → 딕셔너리의 키와 값을 쌍으로 가져온다.

> **결과 해석:** 같은 리스트를 전달해도 `append()`와 `extend()`는 서로 다른 구조를 만들며, 딕셔너리는 키와 값을 함께 순회할 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 리스트 | 튜플 | 딕셔너리 | 집합 |
| --- | --- | --- | --- | --- |
| 형태 | `[]` | `()` | `{key: value}` | `{value}` |
| 접근 | 인덱스 | 인덱스 | 키 | 값 자체 |
| 수정 | 가능 | 원소 수정 불가 | 가능 | 가능 |
| 중복 | 허용 | 허용 | 키 중복 불가 | 불허 |

------------------------------------------------------------------------

## 6. 주의할 점

- `len(리스트)`는 리스트 안 각 값의 길이가 아니라 원소 개수를 반환한다.
- 튜플 원소 수정은 불가능하지만 튜플을 가리키던 변수 전체에 새 값을 대입할 수는 있다.
- 빈 중괄호 `{}`는 빈 집합이 아니라 빈 딕셔너리 형태이다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `list` | 순서가 있고 수정 가능한 컬렉션 |
| `tuple` | 순서가 있고 원소 수정이 불가능한 컬렉션 |
| `dict` | 키와 값으로 관리하는 컬렉션 |
| `set` | 중복을 허용하지 않는 컬렉션 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `append()` | 값을 원소 하나로 추가 |
| `extend()` | 여러 원소를 풀어서 추가 |
| `dic.items()` | 키와 값의 쌍 조회 |

### ⭐ 한 줄 정리

> **리스트, 튜플, 딕셔너리, 집합은 데이터를 저장하는 방식과 수정·접근·중복 규칙이 서로 다르다.**
