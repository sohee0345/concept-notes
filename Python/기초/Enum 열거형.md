# Enum 열거형

## 1. 개념

Enum은 서로 관련된 여러 값을 이름이 있는 멤버의 집합으로 정의하는 열거형이다. 정해진 선택지를 한곳에 모으고 멤버 값을 함부로 바꾸지 못하게 할 때 사용할 수 있다.

> **핵심:** Enum은 이름과 값을 묶어 정해진 값의 집합을 표현한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
RAINBOW
  ├─ RED = "빨강"
  ├─ ORANGE = "주황"
  └─ YELLOW = "노랑"
```

> **쉽게 말하면:** 사용할 수 있는 선택지에 이름표를 붙여 하나의 목록으로 만든 것이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
import enum

class RAINBOW(enum.Enum):
    RED = "빨강"
    ORANGE = "주황"

RAINBOW.RED.value
```

- `enum.Enum` → 열거형 클래스의 기반
- `RAINBOW.RED` → `RED` 멤버
- `.value` → 멤버에 연결된 값

> **핵심:** 서로 관련된 고정 선택지를 이름과 값의 쌍으로 묶어 정의한다.

------------------------------------------------------------------------

## 4. 예제

``` python
RAINBOW.RED.value
```

실행 결과:

``` text
'빨강'
```

`RAINBOW.RED.value = "블랙"`처럼 값을 바꾸려고 하면 `AttributeError`가 발생한다.

### 코드 해석

- `RAINBOW.RED`는 열거형에 정의된 멤버를 선택한다.
- `.value`는 해당 멤버에 연결된 실제 값을 가져온다.

> **결과 해석:** Enum 멤버의 값은 정의된 뒤 직접 바꿀 수 없다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 대문자 변수 | Enum 멤버 |
| --- | --- | --- |
| 변경 제한 | 관례일 뿐 재할당 가능 | 멤버 값 직접 변경 불가 |
| 용도 | 하나의 변경하지 않을 값 표현 | 관련된 값의 집합 표현 |

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `Enum` | 이름이 있는 값의 집합 |
| `멤버` | Enum에 정의된 각 항목 |
| `.value` | 멤버에 연결된 실제 값 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `class 이름(enum.Enum)` | Enum 정의 |
| `이름.멤버.value` | 멤버 값 조회 |

### ⭐ 한 줄 정리

> **Enum은 관련된 고정 선택지를 이름과 값으로 묶어 표현한다.**
