# 변수와 상수

## 1. 개념

변수는 값을 저장하는 이름이며 새로운 값을 다시 대입할 수 있다. Python에서는 변경하지 않을 값을 대문자 이름으로 작성해 상수라는 의도를 나타내지만, 일반 변수처럼 재할당할 수 있다.

> **핵심:** Python의 대문자 상수 표기는 변경 불가능을 강제하는 문법이 아니라 이름 작성 관례이다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
name = "홍길동"
  ↓ 새 값 대입
name = "신사임당"
```

> **쉽게 말하면:** 변수는 내용물을 바꿀 수 있는 이름표이고, 대문자 상수명은 바꾸지 않기로 약속한 이름표이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
name = "홍길동"
PI = 3.14
```

- `변수명 = 값` → 오른쪽 값을 왼쪽 이름에 대입하여 저장
- `name` → 일반 변수 이름
- `PI` → 상수라는 의도를 나타내는 대문자 이름

> **핵심:** 대문자로 작성해도 Python 문법이 값의 변경을 막지는 않는다.

------------------------------------------------------------------------

## 4. 예제

``` python
name = "홍길동"
name = "신사임당"
name
```

실행 결과:

``` text
'신사임당'
```

``` python
PI = 3.14
PI = "홍길동"
PI
```

실행 결과:

``` text
'홍길동'
```

> **결과 해석:** 새 값을 대입하면 기존 값이 바뀌며 대문자 상수명도 Python 문법상 재대입할 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 변수 | 상수 이름 관례 |
| --- | --- | --- |
| 이름 예시 | `name` | `PI` |
| 값 변경 | 가능 | 문법상 가능하지만 변경하지 않기로 약속 |
| 표기 | 보통 소문자 | 대문자 |
