# 변수와 상수

## 1. 개념

변수는 값을 저장하는 이름이며 저장된 값을 변경할 수 있다. Python에서는 변경하지 않을 값의 이름을 대문자로 작성하는 관례가 있지만, 대문자로 썼다는 이유만으로 값 변경이 금지되지는 않는다.

> **핵심:** Python의 일반 변수와 대문자 상수명은 모두 값을 다시 대입할 수 있으며, 대문자 표기는 변경하지 않겠다는 약속이다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

변수는 내용물을 바꿀 수 있는 이름표가 붙은 상자와 같다. 대문자로 작성한 상수명은 상자에 “바꾸지 않음”이라고 표시한 것이지만, Python이 변경 자체를 막지는 않는다.

``` text
name = "홍길동"
  ↓ 다시 대입
name = "신사임당"
```

> **쉽게 말하면:** 변수는 값을 담는 이름이고, 대문자 상수명은 그 값을 바꾸지 말자는 작성 규칙이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
name = "홍길동"
PI = 3.14
```

- `변수명 = 변수값` → 오른쪽 값을 왼쪽 이름에 저장
- `name` → 일반 변수 이름
- `PI` → 변경하지 않을 값에 사용하는 대문자 이름 관례

> **핵심:** `=`은 오른쪽의 값을 왼쪽 변수명에 대입한다.

### 이름이 있는 상수 집합 `enum.Enum`

서로 관련된 상수를 이름과 값의 쌍으로 묶으려면 `enum.Enum`을 사용할 수 있다.

``` python
import enum

class 가위바위보(enum.Enum):
    가위 = 0
    바위 = 1
    보 = 2
```

- `가위바위보.__members__` → Enum에 등록된 멤버 이름과 멤버 확인
- `가위바위보["가위"]` → 문자열 이름으로 멤버 조회
- `가위바위보["가위"].value` → 해당 멤버의 값 `0` 조회

------------------------------------------------------------------------

## 4. 예제

``` python
name = "홍길동"
name
```

실행 결과:

``` text
'홍길동'
```

``` python
name = "신사임당"
name
```

실행 결과:

``` text
'신사임당'
```

상수 이름을 대문자로 작성해도 값을 다시 대입할 수 있다.

``` python
PI = 3.14
PI = "홍길동"
PI
```

실행 결과:

``` text
'홍길동'
```

### 코드 해석

- `name = "홍길동"` → 문자열을 `name`에 저장한다.
- `name = "신사임당"` → 같은 변수에 새 값을 대입한다.
- `PI = 3.14` → 변경하지 않을 값이라는 뜻으로 이름을 대문자로 작성한다.

> **결과 해석:** 변수는 새 값을 대입하면 기존 값이 바뀌며, 대문자 상수명도 Python 문법상 재대입이 가능하다.

Enum의 멤버 이름을 확인하고 이름을 통해 값을 조회할 수 있다.

``` python
import enum

class 가위바위보(enum.Enum):
    가위 = 0
    바위 = 1
    보 = 2

print(가위바위보.__members__)
print(가위바위보["보"].value)
```

`__members__`에 입력값이 있는지 확인하면 허용되지 않은 이름을 걸러낼 수 있다.

``` python
사용자_선택 = "가위"
assert 사용자_선택 in 가위바위보.__members__, "잘못 입력했습니다."
```

가위바위보처럼 값이 순환하는 규칙은 두 Enum 값의 차이와 나머지 연산으로 판정할 수 있다.

``` python
사용자_선택 = "가위"
컴퓨터_선택 = "보"

결과 = (
    가위바위보[사용자_선택].value
    - 가위바위보[컴퓨터_선택].value
) % 3

print(결과)
```

실행 결과:

``` text
1
```

### Enum 코드 해석

- `__members__` → 정의된 멤버 이름을 검사할 때 사용한다.
- `가위바위보[이름]` → 문자열로 Enum 멤버를 찾는다.
- `.value` → 멤버에 연결된 값을 가져온다.
- `(사용자 값 - 컴퓨터 값) % 3` → 수업의 규칙에서 `1`은 승, `0`은 무, 나머지는 패를 뜻한다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 변수 | 대문자 상수명 | `enum.Enum` 멤버 |
| --- | --- | --- | --- |
| 의미 | 값을 저장하는 이름 | 변경하지 않기로 약속한 이름 | 관련된 상수 값의 집합 |
| 값 변경 | 가능 | 문법상 가능 | 멤버의 `value` 직접 변경 불가 |
| 예시 | `name` | `PI` | `RAINBOW.RED` |
| 이름으로 조회 | 해당 없음 | 해당 없음 | `가위바위보["가위"]` |
| 등록 이름 확인 | 해당 없음 | 해당 없음 | `가위바위보.__members__` |

------------------------------------------------------------------------

## 6. 주의할 점

- “변수는 변하는 수”라기보다 값을 저장하고 다시 대입할 수 있는 이름으로 이해한다.
- 상수 이름을 대문자로 작성하는 것은 관례이며 Python이 재대입을 자동으로 막아 주는 것은 아니다.
- Enum 멤버의 이름과 값은 구분해서 사용한다. 이름으로 멤버를 찾은 뒤 `.value`로 연결된 값을 조회한다.
- 가위바위보 판정식은 `가위=0`, `바위=1`, `보=2`라는 수업의 값 배치에 맞춘 규칙이다.
