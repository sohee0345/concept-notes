# 변수와 상수

## 1. 개념

변수는 값을 저장하는 이름이며 새로운 값을 다시 대입할 수 있다. Python에서는 변경하지 않을 값을 대문자 이름으로 작성해 상수라는 의도를 나타내지만 값 변경을 문법으로 막지는 않는다.

> **핵심:** Python 변수는 재대입할 수 있고 대문자 상수 표기는 강제 규칙이 아니라 관례이다.

---

## 2. 쉽게 이해하기

변수는 이름표가 붙은 상자처럼 값을 담는다. 대문자로 쓴 이름은 바꾸지 않겠다는 표시이지만 Python이 변경을 직접 막지는 않는다.

```text
name = "홍길동"
  ↓ 새 값 대입
name = "신사임당"
```

---

## 3. 사용 방법

```python
name = "홍길동"
PI = 3.14
```

- `name` → 값을 저장하는 일반 변수 이름이다.
- `=` → 오른쪽 값을 왼쪽 이름에 대입한다.
- `PI` → 변경하지 않을 값이라는 의도를 대문자로 표시한 이름이다.

---

## 4. 예제

```python
name = "홍길동"
name = "신사임당"

PI = 3.14
PI = "홍길동"

print(name)
print(PI)
```

실행 결과:

```text
신사임당
홍길동
```

마지막에 대입한 값이 저장되므로 대문자 상수 이름도 재대입이 가능하다.

---

## 5. 헷갈리는 개념 비교

|구분|변수|상수 이름 관례|
|---|---|---|
|이름 예시|`name`|`PI`|
|재대입|가능|문법적으로 가능|
|의도|값이 바뀔 수 있음|변경하지 않을 값임을 표시|
