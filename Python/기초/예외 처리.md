# 예외 처리

## 1. 개념

예외 처리는 프로그램 실행 중 발생할 수 있는 오류에 대응하여 실행 흐름을 관리하는 방법이다. `try`에서 예외 가능성이 있는 코드를 실행하고 `except`에서 발생한 예외를 처리한다.

> **핵심:** 예상 가능한 예외를 처리하면 오류가 발생했을 때 실행할 대응 흐름을 정할 수 있다.

---

## 2. 쉽게 이해하기

문제가 생길 수 있는 작업에 미리 대응 절차를 준비하는 것과 같다. 성공과 실패를 나누고 어느 경우에도 실행할 마무리 작업을 지정할 수 있다.

```text
try 실행
  ├─ 예외 발생 → except
  └─ 예외 없음 → else
                    ↓
            finally는 항상 실행
```

---

## 3. 사용 방법

```python
try:
    예외가_발생할_수_있는_코드
except ValueError:
    예외_처리_코드
else:
    예외가_없을_때_코드
finally:
    항상_실행할_코드
```

- `try` → 예외가 발생할 수 있는 코드를 실행한다.
- `except` → 지정한 예외가 발생했을 때 실행한다.
- `else` → 예외가 없을 때만 실행한다.
- `finally` → 예외 발생 여부와 관계없이 항상 실행한다.
- `assert` → 조건이 거짓이면 `AssertionError`를 발생시킨다.
- `raise` → 원하는 상황에서 예외를 직접 발생시킨다.

---

## 4. 예제

```python
x = "120"

try:
    print(f"{int(x)}는 숫자입니다.")
except ValueError:
    print("오류예요")
else:
    print("변환 성공")
finally:
    print("처리 종료")
```

실행 결과:

```text
120는 숫자입니다.
변환 성공
처리 종료
```

정수 변환에 성공해 `else`가 실행되고 마지막에는 `finally`도 실행된다.

---

## 5. 헷갈리는 개념 비교

|구분|`assert`|`raise`|
|---|---|---|
|역할|조건이 참인지 검사|원하는 예외를 직접 발생|
|예외|`AssertionError`|지정한 예외|
