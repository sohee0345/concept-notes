# 예외 처리

## 1. 개념

예외 처리는 프로그램 실행 중 발생할 수 있는 오류에 대응하여 실행 흐름을 관리하는 방법이다. `try`에서 코드를 실행하고 문제가 생기면 해당 예외를 처리하는 `except` 블록으로 이동한다.

> **핵심:** 예상할 수 있는 예외를 처리하면 오류가 발생한 상황에 맞는 동작을 실행할 수 있다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
try 실행
  ├─ 예외 발생 → except
  └─ 정상 실행 → else
          ↓
finally는 항상 실행
```

> **쉽게 말하면:** 먼저 작업을 시도하고, 실패하면 대응하며, 성공하면 성공 코드를 실행한 뒤 공통 마무리를 하는 구조이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
try:
    예외가_발생할_수_있는_코드
except ValueError:
    예외_대응_코드
else:
    정상_실행_코드
finally:
    항상_실행할_코드
```

- `try` → 예외가 발생할 수 있는 코드를 실행한다.
- `except` → 지정한 예외가 발생하면 실행한다.
- `else` → 예외가 발생하지 않았을 때 실행한다.
- `finally` → 예외 발생 여부와 관계없이 실행한다.

> **핵심:** 발생 가능한 예외 종류에 맞는 `except`를 작성한다.

------------------------------------------------------------------------

## 4. 예제

``` python
x = "홍길동"

try:
    print(f"{int(x)}는 숫자입니다.")
except ValueError:
    print("숫자로 바꿀 수 없습니다.")
finally:
    print("처리 종료")
```

실행 결과:

``` text
숫자로 바꿀 수 없습니다.
처리 종료
```

### 코드 해석

- `int(x)` → 문자열을 정수로 바꾸려다 `ValueError`가 발생한다.
- `except ValueError` → 변환 오류에 대응한다.
- `finally` → 예외가 발생해도 실행된다.

> **결과 해석:** 오류 상황을 처리한 뒤 공통 마무리 코드까지 실행된다.

------------------------------------------------------------------------

## 6. 주의할 점

- `else`는 예외가 없을 때만 실행되지만 `finally`는 예외 여부와 관계없이 실행된다.
- `NameError`, `ZeroDivisionError`, `IndexError`, `KeyError`, `TypeError`, `ValueError`처럼 예외 원인에 따라 종류가 다르다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `try` | 예외 발생 가능 코드 실행 |
| `except` | 발생한 예외 처리 |
| `else` | 예외가 없을 때 실행 |
| `finally` | 예외 여부와 관계없이 실행 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `except ValueError` | 값 변환 관련 예외 처리 |
| `int(x)` | 값을 정수로 변환 |

### ⭐ 한 줄 정리

> **예외 처리는 try·except로 오류에 대응하고 else·finally로 정상 흐름과 공통 마무리를 구분한다.**
