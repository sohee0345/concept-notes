# 반복문

## 1. 개념

반복문은 같은 코드를 여러 번 실행하는 흐름 제어 문법이다. `for`문은 데이터의 값을 순서대로 꺼내 반복하고 `while`문은 조건이 `True`인 동안 반복한다.

> **핵심:** `for`는 데이터의 값을 기준으로, `while`은 조건의 참·거짓을 기준으로 반복한다.

---

## 2. 쉽게 이해하기

`for`는 준비된 목록을 한 항목씩 처리하고 `while`은 정해진 조건이 유지되는 동안 같은 일을 계속한다.

```text
for → 다음 값이 있는가? → 값을 꺼내 실행
while → 조건이 True인가? → 실행 후 조건 재확인
```

---

## 3. 사용 방법

```python
for value in [1, 2, 3]:
    print(value)

while 조건:
    반복할_코드
```

- `break` → 반복문을 즉시 종료한다.
- `continue` → 현재 회차의 나머지를 건너뛰고 다음 반복으로 이동한다.
- `pass` → 아무 동작도 하지 않고 다음 코드를 계속 실행한다.
- `for ~ else` → 반복이 `break` 없이 끝났을 때 `else`를 실행한다.

---

## 4. 예제

```python
x = 3

for i in [1, 2, 3, 4, 5]:
    if i % 2 == 0:
        print(f"{x} * {i} = {x * i}")
        break
else:
    print("반복 완료")
```

실행 결과:

```text
3 * 2 = 6
```

첫 번째 짝수인 `2`를 처리한 뒤 `break`로 종료하므로 `else`는 실행되지 않는다.

---

## 5. 헷갈리는 개념 비교

|구분|`break`|`continue`|`pass`|
|---|---|---|---|
|역할|반복문 종료|다음 반복으로 이동|아무 동작도 하지 않음|
|반복 지속|종료|지속|지속|
