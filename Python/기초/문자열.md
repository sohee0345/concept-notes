# 문자열

## 1. 개념

문자열은 문자들이 순서대로 모인 자료형이다. 각 문자는 위치를 나타내는 인덱스를 가지므로 한 문자를 조회하거나 범위를 잘라 낼 수 있으며, 메서드와 포맷팅을 이용해 내용을 가공할 수 있다.

> **핵심:** 문자열은 순서가 있는 데이터이므로 인덱싱과 슬라이싱이 가능하고 다양한 메서드로 처리할 수 있다.

---

## 2. 쉽게 이해하기

문자열은 글자가 한 칸씩 들어 있는 긴 상자와 같다. 첫 번째 칸의 번호는 `0`이며 음수 인덱스는 뒤에서부터 위치를 센다.

```text
H  e  l  l  o
0  1  2  3  4
-5 -4 -3 -2 -1
```

---

## 3. 사용 방법

```python
text = "Hello World"

len(text)
text[0]
text[0:3]
text[시작:끝:간격]
```

- `len()` → 공백을 포함한 문자열 길이를 구한다.
- `text[0]` → 첫 번째 문자를 가져온다.
- `text[시작:끝:간격]` → 시작부터 끝 직전까지 지정한 간격으로 가져온다.
- `\n` → 줄바꿈을 표현한다.
- `\t` → 탭 간격을 표현한다.

---

## 4. 예제

```python
text = "  hello, world, hello  "

print(text.count("hello"))
print(text.strip())
print(text.replace("hello", "hi"))

who = "I"
number = 5
print(f"{who} eat {number} apples.")
```

실행 결과:

```text
2
hello, world, hello
  hi, world, hi  
I eat 5 apples.
```

`count()`는 개수를 세고 `strip()`은 양 끝 공백을 제거한다. `replace()`는 문자열을 치환하며 f-string은 중괄호 안의 값을 문자열에 넣는다.

---

## 5. 헷갈리는 개념 비교

|구분|인덱싱|슬라이싱|
|---|---|---|
|의미|한 위치의 문자 조회|범위에 해당하는 문자열 조회|
|예시|`text[0]`|`text[0:3]`|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|`인덱싱`|위치 번호로 문자 하나를 조회하는 방법|
|`슬라이싱`|시작·끝·간격으로 범위를 조회하는 방법|
|`f-string`|중괄호 안의 값을 문자열에 넣는 포맷팅 방법|

### 💻 주요 코드

|코드|의미|
|---|---|
|`len(text)`|문자열 길이 확인|
|`text[시작:끝:간격]`|문자열 슬라이싱|
|`text.strip()`|양 끝 공백 제거|
|`f"{값}"`|값을 포함한 문자열 생성|
