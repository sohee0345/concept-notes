# 환경 변수 설정

## 1. 개념

환경 변수는 비밀번호와 접속 정보 같은 설정값을 소스 코드와 분리해 관리하는 방법이다. `.env` 파일의 값은 `load_dotenv()`로 프로세스 환경 변수에 불러온 뒤 `os.getenv()`로 읽는다.

> **핵심:** 민감한 설정은 코드에 직접 쓰지 않고 `.env`와 환경 변수로 분리한다.

---

## 2. 쉽게 이해하기

코드는 설정값의 이름만 알고 실제 비밀번호는 별도 보관함에서 실행 시 불러오는 방식이다.

```text
.env → load_dotenv() → 프로세스 환경 변수 → os.getenv()
```

---

## 3. 사용 방법

```python
import os
from dotenv import load_dotenv

load_dotenv()
password = os.getenv("DB_PASSWORD")
port = int(os.getenv("DB_PORT", "3306"))
```

- `.env` → 설정값을 저장하는 파일이다.
- `load_dotenv()` → `.env` 값을 현재 프로세스에 불러온다.
- `os.getenv()` → 환경 변수 값을 읽는다.
- 두 번째 인자는 값이 없을 때 사용할 기본값이다.

---

## 4. 예제

```python
DB_CONFIG = {
    "host": os.getenv("DB_HOST"),
    "port": int(os.getenv("DB_PORT", "3306")),
    "user": os.getenv("DB_USER"),
    "password": os.getenv("DB_PASSWORD"),
    "database": os.getenv("DB_NAME"),
}
```

접속 정보를 하나의 딕셔너리로 모아 데이터베이스 연결에 전달한다.

---

## 5. 헷갈리는 개념 비교

|구분|`.env` 파일|프로세스 환경 변수|
|---|---|---|
|역할|설정값 저장|실행 중 프로그램이 읽는 값|
|연결|`load_dotenv()`로 불러옴|`os.getenv()`로 조회|
