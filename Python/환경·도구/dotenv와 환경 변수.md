# dotenv와 환경 변수

## 1. 개념

환경 변수는 프로그램 설정을 소스 코드 밖에서 전달하는 방법이다. `.env` 파일은 로컬 개발 환경에서 환경 변수 형식의 설정값을 파일로 관리하며, 비밀번호나 API 키를 코드와 분리할 때 유용하다.

> **핵심:** 민감한 설정값은 코드에 직접 쓰지 않고 환경 변수로 주입한다.

------------------------------------------------------------------------

## 2. 동작 흐름

```text
.env 파일
  ↓ load_dotenv()
현재 Python 프로세스의 환경 변수
  ↓ os.getenv()
프로그램 설정
```

`.env` 파일을 생성하는 것만으로 Python이 내용을 읽는 것은 아니다. `python-dotenv`의 `load_dotenv()`를 호출해 값을 불러와야 한다.

------------------------------------------------------------------------

## 3. 사용 방법

`.env` 파일:

```dotenv
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=비밀번호
DB_NAME=classicmodels
```

Python 코드:

```python
import os

from dotenv import load_dotenv

load_dotenv()

db_config = {
    "host": os.getenv("DB_HOST"),
    "port": int(os.getenv("DB_PORT", "3306")),
    "user": os.getenv("DB_USER"),
    "password": os.getenv("DB_PASSWORD"),
    "database": os.getenv("DB_NAME"),
}
```

- `load_dotenv()` → `.env`의 값을 환경 변수로 불러온다.
- `os.getenv(name)` → 현재 프로세스에서 환경 변수 값을 읽는다.
- `os.getenv(name, default)` → 값이 없을 때 사용할 기본값을 지정한다.

------------------------------------------------------------------------

## 4. 주의할 점

- 환경 변수 값은 문자열이므로 포트처럼 숫자가 필요한 값은 `int()`로 변환한다.
- Jupyter Notebook에서 `.env`를 수정한 뒤 값이 갱신되지 않으면 커널을 재시작한다.
