# 표준 라이브러리

## 1. 개념

표준 라이브러리는 Python을 설치할 때 함께 제공되는 모듈과 패키지의 모음이다. 별도 설치 없이 `import`하여 데이터 처리, 수학 계산, 날짜·시간 처리 등의 기능을 사용할 수 있다.

> **핵심:** 표준 라이브러리는 Python에 기본 포함되지만 사용하려는 모듈은 import해야 한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
Python 설치
  └─ 표준 라이브러리 포함
       ├─ collections
       ├─ math
       ├─ datetime
       ├─ urllib
       └─ re
```

> **쉽게 말하면:** Python을 설치할 때 함께 들어오는 기본 도구 상자이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
import math
from collections import Counter
from datetime import datetime
```

- `import 모듈` → 모듈 전체를 가져온다.
- `from 모듈 import 이름` → 필요한 이름만 가져온다.
- `math.sqrt()` → 모듈 이름을 통해 함수에 접근한다.

> **핵심:** 표준 라이브러리와 외부 라이브러리는 설치 필요 여부가 다르다.

------------------------------------------------------------------------

## 4. 예제

``` python
import math

print(math.sqrt(16))
print(math.ceil(3.1))
print(math.floor(3.9))
```

실행 결과:

``` text
4.0
4
3
```

### 코드 해석

- `sqrt()` → 제곱근을 구한다.
- `ceil()`과 `floor()` → 올림과 내림을 수행한다.

> **결과 해석:** 별도 패키지 설치 없이 `math`를 가져와 수학 기능을 사용했다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 표준 라이브러리 | 외부 라이브러리 |
| --- | --- | --- |
| 제공 | Python 설치에 포함 | 별도 배포 |
| 설치 | 별도 설치 불필요 | 별도 설치 필요 |
| 예 | `math`, `datetime`, `re` | `streamlit`, `pandas` |
