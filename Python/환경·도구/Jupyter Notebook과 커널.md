# Jupyter Notebook과 커널

## 1. 개념

Jupyter Notebook은 설명과 Python 코드를 셀 단위로 작성하고 실행할 수 있는 문서 형식이다. 파일 확장자는 `.ipynb`이며, 커널은 각 코드 셀을 실제로 실행하는 Python 환경이다.

> **핵심:** 노트북에서 코드를 실행하려면 사용할 Python 커널을 선택해야 한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
.ipynb 노트북
  ↓ 코드 셀 실행 요청
선택한 Python 커널
  ↓ 코드 처리
셀 아래에 실행 결과 표시
```

> **쉽게 말하면:** 노트북은 코드와 결과를 보여 주는 작업장이고, 커널은 그 코드를 실행하는 엔진이다.

------------------------------------------------------------------------

## 3. 사용 방법

VSCode에 Jupyter 확장 프로그램을 설치하고 `.ipynb` 파일을 만든다. 노트북에서 사용할 Python 커널을 선택한 뒤 셀을 실행한다.

- `.ipynb` → Jupyter Notebook 파일 확장자
- `커널 선택` → 코드를 실행할 Python 환경 선택
- `Shift+Enter` → 현재 셀 실행

> **핵심:** 코드는 현재 선택한 커널의 Python 환경에서 실행된다.

------------------------------------------------------------------------

## 4. 예제

``` python
name = "홍길동"
name
```

실행 결과:

``` text
'홍길동'
```

### 코드 해석

- 첫 줄은 문자열을 변수에 저장한다.
- 마지막 줄의 변수 이름을 실행하면 노트북이 값을 셀 아래에 표시한다.

> **결과 해석:** 선택한 커널이 코드를 실행하고 변수의 값을 출력한 것이다.

------------------------------------------------------------------------

## 6. 주의할 점

- 코드를 실행하기 전에 사용할 Python 커널을 선택한다.
- 커널 동작에 문제가 있으면 VSCode 명령 팔레트에서 `Python Debugger: Clear Cache and Reload Window`를 실행할 수 있다.
