# PATH 환경 변수

## 1. 개념

PATH는 터미널이 명령에 해당하는 실행 파일을 찾을 때 차례로 확인하는 폴더 목록이다. Python의 설치 경로가 PATH에 등록되어 있으면 어느 폴더에서든 `python` 명령을 실행할 수 있다.

> **핵심:** PATH에 실행 파일의 위치를 등록하면 전체 경로를 입력하지 않고 명령 이름만으로 프로그램을 실행할 수 있다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
python 명령 입력
  ↓ PATH에 등록된 폴더를 순서대로 검색
python.exe 발견
  ↓
Python 실행
```

> **쉽게 말하면:** PATH는 터미널이 프로그램을 찾을 때 사용하는 주소 목록이다.

------------------------------------------------------------------------

## 3. 사용 방법

Python 설치 화면에서 `Add Python to PATH`를 선택한다. 설치가 끝난 뒤 새 터미널을 열고 다음 명령으로 정상 등록 여부를 확인한다.

``` powershell
python --version
```

- `python` → PATH에서 Python 실행 파일을 찾는다.
- `--version` → 실행된 Python의 버전을 출력한다.

> **핵심:** 설치 옵션을 선택하는 데서 끝내지 말고 버전 명령이 실제로 실행되는지 확인한다.

------------------------------------------------------------------------

## 4. 예제

``` powershell
python --version
```

실행 결과 예시:

``` text
Python 3.13.15
```

### 코드 해석

- `3`은 메이저 버전, `13`은 마이너 버전, `15`는 패치 버전이다.

> **결과 해석:** 버전 번호가 출력되면 터미널이 PATH를 통해 Python 실행 파일을 찾은 것이다.

------------------------------------------------------------------------

## 6. 주의할 점

- PATH 등록을 선택한 뒤에도 `python --version`을 실행하여 Python이 정상적으로 인식되는지 확인한다.
