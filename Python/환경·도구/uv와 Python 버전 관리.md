# uv와 Python 버전 관리

## 1. 개념

`uv`는 Python 버전과 패키지, 프로젝트 환경을 관리하는 도구이다. 필요한 Python 버전을 설치하고 새 프로젝트를 초기화하거나, 기존 프로젝트의 설정에 맞춰 가상환경과 패키지를 동기화할 수 있다.

> **핵심:** uv를 사용하면 Python 버전 설치부터 프로젝트 생성과 의존성 동기화까지 한 도구로 관리할 수 있다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
새 프로젝트
  ↓ uv init
프로젝트 설정 생성

기존 프로젝트
  ↓ uv sync
설정에 맞는 환경과 패키지 동기화
```

> **쉽게 말하면:** `uv init`은 프로젝트의 시작점을 만들고, `uv sync`는 준비된 설계도에 맞춰 실행 환경을 맞춘다.

------------------------------------------------------------------------

## 3. 사용 방법

uv를 설치한 뒤 다음 명령을 차례로 실행한다.

``` powershell
uv --version
uv python list
uv python install 3.12
uv python list
uv init
uv sync
```

- `uv --version` → uv의 설치 여부와 버전을 확인한다.
- `uv python list` → 사용할 수 있거나 설치된 Python 버전을 확인한다.
- `uv python install 3.12` → Python 3.12를 설치한다.
- `uv init` → 새 Python 프로젝트의 기본 설정 파일을 생성한다.
- `uv sync` → 프로젝트 설정과 잠금 파일에 맞춰 가상환경과 패키지를 설치·동기화한다.

> **핵심:** 처음 만드는 프로젝트에는 `uv init`, 이미 설정 파일이 있는 프로젝트에는 `uv sync`를 사용한다.

------------------------------------------------------------------------

## 4. 예제

``` text
pyproject.toml 없음
  → uv init

pyproject.toml 있음
  → uv sync
```

### 코드 해석

- `uv init`은 새 프로젝트의 `pyproject.toml` 등 기본 구성을 만든다.
- `uv sync`는 기존 프로젝트에 기록된 의존성을 현재 환경에 맞춘다.

> **결과 해석:** 다른 사람이 만든 프로젝트를 받은 경우에는 새로 초기화하지 않고 기존 설정을 유지한 채 `uv sync`로 환경을 재현한다.
