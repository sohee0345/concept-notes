# uv와 Python 버전 관리

## 1. 개념

uv는 Python 개발 환경에서 Python 버전, 가상환경, 패키지 의존성을 관리할 때 사용하는 도구이다. 수업에서는 uv를 설치하고 Python 3.12를 준비한 뒤, 해당 버전을 사용하는 프로젝트와 가상환경을 구성했다.

> **핵심:** uv를 사용하면 필요한 Python 버전을 준비하고 프로젝트별 가상환경과 패키지 의존성을 함께 관리할 수 있다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

컴퓨터에 여러 Python 버전이 필요할 때마다 설치 파일을 직접 찾는 대신 uv에 원하는 버전을 알려 주어 설치할 수 있다. 프로젝트를 만들 때 사용할 Python 버전과 패키지도 명령으로 지정할 수 있다.

``` text
uv 설치
  ↓
uv 버전 확인
  ↓
Python 버전 목록 확인
  ↓
Python 3.12 설치
  ↓
목록을 다시 확인해 검증
  ↓
Python 3.12 프로젝트 초기화
  ↓
필요한 패키지를 의존성으로 추가
  ↓
가상환경과 의존성 동기화
```

> **쉽게 말하면:** uv는 프로젝트 전용 Python 환경과 필요한 패키지를 한곳에서 관리하도록 도와주는 도구이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` powershell
uv --version
uv python list
uv python install 3.12
uv python list
uv init --name venv-uv --python 3.12
uv add jupyter pandas seaborn
uv sync
```

- `uv --version` → uv 설치 여부와 버전 확인
- `uv python list` → 사용할 수 있거나 설치된 Python 버전 목록 확인
- `uv python install 3.12` → Python 3.12 설치
- `uv init --name venv-uv --python 3.12` → Python 3.12를 사용하는 `venv-uv` 프로젝트 초기화
- `uv add jupyter pandas seaborn` → 패키지를 설치하고 프로젝트 의존성에 등록
- `uv sync` → 프로젝트 설정에 맞게 가상환경과 의존성을 동기화
- `pyproject.toml` → 프로젝트 정보와 의존성을 확인하는 파일

> **핵심:** Python 버전을 검증한 뒤 프로젝트를 초기화하고, `uv add`와 `uv sync`로 의존성과 가상환경을 관리한다.

------------------------------------------------------------------------

## 4. 예제

``` powershell
uv python list
uv python install 3.12
uv python list
uv init --name venv-uv --python 3.12
uv add jupyter pandas seaborn
uv sync
```

### 코드 해석

- 첫 번째 `uv python list` → 현재 확인 가능한 Python 버전을 살펴본다.
- `uv python install 3.12` → Python 3.12 설치를 요청한다.
- 두 번째 `uv python list` → 설치 후 Python 3.12가 목록에 있는지 확인한다.
- `uv init` → 지정한 이름과 Python 버전으로 프로젝트를 초기화한다.
- `uv add` → 패키지를 설치하면서 `pyproject.toml`의 의존성에도 등록한다.
- `uv sync` → 프로젝트 설정과 가상환경의 패키지 구성을 맞춘다.

> **결과 해석:** Python 3.12가 준비되고, `pyproject.toml`에서 `jupyter`, `pandas`, `seaborn` 의존성을 확인할 수 있다. `uv sync`를 실행하면 프로젝트 설정에 맞게 환경이 다시 구성된다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `uv python install` | `uv init` | `uv add` | `uv sync` |
| --- | --- | --- | --- | --- |
| 대상 | Python 버전 | 프로젝트 | 개별 패키지 | 전체 프로젝트 환경 |
| 역할 | 지정한 Python 설치 | 프로젝트 초기화 | 패키지 설치와 의존성 등록 | 설정과 환경 동기화 |
| 사용 시점 | 필요한 Python이 없을 때 | 새 프로젝트를 시작할 때 | 패키지가 필요할 때 | 환경을 다시 맞출 때 |

------------------------------------------------------------------------

## 6. 주의할 점

- `uv python install 3.12`의 `3.12`는 Python 12가 아니라 메이저 버전 3, 마이너 버전 12를 의미한다.
- 설치 명령만 실행하고 끝내지 말고 목록을 다시 조회해 설치 여부를 확인한다.
- `uv add`는 단순히 현재 환경에 패키지를 설치하는 데서 끝나지 않고 프로젝트 의존성에도 등록한다.
- 가상환경을 삭제했거나 환경 구성이 달라졌다면 `uv sync`로 프로젝트 설정에 맞게 다시 동기화한다.
