# 모듈과 패키지

## 1. 개념

모듈은 Python 코드를 나눈 파일이고 패키지는 관련 모듈을 폴더 구조로 묶은 것이다. 화면, 응답 로직, 설정, 이력처럼 변경 이유가 다른 코드를 역할별로 분리하면 필요한 부분만 수정하고 재사용하기 쉽다.

> **핵심:** 모듈과 패키지는 코드를 파일과 폴더 단위로 분리하여 재사용하고 관리하기 쉽게 만든다.

---

## 2. 쉽게 이해하기

하나의 긴 문서를 주제별 파일과 폴더로 정리하고 필요한 내용만 꺼내 쓰는 것과 같다.

```text
패키지 폴더
  ↓ 관련 모듈 배치
from 경로 import 이름
  ↓
필요한 기능 사용
```

---

## 3. 사용 방법

```python
from common.ai.ml import get_model
from common.utils import add, sub
from .constants import ROLE
```

- `from 경로 import 이름` → 지정한 모듈에서 필요한 이름을 가져온다.
- 점(`.`)은 패키지와 모듈의 경로를 구분한다.
- 절대 import는 프로젝트의 패키지 경로를 처음부터 작성한다.
- 상대 import는 현재 패키지를 기준으로 하며 `.`은 현재 패키지를 뜻한다.
- `if __name__ == "__main__":` → 파일을 직접 실행할 때 진입점 역할을 한다.

---

## 4. 예제

```python
from common.ai.ml import get_model

def main():
    print(f"model name: {get_model()}")

if __name__ == "__main__":
    main()
```

직접 실행할 때만 `main()`을 호출하고 다른 파일에서 가져올 때는 함수와 값만 재사용할 수 있다.

---

## 5. 헷갈리는 개념 비교

|구분|절대 import|상대 import|
|---|---|---|
|기준|프로젝트 패키지 경로|현재 패키지|
|예시|`from common.show import show_msg`|`from .constants import ROLE`|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|모듈|재사용 가능한 Python 코드 파일|
|패키지|관련 모듈을 묶은 폴더 구조|
|관심사 분리|화면·로직·설정·이력처럼 책임이 다른 코드를 분리하는 방식|
|진입점|파일을 직접 실행할 때 시작하는 부분|

### 💻 주요 코드

|코드|의미|
|---|---|
|`from module import name`|모듈에서 이름 가져오기|
|`from .module import name`|현재 패키지 기준으로 이름 가져오기|
|`if __name__ == "__main__":`|직접 실행 시 진입점 지정|
