# 모듈과 패키지

## 1. 개념

모듈은 함수나 값을 담은 Python 파일이고, 패키지는 관련 모듈을 폴더 구조로 묶은 것이다. 코드를 역할별로 나누면 필요한 기능을 다른 파일에서 가져와 재사용할 수 있다.

> **핵심:** 모듈과 패키지는 코드를 파일과 폴더 단위로 분리하고 import로 연결한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
common/
  ├─ utils.py
  ├─ samples.py
  └─ ai/
      └─ ml.py
```

> **쉽게 말하면:** 기능을 종류별 파일과 폴더에 정리하고 필요한 것만 꺼내 쓰는 구조이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
from common.ai.ml import get_model
from common.samples import get_happy
from common.utils import add, sub
```

- `common.ai.ml` → 폴더와 모듈의 경로
- `import get_model` → 모듈에서 필요한 함수 가져오기

> **핵심:** 점으로 폴더와 모듈 경로를 연결하고 마지막에 가져올 이름을 지정한다.

------------------------------------------------------------------------

## 4. 예제

``` python
from common.ai.ml import get_model

def main():
    print(f"model name: {get_model()}")

if __name__ == "__main__":
    main()
```

실행 결과:

``` text
model name: Qwen Model
```

### 코드 해석

- `get_model`을 다른 모듈에서 가져온다.
- 파일을 직접 실행하면 `main()`을 호출한다.

> **결과 해석:** 여러 파일에 나눈 기능을 import하여 하나의 프로그램으로 연결했다.

------------------------------------------------------------------------

## 6. 주의할 점

- import 경로는 실제 폴더와 파일 구조에 맞아야 한다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 모듈 | Python 코드를 담은 파일 |
| 패키지 | 관련 모듈을 묶은 폴더 구조 |
| import | 다른 모듈의 기능을 가져오는 문법 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `from module import name` | 모듈에서 이름 가져오기 |
| `if __name__ == "__main__"` | 파일을 직접 실행할 때 진입점 실행 |
