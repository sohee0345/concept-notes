# 환경 변수와 dotenv

## 1. 개념

환경 변수는 프로그램 설정값을 코드 밖에서 제공하는 방식이다. `.env` 파일에 데이터베이스 계정 같은 값을 분리하고 `python-dotenv`의 `load_dotenv()`로 등록한 뒤 `os.getenv()`로 읽을 수 있다.

> **핵심:** 접속 정보와 비밀번호를 코드에서 분리해 `.env`에 저장하고 환경 변수로 불러온다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
.env에 설정값 저장
  ↓ load_dotenv()
환경 변수에 등록
  ↓ os.getenv()
Python 코드에서 사용
```

> **쉽게 말하면:** 코드에 비밀번호를 적지 않고 별도의 설정 파일에서 필요한 순간에 가져오는 방식이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
from dotenv import load_dotenv
import os

load_dotenv()

host = os.getenv("host")
port = int(os.getenv("port"))
```

- `.env` → 설정값을 저장하는 파일
- `load_dotenv()` → `.env` 값을 환경 변수로 등록
- `os.getenv()` → 이름으로 환경 변수 값 조회
- `int(...)` → 문자열로 읽은 포트를 정수로 변환

> **핵심:** `.env`를 만든 것만으로는 값이 자동 등록되지 않으므로 `load_dotenv()`를 먼저 실행한다.

------------------------------------------------------------------------

## 4. 예제

``` python
from dotenv import load_dotenv
import os

load_dotenv()

DB_CONFIG = {
    "host": os.getenv("host"),
    "port": int(os.getenv("port")),
    "user": os.getenv("user"),
    "password": os.getenv("password"),
    "database": os.getenv("database"),
}
```

### 코드 해석

- `os` → 운영체제 관련 기능과 환경 변수 접근을 제공하는 표준 모듈
- `os.getenv("password")` → 환경 변수의 비밀번호 값 조회
- `DB_CONFIG` → MySQL 연결에 전달할 설정 구성

> **결과 해석:** 코드에 실제 비밀번호를 직접 작성하지 않고 MySQL 연결 설정을 만들 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `.env` 파일 | 환경 변수 | `os.getenv()` |
| --- | --- | --- | --- |
| 역할 | 값을 파일에 기록 | 실행 환경에 값 보관 | 이름으로 값 읽기 |
| 연결 | `load_dotenv()`가 읽음 | Python 프로세스에서 사용 | 등록된 값 반환 |

------------------------------------------------------------------------

## 6. 주의할 점

- `.env`를 수정한 뒤 Notebook에 변경이 반영되지 않으면 Kernel을 다시 시작한다.
- `os.getenv()`는 값이 없으면 `None`을 반환할 수 있으므로 `int(None)`은 오류가 발생한다.
- 비밀번호 같은 민감한 값을 Python 코드에 직접 작성하지 않는다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `환경 변수` | 코드 밖에서 프로그램에 제공하는 설정값 |
| `.env` | 환경 변수로 등록할 값을 기록하는 파일 |
| `python-dotenv` | `.env`를 읽는 외부 라이브러리 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `load_dotenv()` | `.env` 값 등록 |
| `os.getenv("name")` | 환경 변수 조회 |
| `int(os.getenv("port"))` | 포트 값을 정수로 변환 |

### ⭐ 한 줄 정리

> **`.env`의 설정값을 `load_dotenv()`로 환경 변수에 등록하고 `os.getenv()`로 코드에서 읽는다.**
