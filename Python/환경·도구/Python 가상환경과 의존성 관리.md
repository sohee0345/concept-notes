# Python 가상환경과 의존성 관리

## 1. 개념

가상환경은 프로젝트마다 Python과 패키지 구성을 분리하는 공간이다. 의존성 파일에는 프로젝트 실행에 필요한 패키지를 기록하여 같은 환경을 다시 만들 수 있게 한다.

> **핵심:** 프로젝트별 가상환경과 의존성 기록은 패키지 충돌을 막고 개발 환경을 재현하게 해준다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
프로젝트
  ├─ .venv         독립된 Python 환경
  └─ 의존성 파일   필요한 패키지 목록
```

> **쉽게 말하면:** 프로젝트마다 전용 도구 상자와 준비물 목록을 따로 두는 것이다.

------------------------------------------------------------------------

## 3. 사용 방법

### venv와 pip

``` powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install --upgrade pip
pip install -r .\requirements.txt
deactivate
```

### uv

``` powershell
uv init --name venv-uv --python 3.12
uv add jupyter pandas seaborn
uv sync
```

- `requirements.txt` → pip가 설치할 패키지 목록
- `pyproject.toml` → uv 프로젝트 정보와 의존성 기록
- `-m` → 지정한 Python 모듈을 실행하는 옵션
- `deactivate` → 현재 가상환경 비활성화

> **핵심:** 의존성 파일을 남기면 프로젝트에 필요한 패키지 구성을 다시 만들 수 있다.

------------------------------------------------------------------------

## 4. 예제

``` text
jupyter
pandas
seaborn
```

위 내용을 `requirements.txt`에 저장하고 다음 명령을 실행한다.

``` powershell
pip install -r .\requirements.txt
```

> **결과 해석:** 파일에 한 줄씩 기록한 세 패키지를 가상환경에 설치한다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | venv와 pip | uv |
| --- | --- | --- |
| 환경 생성 | `py -m venv .venv` | `uv init` |
| 의존성 기록 | `requirements.txt` | `pyproject.toml` |
| 패키지 설치 | `pip install -r` | `uv add`, `uv sync` |

------------------------------------------------------------------------

## 6. 주의할 점

- 저장소 하나를 하나의 프로젝트 단위로 열고 프로젝트 안에 `.venv`를 만든다.
- 패키지를 설치하기 전에 사용할 가상환경이 활성화되어 있는지 확인한다.
