# 콜백 함수

## 1. 개념

콜백 함수는 다른 함수의 인자로 전달되어 그 함수 안에서 필요한 시점에 호출되는 함수이다.

> **핵심:** 함수를 값처럼 전달하면 호출받는 함수가 실행할 동작을 외부에서 선택할 수 있다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
처리 함수 + 콜백 전달 → 처리 함수 내부에서 콜백 호출 → 결과 반환
```

> **쉽게 말하면:** 해야 할 일을 함수로 전달해 두고 다른 함수가 필요할 때 대신 실행하게 하는 방식이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
def calculate(x, y, callback):
    return callback(x, y)
```

- `callback` → 전달받을 함수의 자리이다.
- `callback(x, y)` → 전달받은 함수를 호출한다.

> **핵심:** 함수를 전달할 때는 `함수명()`의 호출 결과가 아니라 `함수명` 자체를 인자로 넣는다.

------------------------------------------------------------------------

## 4. 예제

``` python
def 계산(x, y, callback):
    return callback(x, y)

def 더하기(x, y):
    return x + y

print(계산(3, 4, 더하기))
```

실행 결과:

``` text
7
```

### 코드 해석

- `더하기` 함수 자체를 `callback`에 전달한다.
- `계산()` 내부에서 `callback(3, 4)`를 호출한다.

> **결과 해석:** 계산 함수가 전달받은 더하기 함수를 대신 실행한다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 콜백 함수 | 다른 함수에 전달되어 호출되는 함수 |
| 함수 전달 | 함수 이름 자체를 인자로 넘기는 작업 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `func(값, callback)` | 콜백 전달 |
| `callback(값)` | 전달받은 함수 호출 |

### ⭐ 한 줄 정리

> **콜백은 다른 함수에 동작을 전달하고 필요한 시점에 실행하게 하는 함수이다.**
