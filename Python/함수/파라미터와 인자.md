# 파라미터와 인자

## 1. 개념

파라미터는 함수 정의에서 입력을 받을 변수이고, 인자는 함수를 호출할 때 실제로 전달하는 값이다. 기본값을 지정하면 해당 인자를 생략할 수 있다.

> **핵심:** 파라미터는 입력받을 자리이고 인자는 호출할 때 그 자리에 전달하는 실제 값이다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
def func(p_y, p_x=0)  ← 파라미터
func(20, 10)           ← 인자
```

> **쉽게 말하면:** 파라미터는 빈칸의 이름이고 인자는 빈칸에 넣는 값이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
def func(p_y, p_x=0):
    return p_x + 10 + (p_y * 2)

func(p_y=20)
func(20, 10)
```

- 위치 인자 → 선언된 파라미터 순서대로 전달한다.
- 키워드 인자 → `파라미터=값`으로 대상을 명시한다.
- 기본값 파라미터 → 인자가 없으면 미리 정한 값을 사용한다.

> **핵심:** 기본값이 없는 필수 파라미터를 기본값 파라미터보다 앞에 선언한다.

------------------------------------------------------------------------

## 4. 예제

``` python
def func(p_y, p_x=0):
    return p_x + 10 + (p_y * 2)

print(func(p_y=20))
print(func(20, 10))
```

실행 결과:

``` text
50
60
```

### 코드 해석

- 첫 호출은 `p_x`의 기본값 `0`을 사용한다.
- 두 번째 호출은 위치에 따라 `p_y=20`, `p_x=10`을 전달한다.

> **결과 해석:** 같은 함수도 인자 전달 방식에 따라 기본값을 사용하거나 새 값으로 바꿀 수 있다.

------------------------------------------------------------------------

## 6. 주의할 점

- `def func(p_x=0, p_y):`처럼 기본값 파라미터 뒤에 필수 파라미터를 선언하면 `SyntaxError`가 발생한다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 파라미터 | 함수가 입력받을 변수 |
| 인자 | 호출할 때 전달하는 실제 값 |
| 기본값 | 인자를 생략했을 때 사용할 값 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `def func(x=0)` | 기본값 파라미터 정의 |
| `func(10)` | 위치 인자 전달 |
| `func(x=10)` | 키워드 인자 전달 |

### ⭐ 한 줄 정리

> **함수는 파라미터로 입력 자리를 정의하고 호출할 때 인자를 전달받는다.**
