# 람다와 콜백

## 1. 개념

람다는 `def` 없이 한 줄로 작성하는 익명 함수이고, 콜백은 다른 함수의 인자로 전달되어 필요한 시점에 호출되는 함수이다. 짧은 동작을 함수에 전달할 때 함께 활용할 수 있다.

> **핵심:** 함수도 값처럼 다른 함수에 전달할 수 있으며 람다는 짧은 콜백을 간결하게 표현한다.

---

## 2. 쉽게 이해하기

콜백은 다른 함수에 맡겨 두는 작업 지시서이고 람다는 이름 없이 즉석에서 만든 짧은 작업 지시서와 같다.

```text
함수 또는 람다 작성
  ↓ 다른 함수에 인자로 전달
필요한 시점에 콜백 호출
  ↓ 결과 반환
```

---

## 3. 사용 방법

```python
students.sort(key=lambda student: student[1], reverse=True)
```

- `lambda 매개변수: 표현식` → 한 줄짜리 익명 함수를 만든다.
- `key=` → 정렬 기준을 계산할 함수를 전달한다.
- 콜백 함수는 호출 결과가 아니라 함수 자체를 인자로 전달한다.

---

## 4. 예제

```python
def calculate(x, y, callback):
    return callback(x, y)

def add(x, y):
    return x + y

print(calculate(3, 4, add))
```

실행 결과:

```text
7
```

`add` 함수 자체가 콜백으로 전달되고 `calculate` 내부에서 필요한 시점에 호출된다.

---

## 5. 헷갈리는 개념 비교

|구분|람다|콜백|
|---|---|---|
|의미|한 줄 익명 함수|다른 함수에 전달되어 호출되는 함수|
|관계|콜백으로 전달 가능|일반 함수나 람다 모두 사용 가능|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|람다|한 줄로 작성하는 익명 함수|
|콜백|다른 함수에 전달되어 필요한 시점에 호출되는 함수|

### 💻 주요 코드

|코드|의미|
|---|---|
|`lambda x: 표현식`|람다 함수 작성|
|`func(x, callback)`|함수를 인자로 전달|

### ⭐ 한 줄 정리

> **람다는 짧은 익명 함수이며 콜백은 다른 함수에 전달되어 필요한 시점에 실행되는 함수이다.**
