# 가변 인자 args·kwargs

## 1. 개념

가변 인자는 함수가 정해지지 않은 개수의 인자를 받을 수 있게 한다. `*args`는 여러 위치 인자를 튜플로, `**kwargs`는 여러 키워드 인자를 딕셔너리로 받는다.

> **핵심:** 별표 하나는 튜플, 별표 두 개는 딕셔너리로 여러 인자를 모은다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
1, 2, 3       → *args   → (1, 2, 3)
name="홍길동" → **kwargs → {"name": "홍길동"}
```

> **쉽게 말하면:** 입력 개수를 미리 정하지 않고 위치 값은 한 꾸러미로, 이름이 있는 값은 이름표가 달린 꾸러미로 받는다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
def func(*args, **kwargs):
    print(args)
    print(kwargs)
```

- `args`의 자료형 → 튜플
- `kwargs`의 자료형 → 딕셔너리
- `kwargs["키"]` → 전달된 키워드 인자 조회

> **핵심:** 관례적으로 `args`, `kwargs`라는 이름을 사용한다.

------------------------------------------------------------------------

## 4. 예제

``` python
def info(*args, **kwargs):
    return type(args), type(kwargs)

print(info(1, 2, name="홍길동"))
```

실행 결과:

``` text
(<class 'tuple'>, <class 'dict'>)
```

### 코드 해석

- `1, 2` → `args` 튜플에 저장된다.
- `name="홍길동"` → `kwargs` 딕셔너리에 저장된다.

> **결과 해석:** 전달 방식에 따라 같은 호출의 인자들이 서로 다른 자료형으로 묶인다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `*args` | `**kwargs` |
| --- | --- | --- |
| 입력 형태 | 위치 인자 | 키워드 인자 |
| 함수 내부 자료형 | 튜플 | 딕셔너리 |
| 조회 | 인덱스 | 키 |

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 가변 인자 | 개수가 정해지지 않은 인자 |
| `args` | 위치 인자를 담은 튜플 |
| `kwargs` | 키워드 인자를 담은 딕셔너리 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `def func(*args)` | 여러 위치 인자 받기 |
| `def func(**kwargs)` | 여러 키워드 인자 받기 |

### ⭐ 한 줄 정리

> **args는 여러 위치 인자를 튜플로, kwargs는 여러 키워드 인자를 딕셔너리로 받는다.**
