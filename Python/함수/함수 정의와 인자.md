# 함수 정의와 인자

## 1. 개념

함수는 작업을 하나의 이름으로 묶은 코드이다. 파라미터로 입력을 받고 `return`으로 결과를 반환하며, 기본값과 가변 인자를 이용해 다양한 호출 형태를 처리한다.

> **핵심:** 함수의 입력은 파라미터로 정의하고 실제 호출 값은 인자로 전달하며, 결과는 `return`으로 돌려준다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
인자 전달
  ↓
파라미터가 값 받기
  ↓
함수 코드 실행
  ↓
return으로 결과 반환
```

> **쉽게 말하면:** 함수는 재료를 받아 정해진 일을 하고 결과를 돌려주는 작은 작업 기계이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
def func(p_x):
    return p_x + 10

result = func(20)
```

- `p_x` → 함수가 입력을 받는 파라미터
- `20` → 호출할 때 전달하는 인자
- `return` → 계산 결과 반환과 함수 종료

기본값과 가변 인자는 다음처럼 정의한다.

``` python
def func(required, optional=0):
    return required + optional

def add(*args):
    return sum(args)

def info(**kwargs):
    return kwargs
```

> **핵심:** 필수 파라미터를 기본값 파라미터보다 앞에 작성한다.

------------------------------------------------------------------------

## 4. 예제

``` python
def func(p_y, p_x=0):
    return p_x + 10 + (p_y * 2)

print(func(p_y=20))
print(func(20, 10))

def add(*args):
    total = 0
    for value in args:
        total += value
    return total

print(add(1, 2, 3, 4, 5, 6))
```

실행 결과:

``` text
50
60
21
```

### 코드 해석

- `p_y` → 반드시 값을 전달해야 하는 필수 파라미터이다.
- `p_x=0` → 생략하면 0을 사용하는 기본값 파라미터이다.
- `*args` → 전달한 여러 위치 인자를 튜플로 받는다.

> **결과 해석:** 키워드 인자는 이름으로 전달되고 위치 인자는 순서대로 전달되며, `*args`는 개수 제한 없이 받을 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 일반 파라미터 | `*args` | `**kwargs` |
| --- | --- | --- | --- |
| 입력 형태 | 정해진 위치·이름 | 여러 위치 인자 | 여러 `key=value` 인자 |
| 함수 내부 자료형 | 전달된 값 | 튜플 | 딕셔너리 |
| 예시 | `func(10)` | `func(1, 2, 3)` | `func(name="홍길동")` |

------------------------------------------------------------------------

## 6. 주의할 점

- 기본값이 없는 파라미터를 기본값이 있는 파라미터 뒤에 두면 `SyntaxError`가 발생한다.
- 반환값은 변수에 저장할 수도 있고 다른 표현식에서 직접 사용할 수도 있다.
- `return`이 실행되면 함수는 그 지점에서 끝난다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `파라미터` | 함수 정의에서 입력을 받는 변수 |
| `인자` | 호출할 때 전달하는 실제 값 |
| `return` | 결과 반환과 함수 종료 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `def func(x):` | 함수 정의 |
| `x=0` | 기본값 파라미터 |
| `*args` | 여러 위치 인자를 튜플로 받기 |
| `**kwargs` | 여러 키워드 인자를 딕셔너리로 받기 |

### ⭐ 한 줄 정리

> **함수는 파라미터로 입력을 받고, 다양한 형태의 인자를 처리한 뒤 `return`으로 결과를 반환한다.**
