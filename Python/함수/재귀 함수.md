# 재귀 함수

## 1. 개념

재귀 함수는 실행 중 자기 자신을 다시 호출하는 함수이다. 재귀 호출이 멈추는 종료 조건이 반드시 필요하다.

> **핵심:** 재귀 함수는 문제를 더 작은 같은 형태의 문제로 줄여 가며 종료 조건에서 멈춘다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
factorial(3)
  ↓ 3 × factorial(2)
  ↓ 2 × factorial(1)
  ↓ 종료 조건에서 1 반환
```

> **쉽게 말하면:** 함수가 더 작은 입력으로 자신을 다시 부르다가 멈추는 조건을 만나 결과를 되돌려주는 방식이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
def recursive(value):
    if 종료_조건:
        return 결과
    return recursive(더_작은_문제)
```

- 종료 조건 → 재귀 호출을 멈춘다.
- 재귀 호출 → 입력을 변화시켜 자기 자신을 다시 실행한다.

> **핵심:** 호출할 때마다 종료 조건에 가까워지도록 입력값을 변경해야 한다.

------------------------------------------------------------------------

## 4. 예제

``` python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(5))
```

실행 결과:

``` text
120
```

### 코드 해석

- `n <= 1` → 재귀를 멈추는 종료 조건이다.
- `factorial(n - 1)` → 더 작은 값으로 자신을 호출한다.

> **결과 해석:** `5 × 4 × 3 × 2 × 1`이 계산되어 `120`이 된다.

------------------------------------------------------------------------

## 6. 주의할 점

- 종료 조건이 없거나 입력이 종료 조건에 가까워지지 않으면 호출이 계속된다.
