# 재귀 함수

## 1. 개념

재귀 함수는 함수가 자기 자신을 다시 호출하는 함수이다. 반복 호출을 끝내는 종료 조건이 반드시 필요하다.

> **핵심:** 재귀 함수는 문제를 더 작은 같은 문제로 줄이며 종료 조건에서 호출을 멈춘다.

---

## 2. 쉽게 이해하기

큰 문제를 조금 더 작은 문제로 계속 넘기다가 가장 단순한 상태에 도달하면 결과를 거꾸로 계산한다.

```text
factorial(5)
  ↓ factorial(4)
  ↓ factorial(3)
  ↓ 종료 조건
결과를 거꾸로 반환
```

---

## 3. 사용 방법

```python
def recursive(value):
    if 종료_조건:
        return 결과
    return recursive(더_작은_값)
```

- 종료 조건은 자기 호출보다 먼저 검사한다.
- 재귀 호출에서는 문제의 크기가 종료 조건에 가까워져야 한다.

---

## 4. 예제

```python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(5))
```

실행 결과:

```text
120
```

`n`을 하나씩 줄여 `1`에 도달한 뒤 각 호출의 곱을 반환한다.

---

## 5. 헷갈리는 개념 비교

|구분|반복문|재귀 함수|
|---|---|---|
|반복 방식|`for`, `while`로 반복|자기 자신을 호출|
|종료 기준|반복 조건|재귀 종료 조건|
