# 클로저

## 1. 개념

클로저는 내부 함수가 정의될 때의 바깥 변수를 기억하여 바깥 함수 실행이 끝난 뒤에도 그 값을 사용하는 구조이다.

> **핵심:** 클로저는 내부 함수와 그 함수가 기억하는 바깥 상태를 함께 유지한다.

---

## 2. 쉽게 이해하기

바깥 함수가 내부 함수에게 상태가 든 가방을 건네고, 내부 함수가 나중에도 그 가방의 값을 꺼내 쓰는 것과 같다.

```text
바깥 변수 생성
  ↓ 내부 함수 정의
내부 함수 반환
  ↓
바깥 함수 종료 후에도 값 기억
```

---

## 3. 사용 방법

```python
def outer():
    value = 0

    def inner():
        nonlocal value
        value += 1
        return value

    return inner
```

- 내부 함수는 바깥 함수의 변수를 기억한다.
- `nonlocal`은 바깥 함수 영역의 변수를 변경할 때 사용한다.
- 바깥 함수는 내부 함수를 호출하지 않고 반환한다.

---

## 4. 예제

```python
def counter():
    count = 0

    def increase():
        nonlocal count
        count += 1
        return count

    return increase

c = counter()
print(c())
print(c())
```

실행 결과:

```text
1
2
```

`increase`는 호출될 때마다 기억하고 있던 `count`를 증가시킨다.

---

## 5. 헷갈리는 개념 비교

|구분|지역 변수|클로저가 기억하는 변수|
|---|---|---|
|사용 범위|일반적으로 함수 실행 중|반환된 내부 함수가 계속 사용|
|변경|현재 함수에서 변경|`nonlocal`로 바깥 변수 변경|
