# 클로저

## 1. 개념

클로저는 내부 함수가 자신이 정의될 때의 바깥 변수 환경을 기억하여 바깥 함수의 실행이 끝난 뒤에도 그 값을 사용하는 구조이다.

> **핵심:** 바깥 함수가 내부 함수를 반환하면 내부 함수는 필요한 바깥 값을 계속 기억할 수 있다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
바깥 함수 실행 → 내부 함수 생성 → 내부 함수 반환
                                 ↓
                          바깥 값 기억
```

> **쉽게 말하면:** 내부 함수가 자신이 만들어진 작업 공간의 값을 작은 가방에 담아 가지고 나오는 것이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
def outer(value):
    def inner():
        return value
    return inner
```

- 내부 함수 → 바깥 함수의 변수를 사용한다.
- 바깥 함수 → 내부 함수 자체를 반환한다.
- `nonlocal` → 내부 함수에서 바깥 함수의 변수를 변경한다.

> **핵심:** 내부 함수를 호출한 결과가 아니라 내부 함수 자체를 반환한다.

------------------------------------------------------------------------

## 4. 예제

``` python
def counter():
    count = 0

    def increase():
        nonlocal count
        count += 1
        return count

    return increase

c = counter()
print(c())
print(c())
```

실행 결과:

``` text
1
2
```

### 코드 해석

- `c`에는 `increase` 함수가 저장된다.
- `nonlocal count`를 통해 기억한 `count`를 변경한다.

> **결과 해석:** `counter()` 실행이 끝난 뒤에도 `count` 값이 유지된다.

------------------------------------------------------------------------

## 6. 주의할 점

- 바깥 변수를 내부 함수에서 다시 대입하려면 `nonlocal` 선언이 필요하다.
