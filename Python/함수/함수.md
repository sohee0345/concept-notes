# 함수

## 1. 개념

함수는 반복해서 사용할 코드를 하나의 이름으로 묶은 것이다. 파라미터로 입력을 받고 본문을 실행한 뒤 `return`으로 결과를 호출한 곳에 돌려줄 수 있다.

> **핵심:** 함수는 정의한 뒤 호출해야 실행되며 `return`은 결과를 반환하면서 함수를 끝낸다.

---

## 2. 쉽게 이해하기

함수는 입력을 받아 정해진 작업을 처리하고 결과를 내보내는 작은 기계와 같다.

```text
함수 정의
  ↓ 호출과 인자 전달
함수 본문 실행
  ↓ return
호출한 곳에 결과 반환
```

---

## 3. 사용 방법

```python
def func(p_x):
    return p_x + 10

result = func(20)
```

- `def` → 함수를 정의한다.
- `p_x` → 함수가 입력을 받는 파라미터이다.
- `func(20)` → 인자 `20`을 전달해 함수를 호출한다.
- `return` → 결과를 반환하고 함수 실행을 끝낸다.

---

## 4. 예제

```python
def greet(name):
    return f"{name}님, 안녕하세요."

message = greet("홍길동")
print(message)
```

실행 결과:

```text
홍길동님, 안녕하세요.
```

함수 내부에서 만든 결과가 `return`을 통해 밖으로 전달되어 변수에 저장된다.

---

## 5. 헷갈리는 개념 비교

|구분|`print()`|`return`|
|---|---|---|
|역할|값을 화면에 표시|결과를 호출한 곳으로 전달|
|함수 종료|종료하지 않음|함수를 종료함|
