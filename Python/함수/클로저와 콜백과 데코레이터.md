# 클로저와 콜백과 데코레이터

## 1. 개념

Python에서는 함수를 변수처럼 전달하고 반환할 수 있다. 클로저는 내부 함수가 바깥 환경을 기억하는 구조이고, 콜백은 다른 함수에 전달되어 호출되는 함수이며, 데코레이터는 기존 함수를 감싸 기능을 추가한다.

> **핵심:** 함수를 값처럼 주고받을 수 있기 때문에 여러 함수를 조합하여 기능을 확장할 수 있다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
클로저 → 바깥 값을 기억하는 함수
콜백 → 다른 함수에 맡겨 두었다가 호출되는 함수
데코레이터 → 기존 함수 바깥을 감싸 기능을 더하는 함수
```

> **쉽게 말하면:** 함수를 다른 함수의 재료나 결과로 사용해 동작을 조립하는 방법이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
def outer(value):
    def inner():
        return value
    return inner

remember = outer(10)
remember()
```

``` python
def run(callback):
    return callback()
```

``` python
@decorator
def target():
    pass
```

- 클로저 → 내부 함수를 반환
- 콜백 → 함수를 인자로 전달
- 데코레이터 → `@`로 감쌀 함수 지정

> **핵심:** 함수 이름 뒤에 괄호를 붙이지 않고 전달하면 함수를 실행하지 않고 함수 자체를 넘긴다.

------------------------------------------------------------------------

## 4. 예제

``` python
def timer(func):
    def wrapper(*args, **kwargs):
        print(f"{func.__name__} 실행 시작")
        result = func(*args, **kwargs)
        print(f"{func.__name__} 실행 끝")
        return result
    return wrapper

@timer
def hello():
    print("hello")

hello()
```

실행 결과:

``` text
hello 실행 시작
hello
hello 실행 끝
```

### 코드 해석

- `timer(func)` → 원래 함수를 인자로 받는다.
- `wrapper()` → 원래 함수 실행 앞뒤에 추가 동작을 수행한다.
- `return wrapper` → 내부 함수를 반환해 클로저를 만든다.
- `@timer` → `hello`에 데코레이터를 적용한다.

> **결과 해석:** `hello()`를 호출하면 실제로는 감싸진 함수가 실행되어 시작·종료 메시지가 함께 출력된다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 클로저 | 콜백 | 데코레이터 |
| --- | --- | --- | --- |
| 핵심 | 바깥 환경 기억 | 함수를 인자로 전달 | 함수를 감싸 기능 추가 |
| 함수 위치 | 내부 함수를 반환 | 전달받은 함수를 호출 | wrapper를 반환 |
| 주요 형태 | `return inner` | `run(callback)` | `@decorator` |

------------------------------------------------------------------------

## 6. 주의할 점

- 함수를 전달할 때 `func`와 같이 이름만 쓰고, 즉시 실행할 때 `func()`처럼 괄호를 붙인다.
- 내부 함수에서 바깥 함수의 변수 값을 변경하려면 `nonlocal`을 사용한다.
- 데코레이터의 wrapper에서도 원래 함수의 반환값을 다시 반환해야 호출 결과가 유지된다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `클로저` | 내부 함수가 바깥 함수의 환경을 기억하는 구조 |
| `콜백` | 다른 함수의 인자로 전달되어 호출되는 함수 |
| `데코레이터` | 기존 함수를 감싸 추가 기능을 붙이는 문법 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `return inner` | 내부 함수 반환 |
| `nonlocal value` | 바깥 함수의 변수 변경 |
| `callback(x)` | 전달받은 함수 호출 |
| `@decorator` | 함수에 데코레이터 적용 |

### ⭐ 한 줄 정리

> **클로저, 콜백, 데코레이터는 함수를 값처럼 전달하고 반환하여 기존 동작을 조합하고 확장한다.**
