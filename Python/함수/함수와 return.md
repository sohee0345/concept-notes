# 함수와 return

## 1. 개념

함수는 반복해서 사용할 코드를 하나의 이름으로 묶은 것이다. 파라미터로 입력을 받고 `return`으로 결과를 호출한 곳에 돌려줄 수 있다.

> **핵심:** 함수는 정의한 뒤 호출해야 실행되며 `return`은 값을 반환하고 함수 실행을 끝낸다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
인자 전달 → 함수 호출 → 코드 실행 → 결과 반환
```

> **쉽게 말하면:** 함수는 재료를 넣으면 정해진 작업을 하고 결과를 돌려주는 작은 작업 단위이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
def 함수명(파라미터):
    실행할_코드
    return 결과
```

- `def` → 함수를 정의한다.
- 함수 이름 → 호출할 때 사용하는 이름이다.
- `return` → 결과를 호출한 곳으로 반환한다.

> **핵심:** 반환값은 변수에 저장하거나 다른 표현식에서 바로 사용할 수 있다.

------------------------------------------------------------------------

## 4. 예제

``` python
def add_ten(number):
    return number + 10

result = add_ten(20)
print(result)
```

실행 결과:

``` text
30
```

### 코드 해석

- `add_ten(20)` → `number`에 `20`을 전달해 함수를 호출한다.
- `return number + 10` → 계산 결과 `30`을 반환한다.

> **결과 해석:** 반환된 값은 `result`에 저장되어 함수 밖에서 사용할 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `print()` | `return` |
| --- | --- | --- |
| 역할 | 값을 화면에 출력 | 값을 호출한 곳으로 전달 |
| 함수 종료 | 종료하지 않음 | 실행을 끝냄 |

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 함수 정의 | 실행할 코드에 이름을 붙이는 작업 |
| 함수 호출 | 정의된 함수를 실행하는 작업 |
| `return` | 결과 반환 후 함수 종료 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `def func(x):` | 함수 정의 |
| `func(20)` | 함수 호출 |
| `return x` | 값 반환 |

### ⭐ 한 줄 정리

> **함수는 코드를 재사용 가능한 단위로 묶고 return으로 결과를 돌려준다.**
