# 함수 인자

## 1. 개념

함수는 위치 인자와 키워드 인자로 값을 전달받으며 파라미터에 기본값을 지정할 수 있다. 입력 개수가 정해지지 않았다면 `*args`와 `**kwargs`로 여러 인자를 묶어 받는다.

> **핵심:** 위치·키워드·기본값·가변 인자를 목적에 맞게 조합하면 함수 입력을 유연하게 처리할 수 있다.

---

## 2. 쉽게 이해하기

위치 인자는 순서로 목적지를 찾고 키워드 인자는 이름표로 목적지를 찾는다. `*args`는 여러 위치 인자를 튜플에, `**kwargs`는 여러 키워드 인자를 딕셔너리에 담는다.

```text
위치 인자 → 선언 순서로 전달
키워드 인자 → 파라미터 이름으로 전달
*args → 튜플
**kwargs → 딕셔너리
```

---

## 3. 사용 방법

```python
def func(p_y, p_x=0):
    return p_x + 10 + p_y * 2

func(20, 10)
func(p_y=20)
```

- 기본값이 없는 필수 파라미터는 기본값 파라미터보다 앞에 선언한다.
- 위치 인자는 선언된 순서에 따라 전달한다.
- 키워드 인자는 `파라미터=값`으로 전달한다.

---

## 4. 예제

```python
def add(*args):
    total = 0
    for value in args:
        total += value
    return total

print(add(1, 2, 3, 4, 5, 6))
```

실행 결과:

```text
21
```

`*args`가 여러 위치 인자를 튜플로 받아 반복문에서 모두 더한다.

---

## 5. 헷갈리는 개념 비교

|구분|`*args`|`**kwargs`|
|---|---|---|
|받는 인자|여러 위치 인자|여러 키워드 인자|
|자료형|튜플|딕셔너리|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|기본값 파라미터|인자를 생략했을 때 사용할 값을 지정한 파라미터|
|위치 인자|선언 순서에 따라 전달하는 값|
|키워드 인자|파라미터 이름을 지정해 전달하는 값|

### 💻 주요 코드

|코드|의미|
|---|---|
|`def func(x=0)`|기본값 지정|
|`func(x=10)`|키워드 인자 전달|
|`def func(*args)`|여러 위치 인자 받기|
|`def func(**kwargs)`|여러 키워드 인자 받기|
