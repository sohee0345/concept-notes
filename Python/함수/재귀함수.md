# 재귀함수

## 1. 개념

재귀함수는 실행 중 자기 자신을 다시 호출하는 함수이다. 호출이 끝나는 종료 조건이 반드시 필요하다.

> **핵심:** 재귀함수는 문제를 더 작은 같은 문제로 줄이며, 종료 조건에서 호출을 멈춘다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
factorial(3)
  ↓ 3 × factorial(2)
  ↓ 3 × 2 × factorial(1)
  ↓ 종료 조건에서 1 반환
  ↓ 6
```

> **쉽게 말하면:** 함수가 더 작은 값을 들고 자기 자신에게 일을 다시 부탁하다가 종료 조건에서 답을 돌려주는 방식이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
def recursive(value):
    if 종료_조건:
        return 결과
    return recursive(더_작은_값)
```

- 종료 조건 → 재귀 호출을 멈추는 조건
- 재귀 호출 → 함수가 자기 자신을 호출
- 반환 과정 → 가장 안쪽 호출부터 바깥 호출 순서로 결과 계산

> **핵심:** 재귀 호출을 할 때는 입력이 종료 조건에 가까워지도록 변해야 한다.

------------------------------------------------------------------------

## 4. 예제

``` python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

factorial(5)
```

실행 결과:

``` text
120
```

### 코드 해석

- `n <= 1` → 호출을 멈추는 종료 조건이다.
- `factorial(n - 1)` → 더 작은 값으로 자기 자신을 호출한다.
- `n * ...` → 안쪽 호출의 결과가 돌아오면서 차례로 곱한다.

> **결과 해석:** `5 × 4 × 3 × 2 × 1`이 계산되어 120을 반환한다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 반복문 | 재귀함수 |
| --- | --- | --- |
| 반복 방식 | `for`, `while` 블록 반복 | 함수가 자기 자신 호출 |
| 종료 기준 | 반복 조건 또는 `break` | 종료 조건에서 `return` |
| 주의점 | 무한 반복 | 무한 재귀 호출 |

------------------------------------------------------------------------

## 6. 주의할 점

- 종료 조건이 없으면 함수 호출이 계속 이어진다.
- 재귀할 때 전달하는 값이 종료 조건에 가까워지는지 확인한다.
- 종료 조건의 반환값이 전체 계산 결과에 어떤 영향을 주는지 확인한다.
