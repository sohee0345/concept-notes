# 람다 함수

## 1. 개념

람다 함수는 `def` 없이 한 줄의 표현식으로 만드는 익명 함수이다. 짧은 함수를 값처럼 저장하거나 다른 함수에 전달할 때 사용할 수 있다.

> **핵심:** 람다는 한 줄로 표현할 수 있는 간단한 함수를 짧게 작성한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
lambda 입력값: 결과식
```

> **쉽게 말하면:** 이름과 여러 줄의 본문이 필요 없는 작은 함수를 즉석에서 만드는 방법이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
add = lambda x, y: x + y
add(3, 4)
```

- `lambda x, y` → 두 입력값을 받는다.
- `x + y` → 계산하여 반환할 표현식이다.

> **핵심:** 람다 함수의 표현식 결과는 자동으로 반환된다.

------------------------------------------------------------------------

## 4. 예제

``` python
students = [("철수", 90), ("영희", 85)]
students.sort(key=lambda student: student[1], reverse=True)
print(students)
```

실행 결과:

``` text
[('철수', 90), ('영희', 85)]
```

### 코드 해석

- `lambda student: student[1]` → 각 튜플의 점수를 정렬 기준으로 돌려준다.
- `reverse=True` → 점수가 큰 순서로 정렬한다.

> **결과 해석:** 짧은 람다 함수를 `sort()`의 정렬 기준으로 전달했다.
