# 데코레이터

## 1. 개념

데코레이터는 기존 함수의 코드를 직접 바꾸지 않고 함수 실행 앞뒤에 기능을 덧붙이는 구조이다. `@데코레이터명` 형식으로 적용한다.

> **핵심:** 데코레이터는 원래 함수를 감싸는 wrapper 함수를 통해 실행 전후 동작을 추가한다.

---

## 2. 쉽게 이해하기

원래 함수는 그대로 두고 포장지를 씌워 실행 시작과 종료 같은 공통 기능을 추가하는 방식이다.

```text
@decorator 적용
  ↓ wrapper가 원래 함수 감쌈
실행 전 기능
  ↓ 원래 함수 실행
실행 후 기능
```

---

## 3. 사용 방법

```python
def decorator(func):
    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        return result
    return wrapper
```

- 데코레이터는 꾸밀 함수를 인자로 받는다.
- `wrapper`는 원래 함수를 호출하기 전후에 기능을 추가한다.
- `*args`, `**kwargs`로 원래 함수의 인자를 전달한다.

---

## 4. 예제

```python
def timer(func):
    def wrapper(*args, **kwargs):
        print(f"{func.__name__} 실행 시작")
        result = func(*args, **kwargs)
        print(f"{func.__name__} 실행 끝")
        return result
    return wrapper

@timer
def hello():
    print("hello")

hello()
```

실행 결과:

```text
hello 실행 시작
hello
hello 실행 끝
```

`hello()`를 호출하면 `timer`의 wrapper가 실행되어 원래 함수 앞뒤에 메시지를 출력한다.

---

## 5. 헷갈리는 개념 비교

|구분|원래 함수|wrapper 함수|
|---|---|---|
|역할|핵심 기능 수행|원래 함수 앞뒤에 기능 추가|
|수정|직접 변경하지 않음|데코레이터에서 정의|

|`return wrapper`|감싼 함수 반환|
