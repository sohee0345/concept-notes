# 데코레이터

## 1. 개념

데코레이터는 기존 함수의 코드를 직접 수정하지 않고, 함수를 감싸 실행 앞뒤에 기능을 추가하는 방식이다. 적용할 때는 `@데코레이터명` 문법을 사용한다.

> **핵심:** 데코레이터는 함수를 인자로 받아 새로운 동작으로 감싼 함수를 반환한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
기존 함수
  ↓ 데코레이터로 감싸기
추가 기능 → 기존 함수 실행 → 추가 기능
```

> **쉽게 말하면:** 원래 함수를 고치지 않고 함수 바깥에 새로운 포장지를 씌우는 것이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
def decorator(func):
    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        return result
    return wrapper

@decorator
def target():
    pass
```

- 바깥 함수 → 꾸밀 함수를 인자로 받는다.
- `wrapper` → 추가 동작과 원래 함수 호출을 묶는다.
- `@decorator` → 대상 함수에 데코레이터를 적용한다.

> **핵심:** wrapper 안에서 원래 함수를 호출하고 필요한 반환값을 다시 반환한다.

------------------------------------------------------------------------

## 4. 예제

``` python
def timer(func):
    def wrapper(*args, **kwargs):
        print(f"{func.__name__} 실행 시작")
        result = func(*args, **kwargs)
        print(f"{func.__name__} 실행 끝")
        return result
    return wrapper

@timer
def hello():
    print("hello")

hello()
```

실행 결과:

``` text
hello 실행 시작
hello
hello 실행 끝
```

### 코드 해석

- `@timer` → `hello`를 `timer`에 전달한다.
- 실제 호출에서는 `wrapper`가 실행되어 앞뒤 문장을 출력한다.

> **결과 해석:** 기존 `hello`의 본문을 바꾸지 않고 실행 전후 기능이 추가되었다.

------------------------------------------------------------------------

## 6. 주의할 점

- 원래 함수의 결과가 필요하다면 wrapper에서도 그 값을 반환해야 한다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 데코레이터 | 기존 함수를 감싸 기능을 추가하는 함수 |
| wrapper | 원래 함수와 추가 동작을 실행하는 내부 함수 |
| `@` 문법 | 데코레이터 적용 표시 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `@timer` | timer 데코레이터 적용 |
| `func(*args, **kwargs)` | 원래 함수에 인자 전달 |
| `return wrapper` | 감싼 함수 반환 |

### ⭐ 한 줄 정리

> **데코레이터는 기존 함수를 수정하지 않고 wrapper로 감싸 추가 기능을 적용한다.**
