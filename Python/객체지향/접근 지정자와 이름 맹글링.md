# 접근 지정자와 이름 맹글링

## 1. 개념

Python에서는 속성 이름 앞의 밑줄로 외부 접근에 대한 의도를 표현한다. 이중 밑줄로 시작하는 속성에는 이름 맹글링이 적용되어 내부 이름이 바뀐다.

> **핵심:** 밑줄 표기는 접근 의도를 나타내며 `__속성`은 완전한 비공개가 아니라 이름이 변환되는 방식이다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
name    → 외부 사용 가능
_name   → 내부 사용 권장
__name  → 클래스 이름을 포함한 내부 이름으로 변환
```

> **쉽게 말하면:** 밑줄은 다른 코드가 속성을 어떻게 다뤄야 하는지 알려 주는 표시이고, 이중 밑줄은 속성 이름까지 바꾼다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
class Account:
    def __init__(self):
        self.name = "홍길동"
        self._note = "내부용"
        self.__pin = "1234"
```

- `name` → 공개 속성
- `_note` → 내부 사용을 권장하는 관례
- `__pin` → 이름 맹글링 적용

> **핵심:** 외부에서 사용할 값을 명확히 구분하고 내부 값은 메서드나 property를 통해 관리할 수 있다.

------------------------------------------------------------------------

## 4. 예제

``` python
class Student:
    def __init__(self, name, age):
        self.__name = name
        self.age = age

student = Student("홍길동", 33)
print(student.age)
print(student.__name)
```

실행 결과:

``` text
33
AttributeError: 'Student' object has no attribute '__name'
```

### 코드 해석

- `age`는 그대로 접근할 수 있다.
- `__name`은 이름 맹글링으로 내부 이름이 바뀌어 같은 이름으로 접근할 수 없다.

> **결과 해석:** 이중 밑줄은 속성의 외부 접근을 어렵게 하지만 완전한 접근 차단을 의미하지는 않는다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 공개 속성 | 외부에서 사용하는 속성 |
| 밑줄 관례 | 내부 사용을 권장하는 표시 |
| 이름 맹글링 | 이중 밑줄 속성의 내부 이름 변환 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `self.name` | 공개 속성 |
| `self._name` | 내부 사용 권장 속성 |
| `self.__name` | 이름 맹글링 적용 속성 |
