# 이름 맹글링과 property

## 1. 개념

Python은 속성 이름의 `_`와 `__`로 외부 접근에 대한 의도를 나타낸다. `__name`에는 이름 맹글링이 적용되며, `property`를 사용하면 메소드로 속성의 조회·수정·삭제 동작을 정의할 수 있다.

> **핵심:** `__`는 완전한 접근 차단이 아니라 이름을 변경해 직접 접근을 어렵게 하며, `property`는 속성 사용 방식을 메소드로 제어한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
외부에 공개 → name
내부 사용 권장 → _name
이름 맹글링 → __name
  ↓
property로 조회·수정·삭제 통로 정의
```

> **쉽게 말하면:** 내부 데이터의 이름을 감추고 정해 둔 출입구를 통해 사용하도록 만드는 방식이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
class Student:
    def __init__(self, name):
        self.__name = name

    @property
    def name(self):
        return self.__name

    @name.setter
    def name(self, new_name):
        self.__name = new_name

    @name.deleter
    def name(self):
        del self.__name
```

- `@property` → 조회 동작
- `@name.setter` → 대입 시 수정 동작
- `@name.deleter` → `del` 사용 시 삭제 동작

> **핵심:** 외부에서는 메소드 괄호 없이 일반 속성처럼 사용한다.

------------------------------------------------------------------------

## 4. 예제

``` python
student = Student("홍길동")
print(student.name)

student.name = "신사임당"
print(student.name)

del student.name
```

실행 결과:

``` text
홍길동
신사임당
```

### 코드 해석

- `student.name` → getter 호출
- `student.name = ...` → setter 호출
- `del student.name` → deleter 호출
- `self.__name` → 내부적으로 `_Student__name` 형태로 이름 맹글링

> **결과 해석:** 외부에서는 하나의 속성처럼 보이지만 내부에서는 각 작업에 맞는 메소드가 실행된다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 형태 | 의미 | 강제 여부 |
| --- | --- | --- |
| `name` | 공개 사용 | 제한 없음 |
| `_name` | 내부 사용 권장 관례 | 강제하지 않음 |
| `__name` | 이름 맹글링 적용 | 완전한 private는 아님 |
| `property` | 속성 접근 동작 정의 | getter·setter·deleter 실행 |

------------------------------------------------------------------------

## 6. 주의할 점

- `_`와 `__`를 Java 등의 강제 접근 지정자와 완전히 같다고 이해하지 않는다.
- deleter로 내부 속성을 삭제한 뒤 getter를 호출하면 `AttributeError`가 발생한다.
- property 메소드는 외부에서 괄호 없이 속성처럼 사용한다.
