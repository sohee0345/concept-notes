# 속성 관리

## 1. 개념

Python은 밑줄을 이용해 속성 접근 의도를 나타내며 이중 밑줄 속성에는 이름 맹글링이 적용된다. `property`를 사용하면 내부 속성을 직접 노출하지 않고 조회·수정·삭제 동작을 메서드로 관리할 수 있다.

> **핵심:** 이름 맹글링과 property를 이용하면 내부 상태를 보호하면서 속성 문법으로 접근할 수 있다.

---

## 2. 쉽게 이해하기

실제 값은 내부 보관함에 두고 property라는 창구를 통해 값을 읽거나 바꾸게 하는 구조이다.

```text
외부에서 student.name 사용
  ↓ property 또는 setter 호출
내부 __name 조회·수정
```

---

## 3. 사용 방법

- `self.name` → 외부에서도 사용하는 공개 속성이다.
- `self._name` → 내부 사용을 권장한다는 관례이다.
- `self.__name` → 이름 맹글링이 적용된다.
- `@property` → 메서드를 속성처럼 조회한다.
- `@name.setter`, `@name.deleter` → 수정과 삭제를 관리한다.

---

## 4. 예제

```python
class Student:
    def __init__(self, name):
        self.__name = name

    @property
    def name(self):
        return self.__name

    @name.setter
    def name(self, new_name):
        self.__name = new_name

student = Student("홍길동")
student.name = "신사임당"
print(student.name)
```

실행 결과:

```text
신사임당
```

속성 문법을 사용하지만 실제 조회와 수정은 property 메서드가 담당한다.

---

## 5. 헷갈리는 개념 비교

|형태|의미|
|---|---|
|`name`|공개 속성|
|`_name`|내부 사용 권장 관례|
|`__name`|이름 맹글링 적용|
