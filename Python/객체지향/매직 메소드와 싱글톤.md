# 매직 메소드와 싱글톤

## 1. 개념

매직 메소드는 특정 문법을 사용할 때 Python이 자동으로 호출하는 특수 메소드이다. 싱글톤은 인스턴스를 하나만 생성해 공유하는 설계 패턴이며 `__new__`, 메타클래스의 `__call__` 같은 객체 생성 과정과 연결된다.

> **핵심:** 매직 메소드로 객체가 Python 문법에 반응하는 방식을 정의하고, 생성 과정을 제어해 하나의 인스턴스를 공유할 수 있다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
len(obj) → obj.__len__()
obj[index] → obj.__getitem__(index)
obj() → obj.__call__()
Class() → 인스턴스 생성 과정
```

> **쉽게 말하면:** 평범한 Python 문법을 객체에 사용했을 때 어떤 메소드가 실행될지 연결하는 약속이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
class MyDataset:
    def __init__(self, data):
        self.data = data

    def __call__(self, value):
        return len(self.data)

    def __getitem__(self, index):
        return self.data[index]

    def __len__(self):
        return len(self.data)

    def __str__(self):
        return "매직 메소드"
```

> **핵심:** 호출하려는 Python 문법에 맞는 매직 메소드를 정의한다.

------------------------------------------------------------------------

## 4. 예제

``` python
dataset = MyDataset(list(range(50, 100)))

print(dataset("홍길동"))
print(dataset[-1])
print(len(dataset))
print(str(dataset))
```

실행 결과:

``` text
50
99
50
매직 메소드
```

메타클래스로 싱글톤을 구현한 실습:

``` python
class Singleton(type):
    _instances = {}

    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

class Database(metaclass=Singleton):
    pass

db1 = Database()
db2 = Database()
print(db1 is db2)
```

실행 결과:

``` text
True
```

### 코드 해석

- `__call__` → 인스턴스 또는 클래스가 호출될 때의 동작을 정의한다.
- `_instances` → 이미 생성한 클래스별 인스턴스를 저장한다.
- `db1 is db2` → 두 변수가 같은 객체를 가리키는지 확인한다.

> **결과 해석:** 두 번 호출해도 저장해 둔 같은 `Database` 인스턴스를 반환한다.

### MySQL Connection 재사용

싱글톤을 실제 데이터베이스 연결에 적용하면 `MySQLDB(...)`를 여러 번 호출해도 한 번 만든 연결 객체를 계속 사용할 수 있다.

``` python
import pymysql

class Singleton(type):
    _instances = {}

    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

class MySQLDB(metaclass=Singleton):
    def __init__(self, db_config: dict) -> None:
        self.conn = pymysql.connect(
            **db_config,
            charset="utf8mb4",
            cursorclass=pymysql.cursors.DictCursor,
        )

    def __call__(self, query: str):
        with self.conn.cursor() as cursor:
            cursor.execute(query=query)
            return cursor.fetchall()
```

``` python
from connections import MySQLDB

mysqldb = MySQLDB(DB_CONFIG)
results = mysqldb("SELECT * FROM customers;")
```

``` text
MySQLDB(DB_CONFIG)
  ↓ 최초 호출이면 Connection 생성
싱글톤 인스턴스 저장
  ↓
mysqldb("SELECT ...")
  ↓ 인스턴스의 __call__ 실행
Cursor 생성 → SQL 실행 → 결과 반환
```

- `self.conn` → 여러 메소드에서 사용할 MySQL Connection 저장
- `DictCursor` → 컬럼 이름을 키로 가진 딕셔너리 형태로 조회
- 인스턴스의 `__call__` → 객체를 함수처럼 호출해 SQL 실행
- 메타클래스의 `__call__` → 새 인스턴스를 만들지 기존 인스턴스를 반환할지 결정

> **결과 해석:** 객체 생성 단계의 `__call__`은 Connection을 가진 인스턴스를 하나만 만들고, 인스턴스 단계의 `__call__`은 전달받은 SQL을 실행한다.

## 5. 헷갈리는 개념 비교

| 구분 | 일반 인스턴스 생성 | 싱글톤 | `MySQLDB` 인스턴스 호출 |
| --- | --- | --- | --- |
| 호출 | 클래스 호출 | 클래스 호출 | 생성된 객체 호출 |
| 동작 | 매번 새 객체 생성 | 기존 객체가 있으면 재사용 | `__call__`로 SQL 실행 |
| 결과 | 서로 다른 객체 | 같은 객체 공유 | 조회 결과 반환 |

------------------------------------------------------------------------

## 6. 주의할 점

- `__new__`에서 같은 객체를 반환해도 클래스 호출 때 `__init__`이 다시 실행될 수 있다.
- 실습의 메타클래스 방식은 최초 생성 때만 부모의 `__call__`을 실행해 인스턴스를 저장한다.
- `==`는 값의 동등성, `is`는 같은 객체인지 확인한다. 싱글톤 확인에는 `is`가 더 직접적이다.
- 하나의 Connection을 공유하는 구조에서는 해당 연결의 상태도 함께 공유된다.
- 메타클래스의 `__call__`과 인스턴스의 `__call__`은 이름은 같지만 실행되는 시점과 역할이 다르다.
