# 매직 메서드

## 1. 개념

매직 메서드는 이름 앞뒤에 이중 밑줄이 붙으며 특정 문법이나 상황에서 Python이 자동으로 호출하는 특수 메서드이다.

> **핵심:** 매직 메서드를 정의하면 사용자 클래스도 Python의 기본 문법에 맞춰 동작할 수 있다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
dataset[-1] → __getitem__(-1)
len(dataset) → __len__()
str(dataset) → __str__()
dataset(...) → __call__(...)
```

> **쉽게 말하면:** 평범한 Python 문법을 사용하면 약속된 이름의 메서드가 뒤에서 자동 실행된다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
class MyDataset:
    def __init__(self, data):
        self.data = data

    def __getitem__(self, index):
        return self.data[index]

    def __len__(self):
        return len(self.data)
```

- `__init__` → 인스턴스 초기화
- `__call__` → 인스턴스를 함수처럼 호출
- `__getitem__` → 대괄호로 값 조회
- `__len__` → `len()` 호출
- `__str__` → 문자열 표현

> **핵심:** 각 매직 메서드는 연결된 Python 문법과 반환값의 의미가 정해져 있다.

------------------------------------------------------------------------

## 4. 예제

``` python
dataset = MyDataset(list(range(50, 100)))
print(dataset[-1])
print(len(dataset))
```

실행 결과:

``` text
99
50
```

### 코드 해석

- `dataset[-1]` → `__getitem__()`을 호출한다.
- `len(dataset)` → `__len__()`을 호출한다.

> **결과 해석:** 직접 만든 클래스의 인스턴스를 리스트와 비슷한 문법으로 사용할 수 있다.

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 매직 메서드 | Python이 특정 상황에서 자동 호출하는 메서드 |
