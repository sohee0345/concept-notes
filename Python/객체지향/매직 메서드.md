# 매직 메서드

## 1. 개념

매직 메서드는 이름 앞뒤에 `__`가 붙으며 특정 문법이나 상황에서 Python이 자동으로 호출하는 메서드이다.

> **핵심:** 매직 메서드를 정의하면 사용자 클래스도 인덱싱, `len()`, 출력 같은 Python 문법에 맞춰 동작한다.

---

## 2. 쉽게 이해하기

Python 문법과 사용자 클래스를 연결하는 약속된 버튼과 같다. `len(obj)`를 실행하면 Python이 객체의 `__len__`을 찾아 호출한다.

```text
len(instance)
  ↓ Python이 연결된 메서드 탐색
instance.__len__()
  ↓
결과 반환
```

---

## 3. 사용 방법

- `__init__` → 인스턴스 초기화
- `__call__` → 인스턴스를 함수처럼 호출
- `__getitem__` → 인덱싱
- `__str__` → 문자열 변환과 출력
- `__len__` → `len()` 동작
- `__add__` → `+` 연산

---

## 4. 예제

```python
class MyDataset:
    def __init__(self, data):
        self.data = data

    def __getitem__(self, index):
        return self.data[index]

    def __len__(self):
        return len(self.data)

dataset = MyDataset(list(range(50, 100)))
print(dataset[-1])
print(len(dataset))
```

실행 결과:

```text
99
50
```

인덱싱은 `__getitem__`, `len()`은 `__len__`을 자동 호출한다.

---

## 5. 헷갈리는 개념 비교

|문법|호출되는 메서드|
|---|---|
|`obj[index]`|`__getitem__`|
|`len(obj)`|`__len__`|
|`print(obj)`|`__str__`|
