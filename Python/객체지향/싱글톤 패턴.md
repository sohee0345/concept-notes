# 싱글톤 패턴

## 1. 개념

싱글톤은 클래스의 인스턴스를 하나만 만들고 프로그램 전체에서 공유하는 디자인 패턴이다.

> **핵심:** 처음 생성한 인스턴스를 저장하고 이후 호출에서는 같은 인스턴스를 반환한다.

---

## 2. 쉽게 이해하기

여러 사람이 새 객체를 요청해도 하나의 공용 객체만 계속 돌려주는 방식이다.

```text
첫 호출 → 인스턴스 생성·저장
이후 호출 → 저장된 인스턴스 반환
```

---

## 3. 사용 방법

```python
class Singleton(type):
    _instances = {}

    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]
```

인스턴스가 없을 때만 생성하고 딕셔너리에 저장한 뒤 항상 저장된 객체를 반환한다.

---

## 4. 예제

```python
class Database(metaclass=Singleton):
    pass

db1 = Database()
db2 = Database()
print(db1 is db2)
```

실행 결과:

```text
True
```

`is`가 `True`이므로 두 변수는 같은 객체를 가리킨다.

---

## 5. 헷갈리는 개념 비교

|구분|일반 클래스|싱글톤|
|---|---|---|
|호출 결과|여러 인스턴스 생성 가능|같은 인스턴스 반환|
|사용|독립 상태가 필요할 때|하나의 객체를 공유할 때|
