# 싱글톤 패턴

## 1. 개념

싱글톤은 클래스의 인스턴스를 하나만 만들고 프로그램 전체에서 공유하는 디자인 패턴이다.

> **핵심:** 여러 번 클래스를 호출해도 이미 만든 같은 인스턴스를 반환한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
첫 호출 → 인스턴스 생성·저장
다음 호출 → 저장된 인스턴스 반환
```

> **쉽게 말하면:** 이름은 여러 개여도 모두 하나의 객체를 함께 가리키게 하는 방식이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
class Config:
    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance
```

- `_instance` → 처음 만든 인스턴스를 저장한다.
- `__new__` → 인스턴스 생성을 제어한다.
- `is` → 두 변수가 같은 객체를 가리키는지 확인한다.

> **핵심:** 새 인스턴스가 필요한지 먼저 확인하고 기존 인스턴스가 있으면 다시 사용한다.

------------------------------------------------------------------------

## 4. 예제

``` python
a = Config()
b = Config()
print(a is b)
```

실행 결과:

``` text
True
```

### 코드 해석

- 첫 호출에서 인스턴스를 만들어 `_instance`에 저장한다.
- 두 번째 호출에서는 저장된 인스턴스를 반환한다.

> **결과 해석:** `a`와 `b`는 서로 다른 변수이지만 같은 인스턴스를 가리킨다.

------------------------------------------------------------------------

## 6. 주의할 점

- `__new__`로 같은 객체를 반환해도 클래스를 호출할 때마다 `__init__`이 실행될 수 있다.
