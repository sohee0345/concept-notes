# 상속과 오버라이딩

## 1. 개념

상속은 부모 클래스의 속성과 메서드를 자식 클래스가 물려받는 기능이다. 오버라이딩은 물려받은 메서드를 자식 클래스에서 같은 이름으로 다시 정의하는 것이다.

> **핵심:** 상속으로 기존 기능을 재사용하고 오버라이딩으로 필요한 동작만 변경한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
Animal의 공통 기능
  ↓ 상속
Dog에서 사용
  ↓ speak() 오버라이딩
Dog만의 소리 반환
```

> **쉽게 말하면:** 부모의 기본 기능을 이어받고 자식에게 다른 부분만 다시 작성하는 것이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
class 자식클래스(부모클래스):
    pass
```

- 부모 클래스 → 공통 속성과 메서드를 제공한다.
- 자식 클래스 → 부모 기능을 물려받는다.
- 같은 이름의 메서드 재정의 → 부모 메서드를 오버라이딩한다.

> **핵심:** 자식 클래스의 인스턴스에서 오버라이딩한 메서드를 호출하면 자식의 정의가 실행된다.

------------------------------------------------------------------------

## 4. 예제

``` python
class Animal:
    def speak(self):
        return "소리를 냅니다."

class Dog(Animal):
    def speak(self):
        return "멍멍"

print(Dog().speak())
```

실행 결과:

``` text
멍멍
```

### 코드 해석

- `Dog(Animal)` → `Animal`을 상속한다.
- `Dog.speak()` → 부모와 같은 이름으로 메서드를 다시 정의한다.

> **결과 해석:** 자식 클래스가 다시 정의한 동작이 실행된다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 상속 | 오버라이딩 |
| --- | --- | --- |
| 목적 | 부모 기능 재사용 | 물려받은 동작 변경 |
| 문법 | `class Dog(Animal)` | 같은 이름의 메서드 재정의 |

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 부모 클래스 | 기능을 물려주는 클래스 |
| 자식 클래스 | 기능을 물려받는 클래스 |
| 오버라이딩 | 부모 메서드를 자식에서 재정의 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `class Dog(Animal):` | Animal 상속 |
| `def speak(self):` | 메서드 오버라이딩 |

> **상속은 기능을 물려받고 오버라이딩은 물려받은 메서드를 다시 정의한다.**
