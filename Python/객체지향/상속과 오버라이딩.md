# 상속과 오버라이딩

## 1. 개념

상속은 부모 클래스의 속성과 메서드를 자식 클래스가 물려받는 기능이고, 오버라이딩은 물려받은 메서드를 자식 클래스의 동작에 맞게 다시 정의하는 것이다.

> **핵심:** 상속으로 기존 기능을 재사용하고 오버라이딩으로 필요한 동작만 변경한다.

---

## 2. 쉽게 이해하기

부모의 기본 설계도를 물려받아 공통 부분은 그대로 사용하고 필요한 부분만 자식 설계도에서 바꾸는 방식이다.

```text
부모 클래스
  ↓ 상속
자식 클래스
  ↓ 메서드 재정의
자식에게 맞는 동작
```

---

## 3. 사용 방법

```python
class Dog(Animal):
    def speak(self):
        return "멍멍"
```

- `class Dog(Animal)` → `Animal`을 상속한다.
- 부모의 `__init__`과 속성을 그대로 사용할 수 있다.
- 같은 이름의 메서드를 자식에서 정의하면 오버라이딩된다.

---

## 4. 예제

```python
class Animal:
    def speak(self):
        return "소리를 냅니다."

class Dog(Animal):
    def speak(self):
        return "멍멍"

print(Dog().speak())
```

실행 결과:

```text
멍멍
```

자식 클래스에 다시 정의된 `speak()`가 호출된다.

---

## 5. 헷갈리는 개념 비교

|구분|상속|오버라이딩|
|---|---|---|
|역할|부모 기능을 물려받음|물려받은 동작을 다시 정의|
|목적|재사용|동작 변경|
