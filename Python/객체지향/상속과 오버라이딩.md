# 상속과 오버라이딩

## 1. 개념

상속은 부모 클래스의 속성과 메소드를 자식 클래스가 물려받는 기능이다. 오버라이딩은 물려받은 메소드를 자식 클래스에서 다시 정의하는 것이다.

> **핵심:** 상속으로 공통 기능을 재사용하고 오버라이딩으로 자식 클래스의 동작을 바꾼다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
Animal의 공통 속성과 메소드
  ↓ 상속
Dog가 그대로 사용
  ↓ 오버라이딩
Dog에 맞게 speak() 변경
```

> **쉽게 말하면:** 부모의 기본 설계를 물려받되 필요한 부분만 자식에게 맞게 다시 만드는 것이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
class Child(Parent):
    def inherited_method(self):
        return "새 동작"
```

- `Parent` → 속성과 메소드를 제공하는 부모 클래스
- `Child` → 부모 기능을 물려받는 자식 클래스
- 같은 이름의 메소드 재정의 → 오버라이딩

> **핵심:** 자식 클래스에서 다시 정의하지 않은 기능은 부모 클래스의 것을 사용한다.

------------------------------------------------------------------------

## 4. 예제

``` python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return f"{self.name}가 소리를 냅니다."

class Dog(Animal):
    def speak(self):
        return f"{self.name}가 멍멍 짖습니다."

dog = Dog("초코")
print(dog.speak())
```

실행 결과:

``` text
초코가 멍멍 짖습니다.
```

### 코드 해석

- `Dog(Animal)` → `Dog`가 `Animal`을 상속한다.
- `Dog`의 `speak()` → 부모 메소드를 오버라이딩한다.
- `Dog`는 부모의 `__init__`을 사용해 `name` 속성을 얻는다.

> **결과 해석:** 부모의 상태 초기화는 재사용하고 소리 내는 동작은 자식 클래스에 맞게 변경했다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 상속 | 오버라이딩 |
| --- | --- | --- |
| 역할 | 부모 기능 물려받기 | 물려받은 동작 재정의 |
| 문법 | `class Dog(Animal)` | 자식에 같은 이름의 메소드 정의 |
| 결과 | 기존 코드 재사용 | 자식에 맞는 동작 실행 |

------------------------------------------------------------------------

## 6. 주의할 점

- 오버라이딩할 메소드 이름을 부모 메소드와 동일하게 작성한다.
- 자식 클래스에서 오버라이딩하지 않은 메소드는 부모의 구현을 사용한다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `부모 클래스` | 공통 기능을 제공하는 클래스 |
| `자식 클래스` | 부모 기능을 상속받는 클래스 |
| `오버라이딩` | 부모 메소드를 자식에서 재정의 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `class Dog(Animal):` | `Animal` 상속 |
| `def speak(self):` | 부모 메소드 오버라이딩 |

### ⭐ 한 줄 정리

> **자식 클래스는 상속으로 부모 기능을 재사용하고 오버라이딩으로 필요한 동작을 변경한다.**
