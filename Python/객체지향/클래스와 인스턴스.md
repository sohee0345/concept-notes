# 클래스와 인스턴스

## 1. 개념

클래스는 객체의 속성과 동작을 정의하는 설계도이고, 인스턴스는 클래스를 호출해 실제로 만든 객체이다. 하나의 클래스로 여러 인스턴스를 만들 수 있으며 각 인스턴스는 서로 다른 상태를 저장할 수 있다.

> **핵심:** 클래스는 공통 구조를 정의하고 인스턴스는 그 구조에 각자의 데이터를 저장한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
Person 클래스
  ├─ lee 인스턴스: name="이순신"
  └─ kim 인스턴스: name="김유신"
```

> **쉽게 말하면:** 클래스가 같은 형식의 설계도라면 인스턴스는 그 설계도로 각각 만든 실제 대상이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
class Person:
    species = "Human"

    def __init__(self, name):
        self.name = name
```

- `species` → 클래스에 저장되는 클래스 속성
- `self.name` → 각 인스턴스에 저장되는 인스턴스 속성
- `self` → 메서드를 호출한 현재 인스턴스
- `__init__` → 인스턴스의 초기 상태를 설정하는 매직 메서드

> **핵심:** 인스턴스마다 달라야 하는 값은 `self.속성`에 저장한다.

------------------------------------------------------------------------

## 4. 예제

``` python
lee = Person("이순신")
kim = Person("김유신")

print(lee.name)
print(kim.name)
print(Person.species)
```

실행 결과:

``` text
이순신
김유신
Human
```

### 코드 해석

- 두 인스턴스는 서로 다른 `name`을 저장한다.
- `species`는 클래스에 정의된 공통 속성이다.

> **결과 해석:** 같은 클래스로 만들어도 인스턴스별 상태는 독립적으로 관리된다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 클래스 | 인스턴스 |
| --- | --- | --- |
| 의미 | 객체를 만드는 설계도 | 클래스로 만든 실제 객체 |
| 생성 | `class Person:` | `Person("이순신")` |
| 데이터 | 공통 구조 정의 | 개별 상태 저장 |

------------------------------------------------------------------------

## 6. 주의할 점

- 클래스를 다시 정의한 뒤 변경 내용을 적용하려면 인스턴스도 다시 생성한다.
- `__init__`의 파라미터로 받은 값은 `self.속성`에 대입해야 인스턴스가 기억한다.
