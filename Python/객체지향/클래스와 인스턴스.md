# 클래스와 인스턴스

## 1. 개념

클래스는 객체를 만들기 위한 설계도이고 인스턴스는 클래스를 호출해 만든 실제 객체이다. 하나의 클래스로 여러 인스턴스를 만들 수 있으며 각 인스턴스는 `self`를 통해 자신의 상태를 저장한다.

> **핵심:** 클래스는 구조와 동작을 정의하고 인스턴스는 그 정의에 따라 만들어진 독립된 객체이다.

---

## 2. 쉽게 이해하기

클래스가 같은 형태의 제품을 만드는 설계도라면 인스턴스는 설계도로 만든 각각의 제품이다.

```text
클래스 정의
  ↓ 클래스 호출
인스턴스 생성
  ↓ __init__ 실행
인스턴스별 상태 저장
```

---

## 3. 사용 방법

```python
class Person:
    species = "Human"

    def __init__(self, name):
        self.name = name
```

- `self` → 메서드를 호출한 현재 인스턴스를 가리킨다.
- `__init__` → 인스턴스 생성 시 자동 호출되어 초기 상태를 설정한다.
- `species` → 여러 인스턴스가 함께 참조하는 클래스 속성이다.
- `self.name` → 각 인스턴스에 저장되는 인스턴스 속성이다.

---

## 4. 예제

```python
lee = Person("이순신")
kim = Person("김유신")

print(lee.name)
print(kim.name)
```

실행 결과:

```text
이순신
김유신
```

두 인스턴스는 같은 클래스로 만들었지만 서로 다른 `name` 값을 저장한다.

---

## 5. 헷갈리는 개념 비교

|구분|클래스|인스턴스|
|---|---|---|
|의미|객체를 만드는 설계도|클래스로 만든 실제 객체|
|속성|여러 객체가 공유 가능|객체마다 별도 저장|
