# 클래스와 인스턴스

## 1. 개념

클래스는 객체를 만들기 위한 설계이고, 인스턴스는 클래스를 호출해 실제로 만든 객체이다. 하나의 클래스로 서로 다른 상태를 가진 여러 인스턴스를 만들 수 있다.

> **핵심:** 클래스는 공통 구조와 동작을 정의하고 각 인스턴스는 `self` 속성에 자신의 상태를 저장한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
Person 클래스
  ├─ LEE 인스턴스: name="이순신"
  └─ KIM 인스턴스: name="김유신"
```

> **쉽게 말하면:** 하나의 설계도로 여러 객체를 만들되, 각 객체는 서로 다른 값을 기억할 수 있다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
class Person:
    species = "Human"

    def __init__(self, name, age=0):
        self.name = name
        self.age = age

    def introduce(self):
        return f"{self.name} / {self.age}"
```

- `species` → 클래스 속성
- `self.name`, `self.age` → 인스턴스 속성
- `self` → 현재 메소드를 호출한 인스턴스
- `__init__` → 인스턴스의 초기 상태 설정

> **핵심:** 여러 메소드에서 사용할 값은 `self.속성`으로 저장한다.

------------------------------------------------------------------------

## 4. 예제

``` python
LEE = Person("이순신")
KIM = Person("김유신", 45)

print(LEE.introduce())
print(KIM.introduce())
```

실행 결과:

``` text
이순신 / 0
김유신 / 45
```

### 코드 해석

- `Person("이순신")` → 인스턴스를 만들고 `__init__`을 호출한다.
- `self.name = name` → 전달받은 값을 인스턴스가 기억한다.
- `LEE`, `KIM` → 같은 클래스에서 생성했지만 상태가 다른 객체이다.

> **결과 해석:** 각 인스턴스의 속성은 독립적으로 저장된다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 클래스 | 인스턴스 |
| --- | --- | --- |
| 의미 | 객체의 구조와 동작을 정의 | 클래스로 만든 실제 객체 |
| 생성 | `class Person:` | `Person(...)` |
| 상태 | 클래스 속성 공유 가능 | 각자의 인스턴스 속성 보유 |

------------------------------------------------------------------------

## 6. 주의할 점

- 클래스와 인스턴스를 하드디스크와 RAM 자체로 정의하지 않는다. 이는 설계와 실체를 설명하는 비유일 뿐이다.
- 클래스를 다시 정의해도 기존 인스턴스는 자동으로 새 정의를 따르지 않는다.
- 인스턴스 메소드의 첫 파라미터인 `self`에는 호출한 인스턴스가 전달된다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `class` | 객체의 설계 정의 |
| `instance` | 클래스로 생성한 객체 |
| `self` | 현재 인스턴스 자신 |
| `__init__` | 인스턴스 초기 상태 설정 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `class Person:` | 클래스 정의 |
| `Person("이순신")` | 인스턴스 생성 |
| `self.name = name` | 인스턴스 속성 저장 |

### ⭐ 한 줄 정리

> **클래스는 객체의 설계이고 인스턴스는 그 설계로 만든 객체이며, 각 인스턴스는 `self` 속성에 상태를 저장한다.**
