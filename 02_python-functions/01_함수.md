# 함수

## 1. 개념
함수는 반복해서 사용할 코드를 하나의 이름으로 묶어두는 기능이다.

> **핵심:** 함수는 입력값을 받아 필요한 작업을 수행하고 `return`으로 결과를 돌려줄 수 있다.

---

## 2. 쉽게 이해하기
```text
입력값
  ↓
함수
  ↓
처리
  ↓
결과(return)
```

---

## 3. 사용 방법
```python
def add(x, y=0):
    return x + y

result = add(10, 20)
```

- `def` → 함수 정의
- parameter → 함수 정의 시 받는 변수
- argument → 함수를 호출할 때 넣는 실제 값
- `return` → 결과 반환
- 기본값 파라미터 → 인자 생략 시 사용할 값
- `*args` → 여러 위치 인자를 튜플로 받음
- `**kwargs` → 여러 키워드 인자를 딕셔너리로 받음

---

## 4. 예제
```python
def add_all(*args):
    return sum(args)

print(add_all(1, 2, 3, 4))
```

실행 결과:
```text
10
```

---

## 5. 헷갈리는 개념 비교
|구분|parameter|argument|
|---|---|---|
|의미|함수 정의에서 받는 변수|호출할 때 전달하는 실제 값|
|예시|`def add(x, y)`의 `x, y`|`add(1, 2)`의 `1, 2`|
