# 람다 · 클로저 · 콜백 · 재귀 · 데코레이터

## 1. 개념
함수를 더 유연하게 작성하거나 다른 함수와 결합해서 사용할 때 활용하는 여러 함수 형태이다.

> **핵심:** 각각 목적이 다르며, 람다는 짧은 함수, 클로저는 외부 상태 기억, 콜백은 함수를 인자로 전달, 재귀는 자기 자신 호출, 데코레이터는 기존 함수 기능 확장에 사용한다.

---

## 2. 쉽게 이해하기
```text
함수
 ├─ lambda     → 짧게 작성
 ├─ closure    → 값 기억
 ├─ callback   → 함수를 전달
 ├─ recursive  → 자기 자신 호출
 └─ decorator  → 기능 덧붙이기
```

---

## 3. 사용 방법
```python
double = lambda x: x * 2
```

```python
def countdown(n):
    if n == 0:
        return
    print(n)
    countdown(n - 1)
```

- `lambda` → 한 줄 익명 함수
- closure → 함수가 외부 함수의 값을 기억
- callback → 다른 함수에 전달되는 함수
- recursive function → 자기 자신을 호출
- decorator → 기존 함수를 감싸 기능 추가

---

## 4. 예제
```python
numbers = [3, 1, 2]
numbers.sort(key=lambda x: x)
print(numbers)
```

실행 결과:
```text
[1, 2, 3]
```

---

## 5. 헷갈리는 개념 비교
|구분|lambda|일반 함수|
|---|---|---|
|형태|한 줄 표현식|여러 줄 작성 가능|
|주 사용|간단한 일회성 함수|복잡하거나 재사용할 함수|

## 🟦 핵심 정리

### 💡 주요 개념
lambda, closure, callback, recursive function, decorator

### 💻 주요 코드
|코드|의미|
|---|---|
|`lambda x: x * 2`|익명 함수|
|`func(callback)`|함수를 인자로 전달|
|`@decorator`|함수 기능 확장|

### ⭐ 한 줄 정리
> **다양한 함수 형태는 함수를 더 짧게 쓰거나 재사용하고 확장하는 데 활용된다.**
