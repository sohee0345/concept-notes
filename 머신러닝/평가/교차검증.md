# 교차검증

## 1. 개념

교차검증(Cross Validation)은 훈련 데이터를 여러 폴드로 나누고 검증 폴드를 번갈아 바꾸며 모델을 반복 평가하는 방법이다. 하나의 검증 세트에 우연히 잘 맞는 모델을 선택할 위험을 줄이고 일반화 성능을 안정적으로 추정한다.

> **핵심:** 교차검증은 훈련 데이터 안에서 모델을 비교하며 테스트 데이터는 최종 평가를 위해 남겨 둔다.

---

## 2. 쉽게 이해하기

5-Fold 교차검증에서는 훈련 데이터를 다섯 조각으로 나눈 뒤, 네 조각으로 학습하고 남은 한 조각으로 검증하는 일을 다섯 번 반복한다.

```text
훈련 데이터 5분할
  → 검증 폴드를 매번 교체
  → 5개의 검증 점수 계산
  → 평균과 표준편차 확인
```

평균은 전반적인 성능을, 표준편차는 데이터 분할이 바뀔 때의 안정성을 보여준다.

---

## 3. 사용 방법

```python
from sklearn.model_selection import StratifiedKFold, cross_val_score

cv = StratifiedKFold(
    n_splits=5,
    shuffle=True,
    random_state=42,
)

scores = cross_val_score(
    model,
    X_train,
    y_train,
    scoring="roc_auc",
    cv=cv,
)

print(scores.mean(), scores.std())
```

- `n_splits` → 폴드 수
- `shuffle` → 분할 전 데이터 순서 섞기
- `scoring` → 평가 지표
- `cv` → 사용할 분할 전략

> **핵심:** 분류 문제에서는 각 폴드의 클래스 비율을 유지하는 Stratified K-Fold를 우선 고려한다.

---

## 4. 주요 함수

| 함수 | 반환 내용 | 사용 목적 |
| --- | --- | --- |
| `cross_val_score()` | 폴드별 단일 점수 | 한 평가 지표 비교 |
| `cross_validate()` | 시간과 여러 평가 점수 | 상세한 성능 분석 |
| `cross_val_predict()` | Out-of-Fold 예측 | 혼동행렬 등 예측 결과 분석 |

---

## 5. 주의할 점

- 결측치 처리, 인코딩과 스케일링을 전체 데이터에 먼저 학습하면 검증 정보가 새어 들어간다. 전처리와 모델을 파이프라인으로 묶는다.
- 시계열 데이터는 미래 데이터로 과거를 학습하지 않도록 시간 순서를 보존하는 분할을 사용한다.
- 교차검증을 반복해도 별도 테스트 데이터의 최종 평가 역할은 남아 있다.
- 폴드 수가 많으면 훈련 데이터 비율은 커지지만 계산 시간도 증가한다.
