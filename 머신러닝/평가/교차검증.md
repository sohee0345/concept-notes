# 교차검증

## 1. 개념

교차검증은 train 데이터를 여러 폴드로 나누어 학습과 검증을 반복하고 모델과 하이퍼파라미터의 성능을 비교하는 방법이다. 한 번의 데이터 분할에만 의존하지 않으므로 설정의 평균 성능과 변동성을 함께 확인할 수 있다.

> **핵심:** 모델 선택은 교차검증으로 수행하고 test는 선택이 끝난 뒤 한 번만 최종 평가한다.

---

## 2. 쉽게 이해하기

훈련 자료를 여러 묶음으로 나누고 매번 다른 묶음을 모의시험으로 사용해 설정의 안정성을 확인한다.

```text
train → K개 폴드 → K번 학습·검증 → 평균 성능 → 모델 선택
```

---

## 3. 사용 방법

- K-Fold → 각 폴드를 한 번씩 검증에 사용한다.
- StratifiedKFold → 각 폴드의 클래스 비율을 비슷하게 유지한다.
- `cross_val_score` → 한 평가 지표의 폴드별 점수를 반환한다.
- `cross_validate` → 여러 평가 지표와 학습·평가 시간 등을 함께 반환한다.
- `cross_val_predict` → 각 행이 검증 폴드에 포함되었을 때의 예측값을 반환한다.
- 설정 비교에는 점수의 평균뿐 아니라 표준편차도 함께 확인한다. 평균이 높아도 표준편차가 크면 데이터 분할에 따라 성능이 불안정할 수 있다.
- 스케일링이나 결측치 처리처럼 데이터에서 기준을 학습하는 전처리는 모델과 함께 파이프라인에 넣는다. 각 폴드의 훈련 부분으로만 전처리 기준을 학습해야 검증 데이터의 정보가 새는 것을 막을 수 있다.
- test 결과로 하이퍼파라미터를 고르지 않는다.

---

## 4. 예제

```python
from sklearn.model_selection import StratifiedKFold, cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
pipeline = make_pipeline(StandardScaler(), LogisticRegression())

scores = cross_val_score(pipeline, X_train, y_train, cv=cv, scoring="roc_auc")
print(scores.mean(), scores.std())
```

`StandardScaler`가 파이프라인 안에 있으므로 각 반복에서 훈련 폴드만 사용해 평균과 표준편차를 계산한다. `scores.mean()`은 전반적인 성능을, `scores.std()`는 폴드별 성능의 흔들림을 보여준다.

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|폴드|train을 나눈 데이터 묶음|
|교차검증|학습·검증 역할을 바꿔 반복 평가|
|StratifiedKFold|클래스 비율을 유지한 폴드 분할|

### 💻 주요 코드

|코드|의미|
|---|---|
|`StratifiedKFold(n_splits=5)`|5겹 층화 교차검증|
|`cross_val_score(..., scoring="roc_auc")`|폴드별 ROC-AUC 점수 계산|
|`scores.mean()`, `scores.std()`|평균 성능과 변동성 확인|
