# 불균형 데이터 평가

## 1. 개념

불균형 데이터는 클래스 표본 수가 한쪽으로 크게 치우친 데이터이다. 정확도가 높아도 중요한 소수 클래스를 탐지하지 못할 수 있다.

> **핵심:** 소수 클래스의 중요도와 FP·FN 비용에 맞춰 Precision·Recall·F1·PR-AUC를 함께 확인한다.

---

## 2. 쉽게 이해하기

99개 음성과 1개 양성에서 모두 음성이라 답하면 정확도 99%지만 양성을 전혀 찾지 못한다.

```text
클래스 비율 확인 → 혼동행렬 → 소수 클래스 지표 → PR-AUC
```

---

## 3. 사용 방법

- `stratify=y`로 분할 시 클래스 비율을 유지한다.
- DummyClassifier와 비교해 기준 성능을 확인한다.
- ROC-AUC와 PR-AUC를 문제 목적에 맞게 해석한다.
- 희귀 양성 탐지가 중요하면 PR Curve가 더 직접적일 수 있다.

---

## 4. 예제

```python
proba = model.predict_proba(X_test)[:, 1]
precision, recall, _ = precision_recall_curve(y_test, proba)
pr_auc = auc(recall, precision)
```

임계값별 Precision과 Recall의 관계를 면적으로 요약한다.

---

## 5. 헷갈리는 개념 비교

|구분|ROC-AUC|PR-AUC|
|---|---|---|
|관계|TPR·FPR|Precision·Recall|
|불균형 데이터|좋게 보일 수 있음|소수 양성 성능에 더 직접적|

---

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|클래스 불균형|클래스별 표본 수가 크게 다른 상태|
|PR-AUC|Precision-Recall Curve 아래 면적|
|기준 모델|복잡한 모델과 비교할 단순한 기준|

### 💻 주요 코드

|코드|의미|
|---|---|
|`precision_recall_curve()`|임계값별 Precision·Recall 계산|
|`auc(recall, precision)`|PR-AUC 계산|
