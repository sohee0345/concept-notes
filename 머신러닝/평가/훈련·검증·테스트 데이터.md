# 훈련·검증·테스트 데이터

## 1. 개념

훈련 데이터는 모델과 전처리 기준을 학습하고, 검증 데이터는 모델과 하이퍼파라미터를 선택하며, 테스트 데이터는 모든 선택이 끝난 뒤 최종 성능을 평가한다.

> **핵심:** 테스트 데이터는 학습과 선택 과정에서 분리해 최종 평가에만 사용한다.

------------------------------------------------------------------------

## 2. 분할 예제

```python
train, test = train_test_split(
    df,
    test_size=0.2,
    random_state=42,
    stratify=df["target"],
)
```

분할 비율은 데이터 크기와 클래스별 표본 수, 평가 안정성에 따라 정한다.

------------------------------------------------------------------------

## 3. 전처리 순서

```text
train → 전처리 fit + transform → 모델 학습
test  → 같은 전처리로 transform → 최종 평가
```

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| train | 학습에 사용한다. |
| validation | 모델 선택에 사용한다. |
| test | 최종 평가에 사용한다. |

### ⭐ 한 줄 정리

> **테스트 데이터는 전처리 기준과 모델 선택에 사용하지 않고 마지막 평가까지 보존한다.**
