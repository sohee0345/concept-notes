# 결정계수 R²
## 1. 개념

$R^2$는 Target 평균을 예측하는 기준과 비교하여 회귀 모델이 데이터 변동을 얼마나 설명하는지 나타낸다.

> **핵심:** 1에 가까울수록 좋지만 기준보다 나쁜 모델에서는 음수가 될 수 있다.

------------------------------------------------------------------------

## 2. 계산식

$$
R^2=1-\frac{\sum_i(y_i-\hat{y}_i)^2}{\sum_i(y_i-\bar{y})^2}
$$

```python
from sklearn.metrics import r2_score

r2_score(y_valid, pred)
```

------------------------------------------------------------------------

## 3. 해석

- `1` → 실제값을 완벽하게 예측한다.
- `0` → 평균 예측 기준과 같은 수준이다.
- 음수 → 평균 기준보다 예측이 나쁘다.
