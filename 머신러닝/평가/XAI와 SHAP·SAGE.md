# XAI와 SHAP·SAGE

## 1. 개념

설명 가능한 인공지능(XAI)은 모델의 예측과 동작을 사람이 이해할 수 있는 형태로 설명하는 방법과 분야다. SHAP는 주로 개별 예측의 특성별 기여도를 설명하고, SAGE는 전체 데이터에서 모델이 각 특성에 의존하는 정도를 평가한다.

> **핵심:** SHAP는 지역 설명, SAGE는 전역 설명에 초점을 둔다.

---

## 2. 쉽게 이해하기

한 승객의 생존 예측값이 기준값에서 얼마나 달라졌는지를 각 특성의 몫으로 나누면 지역 설명이다. 전체 승객의 예측 손실을 줄이는 데 각 특성이 얼마나 중요했는지를 요약하면 전역 설명이다.

```text
개별 예측의 이유 → SHAP
모델 전체의 특성 의존도 → SAGE
```

---

## 3. SHAP 사용 방법

SHAP는 게임 이론의 Shapley Value를 이용해 기준 예측값과 실제 예측값의 차이를 특성별 기여도로 분해한다.

```python
import shap

explainer = shap.Explainer(model, X_train)
values = explainer(X_test)

shap.plots.waterfall(values[0])
shap.plots.beeswarm(values)
shap.plots.bar(values)
```

- `waterfall` → 한 샘플의 특성별 기여 방향과 크기
- `beeswarm` → 전체 샘플의 특성값과 기여도 분포
- `bar` → 평균 절대 SHAP 값 기반 전역 중요도

> **핵심:** 양의 SHAP 값은 기준값보다 모델 출력을 높이는 기여이며 현실의 양의 상관관계나 인과관계를 뜻하지 않는다.

---

## 4. SHAP와 SAGE 비교

| 구분 | SHAP | SAGE |
| --- | --- | --- |
| 주요 질문 | 이 예측에 무엇이 기여했는가? | 모델 전체가 무엇에 의존하는가? |
| 설명 범위 | 지역 설명 중심, 전역 요약 가능 | 전역 설명 |
| 기준 | 예측값과 기준값의 차이 | 전체 데이터의 예측 손실 |
| 공통점 | Shapley Value 관점 사용 | Shapley Value 관점 사용 |

모델의 분할 횟수나 이득으로 계산한 내장 특성 중요도는 전역 중요도의 한 종류지만 SAGE와 동일하지 않다.

---

## 5. 주의할 점

- 높은 기여도는 모델이 그 특성을 많이 사용했다는 뜻이지 원인이라는 뜻이 아니다.
- 강하게 상관된 특성들은 기여도가 나뉘거나 해석이 불안정해질 수 있다.
- 설명할 데이터의 전처리 열과 순서는 모델 학습 때와 같아야 한다.
- 설명 결과는 모델의 편향과 오류를 발견하는 단서이지 모델의 공정성이나 타당성을 자동으로 보장하지 않는다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `XAI` | 모델 예측과 동작을 이해할 수 있게 설명하는 분야 |
| `SHAP` | 예측값 차이를 특성별 기여도로 분해하는 방법 |
| `SAGE` | 전체 예측 손실을 기준으로 특성 의존도를 평가하는 방법 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `shap.Explainer()` | 모델 설명기 생성 |
| `shap.plots.waterfall()` | 개별 예측 설명 |
| `shap.plots.beeswarm()` | 전체 SHAP 값 분포 시각화 |

### ⭐ 한 줄 정리

> **SHAP는 개별 예측의 특성 기여도를, SAGE는 모델 전체의 특성 의존도를 설명한다.**
