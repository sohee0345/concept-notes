# XAI

## 1. 개념

XAI(Explainable AI, 설명 가능한 인공지능)는 모델이 왜 특정 예측을 했는지 또는 전체적으로 어떤 특성을 중요하게 사용하는지 사람이 이해할 수 있도록 설명하는 방법이다. 복잡한 모델의 판단 근거를 점검하고 결과를 소통하는 데 사용한다.

---

## 2. 쉽게 이해하기

예측값만 알려 주는 모델에게 판단 근거도 함께 설명해 달라고 요청하는 것과 같다. 한 사람의 예측 이유를 살펴보는 지역적 설명과 모델 전체의 경향을 살펴보는 전역적 설명으로 나눌 수 있다.

```text
지역적 설명 → 특정 한 건의 예측에 각 특성이 기여한 정도
전역적 설명 → 전체 데이터에서 모델이 의존하는 특성과 경향
```

---

## 3. 사용 방법

- SHAP은 게임 이론의 Shapley value를 바탕으로 예측값을 기준값과 각 특성의 기여도로 나누어 설명한다.
- SHAP waterfall plot은 한 예측에서 각 특성이 값을 올리거나 내린 방향을 보여준다.
- SHAP beeswarm·bar plot은 여러 샘플을 모아 전역적인 중요도와 영향 방향을 살펴볼 때 사용한다.
- SHAP dependence plot은 한 특성의 값과 기여도의 관계를 확인할 때 사용한다.
- SAGE는 특정 특성 정보를 제거했을 때 손실이 얼마나 증가하는지를 이용해 데이터 전체에서의 전역적 기여도를 평가한다.

설명값은 모델이 사용한 관계를 보여 줄 뿐이다. 특성이 결과의 원인이라는 사실이나 모델이 공정하다는 사실을 증명하지는 않는다.

---

## 4. 예제

```python
import shap

explainer = shap.Explainer(model, X_train)
shap_values = explainer(X_test)

shap.plots.waterfall(shap_values[0])
shap.plots.beeswarm(shap_values)
shap.plots.bar(shap_values)
```

`waterfall`은 첫 번째 샘플의 지역적 설명을, `beeswarm`과 `bar`는 여러 샘플을 종합한 전역적 설명을 보여준다. 양의 SHAP 값은 해당 예측값을 높이는 방향, 음의 값은 낮추는 방향의 기여를 뜻한다.

---

## 5. 헷갈리는 개념 비교

|구분|SHAP|SAGE|모델 내장 특성 중요도|
|---|---|---|---|
|설명 범위|지역적·전역적|전역적|주로 전역적|
|기준|개별 예측에 대한 특성 기여도|특성 정보가 전체 손실을 줄이는 정도|모델 구조가 계산한 중요도|
|해석 초점|예측값이 형성된 과정|전체 예측 성능에 대한 기여|모델 내부의 분할·가중치 등|

계산 기준이 서로 다르므로 세 중요도 값이 같은 순서로 나오지 않아도 오류라고 볼 수 없다.

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|지역적 설명|특정 예측 한 건의 판단 근거|
|전역적 설명|전체 데이터에서 나타나는 모델의 판단 경향|
|SHAP|예측값을 기준값과 특성별 기여도로 설명하는 방법|
|SAGE|특성 정보가 전체 손실을 줄이는 정도로 전역 기여도를 평가하는 방법|

### 💻 주요 코드

|코드|의미|
|---|---|
|`shap.Explainer(model, X_train)`|모델과 기준 데이터로 설명기 생성|
|`shap.plots.waterfall(...)`|한 예측의 지역적 설명 시각화|
|`shap.plots.beeswarm(...)`|여러 예측의 전역적 영향 시각화|

### ⭐ 한 줄 정리
