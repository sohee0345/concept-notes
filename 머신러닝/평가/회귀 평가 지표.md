# 회귀 평가 지표

## 1. 개념

회귀 평가 지표는 실제값과 예측값의 차이를 서로 다른 방식으로 요약한다. 지표마다 단위, 큰 오차에 대한 민감도, 0과 음수 허용 조건이 다르다.

> **핵심:** 값이 작거나 큰지만 보지 말고 지표가 강조하는 오차와 사용 조건을 확인한다.

---

## 2. 쉽게 이해하기

같은 예측 오차를 절댓값, 제곱, 비율, 로그 차이로 재는 여러 자와 같다.

```text
실제값·예측값 → 오차 계산 방식 선택 → 지표 해석
```

---

## 3. 사용 방법

- $R^2$ → 평균 기준 모델 대비 설명력을 나타낸다.
- MAE → 절대오차 평균이며 Target과 같은 단위이다.
- MSE → 제곱오차 평균으로 큰 오차를 더 강조한다.
- RMSE → MSE의 제곱근으로 Target과 같은 단위이다.
- RMSLE → 실제값과 예측값의 `log1p` 차이를 측정한다.
- MAPE·SMAPE → 상대적인 오차 비율을 측정한다.

---

## 4. 예제

```python
r2 = r2_score(y_valid, pred)
mae = mean_absolute_error(y_valid, pred)
mse = mean_squared_error(y_valid, pred)
rmse = np.sqrt(mse)
```

$R^2$는 기준보다 나쁘면 음수가 될 수 있으며 항상 0과 1 사이가 아니다.

---

## 5. 헷갈리는 개념 비교

|지표|특징|주의|
|---|---|---|
|MAE|절대오차 평균|큰 오차 강조가 상대적으로 작음|
|RMSE|제곱 후 제곱근|큰 오차에 민감|
|RMSLE|로그 차이|음수값에 부적합|
|MAPE|실제값 대비 비율|실제값 0 근처에서 불안정|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|$R^2$|평균 기준 모델 대비 설명력|
|절대오차 지표|오차 크기를 절댓값으로 요약|
|제곱오차 지표|큰 오차를 더 크게 반영|
|비율 지표|실제값 대비 상대 오차 측정|

### 💻 주요 코드

|코드|의미|
|---|---|
|`r2_score()`|결정계수 계산|
|`mean_absolute_error()`|MAE 계산|
|`mean_squared_error()`|MSE 계산|
|`np.sqrt(mse)`|RMSE 계산|
