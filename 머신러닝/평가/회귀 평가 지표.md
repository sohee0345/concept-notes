# 회귀 평가 지표

## 1. 개념

회귀 평가 지표는 연속형 실제값과 모델 예측값의 차이를 여러 기준으로 측정한다. 지표마다 큰 오차, 단위, 비율을 다르게 반영한다.

> **핵심:** 하나의 지표만 보지 말고 데이터와 평가 목적에 맞는 지표를 해석한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
실제값 y와 예측값 pred
  ↓ 비교 방식 선택
설명력 → R²
제곱 오차 → MSE / RMSE
절대 오차 → MAE
로그 오차 → RMSLE
비율 오차 → MAPE / SMAPE
```

> **쉽게 말하면:** 같은 예측 오차도 큰 실수를 더 강조할지, 원래 단위로 볼지, 비율로 볼지에 따라 점수가 달라진다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
from sklearn.metrics import (
    r2_score,
    mean_squared_error,
    mean_absolute_error,
    mean_absolute_percentage_error,
)

r2 = r2_score(y_valid, pred)
mse = mean_squared_error(y_valid, pred)
rmse = np.sqrt(mse)
mae = mean_absolute_error(y_valid, pred)
mape = mean_absolute_percentage_error(y_valid, pred)
```

> **핵심:** 오차 지표는 작을수록 좋고, $R^2$는 일반적으로 클수록 설명력이 높다.

------------------------------------------------------------------------

## 4. 예제

``` text
R²    = 0.4849058889476756
MSE   = 2848.3106508475053
RMSE  = 53.369566710321955
MAE   = 41.548506859880604
RMSLE = 0.4180098960600321
MAPE  = 0.3731097043374469
SMAPE = 0.15271405979135058
```

### 결과 해석

- MSE → 큰 오차를 제곱해 더 크게 반영
- RMSE → Target과 같은 단위로 해석 가능
- MAE → 평균적인 절대 오차 크기
- RMSLE → 로그 변환된 값의 차이 평가
- MAPE·SMAPE → 비율 관점의 오차

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 지표 | 기준 | 주의점 |
| --- | --- | --- |
| $R^2$ | Target 변동 설명력 | 음수가 될 수 있음 |
| MSE | 제곱 오차 평균 | 큰 오차에 민감 |
| RMSE | MSE의 제곱근 | MSE와 값 크기 비교 금지 |
| MAE | 절대오차 평균 | 제곱 오차보다 큰 오차 영향이 작음 |
| RMSLE | 로그값의 오차 | 로그 적용 가능 범위 확인 |
| MAPE | 실제값 기준 비율 | 실제값 0에 주의 |
| SMAPE | 실제값·예측값 기준 비율 | 두 값이 모두 0이면 분모 주의 |

------------------------------------------------------------------------

## 6. 주의할 점

- $R^2$는 항상 0과 1 사이인 것이 아니며 모델이 기준보다 나쁘면 음수가 될 수 있다.
- RMSE는 MSE에 제곱근을 취하므로 Target과 같은 단위가 된다.
- 실습 `smape()` 결과는 100을 곱하지 않은 비율이다.
- MAPE와 SMAPE는 분모가 0이 되는 경우를 확인해야 한다.
