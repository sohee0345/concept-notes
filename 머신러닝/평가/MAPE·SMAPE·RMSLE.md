# MAPE·SMAPE·RMSLE

## 1. 개념

MAPE와 SMAPE는 상대적인 오차를, RMSLE는 실제값과 예측값의 로그 차이를 측정한다.

> **핵심:** 0과 음수 처리, 반환 단위와 공식의 구현 방식을 확인하고 사용한다.

------------------------------------------------------------------------

## 2. 비교

| 지표 | 특징 | 주의점 |
| --- | --- | --- |
| MAPE | 실제값 대비 절대오차 비율 | 실제값 0에 취약 |
| SMAPE | 실제값과 예측값 크기를 분모에 함께 사용 | 정의별 배율이 다름 |
| RMSLE | log1p 값의 RMSE | 음수 값에 사용 불가 |

```python
mape = mean_absolute_percentage_error(y_valid, pred)
rmsle = np.sqrt(mean_squared_log_error(y_valid, pred))
```

scikit-learn의 MAPE 결과 `0.2`는 비율이며 백분율로는 20%이다.
