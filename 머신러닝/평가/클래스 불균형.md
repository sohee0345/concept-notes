# 클래스 불균형

## 1. 개념

클래스 불균형은 분류 Target의 클래스별 표본 수가 크게 다른 상태이다. 비율이 낮은 클래스를 모델이 충분히 학습하지 못할 수 있다.

> **핵심:** 분류 문제에서는 모델 학습 전에 클래스별 개수와 비율을 확인한다.

------------------------------------------------------------------------

## 2. 확인 방법

```python
train["target"].value_counts()
train["target"].value_counts(normalize=True)
```

------------------------------------------------------------------------

## 3. 분할

```python
train, test = train_test_split(
    df,
    stratify=df["target"],
    random_state=42,
)
```

`stratify`는 클래스 비율을 분할 결과에 비슷하게 유지한다.
