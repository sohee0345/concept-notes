# 분류 평가 기초

## 1. 개념

분류 모델 평가는 실제 클래스와 예측 클래스를 비교해 Accuracy, Precision, Recall, F1 등으로 성능을 판단하는 과정이다. 클래스 비율이 불균형하면 전체 정확도만으로 판단하기 어렵다.

> **핵심:** 평가 전에 클래스 비율과 학습 경고를 확인하고 test를 최종 평가에만 사용한다.

---

## 2. 쉽게 이해하기

한 클래스가 대부분이면 모델이 다수 클래스만 예측해도 정확도가 높아 보일 수 있다.

```text
클래스 비율 확인 → 모델 학습 → test 예측 → 실제값과 비교
```

---

## 3. 사용 방법

```python
train["survived"].value_counts(normalize=True)
y_pred = model.predict(x_test)
accuracy = accuracy_score(y_test, y_pred)
print(classification_report(y_test, y_pred))
```

- `value_counts(normalize=True)` → 클래스별 비율을 확인한다.
- `accuracy_score()` → 전체 예측 중 맞힌 비율을 계산한다.
- Precision → 양성이라고 예측한 것 중 실제 양성의 비율이다.
- Recall → 실제 양성 중 찾아낸 비율이다.
- F1 → Precision과 Recall의 조화평균이다.
- `classification_report()` → 주요 분류 지표를 함께 출력한다.
- test 결과로 모델 설정을 반복 선택하면 최종 평가의 의미가 약해질 수 있다.

## 4. 예제

```python
from sklearn.dummy import DummyClassifier
from sklearn.metrics import f1_score

dummy = DummyClassifier(strategy="most_frequent")
dummy.fit(x_train, y_train)
pred_dummy = dummy.predict(x_valid)

print(f1_score(y_valid, pred_dummy))
```

양성 클래스가 적으면 모두 음성으로 예측해도 Accuracy가 높을 수 있다. 가장 빈번한 클래스만 예측하는 DummyClassifier와 비교하고 어떤 오류가 중요한지도 확인한다.

## 5. 헷갈리는 개념 비교

|구분|Precision|Recall|
|---|---|---|
|질문|양성 예측 중 실제 양성은?|실제 양성 중 찾아낸 것은?|
|중요 오류|FP|FN|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|정확도|전체 예측 중 맞힌 비율|
|Precision|양성 예측의 정확성|
|Recall|실제 양성 탐지 비율|
|F1|Precision과 Recall의 조화평균|
|클래스 불균형|클래스별 표본 수 차이가 큰 상태|
|일반화 성능|새 데이터에서의 예측 성능|

### 💻 주요 코드

|코드|의미|
|---|---|
|`value_counts(normalize=True)`|클래스 비율 확인|
|`accuracy_score(y, pred)`|정확도 계산|
|`classification_report()`|Precision·Recall·F1 출력|
