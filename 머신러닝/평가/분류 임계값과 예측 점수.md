# 분류 임계값과 예측 점수

## 1. 개념

분류 임계값은 모델의 확률이나 결정 점수를 최종 클래스 레이블로 바꾸는 기준이다.

> **핵심:** 임계값을 바꾸면 Precision과 Recall, FP와 FN의 균형이 달라진다.

------------------------------------------------------------------------

## 2. 출력 비교

```python
probability = model.predict_proba(x)[:, 1]
score = model.decision_function(x)
y_pred = np.where(probability >= 0.5, 1, 0)
```

- `predict_proba()` → 클래스 확률
- `decision_function()` → 분류 결정 점수
- `predict()` → 기본 임계값으로 만든 클래스 레이블
