# 군집 평가 지표

## 1. 개념

군집 평가 지표는 군집 내부의 샘플이 잘 모였는지, 서로 다른 군집이 잘 분리됐는지를 측정한다. 사용할 수 있는 지표는 실제 그룹 레이블의 존재 여부에 따라 달라진다.

> **핵심:** 실제 레이블이 있으면 외부 지표를, 없으면 데이터와 군집 결과만 사용하는 내부 지표를 사용한다.

---

## 2. 실제 레이블이 있을 때

- `Homogeneity`: 하나의 군집이 같은 실제 클래스의 샘플로 구성된 정도
- `Completeness`: 하나의 실제 클래스가 같은 군집으로 빠짐없이 모인 정도
- `V-measure`: Homogeneity와 Completeness의 조화평균

```python
from sklearn.metrics import (
    homogeneity_score,
    completeness_score,
    v_measure_score,
)

h = homogeneity_score(y_true, labels)
c = completeness_score(y_true, labels)
v = v_measure_score(y_true, labels)
```

군집 번호 자체는 의미가 없으므로 정확도처럼 번호를 직접 비교하는 지표보다 군집 구성 관계를 평가하는 지표를 사용한다.

---

## 3. 실제 레이블이 없을 때

실루엣 계수는 같은 군집 안에서의 평균 거리 $a$와 가장 가까운 다른 군집까지의 평균 거리 $b$를 사용한다.

$$s=\frac{b-a}{\max(a,b)}$$

```python
from sklearn.metrics import silhouette_score

score = silhouette_score(X, labels)
```

- 1에 가까움 → 군집 내부가 밀집되고 다른 군집과 잘 분리됨
- 0에 가까움 → 군집 경계가 겹침
- 음수 → 다른 군집에 더 가까운 샘플이 많을 수 있음

---

## 4. 헷갈리는 개념 비교

| 지표 | 실제 레이블 | 평가 관점 |
| --- | --- | --- |
| Homogeneity | 필요 | 군집 안의 클래스 순도 |
| Completeness | 필요 | 클래스가 한 군집에 모인 정도 |
| V-measure | 필요 | Homogeneity와 Completeness의 균형 |
| Silhouette | 불필요 | 군집 내부 응집도와 군집 간 분리도 |

---

## 5. 주의할 점

- 지표가 높아도 업무 목적에 의미 없는 군집일 수 있으므로 도메인 해석이 필요하다.
- Silhouette는 둥글고 밀집된 군집을 선호해 복잡한 모양이나 밀도 차이가 큰 군집을 불리하게 평가할 수 있다.
- 여러 알고리즘을 비교할 때는 같은 전처리 데이터와 같은 평가 조건을 사용한다.
