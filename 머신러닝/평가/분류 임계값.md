# 분류 임계값

## 1. 개념

분류 임계값은 모델의 확률이나 결정 점수를 최종 클래스 레이블로 바꾸는 기준이다. 임계값을 바꾸면 Precision과 Recall의 균형이 달라진다.

> **핵심:** FP와 FN 중 어떤 오류 비용이 큰지에 따라 임계값과 평가 지표를 선택한다.

---

## 2. 쉽게 이해하기

양성으로 판단하기 위한 합격선을 높이거나 낮추는 과정이다.

```text
확률·점수 → 임계값 비교 → 0 또는 1 레이블
```

---

## 3. 사용 방법

```python
probability = model.predict_proba(x_valid)[:, 1]
threshold = 0.5
y_pred = np.where(probability >= threshold, 1, 0)
```

- `predict_proba()` → 클래스별 확률을 반환한다.
- `decision_function()` → 분류 경계로부터의 점수를 반환한다.
- 결정 점수는 확률과 같지 않다.

---

## 4. 예제

```python
threshold = 0.95
pred = np.where(pred_proba > threshold, 1, 0)

precision_score(y_valid, pred), recall_score(y_valid, pred)
```

임계값을 높이면 양성 예측이 줄어 Precision은 올라가고 Recall은 내려가는 방향으로 움직인다. 낮추면 반대 방향으로 움직인다.

---

## 5. 헷갈리는 개념 비교

|구분|임계값 높임|임계값 낮춤|
|---|---|---|
|양성 예측|감소|증가|
|일반적 경향|Precision↑ Recall↓|Precision↓ Recall↑|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|임계값|점수를 클래스 레이블로 바꾸는 기준|
|Trade-off|한 지표 개선 시 다른 지표가 나빠질 수 있는 관계|
|결정 점수|분류 경계로부터의 상대적 점수|

### 💻 주요 코드

|코드|의미|
|---|---|
|`predict_proba()[:, 1]`|양성 클래스 확률|
|`decision_function()`|결정 점수|
|`np.where(score >= threshold, 1, 0)`|임계값으로 레이블 생성|
