# 혼동행렬과 분류 평가 지표

## 1. 개념

혼동행렬은 분류 모델의 실제 클래스와 예측 클래스를 비교해 TP, TN, FP, FN으로 정리한 표이다. 이 값을 이용해 Accuracy, Precision, Recall, F1 Score를 계산한다.

> **핵심:** 어떤 오류를 더 줄여야 하는지에 따라 사용할 분류 평가 지표가 달라진다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

| 구분 | 의미 |
| --- | --- |
| TP | 실제 환자를 환자로 예측 |
| TN | 실제 비환자를 비환자로 예측 |
| FP | 비환자를 환자로 잘못 예측 |
| FN | 환자를 비환자로 잘못 예측 |

> **쉽게 말하면:** 모델이 맞힌 경우뿐 아니라 어떤 방향으로 틀렸는지까지 나누어 보는 표이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
from sklearn.metrics import (
    confusion_matrix,
    accuracy_score,
    precision_score,
    recall_score,
    f1_score,
)

cm = confusion_matrix(y_valid, y_pred)
accuracy = accuracy_score(y_valid, y_pred)
precision = precision_score(y_valid, y_pred)
recall = recall_score(y_valid, y_pred)
f1 = f1_score(y_valid, y_pred)
```

- Accuracy → 전체 예측 중 맞힌 비율
- Precision → Positive 예측 중 실제 Positive 비율
- Recall → 실제 Positive 중 찾아낸 비율
- F1 → Precision과 Recall의 조화평균

> **핵심:** 먼저 무엇을 Positive 클래스로 볼지 정해야 지표를 올바르게 해석할 수 있다.

------------------------------------------------------------------------

## 4. 예제

$Accuracy=\frac{TP+TN}{TP+TN+FP+FN}$

$Precision=\frac{TP}{TP+FP}$

$Recall=\frac{TP}{TP+FN}$

$F1=\frac{2\times Precision\times Recall}{Precision+Recall}$

``` python
from sklearn.metrics import classification_report

print(classification_report(y_valid, y_pred))
```

### 코드 해석

- `confusion_matrix()` → 네 가지 예측 결과의 개수 확인
- `classification_report()` → 클래스별 Precision, Recall, F1 출력

> **결과 해석:** 전체 Accuracy가 높아도 중요한 클래스의 Recall이 낮을 수 있으므로 지표를 함께 확인한다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 지표 | 분모 | 줄이려는 오류 | 적합한 관점 |
| --- | --- | --- | --- |
| Accuracy | 전체 데이터 | 전체 오류 | 클래스가 비교적 균형일 때 |
| Precision | Positive 예측 | FP | Positive 오판 비용이 클 때 |
| Recall | 실제 Positive | FN | Positive 누락 비용이 클 때 |
| F1 | Precision·Recall | FP와 FN 균형 | 두 지표를 함께 볼 때 |

------------------------------------------------------------------------

## 6. 주의할 점

- 클래스 불균형이 크면 다수 클래스만 예측해도 Accuracy가 높을 수 있다.
- Precision과 Recall 중 무엇이 더 중요한지는 업무 목적에 따라 다르다.
- Dummy 모델과 비교해 실제 모델이 기준 성능을 넘는지 확인한다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `TP·TN` | 올바른 Positive·Negative 예측 |

| `F1 Score` | Precision과 Recall의 조화평균 |

| `classification_report()` | 주요 분류 지표 출력 |
