# MAE·MSE·RMSE

## 1. 개념

세 지표는 실제값과 예측값의 오차 크기를 서로 다른 방식으로 요약한다.

> **핵심:** MAE는 절댓값, MSE는 제곱, RMSE는 MSE의 제곱근을 사용한다.

------------------------------------------------------------------------

## 2. 비교

| 지표 | 계산 | 단위 |
| --- | --- | --- |
| MAE | 절대오차 평균 | Target과 같음 |
| MSE | 제곱오차 평균 | Target 단위의 제곱 |
| RMSE | MSE의 제곱근 | Target과 같음 |

```python
mae = mean_absolute_error(y_valid, pred)
mse = mean_squared_error(y_valid, pred)
rmse = np.sqrt(mse)
```

MSE와 RMSE는 큰 오차를 제곱해 더 크게 반영한다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### ⭐ 한 줄 정리

> **오차의 절댓값을 평균하면 MAE, 제곱을 평균하면 MSE, 그 제곱근은 RMSE이다.**
