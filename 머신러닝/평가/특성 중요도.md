# 특성 중요도

## 1. 개념

특성 중요도는 학습된 모델이 예측 과정에서 각 Feature를 얼마나 활용했는지 나타내는 값이다.

> **핵심:** 특성 중요도는 모델의 사용 패턴이며 Feature가 Target의 원인임을 증명하지 않는다.

---

## 2. 쉽게 이해하기

모델이 답을 낼 때 어떤 단서를 자주 또는 크게 사용했는지 보여 주는 점수이다.

```text
학습된 모델 → Feature별 활용도 계산 → 중요도 정렬·시각화
```

---

## 3. 사용 방법

- 모델 유형에 맞는 중요도 계산·시각화 방식을 사용한다.
- 중요도가 높은 Feature를 데이터 의미와 함께 해석한다.
- train·검증 성능과 함께 확인한다.
- 인과관계로 단정하지 않는다.

---

## 4. 예제

```python
from common.modeling import BoostModelType

best_model = modeling.get_best_model()["model"]
BoostModelType.show_plot_importance(best_model)
```

여러 부스팅 모델의 중요도 시각화 함수를 Enum으로 관리하면 모델 유형에 맞는 함수를 일관된 인터페이스로 선택할 수 있다.

---

## 5. 헷갈리는 개념 비교

|구분|특성 중요도|인과관계|
|---|---|---|
|의미|모델의 Feature 활용 정도|Feature가 결과를 발생시키는 관계|
|근거|학습된 모델|별도의 인과 분석 필요|
