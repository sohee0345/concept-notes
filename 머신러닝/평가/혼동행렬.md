# 혼동행렬

## 1. 개념

혼동행렬은 실제 클래스와 최종 예측 클래스를 비교하여 TP, FN, FP, TN의 개수를 정리한 표이다.

> **핵심:** Positive의 의미를 먼저 정하고 실제값과 예측값의 조합을 해석한다.

---

## 2. 쉽게 이해하기

양성과 음성을 맞힌 경우와 틀린 경우를 네 칸에 나누어 세는 표이다.

```text
실제 양성: TP 또는 FN
실제 음성: FP 또는 TN
```

---

## 3. 사용 방법

|실제 / 예측|Positive|Negative|
|---|---|---|
|Positive|TP|FN|
|Negative|FP|TN|

- TP → 실제 양성을 양성으로 예측
- FN → 실제 양성을 음성으로 예측
- FP → 실제 음성을 양성으로 예측
- TN → 실제 음성을 음성으로 예측

---

## 4. 예제

```python
cm = confusion_matrix(y_valid, y_pred)
normalized_cm = confusion_matrix(y_valid, y_pred, normalize="true")
```

`normalize="true"`는 실제 클래스별 행 합이 1이 되도록 정규화한다.

---

## 5. 헷갈리는 개념 비교

|구분|FP|FN|
|---|---|---|
|실제|음성|양성|
|예측|양성|음성|

---

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|TP·TN|올바른 양성·음성 예측|
|FP·FN|잘못된 양성·음성 예측|
|정규화 혼동행렬|실제 클래스별 비율로 표현한 표|

### 💻 주요 코드

|코드|의미|
|---|---|
|`confusion_matrix(y, pred)`|혼동행렬 계산|
|`normalize="true"`|실제 클래스별 정규화|

### ⭐ 한 줄 정리

> **혼동행렬은 실제와 예측 클래스의 조합을 네 가지 결과로 집계한다.**
