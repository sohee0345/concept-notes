# 혼동행렬

## 1. 개념

혼동행렬은 실제 클래스와 예측 클래스를 교차해 TP·TN·FP·FN의 개수를 정리한다.

> **핵심:** 양성 클래스를 먼저 정한 뒤 실제값과 예측값의 조합을 해석한다.

------------------------------------------------------------------------

## 2. 구성

| 실제 / 예측 | Positive | Negative |
| --- | --- | --- |
| Positive | TP | FN |
| Negative | FP | TN |

```python
cm = confusion_matrix(y_true, y_pred)
cm_ratio = confusion_matrix(y_true, y_pred, normalize="true")
```

`normalize="true"`는 실제 클래스별 비율로 정규화한다.
