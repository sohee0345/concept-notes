# Boosting과 Gradient Boosting

## 1. 개념

Boosting은 여러 개의 약한 학습기를 순차적으로 추가하면서 앞선 모델이 부족했던 부분을 보완하는 앙상블 방법이다. 각 모델을 독립적으로 학습하는 것이 아니라, 이전 모델의 예측에서 발생한 오차를 다음 모델이 줄이는 방식으로 학습을 이어 간다.

Gradient Boosting은 손실 함수가 줄어드는 방향, 즉 음의 그래디언트를 다음 모델이 학습하도록 구성하는 Boosting 방법이다.

> **핵심:** Gradient Boosting은 이전 모델의 오차를 보완하는 약한 학습기를 순차적으로 더해 강한 모델을 만든다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

첫 번째 모델이 만든 예측이 완벽하지 않다면, 다음 모델은 그 예측에서 부족했던 부분을 집중적으로 학습한다. 이후 각 모델의 결과를 학습률만큼 반영하면서 전체 예측을 조금씩 개선한다.

``` text
첫 번째 약한 모델 학습
  ↓
현재 예측의 오차 계산
  ↓
오차를 줄이는 다음 모델 학습
  ↓
학습률만큼 결과 추가
  ↓
정해진 횟수만큼 반복
```

> **쉽게 말하면:** 한 모델이 만든 실수를 다음 모델이 차례로 보완하면서 전체 모델의 예측 성능을 높이는 방식이다.

------------------------------------------------------------------------

## 3. 사용 방법

`GradientBoostingClassifier`로 분류 모델을 만들고 학습 데이터에 맞춰 학습할 수 있다.

``` python
from sklearn.ensemble import GradientBoostingClassifier

model = GradientBoostingClassifier(
    n_estimators=100,
    learning_rate=0.1,
    max_depth=2,
    random_state=42,
)
model.fit(X_train, y_train)
```

- `n_estimators` → 순차적으로 추가할 약한 학습기의 개수
- `learning_rate` → 각 학습기의 결과를 전체 예측에 반영하는 정도
- `max_depth` → 개별 트리의 최대 깊이
- `random_state` → 실행할 때 같은 결과를 재현하기 위한 난수 기준값
- `fit(X_train, y_train)` → 학습 데이터와 정답을 이용해 모델을 학습

> **핵심:** `learning_rate`와 `n_estimators`는 서로 함께 조정해야 하며, 개별 트리의 깊이도 과적합에 영향을 준다.

------------------------------------------------------------------------

## 4. 예제

``` python
from sklearn.ensemble import GradientBoostingClassifier

model = GradientBoostingClassifier(
    n_estimators=100,
    learning_rate=0.1,
    max_depth=2,
    random_state=42,
)
model.fit(X_train, y_train)
```

### 코드 해석

- `n_estimators=100` → 약한 학습기를 최대 100개까지 순차적으로 추가한다.
- `learning_rate=0.1` → 각 학습기의 기여를 0.1만큼 반영한다.
- `max_depth=2` → 각 트리를 비교적 얕게 만들어 개별 학습기의 복잡도를 제한한다.
- `model.fit(...)` → 이전 예측의 오차를 줄이는 방향으로 학습기를 차례로 추가한다.

> **결과 해석:** 학습이 끝난 `model`은 여러 약한 학습기의 결과를 결합하여 분류 예측에 사용할 수 있다.

## 5. 헷갈리는 개념 비교

| 구분 | Boosting | Gradient Boosting |
| --- | --- | --- |
| 의미 | 앞선 모델의 부족한 부분을 다음 모델이 보완하는 앙상블 방법 | 손실 함수의 음의 그래디언트를 다음 모델이 학습하는 Boosting 방법 |
| 특징 | 약한 학습기를 순차적으로 결합 | 손실이 줄어드는 방향으로 모델을 순차적으로 추가 |
| 관계 | 여러 순차적 앙상블 방법을 포함하는 상위 개념 | Boosting을 구현하는 구체적인 방법 가운데 하나 |

------------------------------------------------------------------------

## 6. 주의할 점

- `learning_rate`를 낮추면 각 트리의 기여가 작아지므로 일반적으로 더 많은 `n_estimators`가 필요하다.
- 트리를 깊게 만들거나 학습기 수를 지나치게 늘리면 표현력은 높아지지만 과적합 위험과 계산량도 증가한다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `Boosting` | 앞선 모델의 부족한 부분을 다음 약한 학습기가 순차적으로 보완하는 앙상블 방법 |
| `Gradient Boosting` | 손실 함수의 음의 그래디언트를 학습하여 예측을 개선하는 Boosting 방법 |
| `약한 학습기` | 단독으로는 성능이 제한적이지만 여러 개를 결합해 강한 모델을 구성하는 학습기 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `GradientBoostingClassifier(...)` | Gradient Boosting 분류 모델 생성 |
| `model.fit(X_train, y_train)` | 학습 데이터로 모델 학습 |
| `learning_rate` | 각 학습기의 기여도 조절 |
| `n_estimators` | 추가할 학습기의 개수 조절 |
