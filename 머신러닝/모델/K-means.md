# K-means

## 1. 개념

K-means는 정답 레이블 없이 데이터를 사용자가 정한 $K$개의 군집으로 나누는 비지도학습 알고리즘이다. 각 샘플을 가장 가까운 중심에 배정하고, 군집에 속한 샘플의 평균으로 중심을 갱신하는 과정을 반복한다.

> **핵심:** K-means는 군집 내부의 제곱거리 합이 작아지도록 중심과 샘플 할당을 반복해서 갱신한다.

---

## 2. 쉽게 이해하기

여러 사람을 가까운 모임 장소로 배정한 뒤, 각 모임 구성원의 평균 위치로 장소를 옮기는 과정을 반복한다고 생각할 수 있다.

```text
초기 중심 K개 선택
  → 가까운 중심에 샘플 배정
  → 군집별 평균으로 중심 이동
  → 결과가 안정될 때까지 반복
```

> **쉽게 말하면:** 사람을 가까운 대표점에 묶고 대표점을 다시 가운데로 옮기는 일을 반복한다.

---

## 3. 사용 방법

```python
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

X_scaled = StandardScaler().fit_transform(X)

kmeans = KMeans(
    n_clusters=3,
    init="k-means++",
    random_state=42,
)
labels = kmeans.fit_predict(X_scaled)
```

- `n_clusters` → 군집 수 $K$
- `init="k-means++"` → 서로 떨어진 초기 중심을 선택하는 방식
- `labels_` → 학습 샘플의 군집 번호
- `cluster_centers_` → 최종 군집 중심

> **핵심:** 거리 계산 전에 특성 스케일을 맞추고 여러 $K$의 결과를 평가한다.

---

## 4. 주의할 점

- 평균을 사용하므로 이상치에 민감하다.
- 거리 기반이므로 단위가 큰 특성이 결과를 지배할 수 있다.
- 둥글고 크기와 밀도가 비슷한 군집에 적합하며 길쭉하거나 복잡한 군집에서는 실패할 수 있다.
- 군집 수를 미리 정해야 한다.
- 군집 번호는 단순 식별자이므로 실제 클래스 번호와 직접 비교할 수 없다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `Centroid` | 군집 샘플의 평균으로 계산한 중심 |
| `K` | 사용자가 지정하는 군집 수 |
| `k-means++` | 초기 중심 선택을 개선하는 방법 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `KMeans()` | K-means 모델 생성 |
| `fit_predict()` | 모델 학습과 군집 번호 반환 |
| `cluster_centers_` | 학습된 군집 중심 확인 |
