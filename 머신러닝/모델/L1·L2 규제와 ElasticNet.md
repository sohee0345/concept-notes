# L1·L2 규제와 ElasticNet

## 1. 개념

규제는 손실함수에 가중치 크기에 대한 항을 더해 모델 복잡도를 조절한다.

> **핵심:** L1은 일부 계수를 0으로 만들 수 있고 L2는 큰 계수를 부드럽게 줄인다.

------------------------------------------------------------------------

## 2. 비교

| 규제 | 패널티 | 모델 |
| --- | --- | --- |
| L1 | $\alpha\sum|w_j|$ | Lasso |
| L2 | $\alpha\sum w_j^2$ | Ridge |
| 혼합 | L1 + L2 | ElasticNet |

`alpha`는 규제 강도이고 ElasticNet의 `l1_ratio`는 L1과 L2의 혼합 비율이다.

------------------------------------------------------------------------

## 3. 주의할 점

- alpha를 높인다고 점수가 반드시 높아지지 않는다.
- 너무 강한 규제는 과소적합을 만들 수 있다.
- Lasso의 작은 alpha에서는 수렴을 위해 반복 횟수를 늘려야 할 수 있다.

------------------------------------------------------------------------
