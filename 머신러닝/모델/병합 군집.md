# 병합 군집

## 1. 개념

병합 군집은 각 샘플을 하나의 군집으로 시작해 가까운 군집을 차례로 합치며 지정한 군집 수에 도달하는 계층적 군집 방법이다.

> **핵심:** 작은 군집에서 시작해 유사한 군집을 단계적으로 병합한다.

---

## 2. 쉽게 이해하기

모든 샘플이 각자 그룹에서 시작해 가장 가까운 그룹끼리 계속 합치는 방식이다.

```text
샘플별 군집 → 가까운 군집 병합 → 반복 → 목표 군집 수
```

---

## 3. 사용 방법

```python
model = AgglomerativeClustering(n_clusters=10)
labels = model.fit_predict(X_scaled)
```

- `n_clusters` → 최종 군집 수
- 거리와 병합 기준에 따라 계층 구조가 달라진다.
- 거리 기반이므로 스케일을 고려한다.

---

## 4. 예제

```python
from sklearn.cluster import AgglomerativeClustering

cluster = AgglomerativeClustering(n_clusters=10).fit(x)
print_score(x, y, cluster.labels_)
```

손글씨 데이터에서 외부 지표가 K-means보다 높더라도 실루엣 점수는 비슷할 수 있다. 서로 다른 지표는 군집의 다른 성질을 평가한다.

---

## 5. 헷갈리는 개념 비교

|구분|병합 군집|K-means|
|---|---|---|
|과정|군집을 차례로 합침|중심을 반복 갱신|
|구조|계층적|중심 기반|
