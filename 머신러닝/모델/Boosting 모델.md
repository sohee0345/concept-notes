# Boosting 모델

## 1. 개념

Boosting은 약한 학습기를 순차적으로 추가하며 이전 모델이 잘 맞히지 못한 부분을 보완하는 앙상블 방식이다.

> **핵심:** 다음 모델이 이전 예측의 부족한 부분을 순차적으로 보완한다.

---

## 2. 쉽게 이해하기

첫 모델의 오답을 다음 모델이 공부하고 그 오답을 다시 다음 모델이 보완하는 과정이다.

```text
약한 모델 1 → 오차 확인 → 모델 2 보완 → 모델 3 보완 → 결합
```

---

## 3. 사용 방법

- Gradient Boosting → 현재 손실을 줄이는 방향으로 다음 트리를 학습한다.
- `n_estimators` → 추가할 학습기 수이다.
- `learning_rate` → 각 학습기의 기여 크기이다.
- 트리 깊이 → 개별 학습기의 복잡도를 조절한다.

---

## 4. 예제

- XGBoost → 규제와 계산 효율을 강화한 구현
- LightGBM → 손실 감소가 큰 리프를 우선 확장하는 방식
- CatBoost → 범주형 Feature와 순서 기반 통계에 강점

성능과 속도는 데이터와 설정에 따라 달라지므로 교차검증으로 비교한다.

---

## 5. 헷갈리는 개념 비교

|구분|Bagging|Boosting|
|---|---|---|
|학습|주로 병렬|순차적|
|목적|모델 다양성으로 안정화|이전 오류를 보완|
