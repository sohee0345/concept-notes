# 선형모델 규제

## 1. 개념

규제(Regularization)는 손실함수에 가중치 크기에 대한 제약을 추가해 모델의 복잡도를 조절하는 방법이다. 과적합을 줄이고 새로운 데이터에 대한 일반화 성능을 높이는 데 사용한다.

> **핵심:** 규제는 가중치를 제한하며, 강도는 과적합과 과소적합 사이의 균형에 맞춰야 한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
규제가 너무 약함 → Train을 지나치게 외울 수 있음
적절한 규제       → 새로운 데이터에도 잘 작동
규제가 너무 강함 → 모델이 너무 단순해질 수 있음
```

> **쉽게 말하면:** 모델이 자유롭게 외우지 못하도록 규칙을 주되, 아무것도 배우지 못할 만큼 강하게 제한하지 않는 것이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
from sklearn.linear_model import Ridge, Lasso, ElasticNet

ridge = Ridge(alpha=1).fit(X_tr, y_tr)
lasso = Lasso(alpha=0.01, max_iter=100000).fit(X_tr, y_tr)
elastic = ElasticNet(
    alpha=0.01,
    l1_ratio=0.8,
).fit(X_tr, y_tr)
```

- `Ridge` → L2 규제
- `Lasso` → L1 규제
- `ElasticNet` → L1과 L2 혼합
- `alpha` → 규제 강도
- `l1_ratio` → ElasticNet에서 L1과 L2의 혼합 비율

> **핵심:** `alpha`가 커진다고 Test 점수가 반드시 높아지는 것은 아니다.

------------------------------------------------------------------------

## 4. 예제

| 모델 | Train $R^2$ | Test $R^2$ | 사용 Feature |
| --- | ---: | ---: | ---: |
| LinearRegression | 0.9521 | 0.6075 | 104 |
| Ridge, `alpha=1` | 0.8858 | 0.7528 | 104 |
| Lasso, `alpha=0.01` | 0.8962 | 0.7657 | 33 |

### 결과 해석

- 기본 선형회귀는 Train과 Test 점수 차이가 커 과적합 상태로 해석
- Ridge는 계수 크기를 줄여 Test 성능을 개선
- Lasso는 일부 계수를 0으로 만들어 33개 Feature만 사용

> **결과 해석:** 규제 모델은 Train 점수를 일부 낮추더라도 Test 성능과 두 점수의 차이를 함께 확인해야 한다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | Ridge | Lasso | ElasticNet |
| --- | --- | --- | --- |
| 규제 | L2 | L1 | L1 + L2 |
| 계수 0 가능성 | 일반적으로 0까지 만들지 않음 | 일부 계수를 0으로 만들 수 있음 | 혼합 비율에 따라 달라짐 |
| 주요 파라미터 | `alpha` | `alpha`, `max_iter` | `alpha`, `l1_ratio` |

------------------------------------------------------------------------

## 6. 주의할 점

- 규제가 너무 약하면 과적합이 남을 수 있다.
- 규제가 너무 강하면 모델이 단순해져 과소적합될 수 있다.
- Lasso의 `alpha`를 낮출 때 수렴을 위해 `max_iter` 증가가 필요할 수 있다.
- 하이퍼파라미터 튜닝은 점수를 무조건 올리는 작업이 아니다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `규제` | 가중치에 제약을 주어 모델 복잡도 조절 |
| `L1` | 일부 계수를 0으로 만들 수 있는 규제 |
| `L2` | 큰 계수를 줄이는 규제 |
| `alpha` | 규제 강도를 조절하는 하이퍼파라미터 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `Ridge(alpha=...)` | L2 규제 모델 생성 |
| `Lasso(alpha=...)` | L1 규제 모델 생성 |
| `ElasticNet(...)` | L1·L2 혼합 규제 모델 생성 |

### ⭐ 한 줄 정리

> **규제는 가중치 크기를 제한해 복잡도를 조절하며 Ridge는 L2, Lasso는 L1, ElasticNet은 두 규제를 함께 사용한다.**
