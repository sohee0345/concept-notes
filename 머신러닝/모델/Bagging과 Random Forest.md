# Bagging과 Random Forest

## 1. 개념

Bagging은 여러 부트스트랩 표본으로 모델을 병렬 학습해 결과를 결합한다. Random Forest는 Bagging을 결정트리에 적용하고 분할마다 일부 Feature만 후보로 사용한다.

> **핵심:** 여러 트리의 데이터와 Feature 선택을 다양하게 만들어 예측의 안정성을 높인다.

---

## 2. 쉽게 이해하기

서로 다른 문제지를 받은 여러 결정트리가 독립적으로 답한 뒤 다수결이나 평균으로 최종 답을 정한다.

```text
원본 train → 여러 bootstrap 표본 → 모델 병렬 학습 → 투표·평균
```

---

## 3. 사용 방법

- 부트스트랩 → 원본 train에서 복원 추출한 표본이다.
- 분류 → 다수결 또는 클래스 확률 평균을 사용한다.
- 회귀 → 예측값을 평균낸다.
- Random Forest → 일부 Feature만 분할 후보로 사용해 트리 상관을 낮춘다.

---

## 4. 예제

트리 깊이와 리프 조건을 제한해 테스트 성능을 유지하면서 train 성능과 복잡도를 낮출 수 있다.

---

## 5. 헷갈리는 개념 비교

|구분|Bagging|Random Forest|
|---|---|---|
|범위|일반 병렬 앙상블 방식|결정트리 기반 Bagging 모델|
|추가 무작위성|데이터 표본|데이터와 Feature 후보|

---

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|Bagging|부트스트랩 모델을 병렬 학습해 결합|
|Bootstrap|복원 추출한 훈련 표본|
|Random Forest|무작위 Feature를 사용하는 트리 Bagging|

### ⭐ 한 줄 정리

> **Random Forest는 데이터와 Feature 선택을 다양화한 여러 결정트리의 예측을 결합한다.**
