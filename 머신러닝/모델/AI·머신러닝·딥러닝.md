# AI·머신러닝·딥러닝

## 1. 개념

인공지능은 지능적인 작업을 수행하는 기술의 넓은 범주이고, 머신러닝은 데이터로부터 규칙을 학습하는 인공지능 방법이다. 딥러닝은 여러 층의 인공신경망을 사용하는 머신러닝 방법이다.

```text
AI
└─ Machine Learning
   └─ Deep Learning
```

> **핵심:** 딥러닝은 머신러닝의 일부이고 머신러닝은 인공지능의 일부이다.
