# 결정트리

## 1. 개념

결정트리는 특성에 대한 조건으로 데이터를 반복 분할하고, 리프 노드에서 클래스나 값을 예측하는 모델이다. 해석하기 쉽고 비선형 관계를 표현하지만 트리가 지나치게 복잡해지면 과적합하기 쉽다.

> **핵심:** 결정트리는 불순도를 줄이는 조건으로 데이터를 반복 분할하며, 트리의 깊이와 리프 조건으로 복잡도를 제어한다.

---

## 2. 동작 방식

```text
전체 데이터
  → 불순도를 가장 많이 줄이는 조건 선택
  → 자식 노드로 분할
  → 정지 조건까지 반복
  → 리프 노드에서 예측
```

분류에서는 Gini 불순도나 Entropy 등을 기준으로 분할 품질을 평가한다.

---

## 3. 사용 방법

```python
from sklearn.tree import DecisionTreeClassifier

tree = DecisionTreeClassifier(
    max_depth=5,
    min_samples_leaf=3,
    random_state=42,
)
tree.fit(X_train, y_train)
```

- `max_depth`: 최대 깊이
- `min_samples_split`: 분할에 필요한 최소 샘플 수
- `min_samples_leaf`: 리프에 필요한 최소 샘플 수
- `max_leaf_nodes`: 최대 리프 수

훈련 점수가 1이라는 사실만으로 과적합이라고 단정하지 않고 검증 성능과의 차이를 확인한다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `분할` | 특성 조건을 기준으로 데이터를 자식 노드로 나누는 과정 |
| `불순도` | 한 노드에 서로 다른 클래스가 섞인 정도 |
| `리프 노드` | 더 이상 분할하지 않고 최종 예측을 만드는 노드 |
