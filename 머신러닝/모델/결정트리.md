# 결정트리

## 1. 개념

결정트리는 Feature에 대한 질문을 반복해 데이터를 나누고 리프 노드에서 예측하는 모델이다. 구조를 해석하기 쉽지만 트리가 깊으면 과적합될 수 있다.

> **핵심:** 트리 복잡도는 깊이와 분할·리프 조건으로 조절하고 검증 성능으로 선택한다.

---

## 2. 쉽게 이해하기

예·아니오 질문을 따라 내려가 최종 답이 있는 잎에 도착하는 의사결정 흐름이다.

```text
루트 질문 → 가지 분할 → 추가 질문 → 리프 예측
```

---

## 3. 사용 방법

- `max_depth` → 최대 깊이
- `min_samples_split` → 분할에 필요한 최소 샘플 수
- `min_samples_leaf` → 리프의 최소 샘플 수
- `max_leaf_nodes` → 최대 리프 수
- `criterion` → 분할 품질 기준

---

## 4. 예제

먼저 별도의 복잡도 제한 없이 결정트리를 학습하고 훈련 데이터와 테스트 데이터의 정확도를 비교한다.

```python
from sklearn.tree import DecisionTreeClassifier

tree = DecisionTreeClassifier(random_state=0)
tree.fit(X_tr, y_tr)

print(f"훈련용 평가지표: {tree.score(X_tr, y_tr)}")
print(f"테스트용 평가지표: {tree.score(X_te, y_te)}")
```

실행 결과:

```text
훈련용 평가지표: 1.0
테스트용 평가지표: 0.9370629370629371
```

훈련 정확도가 `1.0`이라는 사실만으로 과적합을 단정할 수는 없다. 다만 훈련 성능과 테스트 성능에 차이가 있으므로, 다음과 같이 트리의 깊이와 리프 조건 등을 제한해 복잡도를 조절할 수 있다.

```python
hp = {
    "random_state": 42,
    "max_depth": 4,
    "min_samples_split": 2,
    "criterion": "entropy",
    "max_leaf_nodes": 10,
    "min_samples_leaf": 20,
}

tree = DecisionTreeClassifier(**hp)
tree.fit(X_tr, y_tr)

print(f"훈련용 평가지표: {tree.score(X_tr, y_tr)}")
print(f"테스트용 평가지표: {tree.score(X_te, y_te)}")
```

실행 결과:

```text
훈련용 평가지표: 0.9460093896713615
테스트용 평가지표: 0.916083916083916
```

복잡도를 제한하자 훈련 정확도는 낮아졌지만 이 실습에서는 테스트 정확도도 함께 낮아졌다. 따라서 트리를 단순하게 만들었다고 항상 성능이 좋아지는 것은 아니며, 여러 설정을 검증 데이터나 교차검증으로 비교해 적절한 복잡도를 선택해야 한다.
