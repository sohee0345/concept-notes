# 하이퍼파라미터와 모델 파라미터

## 1. 개념

하이퍼파라미터는 모델을 학습하기 전에 사람이 설정하거나 탐색하는 값이고, 모델 파라미터는 학습 과정에서 데이터로부터 결정되는 값이다.

> **핵심:** 학습 전에 정하는 값과 학습하면서 얻는 값을 구분한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
사람이 하이퍼파라미터 설정
  ↓
모델이 데이터로 학습
  ↓
모델 파라미터 결정
```

> **쉽게 말하면:** 하이퍼파라미터는 학습 방법을 정하는 설정이고, 모델 파라미터는 그 설정으로 학습한 결과이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
from sklearn.linear_model import LogisticRegression

model = LogisticRegression(
    random_state=42,
    max_iter=100,
)

model.fit(x_train, y_train)
```

- `random_state`, `max_iter` → 모델을 만들 때 설정하는 하이퍼파라미터
- `fit()` → Train 데이터로 학습해 모델 파라미터를 결정

> **핵심:** 하이퍼파라미터는 모델 생성·학습 전에 정하고 모델 파라미터는 `fit()` 과정에서 얻는다.

------------------------------------------------------------------------

## 4. 예제

``` text
LogisticRegression(max_iter=100) 생성
  ↓
x_train, y_train으로 fit
  ↓
학습된 모델 파라미터로 x_test 예측
```

실습에서는 기본 반복 횟수 한도에 도달해 `ConvergenceWarning`이 발생했고, 출력 메시지는 반복 횟수 조정 또는 데이터 스케일링 검토를 안내했다.

> **결과 해석:** 학습 경고를 확인하고 관련 하이퍼파라미터나 전처리 상태를 점검해야 한다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 하이퍼파라미터 | 모델 파라미터 |
| --- | --- | --- |
| 결정 시점 | 학습 전 | 학습 중 |
| 결정 주체 | 사람이 설정하거나 탐색 | 데이터로부터 결정 |
| 예시 | `max_iter`, `random_state` | 학습으로 얻은 계수 |
