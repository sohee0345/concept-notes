# 병합 군집과 DBSCAN

## 1. 개념

병합 군집과 DBSCAN은 중심과의 거리만으로 군집을 나누는 K-means의 한계를 보완할 수 있는 군집 알고리즘이다. 병합 군집은 가까운 군집을 계층적으로 합치고, DBSCAN은 밀도가 높은 영역을 연결한다.

> **핵심:** 병합 군집은 계층 관계를, DBSCAN은 밀도와 잡음을 중심으로 군집을 찾는다.

---

## 2. 병합 군집

병합 군집(Agglomerative Clustering)은 각 샘플을 하나의 군집으로 시작해 가장 가까운 군집을 반복해서 합친다. 군집이 합쳐지는 계층 구조는 덴드로그램으로 살펴볼 수 있다.

```python
from sklearn.cluster import AgglomerativeClustering

model = AgglomerativeClustering(n_clusters=3)
labels = model.fit_predict(X)
```

- `n_clusters` → 최종적으로 남길 군집 수
- `linkage` → 군집 사이 거리를 계산하는 방법

---

## 3. DBSCAN

DBSCAN은 한 샘플의 일정 반경 안에 이웃이 충분히 많으면 밀도가 높은 영역으로 판단한다. 핵심 샘플에서 연결되는 이웃을 확장해 군집을 만들며, 연결되지 않은 샘플은 잡음으로 구분한다.

```python
from sklearn.cluster import DBSCAN

model = DBSCAN(eps=0.5, min_samples=5)
labels = model.fit_predict(X_scaled)
```

- `eps` → 이웃으로 인정하는 최대 거리
- `min_samples` → 핵심 샘플이 되기 위한 반경 내 최소 샘플 수
- `labels_ == -1` → 잡음으로 판정된 샘플

`eps`가 커지면 군집들이 연결되어 합쳐지기 쉽다. `min_samples`가 커지면 더 높은 밀도를 요구하므로 핵심 샘플은 줄고 잡음은 늘기 쉽다.

---

## 4. 헷갈리는 개념 비교

| 구분 | 병합 군집 | DBSCAN |
| --- | --- | --- |
| 기본 원리 | 가까운 군집을 반복해서 병합 | 밀도가 높은 이웃을 연결 |
| 군집 수 | 보통 미리 지정 | 미리 지정하지 않음 |
| 잡음 구분 | 기본적으로 모든 샘플을 군집에 배정 | 잡음을 `-1`로 구분 가능 |
| 주요 설정 | `n_clusters`, `linkage` | `eps`, `min_samples` |

---

## 5. 주의할 점

- 두 방법 모두 거리의 영향을 받으므로 특성 스케일을 확인한다.
- DBSCAN은 밀도가 크게 다른 여러 군집을 하나의 `eps`로 처리하기 어려울 수 있다.
- DBSCAN 결과에 군집이 하나뿐이거나 유효 군집이 없으면 실루엣 점수를 계산하거나 해석하기 어렵다.
- 병합 군집은 일반적인 scikit-learn 사용 방식에서 새 샘플의 군집을 예측하는 `predict()`를 제공하지 않는다.
