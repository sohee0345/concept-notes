# 선형회귀

## 1. 개념

선형회귀는 여러 Feature의 선형 결합으로 연속적인 Target을 예측하는 회귀 모델이다.

> **핵심:** 각 Feature에 학습된 계수를 곱하고 절편을 더해 연속값을 예측한다.

---

## 2. 쉽게 이해하기

여러 입력이 결과에 미치는 영향을 직선 형태의 식으로 조합하여 값을 예측한다.

$$
\hat{y}=\beta_0+\beta_1x_1+\cdots+\beta_px_p
$$

---

## 3. 사용 방법

```python
model = LinearRegression()
model.fit(x_train, y_train)
pred = model.predict(x_valid)
```

- `fit()` → train 데이터로 절편과 계수를 학습한다.
- `predict()` → validation Feature의 연속값을 예측한다.
- 예측 배열과 실제 Target의 shape이 일치해야 한다.

---

## 4. 예제

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(x_train, y_train)
pred = model.predict(x_valid)
```

Diabetes 데이터에서 10개 Feature를 사용해 연속적인 질병 진행 수치를 예측하고 validation 실제값과 비교한다.
