# 선형회귀

## 1. 개념

선형회귀는 하나 이상의 Feature와 연속형 Target 사이의 선형 관계를 학습해 값을 예측하는 모델이다.

> **핵심:** 연속형 Target을 직선 또는 선형식으로 예측한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
Feature 입력
  ↓ 선형 관계 학습
예측식
  ↓
연속형 Target 예측값
```

> **쉽게 말하면:** 여러 입력값이 결과에 어떻게 더해지는지 학습해 숫자 결과를 예측한다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(x_train, y_train)
pred = model.predict(x_valid)
```

- `LinearRegression()` → 모델 생성
- `fit()` → Train Feature와 Target으로 학습
- `predict()` → 새로운 Feature의 Target 예측

> **핵심:** 학습에는 Train을 사용하고 성능 평가는 학습에 쓰지 않은 데이터로 수행한다.

------------------------------------------------------------------------

## 4. 예제

``` python
from sklearn.datasets import load_diabetes
from sklearn.model_selection import train_test_split

diabetes = load_diabetes()

x_train, x_valid, y_train, y_valid = train_test_split(
    diabetes.data,
    diabetes.target,
    random_state=42,
)
```

실행 Shape:

``` text
x_train → (331, 10)
x_valid → (111, 10)
y_train → (331,)
y_valid → (111,)
pred    → (111,)
```

### 코드 해석

- Feature 10개를 사용하므로 다중선형회귀에 해당
- Validation Feature 111건에 대해 예측값 111개 생성

> **결과 해석:** 예측값과 실제 Validation Target의 Shape이 같아야 항목별 오차를 평가할 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 단순선형회귀 | 다중선형회귀 |
| --- | --- | --- |
| Feature 수 | 1개 | 2개 이상 |
| Target | 연속형 | 연속형 |
| 수업 예시 | 개념 언급 | Diabetes의 10개 Feature |

------------------------------------------------------------------------

## 6. 주의할 점

- Target이 범주형이면 회귀가 아니라 분류 문제를 고려한다.
- 학습과 평가 데이터를 분리한다.
- 예측값과 실제값의 Shape을 확인한다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `선형회귀` | 연속형 Target의 선형 관계를 학습하는 모델 |
| `단순선형회귀` | Feature 하나를 사용 |
| `다중선형회귀` | 여러 Feature를 사용 |
| `예측값` | 학습된 모델이 출력한 Target 추정값 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `LinearRegression()` | 선형회귀 모델 생성 |
| `model.fit(X, y)` | 모델 학습 |
| `model.predict(X)` | 예측값 생성 |

### ⭐ 한 줄 정리

> **선형회귀는 Feature와 연속형 Target의 선형 관계를 학습해 숫자 값을 예측한다.**
