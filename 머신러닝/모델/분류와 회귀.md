# 분류와 회귀

## 1. 개념

분류는 정해진 클래스 중 하나를 예측하고 회귀는 연속적인 수치를 예측한다. 문제 유형은 Target의 저장 자료형보다 실제 의미로 판단한다.

> **핵심:** 숫자 0과 1도 상태 코드라면 회귀가 아니라 분류 Target이다.

------------------------------------------------------------------------

## 2. 비교

| 문제 | Target | 예시 |
| --- | --- | --- |
| 회귀 | 연속적인 수치 | 집값, 온도 |
| 이진 분류 | 클래스 2개 | 생존/사망 |
| 다중 분류 | 클래스 3개 이상 | 꽃 품종 |

------------------------------------------------------------------------

## 🟦 핵심 정리

### ⭐ 한 줄 정리

> **Target의 의미가 범주이면 분류, 연속적인 양이면 회귀 문제로 정의한다.**
