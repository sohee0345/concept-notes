# 로지스틱 회귀

## 1. 개념

로지스틱 회귀는 입력 특성의 선형 결합에 Sigmoid 또는 Softmax를 적용해 클래스 확률을 예측하는 분류 모델이다. 이름에 회귀가 있지만 분류 문제에 사용한다.

> **핵심:** 로지스틱 회귀는 Feature로 클래스 확률을 학습하고 예측 클래스를 반환한다.

---

## 2. 쉽게 이해하기

각 클래스일 가능성을 계산한 뒤 더 적절한 클래스를 선택하는 모델이다.

```text
Feature → 확률 계산 → 클래스 결정
```

---

## 3. 사용 방법

```python
model = LogisticRegression(C=1.0, max_iter=1000, random_state=42)
model.fit(x_train, y_train)
y_pred = model.predict(x_test)
```

- `fit()` → train 데이터로 모델을 학습한다.
- `predict()` → Feature의 클래스를 예측한다.
- `C` → 규제 강도의 역수이며 작을수록 규제가 강하다.
- `predict_proba()` → 클래스별 확률을 반환한다.
- 수렴 경고가 있으면 학습 완료 여부를 확인한다.

---

## 4. 예제

```python
accuracy = accuracy_score(y_test, y_pred)
```

test Target과 예측 결과를 비교해 정확도를 계산한다.
