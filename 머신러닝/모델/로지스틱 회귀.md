# 로지스틱 회귀

## 1. 개념

로지스틱 회귀는 입력 Feature로 클래스 확률을 계산하여 분류하는 모델이다.

> **핵심:** 이름에 회귀가 들어가지만 클래스 예측에 사용하는 분류 모델이다.

------------------------------------------------------------------------

## 2. 사용 방법

```python
from sklearn.linear_model import LogisticRegression

model = LogisticRegression(random_state=42)
model.fit(x_train, y_train)
y_pred = model.predict(x_test)
```

------------------------------------------------------------------------

## 3. 평가

```python
from sklearn.metrics import accuracy_score

accuracy = accuracy_score(y_test, y_pred)
```

정확도는 전체 예측 중 맞힌 비율이다.

------------------------------------------------------------------------

## 4. 주의할 점

- 최대 반복 횟수에 도달했다는 수렴 경고가 있으면 학습이 충분히 끝났는지 확인한다.
- 클래스 불균형이 있으면 정확도만으로 판단하기 어렵다.
- test 데이터는 모델 선택이 끝난 뒤 최종 평가에 사용한다.
