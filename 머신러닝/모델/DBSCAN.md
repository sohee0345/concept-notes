# DBSCAN

## 1. 개념

DBSCAN은 일정 반경 안에 이웃이 충분한 영역을 연결해 군집을 만들고 어느 군집에도 속하지 않는 샘플을 잡음으로 구분하는 밀도 기반 알고리즘이다.

> **핵심:** 군집 수를 미리 정하지 않고 밀도와 연결성을 이용해 복잡한 모양과 잡음을 찾는다.

---

## 2. 쉽게 이해하기

사람이 붐비는 영역을 이어 하나의 무리로 만들고 주변에 홀로 떨어진 사람은 잡음으로 보는 방식이다.

```text
반경 내 이웃 계산 → 핵심 샘플 탐색 → 밀도 영역 연결 → 잡음 분리
```

---

## 3. 사용 방법

- `eps` → 이웃으로 인정하는 최대 거리
- `min_samples` → 핵심 샘플의 최소 이웃 수
- 레이블 `-1` → 잡음
- `eps` 증가 → 군집이 연결되어 합쳐지기 쉬움
- `min_samples` 증가 → 핵심 샘플 감소와 잡음 증가 가능

---

## 4. 예제

```python
from sklearn.cluster import DBSCAN

dbscan = DBSCAN(min_samples=3, eps=0.05, n_jobs=-1).fit(x)
print_score(x, y, dbscan.labels_)
```

실루엣 점수가 음수라면 많은 샘플이 자신의 군집보다 다른 군집에 더 가까울 수 있으므로 `eps`, `min_samples`, 스케일과 알고리즘 적합성을 점검한다.

---

## 5. 헷갈리는 개념 비교

|구분|DBSCAN|K-means|
|---|---|---|
|군집 수|미리 지정하지 않음|K 지정|
|형태|복잡한 밀도 군집 가능|둥근 중심 기반 군집에 유리|
|잡음|`-1`로 구분|별도 잡음 개념 없음|
