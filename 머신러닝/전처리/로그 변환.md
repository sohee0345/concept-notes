# 로그 변환

## 1. 개념

로그 변환은 큰 양수 값의 차이를 압축하여 오른쪽 꼬리가 긴 분포를 대칭에 가깝게 만들고 극단값의 영향을 줄이는 데 사용할 수 있다.

> **핵심:** 변환 전후의 왜도·첨도와 그래프를 비교해 실제 효과를 확인한다.

------------------------------------------------------------------------

## 2. 사용 방법

```python
df["fare_log"] = np.log1p(df["fare"])
```

`log1p(x)`는 $\log(1+x)$를 계산하므로 값 0을 포함할 수 있다.

------------------------------------------------------------------------

## 3. 확인 방법

```python
df[["fare", "fare_log"]].skew()
df[["fare", "fare_log"]].kurt()
sns.displot(df, x="fare_log")
```

------------------------------------------------------------------------

## 4. 주의할 점

- 모든 분포에 로그 변환을 적용하지 않는다.
- 로그가 제곱근보다 항상 좋은 것은 아니다.
- 데이터 범위와 변환 전후 분포를 확인해 선택한다.

------------------------------------------------------------------------

## 🟦 핵심 정리


### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 로그 변환 | 큰 값의 차이를 압축한다. |
| `log1p` | 0을 포함하는 값에 $\log(1+x)$를 적용한다. |
| 분포 비교 | 변환 전후의 통계와 그래프를 확인한다. |

### ⭐ 한 줄 정리

> **오른쪽 꼬리가 긴 양수 데이터에 log1p를 적용하고 변환 전후 분포를 비교한다.**
