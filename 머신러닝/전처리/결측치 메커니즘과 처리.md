# 결측치 메커니즘과 처리

## 1. 개념

결측치는 관측되어야 할 값이 빠진 상태이다. 처리 방법은 결측 비율뿐 아니라 발생 원인과 변수의 역할, 처리 후 분포 변화를 함께 고려해 선택한다.

> **핵심:** 결측 원인을 확인한 뒤 삭제와 대체가 만드는 정보 손실과 왜곡을 비교한다.

------------------------------------------------------------------------

## 2. 결측 메커니즘

| 구분 | 의미 |
| --- | --- |
| MCAR | 모든 변수와 무관하게 완전히 무작위로 발생 |
| MAR | 다른 관측된 변수로 발생을 설명할 수 있음 |
| MNAR | 빠진 값 자체나 관측되지 않은 원인과 관련됨 |

------------------------------------------------------------------------

## 3. 결측치 확인

```python
count = df.isnull().sum()
ratio = count / len(df)
ratio.sort_values(ascending=False)
```

`isnull()`은 결측 위치에 `True`를 반환한다.

------------------------------------------------------------------------

## 4. 처리 방법

```python
df["age_median"] = df["age"].fillna(df["age"].median())
df.drop(["deck"], axis=1, inplace=True)
```

- 행·컬럼 삭제 → 정보 손실을 확인한다.
- 평균·중앙값 대체 → 분포가 한 값에 몰릴 수 있다.
- 랜덤 표본 대체 → 인덱스 정렬과 그룹별 분포를 확인한다.

```python
mask = df["age"].isnull()
samples = df["age"].dropna().sample(mask.sum(), replace=True)
df.loc[mask, "age"] = samples.to_numpy()
```

------------------------------------------------------------------------

## 5. 주의할 점

- 결측 비율 임계값은 고정 규칙이 아니다.
- 대체 전후 분포를 비교한다.
- Series 대입 시 Pandas의 인덱스 정렬을 고려한다.
