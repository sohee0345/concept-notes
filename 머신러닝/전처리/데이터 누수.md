# 데이터 누수

## 1. 개념

데이터 누수는 실제 예측 시점에는 알 수 없는 정보가 모델 학습이나 전처리에 들어가 평가 성능이 과대평가되는 문제이다.

> **핵심:** 학습·테스트 데이터를 나눈 뒤 전처리 기준은 학습 데이터로만 학습한다.

---

## 2. 쉽게 이해하기

시험 문제의 정답 정보를 공부 과정에 미리 섞으면 시험 점수가 실제 실력보다 좋아 보이는 것과 같다.

```text
train → 전처리 fit + transform → 모델 학습
test  → 같은 기준으로 transform → 최종 평가
```

---

## 3. 사용 방법

- 전체 데이터에서 평균이나 스케일을 먼저 계산하지 않는다.
- 전처리 기준의 `fit`은 train에만 수행한다.
- test에는 train에서 얻은 기준으로 `transform`만 수행한다.
- 교차검증에서는 전처리와 모델을 `Pipeline`으로 묶어 각 반복의 훈련 폴드에서만 전처리 기준을 학습한다.
- 실제 예측 시점에 사용할 수 없는 변수는 Feature에서 제외한다.

---

## 4. 예제

전체 데이터의 평균으로 결측치를 채운 뒤 train과 test를 나누면 test 정보가 평균에 포함된다. 먼저 데이터를 나누고 train 평균으로 두 데이터의 결측치를 처리해야 한다.

교차검증에서도 훈련 세트 전체로 스케일러를 먼저 학습하면 검증 폴드의 정보가 스케일 계산에 포함된다. 스케일러와 모델을 파이프라인으로 묶으면 각 반복에서 훈련 폴드에만 `fit`이 수행되어 이 누수를 막을 수 있다.

---

## 5. 헷갈리는 개념 비교

|구분|`fit`|`transform`|
|---|---|---|
|역할|전처리 기준 학습|학습된 기준 적용|
|데이터|train에만 수행|train과 test에 적용|

|---|---|

|평가 과대추정|실제보다 성능이 좋게 측정되는 현상|
