# 데이터 누수

## 1. 개념

데이터 누수는 실제 예측 시점에 알 수 없는 정보나 평가용 데이터의 정보가 모델 학습에 사용되어 평가 성능이 과대평가되는 문제이다.

> **핵심:** 테스트 데이터는 학습과 전처리 기준 계산에 사용하지 않는다.

------------------------------------------------------------------------

## 2. 전처리 흐름

```text
train → 전처리 fit + transform → 모델 학습
test  → train에서 학습한 전처리로 transform → 평가
```

평균, 중앙값이나 스케일 같은 전처리 기준은 train 데이터에서 계산하고 test에는 같은 기준을 적용한다.

------------------------------------------------------------------------

## 3. 누수 흐름

```text
전체 데이터로 전처리 기준 계산
  ↓
test 정보가 기준에 포함
  ↓
모델 평가가 실제보다 좋아짐
```

------------------------------------------------------------------------

## 🟦 핵심 정리


### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 데이터 누수 | 학습에 사용하면 안 되는 정보가 들어간다. |
| train | 모델과 전처리 기준을 학습하는 데이터이다. |
| test | 학습된 과정의 성능을 평가하는 데이터이다. |

### ⭐ 한 줄 정리

> **전처리와 모델은 train으로만 학습하고 test에는 학습된 변환만 적용한다.**
