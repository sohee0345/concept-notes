# 머신러닝 전처리 흐름

## 1. 개념

머신러닝 전처리는 원본 데이터를 모델이 학습할 수 있는 Feature와 Target으로 정리하고, 결측치 처리·인코딩·스케일링을 일관된 기준으로 적용하는 과정이다.

> **핵심:** 데이터를 먼저 분리하고 Train에서 학습한 전처리 기준을 Test에 그대로 적용한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
Train / Test 분리
  ↓
결측치 처리
  ↓
Feature / Target 분리
  ↓
범주형 인코딩 + 수치형 스케일링
  ↓
Feature 결합과 Shape 검증
  ↓
모델 학습과 평가
```

> **쉽게 말하면:** 학습용 재료로 손질 기준을 정한 뒤 시험용 재료에도 같은 기준을 적용하는 과정이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
train, test = train_test_split(
    df,
    random_state=42,
    test_size=0.2,
)

x_train, y_train = feature_target_split(train)
x_test, y_test = feature_target_split(test)
```

- Train / Test 분리
- Train 중심으로 결측치 대체값 결정
- 수치형 / 범주형 Feature 분리
- Encoder와 Scaler를 Train으로 학습
- Train과 Test에 같은 기준 적용
- 결과 결합 후 Shape 검증

> **핵심:** Test에서 평균·최빈값·범주·스케일 기준을 새로 학습하지 않는다.

------------------------------------------------------------------------

## 4. 예제

``` python
x_train_features = pd.concat(
    [x_train_scaled, x_train_enc], axis=1
)
x_test_features = pd.concat(
    [x_test_scaled, x_test_enc], axis=1
)

assert x_train_features.shape[0] == y_train.shape[0]
assert x_train_features.shape[1] == x_test_features.shape[1]
assert x_test_features.shape[0] == y_test.shape[0]
```

### 코드 해석

- `concat(..., axis=1)` → 수치형과 범주형 Feature를 열 방향으로 결합
- 첫 번째·세 번째 검증 → Feature와 Target의 데이터 개수 확인
- 두 번째 검증 → Train과 Test의 Feature 개수 확인

> **결과 해석:** Shape이 맞아야 모델 학습과 평가에 같은 구조의 데이터를 사용할 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | `fit` | `transform` |
| --- | --- | --- |
| 의미 | 변환 기준 학습 | 학습된 기준 적용 |
| Train | 사용 | 사용 |
| Test | 사용하지 않음 | 사용 |

------------------------------------------------------------------------

## 6. 주의할 점

- Test 데이터로 전처리 기준을 학습하면 데이터 누수가 발생할 수 있다.
- DataFrame을 열 방향으로 합치기 전에 인덱스를 맞춘다.
- 학습 전 Feature·Target 행 수와 Train·Test 열 수를 확인한다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `전처리` | 모델 학습에 맞게 데이터를 정리·변환하는 과정 |
| `fit` | Train에서 변환 기준 학습 |
| `transform` | 학습된 기준 적용 |
| `Shape 검증` | Feature·Target의 행과 Train·Test의 열 확인 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `train_test_split()` | 데이터 분리 |
| `pd.concat(..., axis=1)` | Feature 결합 |
| `assert ...shape...` | 입력 구조 검증 |

### ⭐ 한 줄 정리

> **Train으로 전처리 기준을 학습하고 같은 기준으로 Test를 변환한 뒤 Shape을 검증한다.**
