# PCA

## 1. 개념

PCA는 데이터가 크게 퍼진 방향을 찾아 서로 직교하는 주성분 축으로 투영하는 차원 축소 방법이다.

> **핵심:** 분산을 많이 보존하는 주성분을 선택해 중요한 정보는 유지하고 차원을 줄인다.

---

## 2. 쉽게 이해하기

여러 방향으로 퍼진 데이터를 가장 잘 설명하는 새 관찰 방향으로 돌려 적은 축만 남기는 과정이다.

```text
원본 Feature → 분산이 큰 직교 방향 탐색 → 주성분 선택 → 저차원 투영
```

---

## 3. 사용 방법

```python
pca = PCA(n_components=15)
reduced = pca.fit_transform(features)
ratio = pca.explained_variance_ratio_.sum()
```

- 고유벡터 → 데이터가 퍼진 주요 방향
- 고유값 → 해당 방향이 담은 분산 크기
- `n_components` → 남길 주성분 수
- `explained_variance_ratio_` → 주성분별 설명 분산 비율

---

## 4. 예제

주성분을 너무 적게 남기면 정보 손실로 성능이 낮아질 수 있다. 성분 수는 누적 설명 분산 비율과 교차검증 성능을 함께 보고 정한다.

---

## 5. 헷갈리는 개념 비교

|구분|Feature 선택|PCA|
|---|---|---|
|결과|기존 Feature 일부 유지|기존 Feature의 선형 결합인 새 축|
|해석|원래 의미 유지|주성분 해석 필요|
