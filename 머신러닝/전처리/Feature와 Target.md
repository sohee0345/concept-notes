# Feature와 Target

## 1. 개념

Feature는 모델이 결과를 설명하거나 예측할 때 사용하는 독립변수이고, Target은 모델이 예측하려는 종속변수이다. 보통 Feature는 `X`, Target은 `y`로 나타낸다.

> **핵심:** 무엇을 이용해 무엇을 예측하는지 구분하면 Feature와 Target을 찾을 수 있다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

집값을 예측한다면 평수·방 개수·역과의 거리는 예측에 사용하는 정보이고 집값은 구하려는 답이다.

``` text
평수·방 개수·역과의 거리
  ↓ Feature(X)
머신러닝 모델
  ↓
집값
  ↓ Target(y)
```

> **쉽게 말하면:** Feature는 문제를 풀 때 주어지는 단서이고 Target은 맞혀야 하는 정답이다.

------------------------------------------------------------------------

## 3. 사용 방법

- `X` → 하나 이상의 Feature를 나타내는 관례적인 기호
- `y` → Target을 나타내는 관례적인 기호
- 먼저 예측하려는 결과를 Target으로 정한다.
- 그 결과를 설명하거나 예측하는 데 사용할 변수를 Feature로 구분한다.

> **핵심:** 컬럼이 입력 정보인지 예측 결과인지 데이터 분석의 목적을 기준으로 판단한다.

------------------------------------------------------------------------

## 4. 예제

| 평수 | 방 개수 | 역과의 거리 | 집값 |
| ---: | ---: | ---: | ---: |
| 20 | 2 | 500m | 3억 |
| 30 | 3 | 300m | 5억 |

### 예제 해석

- `X` → 집값을 설명하거나 예측하는 평수·방 개수·역과의 거리
- `y` → 모델이 예측하려는 집값

> **결과 해석:** 같은 데이터 컬럼도 분석 목적에 따라 Feature 또는 Target의 역할이 결정된다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | Feature | Target |
| --- | --- | --- |
| 다른 이름 | 독립변수 | 종속변수 |
| 역할 | 예측에 사용하는 입력 | 예측하려는 결과 |
| 관례적 기호 | `X` | `y` |
| 집값 예측 예시 | 평수, 방 개수, 역과의 거리 | 집값 |

------------------------------------------------------------------------

## 6. 주의할 점

- 예측력이 낮다는 이유만으로 어떤 변수가 수학적으로 독립변수가 될 수 없는 것은 아니다.
- 여러 Feature가 지나치게 비슷한 정보를 가지면 특히 선형회귀 등에서 다중공선성 문제가 생길 수 있다.
- 실제 데이터에서 Feature 사이에 어느 정도 상관관계가 있다는 이유만으로 모두 제거하는 것은 아니다.
