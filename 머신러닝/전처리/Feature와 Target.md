# Feature와 Target

## 1. 개념

Feature는 결과를 설명하거나 예측하는 입력 변수이고 Target은 모델이 예측하려는 결과이다. 보통 Feature는 `X`, Target은 `y`로 표현한다.

> **핵심:** 머신러닝 데이터는 예측에 사용하는 입력과 예측하려는 결과로 나누어 이해한다.

---

## 2. 쉽게 이해하기

집값 예측에서 평수와 방 개수는 판단에 사용하는 단서이고 집값은 맞히려는 정답이다.

```text
Feature X → 모델 → Target y 예측
```

---

## 3. 사용 방법

- Feature·독립변수·입력 변수 → 예측에 사용하는 데이터이다.
- Target·종속변수·출력 변수 → 예측하려는 결과이다.
- Feature끼리 비슷한 정보를 지나치게 많이 담으면 중복 정보가 될 수 있다.

---

## 4. 예제

몸무게의 kg 컬럼과 g 컬럼은 단위만 다를 뿐 같은 정보를 담는다. 두 컬럼을 함께 사용할지는 모델과 예측에 미치는 영향을 확인해 판단한다.

---

## 5. 헷갈리는 개념 비교

|구분|Feature|Target|
|---|---|---|
|기호|`X`|`y`|
|역할|예측 입력|예측 결과|
