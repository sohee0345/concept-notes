# 결측치 처리

## 1. 개념

결측치는 컬럼·행 삭제, 평균·중앙값 대체, 관측값에서 뽑은 랜덤 표본 대체 등으로 처리할 수 있다. 선택한 방법이 분포를 왜곡하는지 확인해야 한다.

> **핵심:** 고정된 비율 규칙보다 결측 원인, 변수 가치, 분포 변화를 근거로 처리 방법을 선택한다.

---

## 2. 쉽게 이해하기

빈칸이 든 행을 버리거나 대표값으로 채우거나 기존 값의 분포에서 새 값을 뽑아 채우는 방식이다.

```text
결측 원인·비율 확인 → 삭제 또는 대체 → 변환 전후 분포 비교
```

---

## 3. 사용 방법

```python
df["age_median"] = df["age"].fillna(df["age"].median())
clean_age = df["age"].dropna()
```

- 결측 비율이 높고 가치가 낮은 컬럼은 삭제를 고려한다.
- 적은 무작위 결측 행은 삭제를 고려한다.
- 평균·중앙값 대체는 같은 값이 반복되어 분산을 바꿀 수 있다.

---

## 4. 예제

```python
missing_mask = df["age"].isnull()
samples = df["age"].dropna().sample(n=missing_mask.sum(), replace=True)
df.loc[missing_mask, "age_random"] = samples.to_numpy()
```

`to_numpy()`를 사용하면 Series 인덱스 정렬 대신 위치 순서대로 값을 대입한다.

---

## 5. 헷갈리는 개념 비교

|구분|통계값 대체|랜덤 표본 대체|
|---|---|---|
|값|평균·중앙값 반복|관측값 분포에서 추출|
|주의|분산과 분포 축소|인덱스 정렬·그룹 차이|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|삭제|결측 행이나 컬럼 제거|
|통계값 대체|평균·중앙값으로 결측 채우기|
|랜덤 표본 대체|관측값에서 추출해 결측 채우기|

### 💻 주요 코드

|코드|의미|
|---|---|
|`dropna()`|결측값 제거|
|`fillna(value)`|지정값으로 결측 대체|
|`sample(..., replace=True)`|복원 추출|
|`to_numpy()`|인덱스 없이 값 배열 전달|
