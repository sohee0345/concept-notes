# 특성 공학

## 1. 개념

특성 공학은 기존 데이터에서 모델 학습에 도움이 될 새 Feature를 만들거나 표현을 바꾸는 과정이다.

> **핵심:** train과 test에 동일한 변환 규칙을 적용하되 각 데이터의 컬럼끼리 계산한다.

---

## 2. 쉽게 이해하기

기존 재료를 조합해 모델이 더 이해하기 쉬운 새로운 단서를 만드는 과정이다.

```text
기존 Feature → 의미 있는 결합·변환 → 새 Feature
```

---

## 3. 사용 방법

```python
for frame in [train, test]:
    frame["family_cnt"] = frame["sibsp"] + frame["parch"]
    frame["deck_who"] = frame["deck"].astype(str) + "_" + frame["who"]
```

- 수치형 컬럼을 계산해 새 수치를 만든다.
- 범주형 컬럼을 결합해 새 범주를 만든다.
- Feature 수는 고정 비율이 아니라 표본 수와 검증 결과로 판단한다.

---

## 4. 예제

```python
train["family_cnt"] = train.apply(
    lambda row: int(row["sibsp"]) + int(row["parch"]),
    axis=1,
)
```

형제·배우자 수와 부모·자녀 수를 더하면 동행 가족 수를 나타내는 `family_cnt`를 만들 수 있다.

---

## 5. 헷갈리는 개념 비교

|구분|Feature 선택|특성 공학|
|---|---|---|
|역할|사용할 기존 Feature 결정|새 Feature 생성·표현 변경|

### 💡 주요 개념

|개념|의미|
|---|---|

|코드|의미|
