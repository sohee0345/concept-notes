# 특성 공학

## 1. 개념

특성 공학은 기존 데이터를 조합하거나 변환하여 모델 학습에 사용할 새 Feature를 만드는 과정이다.

> **핵심:** train과 test에 같은 생성 규칙을 적용하되 규칙의 기준은 train에서 정한다.

------------------------------------------------------------------------

## 2. 예제

```python
for frame in [train, test]:
    frame["family_cnt"] = frame["sibsp"] + frame["parch"]
    frame["deck_who"] = frame["deck"].astype(str) + "_" + frame["who"]
```

- 수치형 특성 → 두 개수 컬럼을 더한다.
- 범주형 특성 → 두 범주를 결합한다.

------------------------------------------------------------------------

## 3. 주의할 점

- test 특성을 train Series로 계산하지 않는다.
- Feature 수에 고정된 비율 제한은 없다.
- 새 Feature가 검증 성능에 도움이 되는지 확인한다.

------------------------------------------------------------------------
