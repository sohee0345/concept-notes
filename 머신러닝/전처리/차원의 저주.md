# 차원의 저주

## 1. 개념

차원의 저주(Curse of Dimensionality)는 특성 수가 늘어날수록 데이터가 고차원 공간에 희박하게 퍼져, 같은 수의 샘플만으로는 패턴을 충분히 학습하기 어려워지는 현상이다. 차원이 커질수록 공간의 크기가 빠르게 증가하므로 비슷한 밀도를 유지하려면 훨씬 많은 데이터가 필요하다.

> **핵심:** 특성이 많다는 사실보다 각 특성이 유용한 정보를 제공하는지가 중요하다.

---

## 2. 쉽게 이해하기

한 줄 위의 점을 채우는 것보다 평면 전체를 채우는 데 더 많은 점이 필요하고, 입체 공간을 채우려면 그보다 더 많은 점이 필요하다. 데이터의 차원도 같은 방식으로 늘어난다.

```text
같은 수의 데이터
  → 특성 수 증가
  → 데이터 사이 빈 공간 증가
  → 가까운 샘플도 상대적으로 멀어짐
  → 학습과 일반화가 어려워짐
```

> **쉽게 말하면:** 데이터 수는 그대로인데 관찰해야 할 방향만 많아져 공간이 듬성듬성해지는 문제다.

---

## 3. 모델에 미치는 영향

KNN은 가까운 이웃을 찾아 예측하므로 고차원에서 거리 차이가 흐려지면 특히 큰 영향을 받는다. 불필요한 특성은 잡음을 늘리고 모델이 훈련 데이터의 우연한 패턴에 의존하게 만들 수도 있다.

차원의 저주에 대응하려면 다음 방법을 고려한다.

- 도메인 지식이나 통계 기준으로 불필요한 특성 제거
- PCA, Truncated SVD, NMF 등을 이용한 차원 축소
- 규제를 사용해 불필요한 특성의 영향 제한
- 더 많은 학습 데이터 수집
- 데이터와 모델에 적합한 인코딩 사용

---

## 4. 예제

```python
from sklearn.model_selection import cross_val_score
from sklearn.neighbors import KNeighborsClassifier

model = KNeighborsClassifier(n_neighbors=5)
score = cross_val_score(model, X, y, cv=5).mean()
```

특성을 추가하거나 차원 축소를 적용한 뒤에는 같은 교차검증 조건에서 점수를 다시 비교한다. 훈련 점수만으로는 일반화 성능을 판단할 수 없다.

---

## 5. 주의할 점

- 차원이 높다고 항상 성능이 나쁜 것은 아니다. 유용한 특성이 충분하고 모델과 데이터 수가 적절하면 성능이 좋아질 수 있다.
- 원-핫 인코딩으로 차원이 늘어나는 것 자체가 항상 문제는 아니다. 범주 수, 희소성, 모델의 처리 방식이 함께 중요하다.
- 차원을 많이 줄인다고 성능이 자동으로 좋아지지는 않는다. 정보 손실과 검증 성능을 확인해야 한다.
