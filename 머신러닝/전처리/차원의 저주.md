# 차원의 저주

## 1. 개념

차원의 저주는 Feature 수가 늘어날수록 데이터가 고차원 공간에 희박하게 퍼져 제한된 샘플로 의미 있는 패턴을 학습하기 어려워지는 현상이다.

> **핵심:** 차원이 증가하면 공간은 빠르게 커지고 샘플 사이 거리의 의미와 모델의 일반화 성능이 약해질 수 있다.

---

## 2. 쉽게 이해하기

같은 수의 점을 더 넓고 많은 방향을 가진 공간에 흩뿌리면 점 사이가 멀어지고 주변 이웃을 찾기 어려워진다.

```text
Feature 증가 → 공간 증가 → 데이터 희박 → 거리 의미 감소 → 학습 어려움
```

---

## 3. 사용 방법

- 거리 기반 KNN은 차원의 저주에 특히 민감하다.
- 불필요한 Feature와 과도한 인코딩 차원을 점검한다.
- 특성 선택, 차원 축소, 데이터 추가 수집, 규제로 대응한다.
- Feature 수 증가가 실제 정보 증가인지 검증한다.

---

## 4. 예제

연속 수치 두 개를 각각 범주처럼 One-Hot Encoding하여 52차원으로 늘린 실습에서는 KNN 테스트 정확도가 크게 낮아졌다. 높은 차원이 항상 더 많은 유용한 정보를 뜻하지 않는다.

---

## 5. 헷갈리는 개념 비교

|구분|유용한 Feature 증가|불필요한 차원 증가|
|---|---|---|
|정보|새로운 예측 정보 추가|중복·희소 정보 증가|
|영향|성능 개선 가능|과적합·거리 왜곡 가능|
