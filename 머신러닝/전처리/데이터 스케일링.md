# 데이터 스케일링

## 1. 개념

데이터 스케일링은 수치형 Feature의 값 범위를 변환하는 전처리이다. Train 데이터로 변환 기준을 학습하고 Test에는 같은 기준을 적용한다.

> **핵심:** `fit_transform()`은 Train에, `transform()`은 Test에 사용한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
Train 수치형 Feature
  ↓ fit + transform
스케일 기준과 Train 변환값

Test 수치형 Feature
  ↓ 같은 기준으로 transform
Test 변환값
```

> **쉽게 말하면:** 학습 데이터에서 만든 하나의 자를 Train과 Test 모두에 사용한다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()

x_train_scaled = scaler.fit_transform(x_train_number)
x_test_scaled = scaler.transform(x_test_number)
```

- `fit_transform()` → 기준 학습과 변환을 한 번에 수행
- `transform()` → 이미 학습한 기준으로 변환
- StandardScaler 결과 → NumPy 배열

> **핵심:** Test에 `fit_transform()`을 사용하지 않는다.

------------------------------------------------------------------------

## 4. 예제

``` python
x_train_scaled = pd.DataFrame(
    data=scaler.transform(x_train_number),
    columns=x_train_number.columns,
)

x_test_scaled = pd.DataFrame(
    data=scaler.transform(x_test_number),
    columns=x_test_number.columns,
)
```

### 코드 해석

- `data` → Scaler가 반환한 NumPy 배열
- `columns` → 원래 수치형 Feature의 컬럼 이름
- `pd.DataFrame()` → 배열을 컬럼명이 있는 표로 복원

> **결과 해석:** 컬럼 선택, 구조 확인, 다른 DataFrame과의 결합이 쉬워진다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 방법 | 기준 |
| --- | --- |
| StandardScaler | Train 데이터에서 학습한 통계 기준 |
| Min-Max Scaler | 최솟값과 최댓값 기준 |
| Normalizer | 각 데이터의 L2 Norm 기준 |

------------------------------------------------------------------------

## 6. 주의할 점

- Test 데이터에서 스케일 기준을 다시 학습하면 데이터 누수가 발생할 수 있다.
- 변환 결과가 NumPy 배열이면 컬럼 이름이 사라진다.
- 모델에 바로 입력할 때는 배열도 가능하지만 전처리 결과를 확인·결합할 때는 DataFrame이 편리하다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `Scaling` | 수치형 Feature 범위 변환 |
| `StandardScaler` | 표준화 기준으로 값을 변환하는 Scaler |
| `Normalizer` | L2 Norm을 기준으로 각 데이터 크기 조정 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `scaler.fit_transform(train)` | Train 기준 학습과 변환 |
| `scaler.transform(test)` | 같은 기준으로 Test 변환 |
| `pd.DataFrame(..., columns=...)` | 컬럼명을 붙여 DataFrame 복원 |

### ⭐ 한 줄 정리

> **Scaler는 Train으로만 학습하고 같은 기준으로 Test를 변환한다.**
