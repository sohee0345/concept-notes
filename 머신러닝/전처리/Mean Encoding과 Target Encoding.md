# Mean Encoding과 Target Encoding

## 1. 개념

Mean Encoding은 범주형 값을 그 범주에 속한 Train 행들의 Target 평균값으로 바꾸는 방법이다. 일반적으로 Target Encoding과 같은 의미로 사용한다.

> **핵심:** 각 범주를 전체 평균이나 범주형 컬럼 자체의 평균이 아니라 해당 범주의 Target 평균으로 변환한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

지역별 고객의 구매 여부가 다음과 같다고 가정한다.

| 지역 | 구매 여부(Target) |
| --- | ---: |
| 서울 | 1 |
| 서울 | 0 |
| 서울 | 1 |
| 부산 | 0 |
| 부산 | 0 |

``` text
서울의 Target 평균 → (1 + 0 + 1) / 3 = 0.667
부산의 Target 평균 → (0 + 0) / 2 = 0
```

인코딩하면 서울은 `0.667`, 부산은 `0`으로 바뀐다.

> **쉽게 말하면:** 범주 이름 대신 그 범주에서 정답이 평균적으로 얼마였는지를 넣는 것이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
category_mean = train.groupby("지역")["구매여부"].mean()

train["지역_encoded"] = train["지역"].map(category_mean)
test["지역_encoded"] = test["지역"].map(category_mean)
```

- `groupby("지역")` → 같은 지역끼리 그룹화
- `["구매여부"].mean()` → 지역별 Target 평균 계산
- `map(category_mean)` → 범주를 계산된 평균값으로 변환

> **핵심:** 범주별 평균은 Train에서만 계산하고 Test에는 그 값을 적용한다.

------------------------------------------------------------------------

## 4. 예제

``` python
category_mean = train.groupby("지역")["구매여부"].mean()
print(category_mean)
```

실행 결과:

``` text
지역
서울    0.667
부산    0.000
```

### 코드 해석

- 서울에 해당하는 Train Target `1`, `0`, `1`의 평균은 약 `0.667`
- 부산에 해당하는 Train Target `0`, `0`의 평균은 `0`

> **결과 해석:** 문자열 범주가 Target과 관련된 수치로 변환된다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | Mean/Target Encoding | One-Hot Encoding |
| --- | --- | --- |
| 변환 기준 | 범주별 Target 평균 | 범주별 해당 여부 |
| Target 사용 | 사용함 | 사용하지 않음 |
| 결과 | 범주당 하나의 수치 | 범주별 0·1 컬럼 |
| 주요 주의점 | 데이터 누수와 과적합 | 범주가 많을 때 컬럼 증가 |

------------------------------------------------------------------------

## 6. 주의할 점

- 전체 데이터나 Test 데이터까지 사용해 범주별 평균을 구하면 데이터 누수가 발생한다.
- 범주별 데이터가 적으면 해당 범주의 Target에 지나치게 맞춰질 수 있다.
- Test에 처음 등장한 범주는 Train에서 평균을 계산하지 못했으므로 별도 처리 기준이 필요하다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `Mean Encoding` | 범주를 해당 범주의 Target 평균으로 변환 |
| `Target Encoding` | 일반적으로 Mean Encoding과 같은 의미로 사용하는 이름 |
| `범주별 Target 평균` | 같은 범주에 속한 Train Target 값들의 평균 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `groupby()[target].mean()` | Train의 범주별 Target 평균 계산 |
| `map()` | 범주를 계산된 평균으로 변환 |

### ⭐ 한 줄 정리

> **Mean Encoding과 Target Encoding은 일반적으로 같은 개념이며, 각 범주를 Train에서 구한 해당 범주의 Target 평균값으로 바꾼다.**
