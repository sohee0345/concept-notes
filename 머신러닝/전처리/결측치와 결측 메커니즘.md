# 결측치와 결측 메커니즘

## 1. 개념

결측치는 관측되지 않은 값이며 Pandas에서는 `NaN`, `None`, `pd.NA` 등이 결측값으로 처리될 수 있다. 처리 방법은 비율뿐 아니라 결측 발생 원인을 함께 고려한다.

> **핵심:** 결측치 수·비율·패턴을 확인하고 MCAR·MAR·MNAR 중 어떤 발생 구조인지 조사한다.

---

## 2. 쉽게 이해하기

빈칸이 얼마나 많은지뿐 아니라 왜 비었는지를 알아야 삭제하거나 채우는 방법을 정할 수 있다.

```text
결측 위치 확인 → 수·비율 계산 → 관련 변수 조사 → 메커니즘 판단
```

---

## 3. 사용 방법

```python
missing_count = df.isnull().sum()
missing_ratio = missing_count / len(df)
sns.heatmap(df.isnull(), cbar=False)
```

- MCAR → 관측값과 미관측값 모두와 무관한 무작위 결측
- MAR → 다른 관측된 변수로 결측 발생을 설명 가능
- MNAR → 결측된 값 자체나 관측되지 않은 원인과 관련

---

## 4. 예제

```python
missing_count = df.isnull().sum()
missing_ratio = (missing_count / df.shape[0]).sort_values(ascending=False)

print(missing_ratio)
```

`isnull()`은 결측 위치를 True로 반환하며 True가 1처럼 합산되므로 컬럼별 결측치 수를 계산할 수 있다. 행 수로 나누면 결측 비율이 된다.

---

## 5. 헷갈리는 개념 비교

|구분|MCAR|MAR|MNAR|
|---|---|---|---|
|관련성|관측·미관측값과 무관|관측 변수와 관련|결측값 자체·미관측 원인과 관련|
