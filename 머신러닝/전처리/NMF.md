# NMF

## 1. 개념

비음수 행렬 분해(Non-negative Matrix Factorization, NMF)는 모든 원소가 0 이상인 행렬 $X$를 두 비음수 행렬 $W$와 $H$의 곱으로 근사하는 방법이다.

$$X \approx WH$$

$X$가 $m \times n$이고 잠재 성분 수가 $p$라면 $W$는 $m \times p$, $H$는 $p \times n$이 된다.

> **핵심:** 입력과 잠재 성분이 모두 음수가 아니므로 여러 양의 부분을 더해 원본을 설명하는 해석이 가능하다.

---

## 2. 쉽게 이해하기

문서-단어 빈도 행렬을 NMF로 분해한다고 생각해 보자. $H$의 각 행은 특정 주제를 구성하는 단어의 비중으로 볼 수 있고, $W$의 각 행은 한 문서가 각 주제를 얼마나 포함하는지 나타낼 수 있다.

```text
비음수 데이터 X
  → 잠재 성분 H 추출
  → 샘플별 성분 가중치 W 계산
  → W와 H의 곱으로 X 근사
```

> **쉽게 말하면:** 음수가 없는 데이터를 몇 가지 양의 재료와 재료별 배합 비율로 나누는 방법이다.

---

## 3. 사용 방법

```python
from sklearn.decomposition import NMF

nmf = NMF(n_components=5, max_iter=500, random_state=42)
W_train = nmf.fit_transform(X_train)
W_test = nmf.transform(X_test)
H = nmf.components_
```

- `n_components` → 추출할 잠재 성분 수 $p$
- `W_train` → 훈련 샘플별 잠재 성분 가중치
- `components_` → 원래 특성으로 잠재 성분을 표현한 행렬 $H$
- `max_iter` → 반복 최적화의 최대 횟수

> **핵심:** NMF에 전달하는 모든 입력값은 0 이상이어야 한다.

---

## 4. 예제

```python
import numpy as np
from sklearn.decomposition import NMF

X = np.array([
    [5.0, 4.0, 0.0, 0.0],
    [4.0, 5.0, 0.0, 0.0],
    [0.0, 0.0, 4.0, 5.0],
])

nmf = NMF(n_components=2, init="nndsvda", random_state=42)
W = nmf.fit_transform(X)
H = nmf.components_
X_approx = W @ H
```

### 코드 해석

- `n_components=2` → 데이터를 두 잠재 성분으로 설명한다.
- `W` → 각 행이 두 잠재 성분을 얼마나 포함하는지 나타낸다.
- `H` → 각 잠재 성분이 원래 네 특성을 어떻게 조합하는지 나타낸다.
- `W @ H` → 원본 행렬과 가까운 비음수 근사 행렬을 만든다.

> **결과 해석:** 앞의 두 행과 마지막 행이 서로 다른 특성 묶음을 사용하므로 두 잠재 성분으로 구분할 수 있다.

## 5. 헷갈리는 개념 비교

| 구분 | PCA·Truncated SVD | NMF |
| --- | --- | --- |
| 성분의 부호 | 음수와 양수 가능 | 음수 불가 |
| 성분 관계 | PCA 성분은 서로 직교 | 직교가 보장되지 않음 |
| 해석 방식 | 방향과 분산 중심 | 부분의 가산적 조합으로 해석 가능 |
| 입력 조건 | 방법에 따라 다름 | 모든 값이 0 이상이어야 함 |

---

## 6. 주의할 점

- 표준화 결과처럼 음수가 포함된 데이터에는 그대로 적용할 수 없다.
- 반복 최적화 방식이므로 초기값과 난수에 따라 결과가 달라질 수 있다. `random_state`를 고정하고 필요하면 초기화 방법을 지정한다.
- `ConvergenceWarning`이 발생하면 `max_iter`만 늘리기 전에 데이터 스케일, 초기화 방식과 성분 수가 적절한지 함께 점검한다.
- 성분 수는 복원 오차뿐 아니라 이후 모델의 검증 성능과 해석 가능성을 함께 고려해 선택한다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `비음수 제약` | 입력과 분해 결과가 모두 0 이상이어야 하는 조건 |
| `W` | 샘플별 잠재 성분 가중치 행렬 |
| `H` | 잠재 성분별 원래 특성 구성 행렬 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `NMF(n_components=p)` | 잠재 성분 수를 지정해 NMF 생성 |
| `fit_transform()` | $W$를 계산하고 $H$를 학습 |
| `components_` | 학습된 $H$ 행렬 확인 |

### ⭐ 한 줄 정리

> **NMF는 비음수 데이터를 양의 잠재 성분과 가중치의 곱으로 근사해 압축과 해석을 함께 돕는다.**
