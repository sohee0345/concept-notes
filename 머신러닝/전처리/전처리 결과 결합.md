# 전처리 결과 결합

## 1. 개념

수치형 스케일링과 범주형 인코딩 결과를 하나의 Feature 데이터로 결합하려면 컬럼 이름, 행 순서, 인덱스와 shape을 맞춰야 한다.

> **핵심:** 변환 배열을 DataFrame으로 복원하고 인덱스를 맞춘 뒤 결합 결과의 행·열 수를 검증한다.

---

## 2. 쉽게 이해하기

서로 다른 방식으로 처리한 표 조각을 같은 행 순서로 맞춰 옆으로 붙이는 과정이다.

```text
수치형 scaling + 범주형 encoding → 인덱스 정리 → concat → shape 검증
```

---

## 3. 사용 방법

```python
x_train_scaled = pd.DataFrame(
    scaler.transform(x_train_number),
    columns=x_train_number.columns,
).reset_index(drop=True)

x_train_features = pd.concat([x_train_scaled, x_train_enc], axis=1)
```

- scikit-learn 변환 결과는 NumPy 배열이므로 컬럼 이름을 다시 지정한다.
- `reset_index(drop=True)`로 결합할 행 인덱스를 맞춘다.
- `concat(axis=1)`으로 컬럼 방향으로 결합한다.

---

## 4. 예제

```python
assert x_train_features.shape[0] == y_train.shape[0]
assert x_train_features.shape[1] == x_test_features.shape[1]
assert x_test_features.shape[0] == y_test.shape[0]
```

Feature와 Target의 행 수, train과 test의 Feature 수가 일치하는지 검사한다.

---

## 5. 헷갈리는 개념 비교

|구분|NumPy 배열|DataFrame|
|---|---|---|
|컬럼 이름|없음|있음|
|결합 확인|위치 중심|컬럼·인덱스 확인 가능|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|컬럼 복원|변환 결과에 원래 Feature 이름 지정|
|인덱스 정렬|결합할 행의 순서와 레이블 통일|

|코드|의미|
