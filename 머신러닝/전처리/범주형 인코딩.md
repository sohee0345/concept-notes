# 범주형 인코딩

## 1. 개념

범주형 인코딩은 문자열이나 범주형 값을 모델이 처리할 수 있는 수치 표현으로 바꾸는 과정이다. 범주의 의미와 개수에 따라 방식을 선택한다.

> **핵심:** 명목형·순서형 여부와 Target 사용에 따른 누수 위험을 고려해 인코딩을 선택한다.

---

## 2. 쉽게 이해하기

모델이 이해할 수 있도록 범주 이름을 숫자로 번역하되 존재하지 않는 순서나 정답 정보가 섞이지 않게 하는 과정이다.

```text
범주 의미 확인 → 인코딩 선택 → train에서 학습 → test에 적용
```

---

## 3. 사용 방법

- One-Hot Encoding → 범주별 0·1 컬럼을 만든다.
- Ordinal Encoding → 순서형 범주를 순서에 맞는 숫자로 바꾼다.
- Target Encoding → 범주별 train Target 평균으로 바꾼다.

---

## 4. 예제

```text
red, blue, green
  ↓ One-Hot
color_red  color_blue  color_green
```

One-Hot은 임의의 순서를 만들지 않지만 범주가 많으면 컬럼 수와 희소한 0 값이 늘어난다.

---

## 5. 헷갈리는 개념 비교

|구분|One-Hot|Ordinal|Target|
|---|---|---|---|
|적합|명목형|순서형|범주와 Target 관계 활용|
|주의|차원 증가|가짜 순서|누수·과적합|
