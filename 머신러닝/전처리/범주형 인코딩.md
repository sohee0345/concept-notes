# 범주형 인코딩

## 1. 개념

범주형 인코딩은 문자열이나 범주 값을 모델이 처리할 수 있는 수치 표현으로 변환한다. 범주의 순서와 개수, Target 사용 여부에 따라 방법을 선택한다.

> **핵심:** 명목형·순서형을 구분하고 Target을 사용하는 인코딩에서는 누수를 막는다.

------------------------------------------------------------------------

## 2. 방법 비교

| 방법 | 사용 대상 | 특징 |
| --- | --- | --- |
| One-Hot | 순서 없는 명목형 | 범주별 0·1 컬럼 생성 |
| Ordinal | 순서형 | 순서에 맞는 숫자 부여 |
| Target | 범주형 | train의 범주별 Target 평균 사용 |

------------------------------------------------------------------------

## 3. 주의할 점

- One-Hot은 범주 수가 많으면 컬럼 수가 크게 증가한다.
- Ordinal을 명목형에 적용하면 잘못된 순서 관계가 생긴다.
- Target Encoding은 test 전체나 자기 Target을 그대로 반영하면 누수와 과적합이 발생하기 쉽다.
