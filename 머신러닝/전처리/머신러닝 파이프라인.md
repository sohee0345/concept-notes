# 머신러닝 파이프라인

## 1. 개념

머신러닝 파이프라인은 전처리 단계와 최종 모델을 정해진 순서로 묶어 학습과 예측에 같은 처리 흐름을 적용하는 구조이다. scikit-learn의 `Pipeline`은 행 단위 처리 순서를, `ColumnTransformer`는 열 유형별로 서로 다른 전처리를 관리한다.

> **핵심:** 전처리와 모델을 하나로 묶으면 처리 과정을 재현하고 교차검증의 데이터 누수를 방지할 수 있다.

---

## 2. 쉽게 이해하기

원재료가 정해진 공정을 순서대로 지나 완제품이 되는 생산 라인과 같다. 수치형 열과 범주형 열은 서로 다른 공정을 거친 뒤 합쳐져 모델에 전달된다.

```text
수치형 열 → 결측치 대체 → 스케일링 ┐
범주형 열 → 결측치 대체 → 인코딩 ├→ 결합 → 모델
```

---

## 3. 사용 방법

```python
preprocessor = ColumnTransformer([
    ("num", numeric_pipe, numeric_columns),
    ("cat", categorical_pipe, categorical_columns),
])
model = make_pipeline(preprocessor, LinearRegression())
```

- `Pipeline`·`make_pipeline` → 전처리와 모델을 순서대로 연결한다.
- `ColumnTransformer` → 지정한 열 그룹마다 다른 변환을 적용하고 결과를 합친다.
- `단계이름__파라미터이름` → 파이프라인 내부 단계의 하이퍼파라미터를 지정한다.

---

## 4. 예제

```python
pipe = Pipeline([
    ("scaler", MinMaxScaler()),
    ("svm", SVC()),
])

param_grid = {
    "svm__C": [0.1, 1, 10],
    "svm__gamma": [0.01, 0.1, 1],
}
search = GridSearchCV(pipe, param_grid=param_grid, cv=5)
search.fit(X_train, y_train)
```

교차검증의 각 반복에서 훈련 폴드로만 `MinMaxScaler`가 학습된 뒤 SVC가 학습된다. 따라서 검증 폴드의 최솟값과 최댓값이 전처리 기준에 섞이지 않는다.

---

## 5. 헷갈리는 개념 비교

|구분|Pipeline|ColumnTransformer|
|---|---|---|
|역할|처리 단계를 순서대로 연결|열 그룹별로 다른 처리 적용|
|결과|마지막 모델까지 하나의 추정기로 동작|변환된 열들을 하나로 결합|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|Pipeline|전처리와 모델의 순서를 묶는 구조|
|ColumnTransformer|열 유형별 전처리를 나누어 적용하는 도구|
|파라미터 경로|`단계이름__파라미터이름`으로 내부 설정을 가리키는 방식|

### 💻 주요 코드

|코드|의미|
|---|---|
|`Pipeline([...])`|이름이 있는 처리 단계 결합|
|`ColumnTransformer([...])`|열 그룹별 변환 적용|
|`svm__C`|`svm` 단계의 `C` 지정|

### ⭐ 한 줄 정리

> **머신러닝 파이프라인은 열별 전처리부터 모델까지 하나의 재현 가능한 학습 과정으로 묶는다.**
