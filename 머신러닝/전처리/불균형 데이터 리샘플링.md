# 불균형 데이터 리샘플링

## 1. 개념

불균형 데이터 리샘플링은 훈련 데이터의 클래스별 표본 수를 조절해 모델이 소수 클래스를 충분히 학습하도록 돕는 방법이다. 다수 클래스를 줄이는 언더샘플링과 소수 클래스를 늘리는 오버샘플링으로 나뉜다.

> **핵심:** 리샘플링은 데이터 분할 후 훈련 세트에만 적용해야 한다.

---

## 2. 쉽게 이해하기

다수 클래스 사례만 반복해서 보는 모델은 모든 사례를 다수 클래스로 판단하기 쉽다. 일부 다수 사례를 덜 보여주거나 소수 사례를 더 보여주면 두 클래스의 경계를 학습할 기회가 늘어난다.

```text
원본 데이터 분할
  → 훈련 세트에만 리샘플링
  → 리샘플링된 훈련 세트로 학습
  → 변경하지 않은 검증·테스트 세트로 평가
```

---

## 3. 사용 방법

```python
from imblearn.over_sampling import SMOTE
from imblearn.pipeline import Pipeline
from sklearn.linear_model import LogisticRegression

pipeline = Pipeline([
    ("sampling", SMOTE(random_state=42)),
    ("model", LogisticRegression(max_iter=1000)),
])

pipeline.fit(X_train, y_train)
y_pred = pipeline.predict(X_test)
```

교차검증에서도 imbalanced-learn의 파이프라인을 사용하면 각 훈련 폴드에만 리샘플링이 적용되어 데이터 누수를 막기 쉽다.

---

## 4. 주요 방법

| 구분 | 방법 | 특징 |
| --- | --- | --- |
| 언더샘플링 | RandomUnderSampler | 다수 클래스 샘플을 무작위로 제거 |
| 언더샘플링 | OneSidedSelection | 경계와 중복 다수 샘플을 이웃 관계로 정리 |
| 언더샘플링 | NeighbourhoodCleaningRule | 주변 클래스 관계를 이용해 경계 샘플 정리 |
| 오버샘플링 | RandomOverSampler | 소수 클래스 샘플을 복원 추출해 반복 |
| 오버샘플링 | SMOTE | 가까운 소수 클래스 샘플 사이를 보간 |
| 오버샘플링 | ADASYN | 학습하기 어려운 소수 샘플 주변을 더 많이 합성 |

---

## 5. 헷갈리는 개념 비교

| 구분 | 언더샘플링 | 오버샘플링 |
| --- | --- | --- |
| 조절 대상 | 다수 클래스 감소 | 소수 클래스 증가 |
| 장점 | 빠르고 데이터 크기 감소 | 다수 클래스 정보를 버리지 않음 |
| 단점 | 유용한 정보 손실 가능 | 데이터 증가와 과적합 가능성 |
| 적합한 상황 | 다수 데이터가 매우 많을 때 | 소수 데이터가 부족할 때 |

---

## 6. 주의할 점

- 분할 전에 리샘플링하면 복제되거나 합성된 정보가 평가 데이터에 섞이는 데이터 누수가 생길 수 있다.
- 범주형 특성이 포함된 데이터에 일반 SMOTE를 그대로 사용하기보다 데이터 유형에 맞는 방법을 검토한다.
- 리샘플링이 항상 성능을 높이지는 않는다. 변경하지 않은 검증 데이터에서 비교해야 한다.
- 소수 클래스 Recall 향상과 Precision 감소가 함께 나타날 수 있으므로 실제 오류 비용을 고려한다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `언더샘플링` | 다수 클래스 샘플을 줄이는 방식 |
| `오버샘플링` | 소수 클래스 샘플을 늘리는 방식 |
| `SMOTE` | 소수 클래스 이웃 사이에 합성 샘플을 만드는 방식 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `fit_resample()` | 훈련 데이터에 리샘플링 적용 |
| `SMOTE()` | 합성 소수 클래스 샘플 생성 |
| `imblearn.pipeline.Pipeline` | 교차검증 중 훈련 폴드에만 샘플링 적용 |

### ⭐ 한 줄 정리

> **리샘플링은 훈련 세트의 클래스 구성을 조절하되 원래 분포를 유지한 검증·테스트 세트로 효과를 평가해야 한다.**
