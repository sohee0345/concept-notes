# 불균형 데이터 리샘플링

## 1. 개념

리샘플링은 train의 클래스별 표본 수를 줄이거나 늘려 모델이 소수 클래스를 더 충분히 학습하도록 돕는 방법이다.

> **핵심:** 리샘플링은 데이터 누수를 막기 위해 분할 후 train에만 적용한다.

---

## 2. 쉽게 이해하기

많은 클래스의 예시를 줄이거나 적은 클래스의 예시를 복제·합성해 학습 균형을 조정한다.

```text
전체 데이터 분할 → train에만 리샘플링 → 모델 학습 → 원래 test 평가
```

---

## 3. 사용 방법

- 언더샘플링 → 다수 클래스 샘플을 줄인다.
- RandomOverSampler → 소수 샘플을 복원 추출한다.
- SMOTE → 가까운 소수 클래스 샘플 사이를 보간한다.
- ADASYN → 어려운 소수 샘플 주변에 더 많이 합성한다.

---

## 4. 예제

```python
X_resampled, y_resampled = SMOTE(random_state=42).fit_resample(X_train, y_train)
model.fit(X_resampled, y_resampled)
y_pred = model.predict(X_test)
```

test는 원래 분포를 유지한 채 최종 성능을 평가한다.

---

## 5. 헷갈리는 개념 비교

|구분|언더샘플링|오버샘플링|
|---|---|---|
|동작|다수 클래스 감소|소수 클래스 증가|
|장점|속도·크기 감소|다수 정보 유지|
|위험|정보 손실|과적합·데이터 증가|

|개념|의미|
|---|---|
