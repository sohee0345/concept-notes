# 시계열 슬라이딩 윈도우

## 1. 개념

시계열 슬라이딩 윈도우는 연속된 과거 구간을 입력으로, 바로 뒤의 미래 구간을 정답으로 만들고 시작 위치를 한 칸씩 이동해 학습 샘플을 생성하는 방법이다.

> **핵심:** 시간 순서를 유지하면서 과거 `input_size`개로 미래 `pred_size`개를 예측하도록 데이터를 재구성한다.

---

## 2. 쉽게 이해하기

과거 3일로 다음 2일을 예측한다면 창을 다음과 같이 이동한다.

```text
[1일, 2일, 3일] → [4일, 5일]
     [2일, 3일, 4일] → [5일, 6일]
          [3일, 4일, 5일] → [6일, 7일]
```

각 줄이 하나의 `(feature, target)` 샘플이 된다.

---

## 3. 사용 방법

```python
features, targets = transform_by_series_dataset(
    data,
    input_size=5,
    pred_size=2,
    target_idx=0,
)
```

- `input_size` → 입력으로 사용할 과거 시점의 수다.
- `pred_size` → 정답으로 사용할 미래 시점의 수다.
- `target_idx` → 여러 변수 중 예측 대상으로 사용할 열의 위치다.

---

## 4. 예제

```python
import numpy as np

def transform_by_series_dataset(
    data,
    input_size=2,
    pred_size=2,
    target_idx=0,
):
    x_lst = []
    y_lst = []

    for i in range(input_size, data.shape[0] - pred_size + 1):
        x_lst.append(data[i-input_size:i])
        y_lst.append(data[i:i+pred_size, target_idx])

    return np.array(x_lst), np.array(y_lst)
```

열이 $F$개인 원본 데이터에서 샘플이 $N$개 만들어졌다면 `features`의 형태는 `(N, input_size, F)`, `targets`의 형태는 `(N, pred_size)`가 된다.

---

## 5. 헷갈리는 개념 비교

| 구분 | 무작위 분할 | 시계열 분할 |
| --- | --- | --- |
| 순서 | 샘플을 섞을 수 있음 | 시간 순서를 유지함 |
| 위험 | 일반 데이터에 주로 사용 | 미래 정보가 과거 학습에 섞이지 않게 주의 |
| 평가 | 임의의 훈련·검증 표본 | 과거로 학습하고 이후 기간으로 평가 |

윈도우를 만들기 전에 전체 시계열을 무작위로 섞으면 시간 관계가 깨진다. 학습과 평가의 경계에서도 미래 정보가 입력에 포함되지 않도록 분할 순서를 확인해야 한다.

## 🟦 핵심 정리

### 💡 주요 개념

슬라이딩 윈도우는 하나의 긴 시계열을 모델이 학습할 수 있는 여러 개의 과거 입력과 미래 정답 쌍으로 바꾼다.

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `data[i-input_size:i]` | 현재 위치 앞의 과거 입력 구간 선택 |
| `data[i:i+pred_size, target_idx]` | 이어지는 미래 정답 구간 선택 |
| `np.array(x_lst)` | 입력 샘플을 3차원 배열로 결합 |

### ⭐ 한 줄 정리

> **슬라이딩 윈도우는 시간 순서를 지키며 과거 구간과 미래 구간의 학습 쌍을 만든다.**
