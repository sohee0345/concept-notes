# 특성과 타깃

## 1. 개념

특성(Feature)은 결과를 설명하거나 예측하기 위해 모델에 입력하는 변수이고, 타깃(Target)은 모델이 예측하려는 결과이다. 보통 특성은 `X`, 타깃은 `y`로 표현한다.

> **핵심:** X는 예측에 사용할 입력이고 y는 예측할 정답 또는 결과이다.

------------------------------------------------------------------------

## 2. 예시

| 평수 | 방 개수 | 역과의 거리 | 집값 |
| ---: | ---: | ---: | ---: |
| 20 | 2 | 500 | 3억 |
| 30 | 3 | 300 | 5억 |

- `평수`, `방 개수`, `역과의 거리` → Feature `X`
- `집값` → Target `y`

------------------------------------------------------------------------

## 3. Feature 사이의 관계

독립변수라는 이름은 Feature끼리 반드시 서로 독립이라는 뜻이 아니다. 몸무게의 kg 컬럼과 g 컬럼처럼 같은 정보를 중복해서 표현하면 강한 관계가 생기며 선형회귀에서는 다중공선성 문제가 될 수 있다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| Feature | 예측에 사용하는 입력 변수이다. |
| Target | 예측하려는 결과이다. |
| 다중공선성 | Feature 사이에 매우 강한 선형 관계가 있는 문제이다. |

### ⭐ 한 줄 정리

> **머신러닝에서는 예측에 사용할 특성을 X로, 예측하려는 타깃을 y로 구분한다.**
