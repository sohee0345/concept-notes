# 가중치와 편향

## 1. 개념

가중치는 각 Feature가 예측에 반영되는 정도를 나타내고 편향은 Feature 값과 별도로 예측에 더해지는 모델 파라미터이다.

$$
\hat{y}=XW+b
$$

> **핵심:** 모델은 학습 과정에서 W와 b를 조정해 예측값을 실제값에 가깝게 만든다.

------------------------------------------------------------------------

## 2. shape

샘플 379개, Feature 104개인 단일 출력 회귀에서는 `X.shape=(379,104)`, `W.shape=(104,)`, 예측값 shape은 `(379,)`, 편향은 스칼라이다.
