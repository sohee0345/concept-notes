# 랜덤 시드와 재현성

## 1. 개념

랜덤 시드는 무작위 연산의 시작 상태를 정하여 같은 조건에서 같은 분할이나 초기화 결과를 재현하게 한다.

> **핵심:** 시드를 고정하면 실험 결과의 차이가 설정 변경 때문인지 비교하기 쉽다.

------------------------------------------------------------------------

## 2. 사용 방법

```python
seed = 42

train, test = train_test_split(
    df,
    random_state=seed,
)
```

------------------------------------------------------------------------

## 3. 주의할 점

- 시드는 실험 재현과 디버깅을 위해 고정한다.
- 데이터와 라이브러리 환경이 달라지면 같은 시드만으로 완전히 같은 결과가 보장되지는 않는다.
- 운영 결과를 일부러 불안정하게 만들기 위한 설정이 아니다.
