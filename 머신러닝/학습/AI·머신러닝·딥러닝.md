# AI·머신러닝·딥러닝

## 1. 개념

인공지능은 지능적인 작업을 수행하는 기술의 넓은 범위이며, 머신러닝은 데이터에서 규칙을 학습하는 인공지능의 한 분야이다. 딥러닝은 여러 층의 인공신경망을 사용하는 머신러닝 방식이다.

> **핵심:** 딥러닝은 머신러닝에, 머신러닝은 인공지능에 포함된다.

---

## 2. 쉽게 이해하기

큰 상자 안에 작은 상자가 들어 있는 포함 관계로 이해할 수 있다.

```text
인공지능 AI
└─ 머신러닝 ML
   └─ 딥러닝 DL
```

---

## 3. 사용 방법

- AI → 지능적 문제 해결 기술 전체를 가리킨다.
- ML → 데이터로 예측 규칙을 학습한다.
- DL → 여러 층의 신경망으로 표현과 규칙을 학습한다.

---

## 4. 예제

사람이 모든 판별 규칙을 직접 작성하기 어려운 문제에서 머신러닝은 Feature와 Target 데이터로 규칙을 학습한다.

---

## 5. 헷갈리는 개념 비교

|구분|AI|ML|DL|
|---|---|---|---|
|범위|가장 넓음|AI의 일부|ML의 일부|
|핵심|지능적 작업|데이터 학습|다층 신경망 학습|
