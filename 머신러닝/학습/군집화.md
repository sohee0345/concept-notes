# 군집화

## 1. 개념

군집화는 정답 레이블 없이 데이터의 유사성을 기준으로 비슷한 샘플을 그룹으로 묶는 비지도학습이다.

> **핵심:** 군집 번호는 단순한 식별자이며 실제 클래스 번호와 같은 의미가 아니다.

---

## 2. 쉽게 이해하기

정답표 없이 데이터끼리 닮은 정도를 보고 자연스러운 그룹을 찾는 과정이다.

```text
Feature 데이터 → 유사성·거리 계산 → 그룹 구조 탐색
```

---

## 3. 사용 방법

- 탐색하려는 군집 모양과 밀도를 고려한다.
- 거리 기반 방법은 스케일링의 영향을 받는다.
- 군집 번호가 달라도 같은 군집 구조일 수 있다.
- 평가 지표와 시각화, 도메인 해석을 함께 사용한다.

---

## 4. 예제

K-means는 중심 거리, 병합 군집은 계층적 결합, DBSCAN은 밀도 연결을 사용하므로 같은 데이터에서도 서로 다른 구조를 찾을 수 있다.

---

## 5. 헷갈리는 개념 비교

|구분|군집화|분류|
|---|---|---|
|정답 레이블|없음|있음|
|목적|숨은 그룹 구조 탐색|정해진 클래스 예측|
