# 데이터 누수

## 1. 개념

데이터 누수(Data Leakage)는 실제 예측 시점에는 알 수 없는 정보가 모델 학습 과정에 들어가는 문제이다. Test 데이터로 전처리 기준이나 모델을 학습하는 것도 누수의 원인이 된다.

> **핵심:** 학습은 Train 데이터로만 수행하고 Test 데이터에는 학습된 변환만 적용한다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
Train 데이터
  ↓ 기준 학습
전처리 기준·모델
  ↓ transform·예측
Test 데이터
```

> **쉽게 말하면:** 시험 문제의 정답을 미리 보고 공부하면 실제 실력을 평가할 수 없는 것과 같다.

------------------------------------------------------------------------

## 3. 사용 방법

- Train 데이터에서 전처리에 필요한 기준을 학습한다.
- Train 데이터로 모델을 학습한다.
- Test 데이터에는 Train에서 만든 기준으로 변환만 수행한다.
- Test 데이터는 최종 평가에 사용한다.

> **핵심:** Test 데이터의 정보를 이용해 학습 기준을 만들지 않는다.

------------------------------------------------------------------------

## 4. 예제

``` text
잘못된 흐름
전체 데이터로 전처리 기준 학습 → Train/Test 분리

올바른 흐름
Train/Test 분리 → Train으로 기준 학습 → Test에는 변환만 적용
```

> **결과 해석:** Test 정보가 학습에 들어가면 평가 점수가 실제보다 좋아질 수 있다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | Train 데이터 | Test 데이터 |
| --- | --- | --- |
| 역할 | 기준과 모델 학습 | 최종 성능 평가 |
| 전처리 | 기준 학습 후 변환 | 학습된 기준으로 변환만 수행 |
| 모델 | 학습에 사용 | 학습에 사용하지 않음 |

------------------------------------------------------------------------

## 6. 주의할 점

- 미래의 알 수 없는 정보가 Feature에 포함되지 않았는지 확인한다.
- Test 데이터로 전처리 기준을 학습하지 않는다.
- Test 데이터가 학습에 섞이면 실제 일반화 성능을 올바르게 평가할 수 없다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `데이터 누수` | 예측 시점에 알 수 없는 정보가 학습에 사용되는 문제 |
| `Train` | 전처리 기준과 모델을 학습하는 데이터 |
| `Test` | 학습된 과정의 성능을 평가하는 데이터 |
| `transform` | Train에서 학습한 기준을 데이터에 적용하는 단계 |

### ⭐ 한 줄 정리

> **Train으로만 학습하고 Test에는 학습된 변환만 적용해야 데이터 누수를 막을 수 있다.**
