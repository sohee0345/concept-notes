# Train과 Test 데이터 분리

## 1. 개념

Train 데이터는 전처리 기준과 모델을 학습하는 데 사용하고, Test 데이터는 학습이 끝난 모델의 성능을 평가하는 데 사용한다.

> **핵심:** 전체 데이터를 먼저 나눈 뒤 Test의 정보를 학습 과정에 사용하지 않는다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
전체 데이터
  ↓ 행 기준 무작위 분리
Train → 기준 결정과 학습
Test  → 최종 평가
```

> **쉽게 말하면:** Train은 공부할 문제이고 Test는 공부가 끝난 뒤 실력을 확인할 시험 문제이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
from sklearn.model_selection import train_test_split

train, test = train_test_split(
    df,
    random_state=42,
    test_size=0.2,
)
```

- `df` → 분리할 전체 DataFrame
- `test_size=0.2` → 전체 행의 20%를 Test로 사용
- `random_state=42` → 같은 분할 결과를 재현하도록 난수 기준 고정

> **핵심:** Test 비율은 데이터 양과 평가에 필요한 표본 수를 고려해 정한다.

------------------------------------------------------------------------

## 4. 예제

``` python
train, test = train_test_split(
    df,
    random_state=42,
    test_size=0.2,
)

train.shape, test.shape
```

실행 결과:

``` text
((712, 12), (179, 12))
```

### 코드 해석

- 전체 891행을 Train 712행과 Test 179행으로 분리
- 컬럼은 나누지 않으므로 두 데이터 모두 12개 컬럼 유지

> **결과 해석:** 행은 8:2에 가깝게 나뉘고 데이터 구조는 유지된다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | Train 데이터 | Test 데이터 |
| --- | --- | --- |
| 역할 | 기준 결정과 모델 학습 | 최종 성능 평가 |
| EDA | 분석 기준으로 사용 | 기준 결정에 사용하지 않음 |
| 전처리 | 기준 학습 | Train에서 정한 기준 적용 |
| 모델 | 학습에 사용 | 예측과 평가에 사용 |

------------------------------------------------------------------------

## 6. 주의할 점

- Test 데이터로 결측치 대체값, 인코딩 기준, Feature 선택 기준을 정하지 않는다.
- Train과 Test의 결측치 개수나 비율은 서로 다를 수 있다.
- `random_state`를 고정하면 개발 중 같은 분할 결과를 재현할 수 있다.

------------------------------------------------------------------------

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `Train` | 전처리 기준과 모델을 학습하는 데이터 |
| `Test` | 학습된 과정의 성능을 평가하는 데이터 |
| `test_size` | Test 데이터의 비율 또는 개수 |
| `random_state` | 무작위 분할 결과를 재현하기 위한 기준값 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `train_test_split()` | 데이터의 행을 Train과 Test로 분리 |
| `train.shape` | Train의 행·열 수 확인 |
| `test.shape` | Test의 행·열 수 확인 |

### ⭐ 한 줄 정리

> **Train은 학습에, Test는 최종 평가에 사용하며 Test 정보는 학습 기준 결정에 포함하지 않는다.**
