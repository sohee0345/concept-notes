# 하이퍼파라미터 탐색

## 1. 개념

하이퍼파라미터 탐색은 학습 전에 정해야 하는 모델 설정의 여러 조합을 시험하여 검증 성능이 좋은 값을 찾는 과정이다. 탐색 중에는 교차검증 성능을 사용하고, test 데이터는 선택이 모두 끝난 뒤 최종 평가에만 사용한다.

---

## 2. 쉽게 이해하기

모델의 설정을 자물쇠 번호처럼 하나씩 맞춰 보는 과정이다. 가능한 조합을 모두 확인할 수도 있고, 일부만 무작위로 시험하거나 이전 결과를 참고해 다음 후보를 똑똑하게 고를 수도 있다.

```text
탐색 공간 정의 → 후보 설정 평가 → 교차검증 점수 비교 → 최적 설정 선택 → test 최종 평가
```

---

## 3. 사용 방법

|방법|탐색 방식|특징|
|---|---|---|
|수동 탐색|사람이 설정을 직접 바꾸며 실험|직관적이지만 범위가 좁고 반복이 어렵다|
|Grid Search|지정한 모든 조합을 평가|작은 탐색 공간에서는 체계적이지만 조합이 늘면 비용이 급증한다|
|Random Search|탐색 공간에서 일부 조합을 무작위 추출|같은 계산 예산으로 더 넓은 범위를 살펴볼 수 있다|
|Bayesian Optimization|이전 실험 결과로 다음 유망 후보를 선택|비싼 실험에서 적은 횟수로 좋은 설정을 찾는 데 유리하다|

Optuna는 Bayesian Optimization 계열의 TPE 샘플러 등을 사용하여 탐색을 수행할 수 있다. 탐색 공간에는 실제 모델이 지원하는 파라미터만 넣고, 범주형·정수형·실수형 범위를 파라미터의 성격에 맞게 정의해야 한다.

---

## 4. 예제

```python
from sklearn.model_selection import GridSearchCV, StratifiedKFold
from sklearn.ensemble import RandomForestClassifier

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
param_grid = {
    "n_estimators": [100, 300],
    "max_depth": [None, 5, 10],
}

search = GridSearchCV(
    RandomForestClassifier(random_state=42),
    param_grid=param_grid,
    scoring="roc_auc",
    cv=cv,
    n_jobs=-1,
)
search.fit(X_train, y_train)

print(search.best_params_)
print(search.best_score_)
```

각 조합은 같은 층화 교차검증으로 평가된다. `best_params_`는 가장 좋은 설정을, `best_score_`는 그 설정의 평균 교차검증 점수를 나타낸다.

---

## 5. 헷갈리는 개념 비교

|구분|Grid Search|Random Search|Bayesian Optimization|
|---|---|---|---|
|다음 후보 선택|미리 정한 모든 조합|무작위 추출|이전 결과를 반영|
|적합한 상황|작고 단순한 탐색 공간|넓은 탐색 공간과 제한된 예산|한 번의 평가 비용이 큰 경우|

성능이 클수록 좋은 지표의 탐색 과정을 그래프로 그릴 때는 현재 값의 누적 최댓값인 `cummax()`를 사용하면 시점별 최고 성능을 확인할 수 있다.
