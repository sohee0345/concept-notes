# 하이퍼파라미터 탐색

## 1. 개념

하이퍼파라미터 탐색은 교차검증 성능을 기준으로 모델의 학습 방식과 구조를 조절하는 설정 조합을 찾는 과정이다. 탐색 대상과 범위, 평가 지표, 계산 예산을 함께 설계해야 한다.

> **핵심:** 하이퍼파라미터는 테스트 점수가 아니라 검증 성능을 기준으로 선택한다.

---

## 2. 탐색 방법

| 방법 | 탐색 방식 | 특징 |
| --- | --- | --- |
| Manual Search | 사람이 조합 선택 | 빠른 초기 탐색에 유용하지만 편향될 수 있음 |
| Grid Search | 모든 지정 조합 평가 | 체계적이지만 조합 수가 빠르게 증가 |
| Random Search | 무작위 조합을 제한된 횟수만큼 평가 | 같은 예산으로 넓은 범위 탐색 가능 |
| Bayesian Optimization | 이전 결과로 다음 유망 지점 선택 | 평가 비용이 큰 문제에서 효율적일 수 있음 |

---

## 3. 사용 방법

```python
from sklearn.model_selection import RandomizedSearchCV

search = RandomizedSearchCV(
    estimator=model,
    param_distributions={
        "max_depth": [3, 5, 7, 9],
        "n_estimators": [100, 300, 500],
        "learning_rate": [0.001, 0.01, 0.1],
    },
    n_iter=20,
    scoring="roc_auc",
    cv=5,
    random_state=42,
)

search.fit(X_train, y_train)
```

- `param_distributions` → 탐색할 값이나 분포
- `n_iter` → 평가할 조합 수
- `scoring` → 최적 조합을 판단할 기준
- `best_params_` → 가장 높은 검증 점수의 설정
- `best_score_` → 최고 평균 교차검증 점수

---

## 4. Optuna

Optuna에서는 Trial이 하이퍼파라미터 후보를 제안하고 목적 함수가 교차검증 점수를 반환한다. 성능을 높이는 문제라면 `direction="maximize"`를 사용한다.

```python
study = optuna.create_study(direction="maximize")
study.optimize(objective, n_trials=50)

print(study.best_value)
print(study.best_params)
```

---

## 5. 주의할 점

- 모델이 실제로 사용하지 않는 파라미터를 탐색 공간에 넣으면 결과 해석과 계산이 왜곡된다.
- 설정을 반복해서 테스트 데이터에 평가하며 범위를 바꾸면 테스트 데이터에 과적합한다.
- 전처리도 각 교차검증 훈련 폴드 안에서 학습되도록 파이프라인을 사용한다.
- 무작위 탐색과 Bayesian Optimization은 `random_state`나 sampler seed를 고정해 재현성을 확보한다.
- ROC-AUC처럼 클수록 좋은 지표의 누적 최고값은 `cummax()`로 계산한다.
