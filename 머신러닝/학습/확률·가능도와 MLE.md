# 확률·가능도와 MLE

## 1. 개념

확률은 분포와 모수가 정해졌을 때 데이터가 관측될 가능성을 계산하고, 가능도는 관측 데이터가 주어졌을 때 어떤 모수가 데이터를 잘 설명하는지 나타낸다. MLE는 가능도를 가장 크게 만드는 모수를 찾는다.

> **핵심:** 확률은 데이터의 가능성을, 가능도는 모수의 그럴듯함을 같은 수식의 다른 관점에서 본다.

---

## 2. 쉽게 이해하기

확률은 주사위가 정해졌을 때 결과를 묻고, 가능도는 결과를 본 뒤 어떤 주사위였는지 묻는다.

```text
관측 데이터 고정 → 모수 비교 → 가능도 최대 모수 선택
```

---

## 3. 사용 방법

$$L(\theta)=\prod_{i=1}^{n}p(x_i\mid\theta)$$

- MLE → 관측 데이터의 가능도를 최대화하는 모수를 찾는다.
- 로그 가능도 → 곱을 합으로 바꿔 계산과 최적화를 쉽게 한다.
- 많은 머신러닝 모델은 가능도를 높이는 방향으로 학습한다.

---

## 4. 예제

로지스틱 회귀는 관측된 클래스가 나타날 가능도를 높이는 계수를 학습한다. 실제 계산에서는 매우 작은 확률의 곱을 피하기 위해 로그 가능도를 사용한다.

---

## 5. 헷갈리는 개념 비교

|구분|확률|가능도|
|---|---|---|
|고정|모수|관측 데이터|
|비교|데이터 결과|모수 후보|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|확률|정해진 모수에서 데이터가 나타날 가능성|
|가능도|관측 데이터를 설명하는 모수의 그럴듯함|
|MLE|가능도를 최대화하는 모수 추정|
|로그 가능도|가능도의 곱을 로그의 합으로 변환|
