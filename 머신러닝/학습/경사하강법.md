# 경사하강법

## 1. 개념

경사하강법은 손실함수의 기울기 반대 방향으로 가중치와 편향을 이동시켜 손실을 줄이는 최적화 방법이다.

> **핵심:** 모델 파라미터는 학습률만큼 기울기 반대 방향으로 반복 갱신된다.

---

## 2. 쉽게 이해하기

산의 기울기를 확인하며 낮은 방향으로 조금씩 내려가 손실이 작은 지점을 찾는 과정이다.

```text
예측 → 손실 계산 → 기울기 계산 → 파라미터 갱신 → 반복
```

---

## 3. 사용 방법

$$
w \leftarrow w-\eta\frac{\partial L}{\partial w},
\qquad b \leftarrow b-\eta\frac{\partial L}{\partial b}
$$

- $w$ → Feature의 영향을 나타내는 가중치이다.
- $b$ → 모든 예측에 더하는 편향이다.
- $L$ → 실제값과 예측값의 차이를 나타내는 손실함수이다.
- $\eta$ → 한 번에 이동할 크기인 학습률이다.

---

## 4. 예제

```python
pred = w * x + b
error = pred - y
loss = np.mean(error ** 2)
w -= learning_rate * 2 * np.mean(error * x)
b -= learning_rate * 2 * np.mean(error)
```

MSE의 기울기를 계산해 가중치와 편향을 갱신한다.

---

## 5. 헷갈리는 개념 비교

|구분|학습률이 작음|학습률이 큼|
|---|---|---|
|영향|학습이 느림|최솟값을 지나치거나 불안정 가능|
