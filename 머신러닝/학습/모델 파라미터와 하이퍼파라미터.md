# 모델 파라미터와 하이퍼파라미터

## 1. 개념

모델 파라미터는 학습 과정에서 데이터로부터 결정되는 값이고 하이퍼파라미터는 학습 전에 사람이 지정하거나 탐색하는 설정값이다.

> **핵심:** 모델이 학습하는 값과 학습 방식을 제어하는 설정을 구분한다.

---

## 2. 쉽게 이해하기

파라미터는 공부하며 얻은 지식이고 하이퍼파라미터는 공부 횟수나 방법처럼 학습 전에 정하는 계획이다.

```text
하이퍼파라미터 설정 → 모델 학습 → 모델 파라미터 결정
```

---

## 3. 사용 방법

```python
model = LogisticRegression(random_state=42)
model.fit(x_train, y_train)
```

- `random_state` 같은 생성자 설정은 하이퍼파라미터이다.
- `fit()`이 데이터에서 결정하는 계수는 모델 파라미터이다.
- 하이퍼파라미터는 train 내부 검증으로 비교한다.

---

## 4. 예제

최대 반복 횟수에 도달했다는 수렴 경고가 발생하면 평가 점수만 보지 말고 학습 설정과 데이터 처리를 함께 확인한다.

---

## 5. 헷갈리는 개념 비교

|구분|모델 파라미터|하이퍼파라미터|
|---|---|---|
|결정|학습 데이터에서 학습|학습 전 지정·탐색|
|예시|모델 계수|랜덤 시드·반복 횟수|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|모델 파라미터|데이터로부터 학습되는 값|
|하이퍼파라미터|학습 전에 정하는 설정|
|수렴|학습 과정이 안정된 해에 도달하는 상태|

### 💻 주요 코드

|코드|의미|
|---|---|
|`Model(option=value)`|하이퍼파라미터 설정|
|`model.fit(X, y)`|모델 파라미터 학습|

### ⭐ 한 줄 정리

> **하이퍼파라미터는 학습 방식을 정하고 모델 파라미터는 데이터 학습으로 결정된다.**
