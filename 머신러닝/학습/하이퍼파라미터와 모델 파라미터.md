# 하이퍼파라미터와 모델 파라미터

## 1. 개념

하이퍼파라미터는 학습 전에 사람이 설정하거나 탐색하는 값이고, 모델 파라미터는 학습 과정에서 데이터로부터 결정되는 값이다.

> **핵심:** 하이퍼파라미터는 학습 방식을 정하고 모델 파라미터는 학습 결과로 얻어진다.

------------------------------------------------------------------------

## 2. 비교

| 구분 | 결정 시점 | 결정 방법 |
| --- | --- | --- |
| 하이퍼파라미터 | 학습 전 | 사람이 설정·탐색 |
| 모델 파라미터 | 학습 중 | 데이터와 학습 알고리즘으로 결정 |

```python
model = LogisticRegression(random_state=42)
model.fit(x_train, y_train)
```

`random_state`는 하이퍼파라미터이고 학습된 계수는 모델 파라미터이다.
