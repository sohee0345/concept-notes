# 과적합·과소적합·일반화

## 1. 개념

과적합은 train에 지나치게 맞고 새 데이터 성능이 낮은 상태이며, 과소적합은 모델이 너무 단순해 train의 패턴도 충분히 학습하지 못한 상태이다. 일반화는 학습하지 않은 데이터에서도 성능을 유지하는 능력이다.

> **핵심:** 하이퍼파라미터 튜닝은 train 점수를 최대로 만드는 것이 아니라 일반화 성능을 찾는 과정이다.

------------------------------------------------------------------------

## 2. 규제와 관계

- 규제가 너무 약함 → 과적합 위험 증가
- 규제가 적절함 → 일반화 성능 향상 가능
- 규제가 너무 강함 → 과소적합 위험 증가
