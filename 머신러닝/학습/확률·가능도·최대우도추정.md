# 확률·가능도·최대우도추정

## 1. 개념

확률은 모수가 정해진 분포에서 데이터가 나타날 가능성을 계산하고, 가능도는 관측된 데이터를 가장 잘 설명하는 모수를 비교한다. 최대우도추정(MLE)은 가능도를 가장 크게 만드는 모수를 선택하는 학습 원리다.

> **핵심:** 확률은 분포에서 데이터를 바라보고, 가능도는 데이터에서 모수를 바라본다.

---

## 2. 쉽게 이해하기

동전을 여러 번 던져 앞면과 뒷면을 관측했다고 하자. 앞면 확률 $p$가 정해져 있을 때 특정 결과가 나올 확률을 계산하는 것은 확률의 관점이다. 이미 결과를 관측한 뒤 어떤 $p$가 그 결과를 가장 그럴듯하게 만드는지 비교하는 것은 가능도의 관점이다.

독립 관측값의 가능도는 각 관측 확률의 곱이다.

$$L(\theta)=\prod_{i=1}^{n}p(x_i\mid\theta)$$

실제 최적화에서는 로그 가능도를 사용해 곱을 합으로 바꾼다.

$$\log L(\theta)=\sum_{i=1}^{n}\log p(x_i\mid\theta)$$

---

## 3. 예제

앞면 8번, 뒷면 2번을 관측했다면 베르누이 분포의 MLE는 $\hat p=8/10=0.8$이다. 즉, 관측 결과를 가장 그럴듯하게 만드는 앞면 확률은 0.8이다.

## 🟦 핵심 정리

### 🔑 주요 개념

| 개념 | 설명 |
| --- | --- |
| 확률 | 모수를 고정하고 데이터의 발생 가능성을 계산 |
| 가능도 | 데이터를 고정하고 모수의 그럴듯함을 비교 |
| MLE | 가능도 또는 로그 가능도를 최대화하는 모수 선택 |

### 🎯 한 줄 정리

> 최대우도추정은 관측 데이터를 가장 잘 설명하는 모델 파라미터를 찾는 방법이다.
