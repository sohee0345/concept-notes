# 경사하강법과 학습률

## 1. 개념

경사하강법(Gradient Descent)은 손실함수의 값을 줄이는 방향으로 모델 파라미터를 반복해서 갱신하는 학습 방법이다. 학습률은 한 번에 이동하는 크기를 정한다.

> **핵심:** Gradient의 반대 방향으로 가중치와 편향을 조금씩 이동해 손실을 줄인다.

------------------------------------------------------------------------

## 2. 쉽게 이해하기

``` text
현재 위치에서 경사 확인
  ↓
내리막 방향 선택
  ↓
학습률만큼 이동
  ↓
최솟값에 가까워질 때까지 반복
```

> **쉽게 말하면:** 안개 낀 산에서 발밑의 기울기를 확인하며 낮은 곳으로 조금씩 내려가는 과정이다.

------------------------------------------------------------------------

## 3. 사용 방법

``` python
y_pred = W * X + b

w_grad = learning_rate * ((y_pred - Y) * X).mean()
b_grad = learning_rate * (y_pred - Y).mean()

W = W - w_grad
b = b - b_grad
```

- `y_pred` → 현재 파라미터로 계산한 예측값
- `w_grad`, `b_grad` → 가중치와 편향의 갱신량
- `learning_rate` → 한 번에 움직이는 크기

> **핵심:** 파라미터에서 Gradient 방향의 값을 빼 손실이 감소하는 쪽으로 이동한다.

------------------------------------------------------------------------

## 4. 예제

``` python
W = np.random.uniform(-1, 1)
b = np.random.uniform(-1, 1)
learning_rate = 0.7

for epoch in range(200):
    y_pred = W * X + b
    error = np.abs(y_pred - Y).mean()

    if error < 0.001:
        break

    W -= learning_rate * ((y_pred - Y) * X).mean()
    b -= learning_rate * (y_pred - Y).mean()
```

### 코드 해석

- 가중치와 편향을 임의의 값으로 초기화
- 예측과 오차를 계산
- 오차가 충분히 작지 않으면 파라미터 갱신
- 최대 200번의 Epoch 동안 반복

> **결과 해석:** 반복이 진행되면 예측 직선이 실제 데이터의 관계에 가까워진다.

------------------------------------------------------------------------

## 5. 헷갈리는 개념 비교

| 구분 | 모델 파라미터 | 학습률 |
| --- | --- | --- |
| 예 | $W$, $b$ | `learning_rate` |
| 역할 | 예측값 결정 | 파라미터 갱신 크기 결정 |
| 결정 | 학습 과정에서 갱신 | 학습 전에 설정 |

------------------------------------------------------------------------

## 6. 주의할 점

- 학습률이 너무 작으면 학습 시간이 오래 걸릴 수 있다.
- 학습률이 너무 크면 최솟값을 지나쳐 학습이 불안정할 수 있다.
- `epoch`는 반복 단계이며 데이터 행 개수와 같은 뜻이 아니다.
