# 과적합과 규제

## 1. 개념

일반화는 학습하지 않은 데이터에서도 성능을 유지하는 능력이다. 과적합은 train에는 잘 맞지만 새 데이터 성능이 낮고, 과소적합은 train의 규칙도 충분히 배우지 못한 상태이다. 규제는 모델 복잡도를 조절한다.

> **핵심:** 규제 강도는 점수를 무조건 높이는 값이 아니라 과적합과 과소적합 사이의 균형을 조절한다.

---

## 2. 쉽게 이해하기

훈련 문제를 외워 버린 모델을 단순하게 만들어 새로운 문제에서도 적용되도록 하는 과정이다.

```text
규제 약함 → 복잡함·과적합 위험
규제 적절 → 일반화 개선
규제 강함 → 단순함·과소적합 위험
```

---

## 3. 사용 방법

- L1 → 절댓값 패널티로 일부 계수를 0으로 만들 수 있다.
- L2 → 제곱 패널티로 큰 계수를 줄인다.
- ElasticNet → L1과 L2를 함께 사용한다.
- `alpha` → 규제 강도이다.
- `l1_ratio` → L1과 L2의 혼합 비율이다.

---

## 4. 예제

```python
ridge = Ridge(alpha=0.1).fit(x_train, y_train)
lasso = Lasso(alpha=0.01).fit(x_train, y_train)
elastic = ElasticNet(alpha=0.01, l1_ratio=0.8).fit(x_train, y_train)
```

모델 복잡도와 규제 강도는 test가 아니라 검증 데이터나 교차검증 오차로 선택한다. 다항회귀에서는 차수가 커질수록 train 오차는 계속 낮아질 수 있으므로 검증 오차가 가장 낮은 차수를 선택한다.

---

## 5. 헷갈리는 개념 비교

|구분|과소적합|적절한 적합|과적합|
|---|---|---|---|
|복잡도|너무 낮음|적절함|너무 높음|
|성능|train·검증 모두 낮음|검증 성능 좋음|train 높고 검증 낮음|

## 🟦 핵심 정리

### 💡 주요 개념

|개념|의미|
|---|---|
|과적합|train에만 지나치게 잘 맞는 상태|
|과소적합|모델이 지나치게 단순한 상태|
|일반화|새 데이터에서도 성능을 유지하는 능력|
|규제|계수 크기를 제한해 복잡도 조절|

### 💻 주요 코드

|코드|의미|
|---|---|
|`Ridge(alpha=...)`|L2 규제|
|`Lasso(alpha=...)`|L1 규제|
|`ElasticNet(...)`|L1·L2 혼합 규제|

### ⭐ 한 줄 정리

> **규제는 계수 크기를 제한해 과적합과 과소적합 사이의 일반화 성능을 조절한다.**
